# Задание 5.2: Promise.allSettled — ждём всех

## Цель

Реализовать визуализацию `Promise.allSettled`, которая наглядно демонстрирует ключевое отличие от `Promise.all`: все промисы дожидаются завершения независимо от наличия ошибок, а результат — всегда массив объектов со статусом каждого.

## Требования

1. **Пять загрузок** (аналогично заданию 5.1): прогресс-бары, переключатели сбоев по умолчанию Beta и Epsilon включены как СБОЙ
2. **Поведение allSettled**:
   - Все загрузки дожидаются 100% прогресса — никто не прерывается
   - Красный прогресс-бар у упавших — но остальные продолжают до конца
   - После завершения последнего — собирается итог
3. **Таблица результатов** с тремя колонками: «Источник», «status», «value / reason»:
   - `fulfilled` строки — зелёный цвет и значение
   - `rejected` строки — красный цвет и причина ошибки
   - Таблица появляется только после завершения всех промисов
4. **Сравнение с Promise.all**: после показа таблицы — блок с объяснением:
   - Если были сбои: «Если бы это был Promise.all — он упал бы на шаге N (Name)...»
   - Если сбоев нет: «В этом случае Promise.all дал бы тот же результат»
5. **Сниппет кода** с паттерном обхода результатов через `forEach`

## Чеклист

- [ ] Компонент называется `Task5_2` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован, заголовок из `t('task.5.2')`
- [ ] Все 5 промисов дожидаются завершения (даже при наличии СБОЙ)
- [ ] Таблица появляется только когда все загрузки завершились
- [ ] Fulfilled строки — зелёные, rejected — красные
- [ ] Есть блок сравнения с `Promise.all`
- [ ] При изменении переключателей сбоев — блок сравнения меняется
- [ ] Кнопка «Сброс» очищает всё
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. По умолчанию Beta и Epsilon — СБОЙ. Нажмите «Запустить» — убедитесь что все 5 загрузок доходят до 100% (не обрывается на первом сбое)
2. Дождитесь таблицы — 3 строки fulfilled (зелёные), 2 строки rejected (красные)
3. Прочитайте блок сравнения — должно быть указано что Promise.all упал бы на шаге Beta (первый по скорости из упавших)
4. Переключите все в OK, перезапустите — таблица 5 зелёных строк, сравнение другое
5. Переключите всех в СБОЙ — таблица 5 красных строк
