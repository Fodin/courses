# Задание 3.3 — Угадай статус-код

## Цель

Закрепить знание статус-кодов через практические сценарии. Уметь выбирать правильный код для конкретной ситуации и объяснить, почему другие варианты не подходят.

## Требования

1. Компонент показывает 10 сценариев из реальных ситуаций API.
2. Для каждого сценария — 3 варианта ответа (один правильный, два неправильных).
3. После выбора — сразу показывается объяснение правильного ответа.
4. Для неправильных вариантов — пояснение, почему они не подходят.
5. Индикатор прогресса показывает счёт (правильные / всего).

## Чеклист

- [ ] 10 сценариев
- [ ] Навигация между сценариями (вперёд/назад)
- [ ] Индикатор номера сценария и общего счёта
- [ ] Объяснение после каждого ответа
- [ ] Пояснение для неправильных вариантов
- [ ] Кнопка сброса для повторного прохождения

## Как проверить себя

Пройдите все 10 сценариев без подсказок. Если набрали 8+ из 10 — отлично. Если меньше — вернитесь к теории по ошибочным сценариям. Особое внимание: 401 vs 403, 400 vs 422, 409 vs 422, 500 vs 502 vs 504.
