# Задание 15.1: Semantic Versioning и git tags

## Цель

Создать интерактивный симулятор версионирования: показать, как тип коммита влияет на версию, и визуализировать, какой CI/CD пайплайн запускается при создании тега.

## Требования

1. Отобразить текущую версию в формате `vMAJOR.MINOR.PATCH` — крупно, по центру панели
2. Реализовать три кнопки типов коммитов: `feat!` (MAJOR), `feat` (MINOR), `fix` (PATCH) — каждая увеличивает соответствующий компонент версии
3. При нажатии на кнопку анимированно обновить версию (хотя бы сменить цвет на секунду) и добавить коммит в лог
4. Показать блок "Создать тег" — кнопка, которая "создаёт" git tag с текущей версией
5. После создания тега показать, какой пайплайн запустится: build → release, с отображением `CI_COMMIT_TAG`
6. Вывести сгенерированный YAML-конфиг с `rules` для тег-триггера, содержащий актуальную версию

## Чеклист

- [ ] Текущая версия отображается крупно в формате vX.Y.Z
- [ ] Кнопки feat!, feat, fix корректно изменяют соответствующий компонент версии
- [ ] При MAJOR-bump обнуляются MINOR и PATCH (1.2.3 → 2.0.0)
- [ ] При MINOR-bump обнуляется PATCH (1.2.3 → 1.3.0)
- [ ] Лог коммитов отображает добавленные "коммиты" с типом и описанием
- [ ] Кнопка "Создать тег" становится активной только после хотя бы одного коммита
- [ ] После создания тега отображается результат: CI_COMMIT_TAG и triggered pipeline
- [ ] YAML-конфиг обновляется с актуальным значением тега

## Как проверить себя

1. Начни с версии 0.1.0 — нажми `fix`, получи 0.1.1
2. Нажми `feat` — получи 0.2.0 (PATCH сброшен)
3. Нажми `feat!` — получи 1.0.0 (MINOR и PATCH сброшены)
4. Нажми "Создать тег" — появится панель с CI_COMMIT_TAG = v1.0.0 и пайплайном
5. Нажми снова `fix` — версия стала 1.0.1, создай ещё один тег — CI_COMMIT_TAG обновится

## Подсказки

- Используй `useState` для `{ major, minor, patch }` и `logs: string[]`
- При MAJOR-bump: `{ major: m+1, minor: 0, patch: 0 }`
- При MINOR-bump: `{ major: m, minor: n+1, patch: 0 }`
- YAML можно строить через template literal, подставляя `v${major}.${minor}.${patch}`
- Для визуальной анимации — можно временно изменить цвет версии через `setTimeout` и дополнительный `useState`
