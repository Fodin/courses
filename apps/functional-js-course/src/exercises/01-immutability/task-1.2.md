# Задание 1.2: Глубокое клонирование

## Цель

Изучить три стратегии клонирования объекта с вложенной структурой и полем `Date`.
Выявить ограничения каждого подхода на практике.

## Требования

1. Создайте объект `original` следующей структуры:
   ```ts
   {
     user: {
       name: 'Bob',
       settings: {
         theme: 'dark',
         notifications: { email: true, sms: false }
       },
       createdAt: new Date('2024-01-01')
     }
   }
   ```
2. Реализуйте три независимые колонки, каждая со своей копией оригинала:
   - **Shallow copy**: `{ ...obj }` (spread только верхнего уровня)
   - **JSON clone**: `JSON.parse(JSON.stringify(obj))`
   - **structuredClone**: `structuredClone(obj)`
3. В каждой колонке — кнопка "Клонировать и модифицировать":
   - Клонируем объект выбранным способом
   - Меняем `clone.user.settings.theme = 'light'` в копии
4. Показываем результат:
   - Значение `theme` в оригинале после клонирования (изменился ли?)
   - Тип поля `createdAt` в клоне (`Date` или `string`)
5. Для Shallow copy — красная подсветка проблемы (оригинал изменился).
6. Для JSON clone — красная подсветка потери типа Date.
7. Для structuredClone — зелёная подсветка корректности.

## Чеклист

- [ ] Каждая колонка использует свою независимую копию оригинала
- [ ] Shallow copy показывает что `orig.user.settings.theme` изменился
- [ ] JSON clone показывает что `typeof createdAt === 'string'`
- [ ] structuredClone показывает что оригинал не тронут и `Date` сохранён
- [ ] Проблемы подсвечены красным, успех — зелёным
- [ ] Код каждого подхода виден в блоке `<pre>`

## Как проверить себя

Нажмите "Клонировать и модифицировать" в колонке Shallow:
оригинальный `theme` должен стать `'light'` — потому что `user` — общая ссылка.

Нажмите в колонке JSON: тема в оригинале не изменится (глубокая копия),
но `createdAt` в клоне будет строкой, а не `Date`.

Нажмите в колонке structuredClone: тема в оригинале не изменится,
`createdAt` останется объектом типа `Date`.

Подсказка: чтобы показать тип, используйте `instanceof Date` или `typeof`.
