# Задание 14.2 — Распутать модульный граф: третий модуль (среднее)

## Цель

На графе из 5 модулей найти цикл между двумя равноправными модулями и разорвать его приёмом «третий модуль».

## Что дано

- `constants.ts` — константа `CURRENCY_SYMBOL` (🔒 только чтение).
- `format.ts` — пустая заготовка будущего третьего модуля.
- `discount.ts` — считает скидку, вызывает `formatCurrency` из `tax.ts`.
- `tax.ts` — считает налог, содержит `formatCurrency`, а заодно импортирует `discountRate` из `discount.ts` — цикл.
- `cart.ts` — потребляет `discount.ts` и `tax.ts`, в цикле не участвует (🔒 только чтение).

## Требования

1. Определите диагноз: `discount.ts` и `tax.ts` — равноправные модули одного уровня, которые взаимно зависят друг от друга по рантайму из-за общей логики форматирования.
2. Перенесите `formatCurrency` в `format.ts` (третий модуль).
3. В `discount.ts` замените импорт `formatCurrency` с `./tax` на `./format`.
4. В `tax.ts` удалите объявление `formatCurrency` — этот модуль больше не должен его содержать (используйте только `discountRate` из `discount.ts`, направление зависимости одностороннее).
5. Нажмите «Проверить».

## Чеклист

- [ ] `formatCurrency` вынесен в `format.ts`
- [ ] `discount.ts` берёт `formatCurrency` из `./format`
- [ ] `tax.ts` больше не содержит `formatCurrency`
- [ ] Проверка `noRuntimeCycles()` — зелёная
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

После правки граф должен стать линейной цепочкой без обратных рёбер: `tax.ts` → `discount.ts` (за `discountRate`) и `discount.ts` → `format.ts` (за `formatCurrency`). Ребра `discount.ts` → `tax.ts` и `tax.ts` → `format.ts` быть не должно.
