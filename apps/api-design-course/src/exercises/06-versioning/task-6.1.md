# Задание 6.1: Сравнение стратегий версионирования

## Цель

Реализовать интерактивный компонент, который наглядно демонстрирует три стратегии версионирования
API: URL versioning, Header versioning и Query param versioning.

## Требования

1. Создать переключатель из трёх вкладок — по одной на каждую стратегию
2. Для каждой стратегии показать реальный HTTP-запрос в стиле кодового блока
3. Реализовать аккордеон с тремя секциями: "Преимущества", "Недостатки", "Кто использует"
4. Каждый аккордеон открывается/закрывается по клику на заголовок
5. Активная вкладка и активная секция подсвечиваются цветом стратегии
6. Добавить подсказку с советом по выбору стратегии

## Чеклист

- [ ] Три кнопки-вкладки с кодом стратегии в подписи
- [ ] Кодовый блок с примером HTTP-запроса (тёмный фон, моноширинный шрифт)
- [ ] Секция "Преимущества" с минимум 3 пунктами
- [ ] Секция "Недостатки" с минимум 2 пунктами
- [ ] Секция "Кто использует" с реальными компаниями (GitHub, Stripe, AWS)
- [ ] Переключение вкладок сбрасывает/сохраняет открытый аккордеон
- [ ] Блок-подсказка внизу с советом

## Как проверить себя

Откройте компонент и проверьте:
- Нажмите на каждую вкладку — запрос меняется
- Раскройте секцию "Кто использует" у URL versioning — должны быть GitHub и Twitter
- Раскройте "Недостатки" у Header versioning — должно быть про сложность кеширования
- Цвет вкладки и рамки карточки совпадают (синий, фиолетовый, зелёный)
