# Задание 1.3: Стратегия масштабирования

## Цель

Для e-commerce системы определить, какие компоненты stateless/stateful, и выбрать стратегию масштабирования для каждого.

## Требования

1. Проанализируйте компоненты e-commerce системы:
   - **User Sessions** — хранение корзины, авторизации
   - **Product Catalog** — каталог товаров (чтение)
   - **Search Service** — полнотекстовый поиск товаров
   - **Order Processing** — создание и обработка заказов
   - **Notification Service** — отправка email/push уведомлений
2. Для каждого компонента определите:
   - **Тип**: stateless или stateful
   - **Стратегия масштабирования**: Scale Up, Scale Out (X-axis), функциональная декомпозиция (Y-axis), шардинг (Z-axis)
   - **Где хранить состояние** (если stateful): Redis, БД, очередь сообщений
3. Обоснуйте каждое решение

## Чеклист

- [ ] Для каждого из 5 компонентов определён тип (stateless/stateful)
- [ ] Для каждого выбрана стратегия масштабирования
- [ ] Указано, где выносить состояние для stateful-компонентов
- [ ] Обоснования учитывают характер нагрузки (read-heavy, write-heavy, CPU-heavy)
- [ ] Ответы совпадают с решением или обоснованно отличаются

## Как проверить себя

1. Откройте задание и для каждого компонента выберите параметры
2. Сравните свои ответы с решением
3. Подумайте: как изменится стратегия, если нагрузка вырастет в 100 раз?
4. Проверьте, не остались ли «скрытые» состояния, которые вы не учли
