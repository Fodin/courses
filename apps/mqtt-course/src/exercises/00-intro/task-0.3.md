# Задание 0.3: MQTT vs HTTP vs WebSocket vs AMQP

## Цель

Систематизировать знания о различиях между протоколами и закрепить понимание того, почему MQTT оптимален для IoT. Реализовать интерактивную сравнительную таблицу с детальным описанием каждого протокола.

---

## Требования

1. Определи интерфейс `Protocol` с полями: `name`, `shortName`, `color`, `bgColor`, `pattern`, `overhead`, `persistent`, `qos`, `broker`, `bidirectional`, `iot` (`'excellent' | 'good' | 'fair' | 'poor'`), `useCases: string[]`, `pros: string[]`, `cons: string[]`

2. Создай массив `protocols` из 4 протоколов: MQTT v5, HTTP/REST, WebSocket, AMQP 1.0. Данные должны быть технически точными.

3. Реализуй два режима отображения (переключатель):
   - **Таблица сравнения**: горизонтальная таблица, строки — критерии, столбцы — протоколы. Строка "Пригодность для IoT" с визуальным рейтингом (звёзды или цветные индикаторы)
   - **Детальный вид**: выбор протокола кнопками, отображение плюсов, минусов и типичных сценариев применения

4. В таблице минимум 6 строк критериев: паттерн взаимодействия, overhead заголовков, persistent соединение, гарантия доставки, нужен ли брокер, двунаправленность

5. В детальном виде для выбранного протокола показывать: плюсы со значком ✅, минусы с ❌, use cases в виде тегов

---

## Чеклист

- [ ] Определён интерфейс `Protocol` со всеми перечисленными полями
- [ ] Массив из 4 протоколов с технически точными данными
- [ ] Переключатель между режимами "Таблица" и "Детали"
- [ ] В таблице минимум 6 строк критериев
- [ ] Цветовое выделение заголовков столбцов (каждый протокол — свой цвет)
- [ ] Строка "IoT-пригодность" с визуальным рейтингом
- [ ] В детальном виде: плюсы, минусы, use cases
- [ ] Кнопки выбора протокола в детальном виде
- [ ] Корректная типизация (тип `IoT` ограничен 4 значениями)

---

## Как проверить себя

1. Видишь переключатель между режимами?
2. В режиме таблицы — 4 столбца протоколов с цветовым выделением?
3. Строка "IoT-пригодность" — у MQTT высший рейтинг, у AMQP низкий?
4. Переключись на "Детали" — кнопки выбора протокола работают?
5. Выбери HTTP — видишь его плюсы и минусы?
6. Выбери MQTT — use cases включают IoT и умный дом?
