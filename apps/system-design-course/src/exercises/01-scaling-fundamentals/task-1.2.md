# Задание 1.2: Планировщик масштабирования

## Цель

Построить интерактивный калькулятор, который рассчитывает количество серверов и сравнивает стоимость вертикального и горизонтального масштабирования для заданной нагрузки.

## Требования

1. Создайте компонент с полями ввода параметров нагрузки:
   - **Target RPS** — целевое количество запросов в секунду
   - **CPU per request** — процент CPU на один запрос
   - **RAM per request** — МБ RAM на один запрос
   - **Base server cost** — стоимость стандартного сервера ($/мес)
2. Рассчитайте, сколько стандартных серверов нужно для горизонтального масштабирования
3. Рассчитайте стоимость эквивалентного вертикального масштабирования (с коэффициентом экспоненциального роста)
4. Визуализируйте сравнение стоимостей: горизонтальная bar-диаграмма для обоих вариантов
5. Покажите точку, в которой горизонтальное масштабирование становится выгоднее вертикального
6. Добавьте пресеты нагрузки: «Стартап», «Средний бизнес», «Highload»

## Чеклист

- [ ] Есть поля ввода для RPS, CPU/request, RAM/request, стоимости сервера
- [ ] Рассчитывается количество серверов для горизонтального масштабирования
- [ ] Стоимость вертикального масштабирования растёт экспоненциально
- [ ] Визуализировано сравнение стоимости двух подходов
- [ ] Есть минимум 3 пресета с реалистичными параметрами
- [ ] Компонент использует `useState` для управления состоянием

## Как проверить себя

1. Откройте задание в браузере
2. Переключитесь между пресетами — параметры должны обновляться
3. Измените RPS — количество серверов и стоимость должны пересчитаться
4. Убедитесь, что при малой нагрузке вертикальное дешевле, а при большой — горизонтальное
5. Проверьте граничные случаи: 0 RPS, очень высокий RPS
