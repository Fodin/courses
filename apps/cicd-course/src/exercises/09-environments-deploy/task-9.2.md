# Задание 9.2: Стратегии деплоя — Rolling, Blue-Green, Canary

## Цель

Создать интерактивный симулятор трёх стратегий деплоя. Пользователь выбирает стратегию и запускает анимированную пошаговую визуализацию процесса обновления инстансов.

## Требования

1. Три вкладки или кнопки для выбора стратегии: `Rolling`, `Blue-Green`, `Canary`
2. Отобразить 4 сервера/инстанса в виде блоков (для каждой стратегии своя логика)
3. Кнопка "Запустить деплой" — запускает пошаговую анимацию обновления
4. Для **Rolling**: блоки обновляются по одному (v1 → v2), текущий обновляемый подсвечивается
5. Для **Blue-Green**: 4 blue-блока (v1) + 4 green-блока (v2), load balancer переключается от blue к green целиком
6. Для **Canary**: 4 блока, 1 становится canary (v2), остальные 3 остаются v1; кнопка "Promote" переводит все в v2
7. Показывать YAML-конфигурацию GitLab CI для выбранной стратегии
8. Показывать характеристики стратегии: Downtime, Rollback speed, Resource cost

## Чеклист

- [ ] Переключение между тремя стратегиями без потери состояния других вкладок
- [ ] Блоки серверов с визуальным отличием версий (v1 — синий, v2 — зелёный, canary — жёлтый)
- [ ] Кнопка "Запустить деплой" — последовательно обновляет блоки (можно без setTimeout, через шаги по клику)
- [ ] Для Blue-Green: отдельная кнопка переключения трафика на Green
- [ ] Для Canary: отдельная кнопка Promote для полного выката
- [ ] YAML-блок с конфигом выбранной стратегии (моноширинный шрифт, тёмный фон)
- [ ] Таблица или плашки с характеристиками: Downtime / Rollback speed / Resource cost
- [ ] Кнопка "Сбросить" для возврата в исходное состояние

## Как проверить себя

1. Выбери Rolling, нажми "Запустить деплой" — блоки должны обновляться последовательно
2. Выбери Blue-Green — должны отображаться 2 группы (blue/green), переключение трафика происходит кнопкой
3. Выбери Canary — 1 из 4 становится canary, Promote переводит все в v2
4. Проверь, что YAML меняется при смене стратегии
5. Кнопка "Сбросить" возвращает все блоки в v1

## Подсказки

- Для пошаговой анимации без таймера: храни `step` (число), каждый клик на Deploy увеличивает шаг на 1
- Rolling: `blocks.map((b, i) => i <= step ? 'v2' : 'v1')`
- Blue-Green: `trafficOnGreen` (boolean) — меняется при нажатии кнопки переключения
- Canary: `promoted` (boolean) — если true, все блоки v2, иначе блок 0 — canary
- Для YAML используй объект `{rolling: '...yaml...', bluegreen: '...yaml...', canary: '...yaml...'}`
