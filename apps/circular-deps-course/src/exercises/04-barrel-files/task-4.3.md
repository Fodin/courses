# Задание 4.3 — Большой barrel: чиним только внутренние импорты (сложное)

## Цель

Научиться отличать легитимный внешний импорт через barrel от внутренних импортов, которые надо исправить, и не сломать публичный API пакета в процессе.

## Что дано

- `src/pkg/index.ts` — barrel пакета `pkg`, реэкспортирует `aValue`, `bValue`, `cValue` (только для чтения).
- `src/pkg/a.ts` — берёт `bValue` через `./index` вместо `./b`.
- `src/pkg/b.ts` — уже импортирует правильно (ни от кого не зависит), трогать не нужно (только для чтения).
- `src/pkg/c.ts` — та же ошибка, что и в `a.ts`: берёт `bValue` через `./index`.
- `src/consumer.ts` — внешний потребитель ВНЕ пакета `pkg`, легитимно импортирует `aValue` и `cValue` из `'./pkg'` (только для чтения) — это и есть правильное назначение barrel.

Из-за ошибок в `a.ts` и `c.ts` возникают циклы `a → index → a` и `c → index → c`.

## Требования

1. В `pkg/a.ts` замени импорт `bValue` на прямой путь `./b`.
2. В `pkg/c.ts` сделай то же самое.
3. Не трогай `pkg/index.ts`, `pkg/b.ts` и `consumer.ts` — публичный API пакета и внешний потребитель должны остаться рабочими как есть.
4. После правок в графе зависимостей не должно быть циклов.

## Чеклист

- [ ] `pkg/a.ts` импортирует `bValue` из `'./b'`
- [ ] `pkg/c.ts` импортирует `bValue` из `'./b'`
- [ ] `pkg/index.ts`, `pkg/b.ts` и `consumer.ts` не изменены
- [ ] Циклов в графе не осталось
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

Убедись, что `consumer.ts` по-прежнему импортирует из `'./pkg'` без изменений — это правильно, и трогать этот файл не нужно. Все проверки в лаборатории должны стать зелёными после правки только двух файлов — `a.ts` и `c.ts`.
