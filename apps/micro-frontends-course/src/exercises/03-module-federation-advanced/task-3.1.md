# Задание 3.1 — Симулятор версионных конфликтов shared

## Цель

Создать интерактивный симулятор, который объясняет, как Module Federation разрешает конфликты версий shared-зависимостей в зависимости от настроек singleton, strictVersion и requiredVersion.

## Требования

1. Две панели конфигурации — Host и Remote — с полями:
   - version (текущая версия библиотеки, например `18.2.0`)
   - requiredVersion (semver-диапазон, например `^18.0.0`)
   - singleton (чекбокс)
   - strictVersion (чекбокс)

2. Кнопка "Проверить совместимость" запускает анализ и показывает:
   - Какая версия будет загружена (resolved version)
   - Будет ли дублирование (оба MFE загрузят свою копию)
   - Будет ли ошибка (strictVersion + несовместимые версии)
   - Статусный индикатор: зелёный (ok), жёлтый (warning), красный (error)

3. Визуальное дерево зависимостей:
   - Строки: host → react@X, remote → react@Y, resolved → react@Z
   - Цвет строки resolved соответствует статусу (зелёный/жёлтый/красный)

4. Минимум 4 пресета сценариев:
   - "Всё совместимо" — идеальный случай
   - "Minor mismatch" — версии отличаются, но в диапазоне
   - "Major conflict" — несовместимые major-версии, strictVersion включён
   - "Дублирование" — singleton выключен

5. Логика разрешения версий:
   - Если `singleton: false` у обоих — дублирование
   - Если `strictVersion: true` и версия не в диапазоне — ошибка
   - Если версии в одном semver-диапазоне — warning с описанием
   - Если версии совпадают — ok

## Checklist

- [ ] Обе панели конфигурации с четырьмя полями
- [ ] Кнопка запускает проверку и показывает результат
- [ ] Три статуса: ok / warning / error с цветовой индикацией
- [ ] Дерево зависимостей (host → remote → resolved)
- [ ] Все 4 пресета применяются корректно и дают ожидаемый результат
- [ ] При ручном редактировании полей результат сбрасывается

## Как проверить себя

- Пресет "Major conflict" должен давать статус error
- Пресет "Дублирование" должен давать warning с сообщением про два экземпляра
- Пресет "Minor mismatch" должен давать warning с resolved-версией (более новой)
- При включении strictVersion + несовместимые версии → ошибка
- При включении strictVersion + совместимые версии → ошибки нет

## Подсказка

Разберитесь, как работает semver-диапазон `^X.Y.Z`: он допускает любые X.y.z, где y >= Y или (y === Y и z >= Z), при условии X совпадает. Для X=0 правила строже — только minor совпадает.
