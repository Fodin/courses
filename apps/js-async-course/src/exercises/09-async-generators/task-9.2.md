# Задание 9.2: Pipeline из async-генераторов

## Цель

Реализовать трёхзвенный конвейер из async-генераторов: source → filter → map. Визуализировать прохождение каждого элемента через этапы, показав как генераторы компонуются без создания промежуточных массивов.

## Требования

1. **Генератор `source(count, delayMs)`** — генерирует числа от 1 до `count` с задержкой `delayMs` между каждым

2. **Генератор `filterEven(upstream)`** — принимает AsyncGenerator, пропускает только чётные числа через `for await...of`

3. **Генератор `mapDouble(upstream)`** — принимает AsyncGenerator, удваивает каждое значение

4. **Компоновка** — `const pipeline = mapDouble(filterEven(source(20, 400)))` — вложенный вызов без вспомогательных массивов

5. **Визуализация потока** — каждый элемент отображается цветным блоком с подписью текущего этапа:
   - `source` (синий) — элемент только создан
   - `filter` (жёлтый) — проходит фильтр
   - `output` (зелёный) — прошёл через map, итоговое значение
   - `rejected` (красный, перечёркнутый) — нечётное, не прошло фильтр

6. **Кнопки управления**: "Запустить", "Пауза" (backpressure — pipeline останавливается), "Стоп"

7. **Итоговый массив** — после завершения отображается `[4, 8, 12, 16, ..., 40]`

## Чеклист

- [ ] Компонент называется `Task9_2` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован, `t('task.9.2')` используется в заголовке
- [ ] Все три генератора используют `async function*` и `for await...of` для upstream
- [ ] Компоновка через вложенный вызов: `mapDouble(filterEven(source(20, 400)))`
- [ ] Каждый элемент визуально проходит через этапы: source → filter → output/rejected
- [ ] "Пауза" останавливает поток (без отображения новых элементов)
- [ ] "Стоп" прерывает генератор и сбрасывает состояние
- [ ] Итоговый результат показан в конце
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Нажмите "Запустить" — числа 1, 2, 3... начинают появляться с задержкой 400мс
2. Нечётные числа (1, 3, 5...) должны окраситься в красный и быть перечёркнуты
3. Чётные (2, 4, 6...) проходят filter, затем удваиваются в output
4. Нажмите "Пауза" в середине — новые элементы не появляются
5. Нажмите "Продолжить" — pipeline возобновляется
6. После завершения всех 20 чисел — результат должен быть `[4, 8, 12, 16, 20, 24, 28, 32, 36, 40]`
