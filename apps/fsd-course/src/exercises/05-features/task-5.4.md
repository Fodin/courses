# Задание 5.4 — Фича не импортирует вверх (простое)

## Цель

Убрать зависимость фичи от вышестоящего слоя — виджета, который её использует.

## Что дано

- `features/toggle-favorite/ui/ToggleFavoriteButton.tsx` — импортирует константу
  `CARD_WIDTH` из `@/widgets/product-card`, чтобы вычислить размер иконки.

## Требования

1. Уберите импорт `@/widgets/product-card` из `ToggleFavoriteButton.tsx`.
2. Определите размер иконки локальной константой прямо в файле фичи (например,
   `ICON_SIZE`).
3. Нажмите «Проверить».

## Чеклист

- [ ] `ToggleFavoriteButton.tsx` не импортирует ничего из `widgets`
- [ ] Размер иконки — локальная константа фичи
- [ ] Пройти квиз уровня ≥ 80%
