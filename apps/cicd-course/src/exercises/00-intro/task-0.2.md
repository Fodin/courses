# Задание 0.2: Анатомия пайплайна

## Цель

Научиться визуально представлять структуру CI/CD пайплайна. Реализовать горизонтальную интерактивную визуализацию: стадии слева направо, джобы внутри стадий, порядок выполнения и зависимости.

---

## Что нужно сделать

Создай компонент `Task0_2`, который визуализирует CI/CD пайплайн в виде горизонтального потока.

### Требования

1. Определи TypeScript-интерфейсы:
   - `PipelineJob` — отдельный джоб: `id`, `name`, `duration` (строка, например `'~2 мин'`), `status` (`'pending' | 'running' | 'success' | 'failed'`)
   - `PipelineStage` — стадия: `id`, `name`, `jobs` (массив `PipelineJob`), `color` (цвет заголовка)

2. Создай массив `pipelineStages` с минимум 4 стадиями:
   - **Source** — джобы: checkout, install dependencies
   - **Build** — джобы: compile, build docker image
   - **Test** — джобы: unit tests, integration tests, lint
   - **Deploy** — джобы: deploy to staging, smoke tests, deploy to prod

3. Реализуй состояние `selectedStage` — хранит id выбранной стадии или `null`

4. Отобрази стадии горизонтально (flex, слева направо):
   - Между стадиями — стрелка `→`
   - Каждая стадия — прямоугольник с названием и количеством джобов
   - Клик по стадии показывает список джобов внутри неё

5. В панели деталей (ниже или сбоку) при выбранной стадии покажи:
   - Список джобов с иконками статуса
   - Время выполнения каждого джоба
   - Суммарное время стадии

6. Добавь кнопку "Запустить пайплайн" — она последовательно анимирует статусы джобов (`pending → running → success`) с интервалом в 500 мс

---

## Ожидаемый результат

- Горизонтальная цепочка: Source → Build → Test → Deploy
- Клик по стадии открывает список джобов
- Анимация "запуска" пайплайна показывает прогресс выполнения
- Видны времена выполнения

## Как проверить себя

1. Открой компонент — видишь горизонтальную цепочку стадий?
2. Стрелки между стадиями указывают слева направо?
3. Кликни на "Test" — видишь три джоба (unit tests, integration tests, lint)?
4. Нажми "Запустить пайплайн" — статусы меняются последовательно?
5. Джобы в одной стадии запускаются параллельно (одновременно переходят в running)?
