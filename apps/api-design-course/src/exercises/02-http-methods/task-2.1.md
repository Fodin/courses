# Задание 2.1 — Матрица HTTP-методов

## Цель

Изучить и запомнить свойства всех ключевых HTTP-методов: безопасность, идемпотентность, наличие тела запроса/ответа и типичное применение. Использовать фильтрацию для сравнения групп методов.

## Требования

1. Компонент отображает таблицу всех HTTP-методов: GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS.
2. Для каждого метода показаны четыре свойства: безопасность, идемпотентность, наличие тела запроса, наличие тела ответа.
3. Кнопки-фильтры позволяют отображать только безопасные, только идемпотентные, безопасные+идемпотентные или все методы.
4. При клике на строку таблицы раскрывается пояснение свойств выбранного метода.
5. Методы визуально различаются цветами.

## Чеклист

- [ ] Таблица с 7 HTTP-методами
- [ ] Колонки: метод, безопасный, идемпотентный, тело запроса, тело ответа, использование
- [ ] Фильтры: все / безопасные / идемпотентные / безопасные+идемпотентные
- [ ] Клик по строке — детальное описание метода
- [ ] Цветовая кодировка методов

## Как проверить себя

Не глядя в теорию, ответьте: какие методы безопасны? Какие идемпотентны? Почему POST не идемпотентен? Проверьте через фильтры и детальные карточки.
