# Задание 12.4: Worker Pool

## Цель

Реализовать паттерн Worker Pool: фиксированный набор воркеров обрабатывает очередь из 20 задач разной сложности. Воркер, завершив задачу, немедленно берёт следующую из очереди. Наглядно показать: чем больше воркеров — тем быстрее, но после достижения числа CPU-ядер прирост минимален (diminishing returns).

## Требования

1. **Слайдер размера пула:** 1–8 воркеров. Отображать количество CPU-ядер через `navigator.hardwareConcurrency`.

2. **20 задач** с разной сложностью (1–5 баллов). Сложность определяет время выполнения — Worker выполняет вычисления пропорционально сложности.

3. **Визуализация воркеров:** N слотов, каждый показывает:
   - "простаивает" — если ждёт задачу
   - Номер задачи + цветовые квадраты сложности — если выполняет

4. **Сетка задач:** 20 карточек, цвет зависит от сложности (зелёный=1, фиолетовый=5):
   - "ожид." — ждёт в очереди
   - "..." — выполняется (синий)
   - Время в мс — завершена (зелёный)

5. **Счётчики:** В очереди / Выполняется / Готово

6. **Итоговое время:** после завершения всех задач — общее время с подсказкой (оптимально / можно добавить / слишком много воркеров)

7. **Диспетчер очереди:** воркер после завершения задачи немедленно берёт следующую из очереди. Если очередь пуста — помечается как idle. Когда все задачи выполнены и все воркеры idle — записать totalElapsed.

## Чеклист

- [ ] Компонент `Task12_4` использует `useLanguage` и `t('task.12.4')` в заголовке
- [ ] Слайдер 1–8 воркеров работает, отображается `navigator.hardwareConcurrency`
- [ ] Создаются реальные Workers через Blob URL
- [ ] Все 20 задач отображаются с правильным цветом сложности
- [ ] Воркеры берут задачи из очереди и обновляют статус карточек
- [ ] Карточки задач обновляются: pending → running → done
- [ ] После завершения всех задач: отображается итоговое время
- [ ] Подсказка о оптимальности пула относительно CPU-ядер
- [ ] `worker.terminate()` при сбросе
- [ ] Нет TypeScript ошибок с `any`

## Как проверить себя

1. Установите пул = 1 воркер, нажмите "Запустить пул"
2. Видите: 1 слот активен, задачи выполняются последовательно
3. Запомните итоговое время
4. Нажмите "Сброс", установите пул = 4 воркера, запустите снова
5. Видите: 4 слота активны одновременно, задачи параллельны
6. Итоговое время должно быть ~4x меньше
7. Установите пул = 8, снова запустите
8. Время не уменьшится так же драматично — появится подсказка о diminishing returns
