# Задание 8.5 — Кольцо из трёх слайсов одного слоя (среднее)

## Цель

Распутать кольцо из трёх слайсов одного слоя, устранив все cross-import'ы между ними.

## Что дано

Три слайса слоя `entities` замкнуты в кольцо:

- `src/entities/user/model/user.ts` (редактируется) — импортирует `getLastOrderId` из `entities/order`.
- `src/entities/order/model/order.ts` (редактируется) — импортирует `getPaymentStatus` из `entities/payment`.
- `src/entities/payment/model/payment.ts` (редактируется) — импортирует `getUserName` из `entities/user`.

Кольцо `user → order → payment → user` — это одновременно три нарушения изоляции слайсов и трёхузловой рантайм-цикл.

## Требования

1. Уберите импорт `getLastOrderId` из `entities/user/model/user.ts`.
2. Уберите импорт `getPaymentStatus` из `entities/order/model/order.ts`.
3. Уберите импорт `getUserName` из `entities/payment/model/payment.ts`.
4. Каждая функция должна получать нужные ей данные соседнего слайса через параметр, а не через прямой импорт.
5. После правки в проекте не должно быть рантайм-цикла, а слайсы `user`, `order`, `payment` не должны импортировать друг друга.

## Чеклист

- [ ] `entities/user/model/user.ts` не импортирует ничего из `entities/order`
- [ ] `entities/order/model/order.ts` не импортирует ничего из `entities/payment`
- [ ] `entities/payment/model/payment.ts` не импортирует ничего из `entities/user`
- [ ] Проверка «нет рантайм-цикла» — зелёная
- [ ] Проверка «импорты уважают слои и изоляцию слайсов» — зелёная
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

1. Нажмите «Проверить» — обе проверки должны стать зелёными.
2. Обведите на бумаге кольцо из трёх стрелок — после правки ни одна из них не должна остаться.
3. Сравните с эталоном через «Показать эталон», если застряли.
