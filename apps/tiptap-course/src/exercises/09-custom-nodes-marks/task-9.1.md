# Задание 9.1: Кастомный Mark: Highlight

## Цель

Реализовать mark `highlight`, поддерживающий выбор цвета фона, с собственными командами `setHighlight`/`unsetHighlight`.

## Требования

1. Создайте `Mark.create({ name: 'highlight', ... })` с `addAttributes()`, содержащим `color` (default `'#fff3a3'`, `parseHTML`/`renderHTML` через `data-color` + inline `style`)
2. `parseHTML()` — распознавание тега `<mark>`
3. `renderHTML()` — сериализация в `<mark data-color="..." style="background-color: ...">`
4. `addCommands()` — команды `setHighlight(color?)` и `unsetHighlight()`
5. В React-компоненте реализуйте палитру из 4 цветов (кнопки-кружки), клик по цвету вызывает `editor.chain().focus().setHighlight(color).run()`
6. Кнопка "Убрать выделение" вызывает `unsetHighlight()`

## Чеклист

- [ ] Компонент называется `Task9_1` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.9.1')` используется в заголовке
- [ ] Mark корректно применяется с выбранным цветом
- [ ] HTML-вывод содержит `<mark data-color="...">`
- [ ] Кнопка снятия выделения работает
- [ ] Нет TypeScript-ошибок типа `any` (кроме необходимых `unknown`/generic-параметров команд)

## Как проверить себя

1. Выделите текст, нажмите на один из цветов палитры — фон текста должен окраситься
2. Выделите другой текст, примените другой цвет — оба должны сохранить свои цвета одновременно
3. Выведите `editor.getHTML()` — убедитесь, что видна структура `<mark data-color="#..." style="...">`
4. Нажмите "Убрать выделение" на отформатированном тексте — mark должен исчезнуть
