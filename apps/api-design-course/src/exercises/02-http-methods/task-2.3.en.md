# Task 2.3 — CRUD Endpoints for the Tasks Resource

## Goal

Study the complete reference set of REST endpoints for a single resource (task manager). Consolidate the relationship between HTTP method, URL, response status code, and request/response body structure.

## Requirements

1. The component displays a table of 6 reference endpoints for the `/tasks` resource.
2. For each endpoint, the method, URL, description, and HTTP response status are shown.
3. Clicking a row expands examples of the request body (if any) and the response body in JSON.
4. A separate expandable block with query param examples for GET /tasks (filtering, pagination, sorting).
5. A "Test yourself" block with self-control questions.

## Checklist

- [ ] 6 endpoints: GET /tasks, POST /tasks, GET /tasks/:id, PUT /tasks/:id, PATCH /tasks/:id, DELETE /tasks/:id
- [ ] JSON examples for request and response
- [ ] Correct status codes (200, 201, 204)
- [ ] Query params for filtering and pagination
- [ ] Self-check questions

## How to Check Yourself

Close the table and try to reproduce all 6 endpoints from memory: method, URL, status. Then open each row and check the request/response examples.
