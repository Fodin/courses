# Задание 15.3: Decision Matrix — выбор технологий для сценария

## Цель

Реализовать интерактивную матрицу решений с 4 реальными сценариями MFE-архитектуры. Для каждого сценария нужно выбрать технический стек (интеграция + репозиторий + deploy), затем сравнить с экспертной рекомендацией и получить обоснование. Итоговый счёт показывает уровень понимания курса.

## Требования

1. Реализовать 4 сценария (tabs/cards): Стартап / Банк / E-commerce / SaaS, у каждого — title, description, constraints[], expertChoice, expertRationale и функция matchCriteria для подсчёта score
2. Tabs сценариев: активный — синий, заполненный — зелёный border + ✓ префикс
3. Layout 2 колонки: левая — описание и список ограничений (bullet points), правая — выбор пользователя
4. Три select для выбора стека: Интеграция (5 вариантов), Структура репозиториев (4 варианта), Стратегия деплоя (5 вариантов)
5. Кнопка "Показать экспертную рекомендацию" активируется только когда заполнены все 3 поля
6. После reveal: показать score/3, feedback (объяснение совпадений/несовпадений), экспертный выбор с ратionale. Цвет блока: зелёный (3/3), оранжевый (2/3), красный (<=1/3)
7. Реализовать логику matchCriteria для каждого сценария (score 0/0.5/1 за каждый из 3 выборов):
   - Стартап: MF (1) / MF+SSPA (0.5) + monorepo (1) + independent deploy (1) / canary (0.5)
   - Банк: Web Components (1) / MF+SSPA (0.5) + polyrepo (1) + blue/green (1) / rolling (0.5)
   - E-commerce: MF (1) / MF+SSPA (0.5) + monorepo (1) + canary+FF (1) / blue/green (0.5)
   - SaaS: MF+SSPA (1) / MF (0.5) + monorepo (1) + independent deploy (1) / canary+FF (0.5)
8. Изменение любого select скрывает reveal (сбрасывает revealed state)
9. Кнопка "Итоговый счёт" появляется когда все 4 сценария заполнены (не обязательно раскрыты)
10. Итоговый счёт: X/12, метка — "Архитектор уровня Senior" (≥10), "Хорошее понимание" (≥7), "Изучите теорию глубже" (<7)

## Чеклист

- [ ] 4 сценария реализованы с description, constraints и expertChoice
- [ ] Tabs: зелёный border и ✓ для заполненных сценариев
- [ ] Layout 2 колонки: слева — описание, справа — форма выбора
- [ ] 3 select dropdown для каждого сценария с правильными вариантами
- [ ] Кнопка "Показать экспертную рекомендацию" заблокирована до заполнения всех 3 полей
- [ ] matchCriteria возвращает score (0-3) и feedback string
- [ ] Блок результата меняет цвет: зелёный (3/3), оранжевый (2/3), красный (<=1)
- [ ] Блок результата показывает: итоговый score, feedback, экспертный выбор (3 строки), rationale
- [ ] Изменение select скрывает reveal и сбрасывает счёт
- [ ] Кнопка "Итоговый счёт" активна только когда все 4 сценария полностью заполнены
- [ ] Итоговый счёт X/12 с правильной меткой уровня

## Как проверить себя

1. Откройте задание — должны быть видны 4 таба, активен первый (Стартап)
2. Для сценария Стартап выберите: Module Federation + Monorepo (Nx) + Independent deploy → нажмите "Показать" → должен появиться зелёный блок "Отличное решение! 3/3"
3. Для сценария Банк выберите: Module Federation + Monorepo + Blue/Green → ожидается score 1/3 (красный)
4. Для сценария Банк выберите: Web Components + Polyrepo + Blue/Green → ожидается 3/3 (зелёный)
5. Заполните все 4 сценария → должна появиться кнопка "Итоговый счёт"
6. Если все 4 совпадают с экспертными → 12/12 "Архитектор уровня Senior"
