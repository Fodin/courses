# Задание 11.4: Планировщик задач с тремя очередями

## Цель

Реализовать визуальный планировщик задач, демонстрирующий приоритеты выполнения: срочные задачи (каждый кадр), анимационные (через rAF), фоновые (через rIC). Понять, как браузер распределяет работу во времени.

## Требования

1. **Три очереди задач** — три колонки с цветовым кодированием:
   - Срочные (красный) — `queueMicrotask / sync`: обрабатываются каждый кадр полностью
   - Анимация (фиолетовый) — `requestAnimationFrame`: максимум 2 задачи за кадр
   - Фоновые (зелёный) — `requestIdleCallback`: обрабатываются в idle-время

2. **Кнопка "Добавить"** в каждой колонке — добавляет задачу с реалистичным именем в соответствующую очередь

3. **Счётчик задач** — бейдж с количеством ожидающих задач в каждой колонке

4. **Список ожидающих задач** — в каждой колонке отображается до 4 pending-задач с id и именем

5. **Timeline последних кадров** — показывает что выполнилось в каждом кадре:
   - Номер кадра и задачи с цветовыми тегами
   - Последние 5 записей (новые сверху)

6. **Планка приоритетов** — наглядно: Urgent > Animation > Background

7. **Счётчик выполненных** — для каждой очереди отдельно

8. **Кнопки "Запустить планировщик" / "Остановить" / "Сброс"**

9. **Реальные API** — используются настоящие `requestAnimationFrame` и `requestIdleCallback`

## Чеклист

- [ ] Компонент называется `Task11_4` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован, `t('task.11.4')` используется в заголовке
- [ ] Используется `requestAnimationFrame` для основного цикла кадров
- [ ] Используется `requestIdleCallback` для фоновых задач
- [ ] Срочные задачи обрабатываются полностью за каждый кадр
- [ ] Анимационные: не более 2 за кадр (имитация ограниченного бюджета)
- [ ] Фоновые: только в idle, при наличии `deadline.timeRemaining() > 2`
- [ ] При остановке отменяются rAF и rIC (`cancelAnimationFrame`, `cancelIdleCallback`)
- [ ] При размонтировании — очистка всех подписок
- [ ] Нет TypeScript-ошибок, нет `any`

## Как проверить себя

1. Добавьте по 3-4 задачи в каждую очередь
2. Нажмите "Запустить планировщик"
3. Наблюдайте: срочные задачи исчезают быстро, анимационные — по 1-2 за цикл, фоновые — медленнее всего
4. Добавляйте новые задачи во время работы — они добавляются в конец очереди
5. В Timeline: убедитесь, что задачи разных типов попадают в разные "окна" кадра
6. Нажмите "Стоп", затем "Запустить" снова — всё продолжается корректно
7. "Сброс" очищает все очереди и счётчики
