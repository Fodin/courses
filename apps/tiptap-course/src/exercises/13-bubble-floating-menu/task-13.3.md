# Задание 13.3: shouldShow: кастомная логика

## Цель

Реализовать `BubbleMenu`, который показывается только при выделении текста ВНУТРИ заголовка (h1-h3), демонстрируя возможности `shouldShow`.

## Требования

1. Создайте `editor` через `useEditor` с `StarterKit`
2. Реализуйте `<BubbleMenu editor={editor} shouldShow={...}>` с кастомной функцией:
   - Получите `from`/`to` из `state.selection` (либо из аргументов `shouldShow`)
   - Верните `true`, только если `from !== to` (есть реальное выделение текста) **и** `editor.isActive('heading')`
3. Внутри меню разместите кнопки, специфичные для заголовков (например, переключение уровня H1/H2/H3)
4. Начальный контент должен включать и обычные параграфы, и заголовки, чтобы разница в поведении была заметна

## Чеклист

- [ ] Компонент называется `Task13_3` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.13.3')` используется в заголовке
- [ ] Выделение текста в обычном параграфе НЕ показывает меню
- [ ] Выделение текста внутри заголовка ПОКАЗЫВАЕТ меню
- [ ] Кнопки внутри меню корректно меняют уровень заголовка
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Выделите текст в обычном параграфе — меню НЕ должно появиться
2. Выделите текст внутри заголовка — меню должно появиться
3. Внутри меню переключите уровень заголовка — изменение должно примениться, меню — остаться видимым (текст всё ещё выделен и это всё ещё заголовок)
4. Снимите выделение — меню должно исчезнуть в обоих случаях
