# Задание 7.3: Browser API Store

## Задание

Реализуйте три хука через `useSyncExternalStore`, которые подключают браузерные API к React: `useOnlineStatus()`, `useWindowSize()` и `useLocalStorage(key)`. Соберите их в единый дашборд.

## Цель

Закрепить навык построения production-ready хуков на основе `useSyncExternalStore`. Каждый хук решает реальную задачу и демонстрирует отдельный аспект API: работа с событиями, работа с объектами-снимками и работа с внешним хранилищем данных.

## Требования

### useOnlineStatus()

1. Подписаться на события `'online'` и `'offline'` на `window`
2. `getSnapshot` возвращает `navigator.onLine` (примитив — boolean)
3. `getServerSnapshot` возвращает `true` (на сервере считаем, что онлайн)
4. Хук возвращает `boolean`

### useWindowSize()

1. Подписаться на событие `'resize'` на `window`
2. Объект `{ width: number, height: number }` нельзя возвращать каждый раз новым — нужно кэшировать
3. Кэш: хранить предыдущий объект в переменной вне компонента, возвращать его если размеры не изменились
4. `getServerSnapshot` возвращает `{ width: 0, height: 0 }`
5. Хук возвращает `{ width: number, height: number }`

### useLocalStorage(key: string, defaultValue: string)

1. Читать значение через `localStorage.getItem(key) ?? defaultValue`
2. Подписаться на событие `'storage'` на `window` (срабатывает при изменении из другой вкладки)
3. Предоставить функцию `setValue(value: string)` для записи (вызывает `localStorage.setItem` и затем `subscribe callback` вручную для синхронизации в рамках той же вкладки)
4. `getServerSnapshot` возвращает `defaultValue`
5. Хук возвращает `[value: string, setValue: (v: string) => void]`

### Дашборд

6. Создать компонент `BrowserApiDashboard`, показывающий все три хука:
   - Статус сети (онлайн/офлайн) с цветовым индикатором
   - Размер окна в реальном времени
   - Значение из localStorage с возможностью редактировать через input

## Чеклист

- [ ] `useOnlineStatus` возвращает корректное значение сразу при монтировании
- [ ] `useWindowSize` не вызывает бесконечный цикл ре-рендеров (кэш объекта реализован)
- [ ] `useLocalStorage` синхронизируется при изменении из другой вкладки (событие 'storage')
- [ ] `useLocalStorage` обновляет UI сразу при вызове setValue (не только через событие 'storage')
- [ ] Все три хука имеют `getServerSnapshot` (SSR-safe)
- [ ] `subscribe` для каждого хука определён вне компонента (стабильная ссылка)
- [ ] Дашборд показывает все три значения в реальном времени
- [ ] При сужении/расширении окна `useWindowSize` обновляется без задержки

## Как проверить себя

1. Откройте DevTools → Network → переключитесь в режим "Offline" — статус в дашборде должен измениться немедленно
2. Измените размер окна браузера — размер в дашборде обновляется в реальном времени
3. Откройте ту же страницу в двух вкладках, в одной измените значение localStorage — во второй должно обновиться автоматически
4. Убедитесь, что ввод нового значения в input сразу отражается в UI (не нужно переключать вкладку)
5. Проверьте в React DevTools: при изменении размера окна ре-рендерится только компонент с `useWindowSize`, а не весь дашборд
