# Задание 7.2: Content-выражения

## Цель

На практике продемонстрировать, как content-выражение `blockquote` (`'block+'`) допускает несколько параграфов внутри цитаты, а `codeBlock` (`'text*'`, без marks) — нет.

## Требования

1. Создайте `editor` через `useEditor` с `StarterKit`
2. Заведите начальный контент с одной цитатой (`blockquote`), содержащей **два** параграфа
3. Добавьте кнопку "Добавить параграф в конец документа" — демонстрирует, что `doc` допускает произвольное число блоков
4. Добавьте кнопку "Попробовать bold в code block" — переключите блок кода и попробуйте применить `toggleBold()`, покажите пользователю результат через `editor.can().toggleBold()` до и после переключения в codeBlock (должно стать `false`, т.к. `codeBlock` имеет `marks: ''`)
5. Выведите текст-объяснение результата (доступен ли bold в текущем типе блока)

## Чеклист

- [ ] Компонент называется `Task7_2` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.7.2')` используется в заголовке
- [ ] Blockquote с двумя параграфами корректно отображается
- [ ] Демонстрация показывает, что в codeBlock применение bold недоступно (`can().toggleBold()` возвращает `false`)
- [ ] Вне codeBlock `can().toggleBold()` возвращает `true`
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Убедитесь, что в blockquote видно два отдельных параграфа
2. Поставьте курсор в обычный параграф — индикатор должен показать "Bold доступен"
3. Переключитесь в code block, поставьте туда курсор — индикатор должен показать "Bold недоступен"
