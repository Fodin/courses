# Задание 4.2: withAuth — HOC авторизации через Context

## Цель

Реализовать HOC `withAuth<P>`, который проверяет авторизацию пользователя через React Context и либо рендерит компонент, либо заглушку с предложением войти.

## Требования

1. Создайте `AuthContext` с помощью `React.createContext`. Тип значения контекста:
   ```ts
   interface AuthContextValue {
     isAuthenticated: boolean
     user: { name: string; role: 'admin' | 'user' } | null
     login: () => void
     logout: () => void
   }
   ```
2. Создайте `AuthProvider` — компонент-провайдер, который управляет состоянием авторизации (для демонстрации достаточно `useState`)
3. Реализуйте HOC `withAuth<P>(Component, options?)`:
   - Читает `isAuthenticated` из `AuthContext` через `useContext`
   - Если не авторизован — рендерит компонент-заглушку (LoginPrompt) с кнопкой "Войти"
   - Если авторизован — рендерит оригинальный `Component` с его пропсами
   - Опционально: принимает `options.requiredRole` — если роль не совпадает, показывает "Доступ запрещён"
4. Установите `displayName` в формате `withAuth(ComponentName)`
5. Продемонстрируйте: `Dashboard` и `AdminPanel` обёрнуты `withAuth`. `AdminPanel` требует роль `admin`. Добавьте кнопки "Войти как user" / "Войти как admin" / "Выйти"

## Подсказки

- HOC может использовать хуки (`useContext`) — это нормально, потому что возвращаемая функция является React-компонентом
- `useContext` нужно вызывать внутри возвращаемого компонента, не в самой функции-фабрике HOC
- Для `AuthProvider` удобно использовать `useMemo` для значения провайдера
- `options` передаётся в функцию-фабрику, не в компонент: `withAuth(Dashboard, { requiredRole: 'admin' })`

## Чеклист

- [ ] `AuthContext` типизирован и создан
- [ ] `AuthProvider` управляет состоянием login/logout
- [ ] HOC читает контекст через `useContext`
- [ ] Неавторизованный пользователь видит заглушку с кнопкой "Войти"
- [ ] `displayName` установлен корректно
- [ ] Демонстрация с переключением ролей работает
- [ ] Опциональная проверка роли (AdminPanel доступен только admin)

## Как проверить себя

1. Откройте страницу — оба компонента показывают заглушку (не авторизован)
2. Нажмите "Войти как user" — Dashboard открывается, AdminPanel показывает "Доступ запрещён"
3. Нажмите "Войти как admin" — оба компонента открываются
4. Нажмите "Выйти" — оба компонента снова показывают заглушку
