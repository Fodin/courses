# Задание 9.4 — Разрыв cross-import (простое)

## Цель

Разорвать прямую связь между двумя слайсами одного слоя.

## Что дано

- `entities/product/model/types.ts` — тип `Product`, который импортирует `User` из
  соседнего слайса и хранит объект продавца целиком (`seller: User`).

## Требования

1. Уберите импорт `@/entities/user` из `product/model/types.ts`.
2. Замените поле `seller: User` на `sellerId: string` — сущность ссылается на продавца
   по идентификатору, а не встраивает его.
3. Нажмите «Проверить».

## Чеклист

- [ ] В `product/model/types.ts` нет импорта соседнего слайса
- [ ] `Product` хранит `sellerId: string`
- [ ] Пройти квиз уровня ≥ 80%
