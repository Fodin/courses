# Задание 2.1: mosquitto.conf — основные параметры

## Цель

Изучить ключевые параметры конфигурации Mosquitto и научиться работать со справочником. Реализовать интерактивный справочник с поиском, фильтрацией по категориям и подробным описанием каждого параметра.

---

## Требования

1. Определи интерфейс `ConfigParam` с полями: `key`, `defaultValue`, `type` (`'integer' | 'boolean' | 'string' | 'path'`), `category` (`'general' | 'network' | 'logging' | 'security' | 'persistence'`), `description`, `example`, опционально `note`

2. Создай массив `configParams` минимум из 12 параметров, охватывающих все 5 категорий. Включи: `listener`, `bind_address`, `max_connections`, `persistence`, `persistence_location`, `log_dest`, `log_type`, `allow_anonymous`, `password_file`, `pid_file`, `message_size_limit`, `keepalive_interval`

3. Реализуй строку поиска (фильтрация по `key` и `description`)

4. Реализуй кнопки фильтрации по категориям (включая "Все"). Активная категория выделяется цветом этой категории.

5. Список параметров: прокручиваемый список с: иконкой категории, именем параметра (monospace, жирный), значением по умолчанию в сером бейдже

6. Клик на параметр открывает панель с: именем и типом, подробным описанием, значением по умолчанию, примечанием (если есть) в жёлтом блоке, примером использования в стиле терминала

---

## Чеклист

- [ ] Определён интерфейс `ConfigParam` с полем `note` как опциональным
- [ ] 12+ параметров с технически точными данными для Mosquitto 2.x
- [ ] Поле поиска фильтрует список в реальном времени
- [ ] 6 кнопок фильтрации (Все + 5 категорий) с цветовым выделением
- [ ] Счётчик "Найдено: N параметров"
- [ ] Список с прокруткой (maxHeight)
- [ ] Клик открывает детальную панель
- [ ] В панели: бейдж с типом, описание, значение по умолчанию
- [ ] Примечание `note` в жёлтом блоке с ⚠️
- [ ] Пример использования в тёмном терминале
- [ ] Корректная TypeScript типизация

---

## Как проверить себя

1. Видишь список параметров с кнопками категорий сверху?
2. Набери "log" в поиске — список сократился до параметров логирования?
3. Нажми фильтр "Persistence" — видишь только параметры persistence?
4. Кликни `persistence_location` — в панели появилось описание и примечание про tmpfs?
5. Примечание показывается в жёлтом блоке с ⚠️?
6. В примере видишь реальные пути `/tmp/mosquitto/`?
