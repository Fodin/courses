# Задание 0.3: Анализ API (Self-check)

## Цель

Применить критерии качественного API-дизайна к реальному популярному API и сформировать собственную оценку.

## Требования

1. Создайте компонент `Task0_3`, который показывает разбор **реального публичного API** по выбранным критериям
2. Используйте минимум **5 критериев оценки** с указанием веса каждого (в процентах, сумма = 100%)
3. Для каждого критерия отображайте:
   - Оценку выбранного API (по шкале 1–10)
   - Комментарий с обоснованием
   - Пример из реального API (HTTP-запрос, ответ или фрагмент кода)
4. Покажите итоговую взвешенную оценку (weighted score)
5. Добавьте **блок self-check**: предложите пользователю самостоятельно проанализировать другой публичный API по тем же критериям
6. Блок self-check содержит список критериев для заполнения и кнопку "Отметить как выполнено"

## Чеклист

- [ ] Минимум 5 критериев оценки
- [ ] Сумма весов критериев = 100%
- [ ] Для каждого критерия: оценка + комментарий + пример кода
- [ ] Итоговая взвешенная оценка отображается
- [ ] Блок self-check присутствует
- [ ] Кнопка "Отметить как выполнено" меняет состояние
- [ ] Критерии можно разворачивать/сворачивать для детального просмотра
- [ ] Компонент обёрнут в `<div className="exercise-container">`

## Как проверить себя

1. Откройте задание и изучите разбор выбранного API
2. Нажмите "Развернуть все критерии" — все детали должны стать видны
3. Проверьте: сумма весов в заголовках критериев должна составлять 100%
4. Прочитайте пример кода для каждого критерия — убедитесь, что он реальный (не выдуманный)
5. Перейдите в блок self-check и выберите любой другой публичный API (Stripe, Telegram Bot API, OpenWeatherMap, Spotify API)
6. Запишите свои оценки и комментарии
7. Нажмите "Отметить как выполнено" — кнопка должна поменять текст на "Выполнено"

## Рекомендуемые API для self-check

- **Stripe API** (stripe.com/docs/api) — платёжный, эталон индустрии
- **Telegram Bot API** (core.telegram.org/bots/api) — простой и предсказуемый
- **OpenWeatherMap API** (openweathermap.org/api) — хороший пример с проблемами
- **Spotify Web API** (developer.spotify.com) — сложный, богатый фичами
- **JSONPlaceholder** (jsonplaceholder.typicode.com) — простой учебный API
