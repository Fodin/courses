# Задание 5.2: Проверка can()

## Цель

Построить тулбар, где кнопки корректно отключаются (`disabled`), когда соответствующая команда недоступна в текущем контексте — используя `editor.can()`.

## Требования

1. Создайте `editor` через `useEditor` с `StarterKit`
2. Добавьте кнопки "Undo" и "Redo", использующие `editor.chain().focus().undo().run()` / `redo()`
3. `disabled` для этих кнопок должен определяться через `!editor.can().undo()` / `!editor.can().redo()`
4. Добавьте кнопку "Bold", `disabled` которой определяется через `!editor.can().toggleBold()`
5. Продемонстрируйте на практике ситуацию, когда `can()` возвращает `false` (например, "Undo" недоступен сразу после открытия задания, пока не сделано ни одного изменения)

## Чеклист

- [ ] Компонент называется `Task5_2` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.5.2')` используется в заголовке
- [ ] Кнопка Undo отключена, если нечего отменять
- [ ] Кнопка Redo отключена, если нечего повторять
- [ ] После изменения текста кнопка Undo становится активной
- [ ] После Undo кнопка Redo становится активной
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Откройте задание — кнопки Undo и Redo должны быть неактивны
2. Введите текст — кнопка Undo должна стать активной
3. Нажмите Undo — текст должен исчезнуть, кнопка Redo должна стать активной, Undo может снова стать неактивной (если это было единственное изменение)
4. Нажмите Redo — текст должен вернуться
