Проверить понимание ключевых решений при проектировании распределённого кэша: consistent hashing с virtual nodes, gossip protocol, split-brain protection, persistence (RDB + AOF).

## Требования

1. Прочитайте теорию уровня 15 (README)
2. Пройдите квиз из 4 вопросов по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ
4. Постарайтесь ответить без подглядывания в теорию
