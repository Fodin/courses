# Level 2: Render Props

## Что такое Render Props

Render Props — это паттерн, при котором компонент принимает функцию через пропс и вызывает её для формирования своего вывода. Компонент владеет **поведением**, а вызывающий код — **внешним видом**.

```mermaid
graph LR
    A[Компонент\nс состоянием] -->|передаёт данные| B[render prop\nфункция]
    B -->|возвращает| C[JSX\nвывод]
```

---

## Формы render props

**Function as children** — функция передаётся через `children`:

```tsx
<MouseTracker>
  {({ x, y }) => <Tooltip x={x} y={y} />}
</MouseTracker>
```

**Именованный render prop** — функция передаётся через явный пропс:

```tsx
<DataList
  data={users}
  renderItem={(user) => <UserCard key={user.id} user={user} />}
  renderEmpty={() => <p>Список пуст</p>}
/>
```

📌 Именованные пропсы предпочтительнее: их назначение понятно без чтения реализации компонента.

---

## Render Props vs Хуки

| Критерий | Render Props | Хуки |
|----------|-------------|------|
| Доступ к JSX-контексту | ✅ напрямую | ✅ через компонент |
| Вложенность | Растёт при нескольких | Плоская |
| Переиспользование логики | ✅ | ✅ (предпочтительно) |
| Ограничение областью | ✅ изолирует | ✅ изолирует |
| Правила хуков в рендере | Не применяются | Обязательны |

💡 Правило выбора: если нужно переиспользовать **логику без UI** — хук. Если нужно дать потребителю контроль над **рендером части UI** — render prop.

## ⚠️ Типичные ошибки новичков

**❌ Создание функции прямо в JSX без useCallback**
```tsx
// Каждый рендер создаёт новую функцию — дочерний компонент
// перерисовывается даже если данные не изменились
<DataList renderItem={(item) => <Card item={item} />} />
```
✅ Если производительность критична — выносите функцию или оборачивайте в `useCallback`.

**❌ Render prop возвращает не один корневой элемент**
```tsx
// TypeScript (и React) ожидает ReactNode — это нормально,
// но фрагменты могут сломать логику позиционирования
renderItem={() => <A /><B />} // ошибка синтаксиса
```
✅ Используйте фрагменты: `() => <><A /><B /></>`.

**❌ Путаница типов в generic-компонентах**
```tsx
// Ошибка: item имеет тип unknown
function DataList({ renderItem }) {
  return renderItem(data[0])
}
```
✅ Параметризуйте через дженерик: `DataList<T>` с `renderItem: (item: T) => ReactNode`.
