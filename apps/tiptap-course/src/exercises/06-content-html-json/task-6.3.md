# Задание 6.3: Контролируемый контент

## Цель

Реализовать полностью контролируемый (controlled) редактор — компонент, принимающий `value` и `onChange` как пропсы, синхронизирующий состояние без цикла и без сброса позиции курсора.

## Требования

1. Реализуйте компонент `ControlledEditor({ value, onChange }: { value: string; onChange: (html: string) => void })`
2. Внутри создайте `editor` через `useEditor` с `content: value` при инициализации
3. В `onUpdate` вызывайте `onChange(editor.getHTML())`
4. В `useEffect`, реагирующем на изменение `value`, сравнивайте `editor.getHTML() === value` — обновляйте `editor.commands.setContent(value, { emitUpdate: false })` только если значения различаются
5. В родительском компоненте `Task6_3` заведите `useState<string>` и передайте его как `value`/`setValue` как `onChange` в `ControlledEditor`
6. Добавьте вторую кнопку "Сброс извне", которая устанавливает `value` в фиксированную строку напрямую через `setValue` (не через редактор) — это демонстрирует синхронизацию "снаружи внутрь"

## Чеклист

- [ ] Компонент `Task6_3` экспортируется, использует `ControlledEditor`
- [ ] `useLanguage` импортирован и `t('task.6.3')` используется в заголовке
- [ ] Ввод текста в редакторе не вызывает потери фокуса/курсора
- [ ] Кнопка "Сброс извне" корректно меняет содержимое редактора программно
- [ ] Нет бесконечного цикла обновлений (проверка `editor.getHTML() === value` предотвращает его)
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Печатайте быстро длинный текст в редакторе — курсор не должен "прыгать" или сбрасываться в начало
2. Откройте консоль браузера, временно уберите проверку `isSame` (в отладочных целях) и убедитесь, что без неё возникает проблема — затем верните проверку
3. Нажмите "Сброс извне" — содержимое редактора должно замениться на фиксированный текст без ошибок
