# Задание 6.1: Publisher Confirms — визуализация подтверждений

## Цель

Реализовать интерактивную визуализацию механизма Publisher Confirms в RabbitMQ: симуляцию отправки сообщений и получения ACK/NACK от брокера в трёх режимах.

## Требования

1. Добавить переключатель режима подтверждений: individual, batch, async
2. При нажатии "Отправить" запускать симуляцию отправки 10 сообщений
3. Визуализировать sequence diagram: Producer → [стрелки] → Broker с результатами ACK/NACK
4. Отображать события подтверждений в виде вызовов `basicAck(deliveryTag, multiple)` / `basicNack(deliveryTag, multiple)`
5. Добавить слайдер вероятности NACK (0–50%)
6. Для режима batch — добавить настройку размера батча (2–10)
7. Показывать счётчики: ACK, NACK, in-flight
8. Разные цвета статусов: pending (серый), sent (голубой), confirmed (зелёный), nacked (красный)

## Чеклист

- [ ] Режим individual: каждое сообщение ждёт ACK последовательно
- [ ] Режим batch: сообщения отправляются группами, один ACK с multiple=true
- [ ] Режим async: все сообщения отправляются без ожидания, ACK приходят в случайном порядке
- [ ] Sequence diagram обновляется в реальном времени
- [ ] Лог событий показывает корректный синтаксис basicAck/basicNack
- [ ] Кнопка "Сброс" очищает всё состояние
- [ ] Статистика ACK/NACK/in-flight актуальна

## Как проверить себя

Запусти симуляцию в режиме async с NACK=20%:
- Стрелки в sequence diagram должны обновляться асинхронно (не по порядку)
- Некоторые сообщения получают красный NACK
- Лог содержит события: `basicNack(deliveryTag=X, multiple=false)`

Переключись на batch с batchSize=5:
- 10 сообщений разбиваются на 2 группы
- Каждая группа получает один ACK с `multiple=true`
- Delivery tag в ACK равен последнему тегу в батче

## Подсказки

- Используй `useState` для списка сообщений и их статусов
- Для async режима: отправь все сообщения сразу, затем используй `setTimeout` с разными задержками для имитации асинхронных ACK
- `deliveryTag` — монотонно возрастающее число, начиная с 1
- `multiple=true` означает "подтверждаю все теги <= этого значения"
