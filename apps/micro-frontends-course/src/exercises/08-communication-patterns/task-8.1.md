# Задание 8.1: Визуализатор Event Bus

## Цель

Построить интерактивный визуализатор, демонстрирующий работу typed event bus между тремя MFE (Каталог, Корзина, Профиль): отправка событий, управление подписками и лог событий.

## Требования

1. Отобразить три цветных блока-MFE: Каталог (синий), Корзина (зелёный), Профиль (фиолетовый)
2. В каждом блоке — кнопки для отправки двух событий с названием в формате `mfe:action`
3. При отправке события: определить подписчиков и добавить запись в лог
4. Показать анимированные стрелки-индикаторы от отправителя к получателям (1.2 секунды)
5. Блок-получатель подсвечивается свечением на время получения события
6. Реализовать таблицу подписок с переключателями on/off для каждой пары событие→MFE
7. Отправитель события не может быть его подписчиком (кнопок нет, показывается "emit")
8. Лог событий в тёмном терминальном стиле с автоскроллом к последней записи
9. Кнопка "Очистить" для сброса лога

## Чеклист

- [ ] Три MFE-блока в ряд с цветами: Каталог (#2196f3), Корзина (#4caf50), Профиль (#9c27b0)
- [ ] 2 кнопки событий в каждом блоке (итого 6 событий)
- [ ] Формат событий: `catalog:add-to-cart`, `cart:checkout-started`, `profile:logout` и т.д.
- [ ] Анимация стрелки при отправке события (visible 1200ms → исчезает)
- [ ] Блок-получатель светится при получении события
- [ ] Таблица подписок: строки = события, столбцы = MFE, ячейки = on/off или "emit"
- [ ] Начальные подписки: catalog:add-to-cart → cart, profile; cart:checkout-started → profile; profile:logout → catalog, cart; profile:address-updated → cart
- [ ] Лог: [время] Отправитель → emit event-name payload • получатели
- [ ] Автоскролл лога вниз при добавлении записи
- [ ] Кнопка "Очистить" сбрасывает лог
- [ ] Если нет подписчиков — пишет "нет подписчиков"
- [ ] Все стили inline

## Как проверить

1. Нажмите кнопку "Добавить в корзину" в блоке Каталог — Корзина и Профиль должны засветиться
2. Отключите подписку Профиля на событие `catalog:add-to-cart` через таблицу
3. Снова нажмите — теперь должна подсвечиваться только Корзина
4. Нажмите "Выйти из аккаунта" в Профиле — Каталог и Корзина должны засветиться
5. В логе должны появиться записи с временными метками и списком получателей
6. Отключите все подписки для события — в логе должно появиться "нет подписчиков"
