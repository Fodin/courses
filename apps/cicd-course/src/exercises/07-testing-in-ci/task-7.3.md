# Задание 7.3: Coverage и JUnit отчёты

## Цель

Создать интерактивный настройщик отчётности о тестах: JUnit XML и coverage. Пользователь выбирает тест-фреймворк, формат отчёта и видит готовую конфигурацию с правильным regex для coverage и настройками artifacts:reports.

## Требования

1. Реализовать выбор тест-фреймворка: Jest, Vitest, pytest, go test — каждый со своим выводом покрытия
2. При выборе фреймворка показывать пример stdout-вывода coverage (имитация реального вывода)
3. Показать поле для ввода regex и кнопку "Проверить" — она тестирует regex на примере вывода и подсвечивает найденное число
4. Предоставить готовые варианты regex для каждого фреймворка (выбор кнопкой)
5. Реализовать выбор формата coverage отчёта: только regex, Cobertura XML, lcov
6. При выборе Cobertura — показать дополнительный блок artifacts:reports:coverage_report
7. Показать переключатель `artifacts:when` с объяснением, почему `always` важен для тест-отчётов
8. Генерировать итоговый YAML-конфиг

## Чеклист

- [ ] Кнопки выбора фреймворка (Jest, Vitest, pytest, go test)
- [ ] Блок с имитацией вывода coverage для выбранного фреймворка
- [ ] Поле для ввода regex с live-тестированием на примере вывода
- [ ] Подсветка найденного числа в примере вывода при совпадении regex
- [ ] Кнопки с готовыми regex для каждого фреймворка
- [ ] Выбор формата: только regex / Cobertura / lcov
- [ ] YAML с artifacts:reports:junit и coverage_report (для Cobertura)
- [ ] Объяснение важности artifacts:when: always

## Как проверить себя

1. Выбери Jest — в примере вывода должны быть строки вида "Lines : 85.32%"
2. Нажми "Использовать готовый regex" — он должен подсветить "85.32" в примере вывода
3. Введи неправильный regex — должно появиться сообщение "Regex не совпал"
4. Выбери Cobertura — в YAML должен появиться блок coverage_report
5. Переключи when на on_success — должно появиться предупреждение о потере отчётов при падении

## Подсказки

- Имитация вывода — просто строки в константе для каждого фреймворка
- Тестирование regex: `new RegExp(userRegex).exec(exampleOutput)?.[1]`
- При ошибке в regex используй try/catch вокруг `new RegExp()`
- Подсветку числа в выводе можно сделать через split + span с фоном
- Используй `useState` для: `framework`, `userRegex`, `coverageFormat`, `artifactsWhen`
