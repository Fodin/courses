# Задание 10.4 — Несколько нарушений сразу: цикл + импорт вверх (простое)

## Цель

Найти в слайсе `entities/product` одновременно два связанных нарушения — импорт вверх по слоям и рантайм-цикл, который он создаёт, — и починить оба одной правкой.

## Что дано

- `src/features/add-to-cart/index.ts` (только для чтения) — легально импортирует `Product` из `entities/product` (это импорт «вниз», всё в порядке).
- `src/entities/product/index.ts` (редактируется) — импортирует `addToCart` из `features/add-to-cart` внутри `getProductWithCartAction`. Это импорт «вверх» по слоям, и вместе с легальным импортом из первого файла он замыкает цикл `entities → features → entities`.

## Требования

1. Не редактируйте `features/add-to-cart/index.ts` — он уже корректен.
2. Уберите импорт `addToCart` из `entities/product/index.ts`.
3. Функция `getProductWithCartAction` должна получать колбэк добавления в корзину через параметр (dependency injection), а не импортировать его из вышестоящего слоя.
4. После правки в проекте не должно быть рантайм-цикла импортов.
5. Все импорты должны идти строго «вниз» по иерархии `app → pages → widgets → features → entities → shared`.

## Чеклист

- [ ] `entities/product/index.ts` больше не импортирует ничего из `features`
- [ ] `getProductWithCartAction` принимает `addAction` параметром
- [ ] Проверка «нет рантайм-цикла» — зелёная
- [ ] Проверка «импорты уважают слои» — зелёная
- [ ] Пройти квиз уровня ≥ 80%

1. Нажмите «Проверить» — обе проверки должны стать зелёными.
2. Откройте «Показать эталон», если не получается.
3. Найдите в теории (README-long.md) раздел про «Нарушение 1: импорт вверх по слоям» и сравните пример с этим заданием.
