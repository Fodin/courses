# Task 4.2 — Envelope vs Flat

## Goal

Understand two approaches to structuring API responses: the envelope pattern and flat style. Understand when each is justified.

## Requirements

1. The component shows the same response in two styles: envelope and flat.
2. A toggle allows switching between the approaches.
3. Four scenarios are provided: collection, single resource, error, resource creation.
4. Under each example — a comment: what this means for the client in this context.
5. A pros and cons block for each approach updates when the toggle is switched.

## Checklist

- [ ] Envelope / Flat toggle
- [ ] At least 3 scenarios: collection, single resource, error
- [ ] Switching between scenarios
- [ ] Comment for each approach+scenario combination
- [ ] Pros and cons of both approaches
- [ ] Warning about the inadmissibility of mixing styles

## How to Check Yourself

Can you answer without a hint: in which case is envelope justified, and in which is it excessive? If yes, explain it using two specific endpoints from your last project.
