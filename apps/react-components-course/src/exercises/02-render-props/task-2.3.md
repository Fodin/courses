# Задание 2.3: Toggle с render prop

## Цель

Реализовать компонент `Toggle`, который управляет булевым состоянием открыт/закрыт и передаёт его через render prop. На основе одного `Toggle` создать три принципиально разных UI-элемента.

---

## Требования

1. Компонент `Toggle` принимает:
   - `render: (props: ToggleRenderProps) => ReactNode` — функция рендера
   - `defaultOpen?: boolean` — начальное состояние (по умолчанию `false`)
2. В `ToggleRenderProps` передаются:
   - `isOpen: boolean` — текущее состояние
   - `toggle: () => void` — переключить состояние
   - `open: () => void` — открыть
   - `close: () => void` — закрыть
3. Реализовать три использования `Toggle`:
   - **Dropdown-меню**: кнопка «Меню» с индикатором ▼/▲, при открытии появляется список пунктов
   - **Modal trigger**: кнопка «Открыть модалку», при нажатии показывается оверлей с окном и кнопкой закрытия
   - **Expandable section (аккордеон)**: заголовок раздела при клике разворачивает/сворачивает содержимое
4. Каждый из трёх примеров должен быть независим (своя копия `Toggle` — своё состояние)

---

## Подсказки

- Тип `ToggleRenderProps` объявите как интерфейс вне компонента, чтобы потребители могли импортировать его
- Для модального оверлея используйте `position: fixed`, `inset: 0`, `background: rgba(0,0,0,0.5)`
- Чтобы закрыть modal при клике на оверлей — повесьте `close` на внешний div, а `e.stopPropagation()` на внутреннее окно
- `defaultOpen` лучше передавать в `useState`: `const [isOpen, setIsOpen] = useState(defaultOpen ?? false)`

---

## Чеклист

- [ ] Интерфейс `ToggleRenderProps` объявлен с `isOpen`, `toggle`, `open`, `close`
- [ ] Компонент `Toggle` принимает `render` и `defaultOpen`
- [ ] Dropdown: список появляется/скрывается по кнопке, индикатор меняется
- [ ] Modal: оверлей показывается поверх контента, закрывается по кнопке «×» или клику вне окна
- [ ] Expandable section: содержимое разворачивается/сворачивается, заголовок кликабелен
- [ ] Три примера независимы друг от друга

---

## Как проверить себя

Откройте dropdown — модалка и аккордеон не должны реагировать. Откройте модалку кликом на оверлей (не на окно) — она должна закрыться. Проверьте, что у каждого Toggle своё изолированное состояние.
