# Задание 6.1: Квиз — Проектирование API

## Цель

Проверить понимание стилей API (REST, GraphQL, gRPC), пагинации, rate limiting, версионирования и idempotency.

## Требования

1. Прочитайте теорию уровня 6 (README)
2. Пройдите квиз из 5 вопросов по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ (один или несколько)
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист

- [ ] Понятна разница между REST, GraphQL и gRPC — когда что применять
- [ ] Знакомы с Richardson Maturity Model (Level 0-3)
- [ ] Понятна разница между offset и cursor пагинацией
- [ ] Знакомы с алгоритмами rate limiting (token bucket, sliding window, fixed window)
- [ ] Понятен механизм idempotency keys и зачем они нужны
- [ ] Знакомы со стратегиями версионирования API
- [ ] Понятен OAuth2 authorization code flow
- [ ] Пройден квиз с результатом не менее 80%

## Как проверить себя

1. Откройте квиз и ответьте на все вопросы
2. Проверьте объяснения для неправильных ответов
3. Если результат ниже 80% — перечитайте соответствующие разделы теории
