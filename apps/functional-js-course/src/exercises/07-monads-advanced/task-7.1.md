# Задание 7.1 — IO-монада

## Цель

Реализовать IO-монаду и построить с её помощью пайплайн из синхронных побочных эффектов, наглядно показывающий разницу между "описанием эффекта" и "выполнением эффекта".

## Требования

1. Реализуйте класс `IO<T>` с полем `private effect: () => T`
2. Реализуйте статический метод `IO.of<T>(value: T): IO<T>` — поднимает значение в IO
3. Реализуйте метод `map<U>(fn: (value: T) => U): IO<U>` — создаёт новый IO с трансформацией, **не вызывая** эффект
4. Реализуйте метод `flatMap<U>(fn: (value: T) => IO<U>): IO<U>` — цепочка IO-шагов, эффект не вызывается
5. Реализуйте метод `run(): T` — единственное место, где эффект выполняется
6. Реализуйте четыре IO-шага:
   - `readConfig()` — возвращает `IO<Config>` с `{ dbHost: 'localhost', port: 5432 }`
   - `connectDB(config)` — принимает конфиг, возвращает `IO<Connection>`
   - `queryUsers(db)` — принимает соединение, возвращает `IO<User[]>`
   - `formatReport(users)` — принимает массив пользователей, возвращает `IO<string>`
7. Постройте пайплайн: `readConfig().flatMap(connectDB).flatMap(queryUsers).flatMap(formatReport)`
8. Добавьте индикатор: до `run()` — "Побочных эффектов: 0. Ничего не выполнено.", после — "Выполнено!"
9. Кнопка "run()" запускает цепочку и показывает лог выполненных шагов
10. Повторное нажатие запускает всё заново — IO можно выполнять многократно

## Чеклист

- [ ] Класс `IO<T>` с корректным типом `effect: () => T`
- [ ] `IO.of` создаёт IO из значения без побочных эффектов
- [ ] `map` и `flatMap` не вызывают `this.effect` — только создают новый IO
- [ ] `run()` вызывает `this.effect()` и возвращает результат
- [ ] Пайплайн из 4 шагов собирается через `flatMap`
- [ ] До `run()` никаких видимых эффектов нет
- [ ] После `run()` лог показывает все 4 шага с результатами
- [ ] Повторный `run()` работает корректно (IO выполняется заново)

## Как проверить себя

1. Убедитесь, что при загрузке компонента и до нажатия кнопки индикатор показывает 0 эффектов
2. Нажмите кнопку — шаги должны появляться по одному с задержкой
3. Нажмите ещё раз — лог должен обновиться (IO перезапускается)
4. Попробуйте намеренно вызвать `this.effect()` внутри `map` — убедитесь, что это нарушает ленивость

## Подсказки

- `flatMap` должен возвращать `new IO(() => fn(this.effect()).run())` — оба `this.effect()` и `.run()` вызываются только внутри нового `() =>`
- `map` — частный случай: `new IO(() => fn(this.effect()))`
- Аналогия: IO = рецепт приготовления блюда. Пока не скажете "готовь", ничего не происходит
