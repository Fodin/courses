# Задание 12.2. Композиция хуков

## Цель

Реализовать три компонуемых хука на FP-принципах: `useValidation` (pipe правил валидации), `useDebouncedValue` (дебаунс обновления), `useFilteredList` (composable фильтры).

## Требования

1. Реализуй `pipeRules(...rules)`: принимает произвольное количество `ValidationRule`, возвращает новое правило, которое запускает все правила подряд и объединяет все ошибки в один массив (через `flatMap`).
2. Реализуй фабрики правил: `checkRequired(msg)`, `checkMinLength(min, msg)`, `checkPattern(pattern, msg)`. Каждая возвращает `ValidationRule: (value: string) => string[]`.
3. Реализуй `useValidation(rules)`: хранит массив ошибок в состоянии, предоставляет функцию `touch(value)` которая запускает все правила и обновляет ошибки.
4. Реализуй `useDebouncedValue<T>(value, delay)`: возвращает дебаунсированное значение. Используй `useEffect` с `setTimeout` и обязательным `clearTimeout` в cleanup-функции.
5. Реализуй `useFilteredList<T>(items, filters)`: возвращает элементы, прошедшие все фильтры (`filters.every(f => f(item))`).
6. Реализуй фабрики фильтров: `byCategory(cat)`, `byPriceRange(min, max)`, `bySearchTerm(term)`.

## Чеклист

- [ ] `pipeRules` собирает ошибки от всех правил, не останавливается на первой
- [ ] `checkRequired` возвращает ошибку только если строка пустая (после trim)
- [ ] `checkMinLength` не срабатывает на пустой строке (required проверяет пустоту)
- [ ] `checkPattern` не срабатывает на пустой строке
- [ ] `useDebouncedValue` использует cleanup в useEffect
- [ ] При быстром вводе дебаунсированное значение отстаёт от реального
- [ ] `useFilteredList` применяет все фильтры одновременно (AND, не OR)
- [ ] `byCategory('All')` пропускает все элементы

## Как проверить себя

1. Введи пустую строку в поле "Имя" — появится ошибка "Обязательное поле".
2. Введи "ab" — появится "Минимум 3 символа", но не "Обязательное поле".
3. Введи "ab1" — появится "Только латинские буквы".
4. Введи "abc" — ошибок нет, показывается "Валидно".
5. Введи быстро несколько символов в поиск — дебаунсированное значение обновляется с задержкой.
6. Выбери категорию "Fruits" — отображаются только фрукты.
7. Сдвинь ползунок цены — список фильтруется по цене одновременно с категорией.
