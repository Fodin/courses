# Задание 9.2: Кастомный Node: Callout

## Цель

Реализовать блочную ноду `callout` ("врезка" / "заметка на полях") — контейнер, способный содержать несколько параграфов, с визуальным оформлением через `data`-атрибут типа.

## Требования

1. Создайте `Node.create({ name: 'callout', group: 'block', content: 'block+', ... })`
2. `parseHTML()` — распознавание `div[data-callout]`
3. `renderHTML()` — сериализация через `mergeAttributes(HTMLAttributes, { 'data-callout': '' })`
4. Добавьте команду `addCommands()` → `setCallout: () => ({ commands }) => commands.wrapIn(this.name)` — оборачивает текущий блок в callout
5. В React-компоненте кнопка "Вставить врезку" вызывает `editor.chain().focus().setCallout().run()`
6. Стилизуйте `[data-callout]` через CSS: рамка слева, светлый фон, отступ

## Чеклист

- [ ] Компонент называется `Task9_2` и экспортируется

## Как проверить себя

1. Поставьте курсор в параграф, нажмите "Вставить врезку" — блок должен получить визуальное оформление врезки
2. Нажмите `Enter` внутри врезки и напечатайте текст — новый параграф должен остаться внутри врезки (content: 'block+' это разрешает)
3. Проверьте HTML-вывод — должен быть виден `<div data-callout="">` с одним или несколькими `<p>` внутри
