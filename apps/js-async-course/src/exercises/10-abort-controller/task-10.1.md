# Задание 10.1: Отмена fetch с AbortController

## Цель

Реализовать интерактивную демонстрацию отмены длинного fetch-запроса через `AbortController`. Показать жизненный цикл сигнала: от создания до отмены, с визуальным прогресс-баром и логом событий.

## Требования

1. **Кнопка "Загрузить"** — запускает симулированный fetch с прогресс-баром (5 шагов по 700мс = ~3.5с):
   - Создаёт `new AbortController()`, сохраняет в `ref`
   - Передаёт `signal` в симулированный запрос
   - Обновляет прогресс-бар от 0% до 100%

2. **Кнопка "Отменить"** — вызывает `controller.abort(reason)`:
   - Активна только во время загрузки
   - После нажатия: `AbortError` ловится в `catch`, прогресс-бар становится красным
   - В лог добавляется запись `'controller.abort() вызван'`

3. **Прогресс-бар**:
   - Зелёный/синий при загрузке
   - Красный при отмене
   - Зелёный при успешном завершении

4. **Лог событий** (снизу):
   - `'fetch() started'` при запуске
   - `'progress X%'` на каждом шаге
   - `'controller.abort() вызван'` при нажатии кнопки отмены
   - `'AbortError caught'` в блоке catch

5. **Статус signal**:
   - Показывать `signal.aborted` (true/false)
   - Показывать `signal.reason` (строка)

6. **Сброс** — кнопка "Сброс" возвращает в начальное состояние

## Чеклист

- [ ] Компонент называется `Task10_1` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован и `t('task.10.1')` используется в заголовке
- [ ] `AbortController` создаётся в `ref` (не в state — иначе пересоздаётся при ре-рендере)
- [ ] `signal` передаётся в симулированный fetch через `signal.addEventListener('abort', ...)`
- [ ] Прогресс-бар меняет цвет в зависимости от статуса
- [ ] Лог событий отображает хронологию: start → progress → abort/done
- [ ] `signal.aborted` и `signal.reason` отображаются в реальном времени
- [ ] Кнопка "Загрузить" заблокирована во время загрузки
- [ ] Кнопка "Отменить" заблокирована в не-loading состоянии
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Нажмите "Загрузить" — прогресс-бар начинает расти, лог заполняется
2. На середине нажмите "Отменить" — прогресс-бар становится красным, лог показывает `AbortError caught`
3. Проверьте `signal.aborted = true` и `signal.reason` в панели статуса
4. Нажмите "Сброс" и дайте загрузке завершиться — прогресс достигнет 100%, статус "Завершено"
5. Убедитесь, что кнопка "Отменить" неактивна в состояниях `idle` и `done`
