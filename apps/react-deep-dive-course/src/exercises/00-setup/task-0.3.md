# Задание 0.3: Profiler API — замеряем рендеры

## Цель

Использовать встроенный `React.Profiler` для сбора данных о рендерах и отображать их в виде таблицы. Это научит тебя пользоваться Profiler API — инструментом, который пригодится на протяжении всего курса.

## Требования

1. Создать компонент `SlowComponent` — имитирует тяжёлый рендер с помощью синхронной задержки (пустой цикл ~1-2 мс). Принимает `value: number` в props.
2. Обернуть `SlowComponent` в `<Profiler id="slow-component" onRender={handleRender}>`.
3. Хранить историю рендеров в `useRef` (массив объектов). Каждый объект содержит: `phase`, `actualDuration`, `baseDuration`, `startTime`, `commitTime`.
4. Callback `handleRender` добавляет новую запись в массив и вызывает форс-ре-рендер чтобы таблица обновилась.
5. Отображать таблицу с колонками: `#`, `Phase`, `Actual (ms)`, `Base (ms)`.
6. Добавить две кнопки:
   - **"Обновить значение"** — изменяет `value`, переданный в `SlowComponent` (новый рендер с изменёнными props)
   - **"Тот же value"** — устанавливает то же значение (потенциальный bailout)

## Чеклист

- [ ] `SlowComponent` обёрнут в `<Profiler>` с корректными props
- [ ] `onRender` callback принимает все 6 аргументов и записывает их
- [ ] История рендеров хранится в `useRef` (не в `useState` — чтобы не вызывать лишних ре-рендеров)
- [ ] Таблица отображает каждую запись с округлёнными значениями (`.toFixed(2)`)
- [ ] Колонка `Phase` показывает `mount` при первом рендере и `update` при обновлениях
- [ ] Кнопки работают и вызывают рендеры с разным результатом

## Как проверить себя

1. При загрузке в таблице появляется первая строка с `phase = "mount"`.
2. Клик "Обновить значение" — добавляется строка с `phase = "update"`, `actualDuration` больше нуля.
3. Несколько кликов — видна история рендеров в хронологическом порядке.
4. Сравни `actualDuration` и `baseDuration` — если компонент не мемоизирован, они должны быть близки.
5. Попробуй обернуть `SlowComponent` в `React.memo` и нажать "Тот же value" — `actualDuration` станет почти нулевым.

> 💡 Подсказка: `onRender` callback передаётся как prop компоненту Profiler: `<Profiler id="..." onRender={fn}>`. Сигнатура функции: `(id, phase, actualDuration, baseDuration, startTime, commitTime) => void`.
