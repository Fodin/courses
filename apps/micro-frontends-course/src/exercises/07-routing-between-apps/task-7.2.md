# Задание 7.2: Конструктор таблицы маршрутов

## Цель

Создать визуальный конструктор конфигурации роутера для MFE-системы: таблица shell routes, раскрываемые секции с internal routes для каждого MFE, живой preview в двух форматах (JSON и React Router JSX), валидация пересечений и ошибок конфигурации.

## Требования

1. **Таблица Shell Routes** — отображает список верхнеуровневых маршрутов в виде таблицы с колонками: Path, MFE, Strategy, Exact. Форма добавления: поле path, поле mfe-name, селект strategy (lazy/eager), чекбокс exact. Кнопки управления порядком (↑/↓) и удаления для каждой строки.

2. **MFE Internal Routes** — список MFE в виде раскрываемых секций. Каждая секция: заголовок с именем MFE и счётчиком маршрутов, кнопка удаления MFE, внутри — список internal routes (relative path, component name, бейдж index). Форма добавления internal route: селект MFE, поле пути, поле компонента, чекбокс index. Кнопка добавления нового MFE (поле имени + кнопка).

3. **Live Preview** с двумя табами:
   - `router.config.json` — структура в формате JSON с ключами `shell.routes[]` и `mfes.{name}.routes[]`
   - `React Router JSX` — готовый код `createBrowserRouter([...])` с `lazy()` импортами для lazy-стратегии, `children[]` для internal routes, `Suspense` обёрткой

4. **Валидация** (запускается автоматически после каждого изменения):
   - Дублирующиеся path в shell routes
   - Wildcard (`*` или `/*`) не на последнем месте
   - MFE без ни одного internal route
   - Internal route path не начинается с `/`
   - Дублирующиеся пути внутри одного MFE
   
   Ошибки показываются красным блоком над конструктором. Статус валидации отображается в шапке preview (зелёный/красный).

5. Начальное состояние: Shell с тремя маршрутами (Home, /catalog/*, /cart/*) и двумя MFE (catalog с 3 маршрутами, cart с 2 маршрутами).

## Чеклист

- [ ] Таблица shell routes отображает все поля и позволяет удалять строки
- [ ] Кнопки ↑/↓ корректно меняют порядок маршрутов
- [ ] Добавление нового shell route через форму работает
- [ ] Раскрывающиеся секции MFE показывают/скрывают internal routes
- [ ] Форма добавления internal route добавляет маршрут в нужный MFE
- [ ] JSON preview обновляется в реальном времени при любом изменении
- [ ] JSX preview генерирует валидный код с lazy() для lazy-стратегии
- [ ] При ошибках валидации показывается красный блок с сообщениями
- [ ] Статус «✓ Конфигурация валидна» / «✕ N ошибок» виден в шапке preview

## Как проверить себя

1. Добавьте shell route `/profile/*` с MFE `profile` и стратегией `lazy`. Проверьте, что он появляется в таблице и в JSON preview.
2. Попробуйте добавить shell route с тем же путём, что уже есть — должна появиться ошибка «Дублирующийся shell маршрут».
3. Добавьте новый MFE `profile` через форму — секция должна появиться без маршрутов, показывая ошибку «MFE не имеет ни одного внутреннего маршрута».
4. Добавьте internal route без `/` в начале (например `orders`) — должна появиться ошибка.
5. Переключитесь на таб «React Router JSX» — убедитесь, что lazy MFE имеют `lazy(() => import(...))` и `<Suspense>` обёртку.
