# Задание 3.3 — Разорвать сразу два цикла вокруг общего файла (сложное)

## Цель

Научиться работать с графом, где часть рёбер — значения (трогать нельзя), а
часть — типы (нужно исправить), и не перепутать одно с другим при нескольких
файлах и двух отдельных циклах одновременно.

## Что дано

Пять файлов вокруг общего узла `b.ts`:

- `a.ts` (только чтение) — реально импортирует значение `bValue` из `b.ts`.
- `b.ts` (редактируется) — импортирует `A` из `a.ts` как тип (нужно
  исправить) и `dValue` из `d.ts` как значение (трогать нельзя).
- `c.ts` (только чтение) — сторонний потребитель `bValue`, в цикле не
  участвует.
- `d.ts` (редактируется) — импортирует `B` из `b.ts` как тип (нужно
  исправить).
- `e.ts` (только чтение) — сторонний потребитель `dValue`, в цикле не
  участвует.

Получаются два отдельных цикла: `a.ts ⇄ b.ts` и `b.ts ⇄ d.ts`.

## Требования

1. В `b.ts` переведите импорт `A` из `a.ts` в `import type`, оставив импорт
   `dValue` из `d.ts` без изменений — это реальная зависимость.
2. В `d.ts` переведите импорт `B` из `b.ts` в `import type`.
3. Не трогайте `a.ts`, `c.ts`, `e.ts`.
4. Нажмите «Проверить».

## Чеклист

- [ ] `b.ts` импортирует `A` через `import type`, а `dValue` — по-прежнему
      как значение
- [ ] `d.ts` импортирует `B` через `import type`
- [ ] Ни одного рантайм-цикла в графе не осталось
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

Отдельно разберите каждый из двух циклов. `a.ts ⇄ b.ts`: ребро `a.ts → b.ts`
(значение `bValue`) — реальная зависимость, а `b.ts → a.ts` (тип `A`) — нет,
его и правим. `b.ts ⇄ d.ts`: ребро `b.ts → d.ts` (значение `dValue`) —
реальная зависимость, её оставляем как есть, а `d.ts → b.ts` (тип `B`) —
типовое, его и правим.
