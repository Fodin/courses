# Задание 7.5 — Динамический import() в цепочке из трёх модулей (среднее)

## Цель

Разорвать цикл длиной 3: `start.ts → step-b.ts → step-c.ts → start.ts`, заменив один статический импорт на динамический.

## Что дано

- `start.ts` — экспортирует `start`, `finish`; вызывает `stepB` из `step-b.ts` (🔒 только чтение);
- `step-b.ts` — вызывает `stepC` из `step-c.ts` (🔒 только чтение);
- `step-c.ts` — импортирует `finish` статически из `start.ts` — это и замыкает цикл.

## Требования

1. В `step-c.ts` уберите статический `import { finish } from './start'`.
2. Сделайте `stepC` асинхронной функцией.
3. Внутри неё получите `finish` через `const { finish } = await import('./start')`.
4. Нажмите «Проверить» — все проверки должны стать зелёными.

## Чеклист

- [ ] `step-c.ts` не содержит статического импорта из `start.ts`
- [ ] `stepC` использует `await import('./start')` внутри тела функции
- [ ] Цикл в графе импортов отсутствует
- [ ] Пройти квиз уровня ≥ 80%
