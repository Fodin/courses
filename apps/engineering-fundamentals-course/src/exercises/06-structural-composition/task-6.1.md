# Задание 6.1: Квиз — Композиция, агрегация, делегирование

## Цель
Проверить понимание структурных паттернов: разница между наследованием и композицией, агрегацией и делегированием.

## Требования
1. Прочитайте теорию уровня 6 (README)
2. Пройдите квиз по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист
- [ ] Прочитана теория по композиции vs наследованию (IS-A vs HAS-A)
- [ ] Прочитана теория по агрегации и различию с композицией (время жизни объектов)
- [ ] Прочитана теория по делегированию и паттернам (Decorator, Strategy, Proxy)
- [ ] Прочитана теория по миксинам и трейтам
- [ ] Пройден квиз с результатом не менее 80%

## Как проверить себя
1. Откройте квиз и ответьте на все вопросы
2. Проверьте объяснения для неправильных ответов
3. Если результат ниже 80% — перечитайте соответствующие разделы теории
