# Задание 1.3: Счётчик символов

## Цель

Построить счётчик символов и слов, который обновляется через `onUpdate`, с ограничением максимального числа символов и визуальным предупреждением при приближении к лимиту.

## Требования

1. Создайте `editor` через `useEditor` с `StarterKit`
2. Заведите константу `MAX_CHARS = 280` (как в твиттере)
3. В `onUpdate` считайте количество символов через `editor.getText().length` (используйте `getText()`, а не `getHTML()`, чтобы не учитывать теги) и количество слов (разбейте `getText()` по пробелам, отфильтровав пустые строки)
4. Отобразите счётчик в формате `237 / 280` под редактором
5. Если символов больше 90% от лимита — счётчик должен окраситься в оранжевый
6. Если лимит превышен — счётчик красный, но **не блокируйте ввод** (просто предупреждение)
7. Отдельно выведите количество слов

## Чеклист

- [ ] Компонент называется `Task1_3` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.1.3')` используется в заголовке
- [ ] Счётчик символов использует `editor.getText().length`, а не `getHTML().length`
- [ ] Счётчик слов корректно считает слова, разделённые пробелами (без учёта лишних пробелов)
- [ ] Цвет счётчика меняется на оранжевый при >90% лимита и на красный при превышении
- [ ] Ввод текста не блокируется даже при превышении лимита
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Введите короткий текст — счётчик должен показывать актуальное число символов зелёным/обычным цветом
2. Введите текст, близкий к 280 символам (например, 260) — счётчик должен стать оранжевым
3. Продолжайте печатать, превысив 280 — счётчик должен стать красным, но ввод текста продолжит работать
4. Проверьте подсчёт слов на фразе из нескольких слов с двойными пробелами — лишние пробелы не должны создавать "пустые" слова
