# Задание 7.2: useForm — форма как состояние

## Цель

Реализовать универсальный хук `useForm<T>` для управления состоянием формы с валидацией. Компонент формы должен быть чистым слоем рендеринга — вся логика в хуке.

## Требования

1. Реализуйте интерфейс состояния формы:
   - `values: T` — текущие значения полей
   - `errors: Partial<Record<keyof T, string>>` — ошибки валидации
   - `touched: Partial<Record<keyof T, boolean>>` — поля, которых касался пользователь
   - `isSubmitting: boolean` — идёт ли отправка
2. Реализуйте хук `useForm<T>(initialValues: T, validate?: (values: T) => Partial<Record<keyof T, string>>)`:
   - `handleChange(field, value)` — обновляет значение поля; если поле уже `touched` — запускает валидацию этого поля
   - `handleBlur(field)` — помечает поле как `touched` и валидирует его
   - `handleSubmit(onSubmit)` — возвращает обработчик события формы; перед вызовом `onSubmit` помечает все поля как `touched`, запускает полную валидацию; если ошибок нет — вызывает `onSubmit(values)` и управляет флагом `isSubmitting`
   - `reset()` — возвращает форму в исходное состояние
3. Реализуйте компонент формы регистрации `RegistrationForm`, который использует `useForm`:
   - Поля: имя, email, пароль
   - Валидация: имя обязательно; email должен содержать `@`; пароль минимум 6 символов
   - Ошибки показываются только для `touched` полей
   - Кнопка отправки заблокирована во время `isSubmitting`
   - При успешной отправке форма сбрасывается и показывается сообщение об успехе

## Подсказки

- `touched[field]` используйте для условного показа ошибок: `{form.touched.name && form.errors.name && <span>...`
- Для пометки всех полей как `touched` используйте `Object.keys(values).reduce(...)`
- `isSubmitting` обновляйте через `finally`, чтобы он сбрасывался даже при ошибке
- Не забывайте `e.preventDefault()` в `handleSubmit`
- Тип `Partial<Record<keyof T, string>>` — удобная TypeScript-конструкция для необязательных ошибок по ключам

## Чеклист

- [ ] `useForm` принимает `initialValues` и опциональную функцию `validate`
- [ ] `handleChange` обновляет `values` и запускает валидацию если поле `touched`
- [ ] `handleBlur` помечает поле как `touched` и показывает ошибку
- [ ] `handleSubmit` валидирует все поля перед отправкой
- [ ] Ошибки показываются только для полей, которых касались
- [ ] `isSubmitting` управляет состоянием кнопки отправки
- [ ] `reset()` возвращает форму в исходное состояние
- [ ] Компонент `RegistrationForm` не содержит логики валидации

## Как проверить себя

Откройте форму и сразу нажмите "Отправить" — все поля должны показать ошибки (они все помечаются как touched). Заполните только email некорректно — ошибка появится после потери фокуса. Исправьте email — ошибка исчезнет на лету. Заполните все поля корректно и отправьте — должно появиться сообщение об успехе и форма сбросится.
