# Assignment 0.1: Quiz — Networking and Protocols

## Goal

Test understanding of network protocol basics: TCP/IP, HTTP versions, WebSocket, gRPC, DNS, and TLS.

## Requirements

1. Read the Level 0 theory (README)
2. Take a 5-question quiz on key concepts
3. For each question, select the correct answer (one or multiple)
4. Try to answer without looking at the theory

## Checklist

- [ ] Read theory on TCP/IP, HTTP/1.1 vs HTTP/2 vs HTTP/3
- [ ] Understand the difference between TCP and UDP
- [ ] Understand the multiplexing mechanism in HTTP/2
- [ ] Know the order of stages: DNS → TCP → TLS → HTTP
- [ ] Complete the quiz with at least 80% score

## How to Check Yourself

1. Open the quiz and answer all questions
2. Review explanations for incorrect answers
3. If score is below 80% — reread the relevant theory sections
