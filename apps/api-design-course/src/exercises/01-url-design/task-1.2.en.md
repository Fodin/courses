# Task 1.2 — Fix the URL Errors

## Goal

Learn to recognize typical URL anti-patterns: verbs in the path, wrong case, incorrect HTTP methods, actions in query params.

## Requirements

1. The component shows a list of 8–10 URLs with typical mistakes.
2. Each item contains: a "bad" URL with its method and an error type label.
3. The correct version is hidden by default.
4. A "Show answer" button reveals the corrected URL, method, and explanation.
5. A "Show all answers" button reveals all at once.
6. Errors cover different categories: verbs, case, plural, RPC style.

## Checklist

- [ ] At least 8 URLs with errors
- [ ] Each URL has an error type label
- [ ] The corrected version includes the correct method
- [ ] The explanation explains "why this is correct", not just "what to change"
- [ ] "Show all answers" button works
- [ ] Different types of errors are covered

## How to Check Yourself

Look at each "bad" URL and formulate the error yourself before clicking "Show answer". If your formulation matches the explanation — you have mastered the material.
