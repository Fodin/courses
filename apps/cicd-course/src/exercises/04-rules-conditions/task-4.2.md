# Задание 4.2: rules:changes — реакция на файлы

## Цель

Создать интерактивный симулятор `rules:changes` — файловое дерево репозитория, где можно отмечать изменённые файлы и видеть, какие CI-джобы при этом запустятся.

## Требования

1. Файловое дерево монорепо с тремя модулями: frontend/, backend/, docs/ и конфигурационные файлы в корне
2. Чекбоксы для каждого файла — отмечаем "изменён"
3. Кнопка "Выбрать случайные изменения" — выбирает 2-3 случайных файла
4. Кнопка "Сбросить" — снимает все чекбоксы
5. Список из 6 CI-джобов с rules:changes паттернами
6. Для каждого джоба — статус "запустится" / "пропущен" на основе пересечения изменённых файлов с glob-паттернами джоба
7. Счётчик: "изменено X файлов, запустится Y джобов"

## Структура файлового дерева

```
frontend/
  src/
    App.tsx
    components/Button.tsx
  package.json
  webpack.config.js
backend/
  src/
    server.go
    handlers/api.go
  go.mod
  Dockerfile
docs/
  README.md
  api-spec.yaml
.gitlab-ci.yml
docker-compose.yml
```

## CI-джобы и их паттерны

| Джоб | rules:changes паттерны |
|---|---|
| frontend-lint | frontend/**/* |
| frontend-test | frontend/**/* |
| backend-test | backend/**/*.go, backend/go.mod |
| docker-build | backend/Dockerfile |
| docs-publish | docs/**/* |
| full-pipeline | .gitlab-ci.yml |

## Чеклист

- [ ] Файловое дерево с чекбоксами, отображающее структуру папок с отступами
- [ ] Визуальное выделение изменённых файлов (фон/цвет)
- [ ] 6 джобов с отображением их glob-паттернов
- [ ] Реактивное обновление статусов джобов при изменении чекбоксов
- [ ] Для каждого активного джоба — список совпавших файлов
- [ ] Счётчик изменений и активных джобов в заголовке
- [ ] Кнопки "Случайные изменения" и "Сбросить"

## Как проверить себя

- Отметь только `docs/README.md` — должен запуститься только docs-publish
- Отметь `backend/Dockerfile` — должны запуститься backend-test (нет! нет go-файлов) и docker-build
- Отметь `.gitlab-ci.yml` — должен запуститься full-pipeline
- Отметь файлы в обоих frontend/ и backend/ — должны запуститься джобы для обоих модулей
- Сбрось все — ни один джоб не должен запускаться
