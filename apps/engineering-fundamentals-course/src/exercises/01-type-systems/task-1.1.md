## Цель
Проверить понимание систем типов: номинальная vs структурная типизация, вариантность, дженерики и их ограничения.

## Требования
1. Прочитайте теорию уровня 1 (README)
2. Пройдите квиз по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ
4. Постарайтесь ответить без подглядывания в теорию
