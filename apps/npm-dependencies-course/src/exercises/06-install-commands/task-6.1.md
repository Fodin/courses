# Задание 6.1: Квиз — Команды установки и обновления

## Цель

Научиться выбирать правильную команду для каждой задачи: установка, воспроизводимая сборка, обновление, очистка зависимостей.

## Требования

1. Прочитайте теорию уровня (Кратко и Подробно)
2. Пройдите квиз
3. Для каждого вопроса разберите объяснения всех вариантов
