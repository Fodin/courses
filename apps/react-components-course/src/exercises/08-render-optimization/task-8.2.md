# Задание 8.2: Паттерн "state down, children up" — без единого memo

## Цель

Освоить структурные оптимизации рендеринга: научиться перемещать state и компоненты так, чтобы лишние ре-рендеры исчезли без использования `React.memo`.

## Контекст

Перед тобой компонент настроек темы: цветовой пикер, который обновляет background страницы. Рядом с ним — тяжёлый компонент `HeavyPreview` (симулирует долгий рендер через render counter). Сейчас `HeavyPreview` ре-рендерится при каждом изменении цвета, хотя не использует цвет для отображения.

Задача — исправить это **без `React.memo`**, только структурными изменениями.

## Требования

1. Добавь render counters в `HeavyPreview` и в компонент с пикером — чтобы видеть проблему
2. Часть 1 — **State down**: если color-пикер и его state можно вынести в отдельный компонент, сделай это. `HeavyPreview` переедет в родителя и перестанет быть потомком компонента со state
3. Часть 2 — **Children up**: альтернативный подход — пусть компонент со state принимает `children`. Тогда `HeavyPreview` создаётся снаружи и не пересоздаётся при изменении state
4. Реализуй **оба** подхода — покажи их рядом с объяснением что происходит
5. Убедись что `HeavyPreview` не ре-рендерится при изменении цвета — только когда изменяются его собственные пропсы

## Подсказки

- **State down**: вынеси `useState(color)` и `input[type=color]` в отдельный `ColorPicker` компонент. `HeavyPreview` останется в `Page` — рядом, но уже не потомком `ColorPicker`
- **Children up**: сделай компонент `ColorWrapper({ children })` — он хранит state и рендерит `{children}`. Снаружи: `<ColorWrapper><HeavyPreview /></ColorWrapper>`. `HeavyPreview` создаётся в `Page`, не в `ColorWrapper` — значит не зависит от его state
- Ключевое понимание: React не пересоздаёт JSX-элемент, если он передаётся как `children` извне
- `HeavyPreview` может принимать любые стабильные пропсы для демонстрации

## Чеклист

```
[ ] Render counters добавлены и видны в UI
[ ] Реализован вариант "State down": ColorPicker как отдельный компонент
[ ] В варианте "State down" HeavyPreview НЕ ре-рендерится при смене цвета
[ ] Реализован вариант "Children up": ColorWrapper принимает children
[ ] В варианте "Children up" HeavyPreview НЕ ре-рендерится при смене цвета
[ ] Оба варианта показаны рядом с подписями
[ ] React.memo НЕ использован ни в одном из вариантов
```

## Как проверить себя

Открой компонент и меняй цвет через пикер. Счётчик рендеров у цветового пикера должен расти. Счётчик `HeavyPreview` — оставаться неизменным в обоих вариантах.
