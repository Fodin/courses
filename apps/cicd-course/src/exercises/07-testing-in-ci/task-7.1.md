# Задание 7.1: Пирамида тестов в пайплайне

## Цель

Создать интерактивную визуализацию пирамиды тестов с настройкой структуры пайплайна GitLab CI. Показать, как разные типы тестов отображаются в stages и почему важен порядок.

## Требования

1. Отобразить визуальную пирамиду с тремя уровнями: Unit (основание), Integration (середина), E2E (вершина)
2. Каждый уровень пирамиды кликабелен — при выборе подсвечивается и показывает детали: типичное время выполнения, процент от всех тестов, нужны ли внешние зависимости
3. Показать соответствующий pайплайн YAML с stages, который обновляется при выборе уровня
4. Реализовать чекбоксы для включения/отключения каждого типа тестов в пайплайне
5. При отключении более быстрых тестов показать предупреждение о нарушении принципа fail-fast
6. Показать итоговое ожидаемое время пайплайна как сумму выбранных этапов

## Чеклист

- [ ] Визуальная пирамида с тремя уровнями разной ширины (Unit — широкий, E2E — узкий)
- [ ] Цветовое кодирование уровней (зелёный — unit, синий — integration, оранжевый — e2e)
- [ ] При клике на уровень — блок с детальной информацией (время, % тестов, зависимости)
- [ ] YAML-блок с актуальными stages для выбранного набора тестов
- [ ] Чекбоксы для включения/отключения типов тестов
- [ ] Предупреждение при нарушении порядка (E2E без unit-тестов)
- [ ] Отображение итогового времени пайплайна

## Как проверить себя

1. Кликни на каждый уровень пирамиды — убедись, что показывается разная информация
2. Отключи Unit-тесты — должно появиться предупреждение о принципе fail-fast
3. Включи только E2E — время пайплайна должно показать "~20 мин"
4. Включи все три уровня — YAML должен содержать stages: [lint, unit-test, integration, e2e, deploy]
5. Проверь, что YAML обновляется при изменении чекбоксов

## Подсказки

- Пирамиду можно нарисовать через `div` с `clipPath` или через CSS `border` (треугольники через border trick)
- Проще всего — три прямоугольника разной ширины, центрированные, с разными цветами
- Используй `useState` для хранения `selectedLevel` (строка) и `enabledTypes` (Set или массив)
- Время пайплайна — просто сумма констант: unit ≈ 2 мин, integration ≈ 5 мин, e2e ≈ 15 мин
- YAML собирай через template literal с условными блоками
