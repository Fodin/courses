# Задание 15.2: Мастер-конструктор архитектурного документа

## Цель

Реализовать 6-шаговый wizard для создания полного архитектурного документа (ADR) MFE-платформы. Каждый шаг собирает один аспект архитектуры: MFE, shared deps, event-контракты, routing, deploy-стратегии, мониторинг. Финальный экран генерирует ADR в Markdown-формате и оценивает качество решений по 10-пунктовому чеклисту.

## Требования

1. Реализовать progress bar из 6 шагов с метками (MFE / Shared Deps / Contracts / Routing / Deploy / Monitoring): выполненные шаги подсвечиваются синим + галочка, текущий — голубой
2. Шаг 1 (MFE): список карточек с 4 полями (имя, домен, framework-select, команда), кнопки Добавить/Удалить
3. Шаг 2 (Shared Deps): кнопки-теги для добавления dep из предопределённого списка, для каждого выбранного — strategy-select (module-federation/import-map/cdn) + singleton-чекбокс
4. Шаг 3 (Contracts): для каждого контракта — select источника MFE, select получателя MFE, поле события (monospace), поле payload. Блокировать если < 2 MFE
5. Шаг 4 (Routing): добавление маршрутов MFE → path + lazy-чекбокс. Path отображать в фиолетовом monospace
6. Шаг 5 (Deploy): кнопка "Автозаполнить все MFE" + для каждого MFE strategy-select + rollback-чекбокс
7. Шаг 6 (Monitoring): кнопка "Автозаполнить все MFE" + для каждого MFE SLO-select + errorBoundary-чекбокс + circuitBreaker-чекбокс
8. Кнопки навигации: "Назад" (заблокирован на шаге 1) и "Далее →" (шаги 1-5) / "Сгенерировать ADR" (зелёный, шаг 6)
9. После нажатия "Сгенерировать ADR": показать ADR в monospace-панели (Markdown-формат) + чеклист с 10 пунктами (✓/✗)
10. Чеклист оценивает: наличие MFE (≥2), у всех есть домен, у всех есть команда, наличие shared deps, контрактов, routing, deploy-конфигов, хоть один rollback, мониторинг, у всех error boundary

## Чеклист

- [ ] Progress bar: 6 шагов, выполненные — синие с ✓, текущий — голубой
- [ ] Шаг 1: добавление/удаление MFE, все 4 поля редактируемы
- [ ] Шаг 2: кнопки-теги меняют цвет при выборе, стратегия и singleton доступны для каждого dep
- [ ] Шаг 3: выбор источника и получателя из списка MFE с шага 1; блокировка при < 2 MFE
- [ ] Шаг 4: маршруты с path в фиолетовом monospace, lazy чекбокс работает
- [ ] Шаг 5: Автозаполнить добавляет все MFE у которых нет deploy-конфига
- [ ] Шаг 6: Автозаполнить добавляет все MFE у которых нет мониторинга
- [ ] "Назад" заблокирован на шаге 1, навигация между шагами работает
- [ ] ADR генерируется в корректном Markdown-подобном формате со всеми 6 секциями
- [ ] Чеклист: все 10 пунктов отображаются с ✓/✗ на основе реальных данных
- [ ] Скор чеклиста: зелёный ≥8/10, жёлтый ≥5, красный <5
- [ ] Кнопка "Скопировать ADR" вызывает navigator.clipboard.writeText

## Как проверить себя

1. На шаге 1 добавьте 3 MFE (catalog, cart, checkout) с доменами и командами — progress bar должен показывать шаг 1 активным
2. Перейдите на шаг 3 — в selects должны быть доступны все 3 MFE из шага 1
3. На шаге 5 нажмите "Автозаполнить" — все 3 MFE должны появиться с Blue/Green и rollback: true
4. На шаге 6 нажмите "Сгенерировать ADR" — должна появиться документ с 6 секциями
5. В чеклисте: если не добавили ни одного контракта — пункт "Определены event-контракты" должен быть ✗
6. Чеклист 10/10: добавьте по 1 записи в каждую секцию, включите ErrorBoundary для всех MFE мониторинга
