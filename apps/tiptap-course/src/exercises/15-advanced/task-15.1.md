# Задание 15.1: Decorations

## Цель

Реализовать live-поиск по документу с подсветкой всех совпадений через `Decoration`, управляемый состоянием ProseMirror-плагина, обновляемым через `setMeta`.

## Требования

1. Создайте `PluginKey<{ query: string }>('search')`
2. Реализуйте `Plugin` с `state: { init, apply }`, хранящим текущий поисковый запрос
3. `props.decorations(state)` — находит все вхождения `query` в тексте документа и подсвечивает их через `Decoration.inline`
4. В React-компоненте — текстовое поле поиска; при изменении вызывайте `editor.view.dispatch(editor.state.tr.setMeta(searchKey, { query }))`
5. Выведите количество найденных совпадений

## Чеклист

- [ ] Компонент называется `Task15_1` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.15.1')` используется в заголовке
- [ ] Ввод в поле поиска подсвечивает все совпадения в реальном времени
- [ ] Очистка поля поиска убирает подсветку
- [ ] Количество совпадений отображается корректно
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Введите в поле поиска слово, которое встречается в тексте несколько раз — все вхождения должны подсветиться
2. Измените запрос — старая подсветка должна исчезнуть, новая появиться
3. Очистите поле — подсветка должна пропасть полностью
4. Проверьте счётчик совпадений — число должно точно соответствовать количеству подсвеченных фрагментов
