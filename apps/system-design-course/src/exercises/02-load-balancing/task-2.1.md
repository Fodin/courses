# Задание 2.1: Квиз — Балансировка нагрузки

## Цель

Проверить понимание основ балансировки нагрузки: L4 vs L7, алгоритмы распределения, health checks, consistent hashing, sticky sessions.

## Требования

1. Прочитайте теорию уровня 2 (README)
2. Пройдите квиз из 5 вопросов по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ (один или несколько)
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист

- [ ] Прочитана теория по L4 и L7 балансировке
- [ ] Понятна разница между алгоритмами (Round Robin, Weighted, Least Connections, IP Hash, Consistent Hashing)
- [ ] Понятен механизм consistent hashing и virtual nodes
- [ ] Знакомы с active и passive health checks
- [ ] Понятны проблемы sticky sessions
- [ ] Пройден квиз с результатом не менее 80%

## Как проверить себя

1. Откройте квиз и ответьте на все вопросы
2. Проверьте объяснения для неправильных ответов
3. Если результат ниже 80% — перечитайте соответствующие разделы теории
