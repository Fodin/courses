# Задание 0.2: Container/Presentational разделение

## Цель

Разделить монолитный `UserProfile` на два компонента: `UserProfileContainer` (загружает и хранит данные) и `UserProfileView` (только отображение). Это классический паттерн Smart/Dumb компонентов.

## Требования

1. Создайте интерфейс `User` с полями: `id`, `name`, `email`, `role`, `avatar`, `isOnline`, `joinedAt`
2. Создайте `UserProfileView` — dumb компонент, который принимает `user: User` и отображает профиль. У него нет state, нет fetch, нет side effects
3. Создайте `UserProfileContainer` — smart компонент, который:
   - Хранит `user`, `loading`, `error` в state
   - Симулирует загрузку данных (setTimeout 1 секунда)
   - Показывает спиннер во время загрузки
   - Показывает сообщение об ошибке при ошибке
   - Рендерит `UserProfileView` с загруженными данными
4. Компонент `Task0_2` рендерит `UserProfileContainer`
5. Добавьте кнопку "Перезагрузить" в контейнере для повторной имитации загрузки

## Подсказки

- `UserProfileView` — максимально "тупой": только props → JSX. Его можно тестировать без любых моков
- `UserProfileContainer` управляет жизненным циклом данных: загрузка, успех, ошибка
- Используйте `useEffect` для имитации загрузки (setTimeout внутри)
- Кнопка "Перезагрузить" должна сбрасывать state и запускать загрузку заново

## Чеклист

- [ ] Интерфейс `User` определён со всеми полями
- [ ] `UserProfileView` не имеет state и side effects
- [ ] `UserProfileContainer` управляет `loading`, `error`, `user`
- [ ] Во время загрузки показывается индикатор (текст или анимация)
- [ ] При "ошибке" показывается сообщение (можно симулировать случайно)
- [ ] Кнопка "Перезагрузить" работает
- [ ] `Task0_2` рендерит контейнер

## Как проверить себя

1. При первом рендере должна появиться надпись "Загрузка..."
2. Через секунду должен появиться профиль пользователя
3. Нажмите "Перезагрузить" — снова "Загрузка...", затем профиль
4. Попробуйте передать `UserProfileView` напрямую с захардкоженным объектом — он должен работать без контейнера
