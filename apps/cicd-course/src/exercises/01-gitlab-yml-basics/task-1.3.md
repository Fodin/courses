# Задание 1.3: Ключевое слово script

## Цель

Разобраться в тонкостях ключевых слов `script`, `before_script` и `after_script`: как они взаимодействуют, что происходит при ошибках, и как правильно организовывать многострочные команды.

---

## Что нужно сделать

Создай компонент `Task1_3`, который симулирует выполнение CI job'а с консольным выводом. Студент видит, как выполняются команды и как exit code влияет на результат.

### Требования

1. Определи TypeScript-интерфейс `ScriptLine`:
   - `command` — текст команды
   - `output` — вывод команды (строка)
   - `exitCode` — код возврата (0 = успех, любое другое = ошибка)
   - `section` — `'before_script' | 'script' | 'after_script'`

2. Создай три предустановленных сценария (`ScenarioId: 'success' | 'script-fail' | 'before-fail'`):
   - **"Успешное выполнение"**: все команды возвращают exit code 0
   - **"Ошибка в script"**: одна команда в `script` возвращает exit code 1
   - **"Ошибка в before_script"**: команда в `before_script` возвращает exit code 1

3. Реализуй "консольный" вывод:
   - Тёмный фон (например, `#1e1e1e`), зелёный или белый текст
   - Каждая строка начинается с `$` для команд
   - Вывод команды идёт следующей строкой без `$`
   - Строки с ошибкой выделяются красным

4. Реализуй симуляцию выполнения с задержкой через `useState` + `useEffect`:
   - Команды появляются одна за другой с интервалом ~500мс
   - При ошибке в `script` — следующие команды `script` не выполняются
   - `after_script` выполняется всегда (даже после ошибки в `script`)
   - `after_script` не выполняется если упал `before_script`

5. В конце показывай итог: "Job succeeded" (зелёный) или "Job failed" (красный)

6. Добавь кнопки для выбора сценария и кнопку "Запустить"

---

## Ожидаемый результат

- Три кнопки выбора сценария
- Консоль в тёмном стиле с пошаговым выводом команд
- Визуальное разделение секций (before_script / script / after_script)
- Наглядная демонстрация того, что after_script выполняется при ошибке в script

---

## Как проверить себя

1. Выбери сценарий "Успешное выполнение" и нажми "Запустить" — все команды зелёные, финальный статус "Job succeeded"?
2. Выбери "Ошибка в script" — after_script всё равно выполнился, но Job failed?
3. Выбери "Ошибка в before_script" — after_script не выполнился, и Job failed?
4. Видишь визуальную границу между секциями before_script, script и after_script?
