# Задание 5.1: Квиз — Очереди сообщений и асинхронная обработка

## Цель

Проверить понимание очередей сообщений, паттернов доставки, гарантий и event-driven архитектуры.

## Требования

1. Прочитайте теорию уровня 5 (README)
2. Пройдите квиз из 5 вопросов по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ (один или несколько)
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист

- [ ] Прочитана теория по sync vs async коммуникации
- [ ] Понятна разница между Queue (Point-to-Point) и Topic (Pub/Sub)
- [ ] Понятны гарантии доставки: at-most-once, at-least-once, exactly-once
- [ ] Знакомы с Dead Letter Queue и её назначением
- [ ] Понятна разница между RabbitMQ и Kafka
- [ ] Знакомы с Kafka partitions и consumer groups
- [ ] Понятна роль idempotency при at-least-once
- [ ] Пройден квиз с результатом не менее 80%

## Как проверить себя

1. Откройте квиз и ответьте на все вопросы
2. Проверьте объяснения для неправильных ответов
3. Если результат ниже 80% — перечитайте соответствующие разделы теории
