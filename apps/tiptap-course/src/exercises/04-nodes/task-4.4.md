# Задание 4.4: CodeBlock

## Цель

Реализовать блок кода без подсветки синтаксиса (встроенный `codeBlock` из `StarterKit`) и продемонстрировать переключение в него/из него.

## Требования

1. Создайте `editor` с `StarterKit`
2. Кнопка "Code Block" — `toggleCodeBlock()`, подсветка через `isActive('codeBlock')`
3. Начальный контент должен содержать один готовый блок кода с многострочным примером
4. Стилизуйте `<pre><code>` через CSS: моноширинный шрифт, тёмный или светло-серый фон, отступы
5. Продемонстрируйте, что нажатие `Enter` внутри блока кода создаёт новую строку **внутри** блока, а не выходит из него (а тройной `Enter` на пустой строке — выходит, это поведение "из коробки")

## Чеклист

- [ ] Компонент называется `Task4_4` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.4.4')` используется в заголовке
- [ ] Кнопка переключает блок кода корректно
- [ ] Блок кода стилизован и визуально отличим от обычного текста
- [ ] Многострочный ввод внутри блока кода работает (Enter не выходит из блока раньше времени)
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Поставьте курсор в параграф, нажмите "Code Block" — блок должен превратиться в моноширинный блок кода
2. Введите несколько строк кода, используя `Enter` между ними — все строки должны остаться внутри одного блока
3. На пустой строке в конце блока нажмите `Enter` дважды — курсор должен выйти из блока кода в обычный параграф
