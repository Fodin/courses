# Задание 0.1: Квиз — Сеть и протоколы

## Цель

Проверить понимание основ сетевых протоколов: TCP/IP, HTTP-версий, WebSocket, gRPC, DNS и TLS.

## Требования

1. Прочитайте теорию уровня 0 (README)
2. Пройдите квиз из 5 вопросов по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ (один или несколько)
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист

- [ ] Прочитана теория по TCP/IP, HTTP/1.1 vs HTTP/2 vs HTTP/3
- [ ] Понятна разница между TCP и UDP
- [ ] Понятен механизм мультиплексинга в HTTP/2
- [ ] Известен порядок этапов: DNS → TCP → TLS → HTTP
- [ ] Пройден квиз с результатом не менее 80%

## Как проверить себя

1. Откройте квиз и ответьте на все вопросы
2. Проверьте объяснения для неправильных ответов
3. Если результат ниже 80% — перечитайте соответствующие разделы теории
