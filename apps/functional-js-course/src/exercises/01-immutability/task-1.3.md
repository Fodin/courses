# Задание 1.3: Immer produce

## Цель

Сравнить два подхода к иммутабельным обновлениям стейта: ручной spread и Immer `produce`.
Почувствовать разницу в читаемости и количестве кода.

## Требования

1. Создайте тип `Todo = { id: number; text: string; done: boolean }` и стейт
   `{ todos: Todo[]; nextId: number }` с двумя начальными задачами.
2. Реализуйте три операции двумя способами каждую:
   - **Добавить todo** — ручной: `{ ...state, todos: [...state.todos, newItem], nextId: state.nextId + 1 }`,
     Immer: `produce(state, draft => { draft.todos.push(newItem); draft.nextId++ })`
   - **Toggle done** — ручной: `.map(t => t.id === id ? { ...t, done: !t.done } : t)`,
     Immer: находим todo в `draft` и меняем `todo.done`
   - **Удалить todo** — ручной: `.filter(t => t.id !== id)`,
     Immer: `draft.todos.splice(idx, 1)`
3. Отобразите две колонки с кодом операций (ручной и Immer) — код переключается в зависимости от последнего действия.
4. Показывайте счётчик: "Строк кода: ручной X vs Immer Y" и процент экономии.
5. Поле ввода для текста новой задачи + кнопка "Добавить".
6. Для каждого todo в списке — кнопки "Done/Undone" и "Del".
7. История последних 5 состояний в виде краткого JSON.

## Чеклист

- [ ] Тип `Todo` объявлен и строго типизирован
- [ ] `import { produce } from 'immer'` присутствует
- [ ] Все три операции реализованы через `produce`
- [ ] Код Immer версий короче ручных на каждую операцию
- [ ] Счётчик строк кода обновляется корректно
- [ ] История обновляется после каждой операции
- [ ] Список todo отображает статус `done` визуально (зачёркнутый текст)
- [ ] `nextId` корректно инкрементируется при добавлении

## Как проверить себя

Добавьте несколько задач через поле ввода — проверьте что `nextId` растёт.

Нажмите "Done" на задаче — текст должен зачеркнуться.
Нажмите снова — должен разлиниться (toggle).

Нажмите "Del" — задача исчезает.

В колонке кода: когда вы добавляете — показывается код `add`,
когда делаете toggle — код `toggle`, при удалении — код `delete`.

Убедитесь что ручной код и Immer-код дают одинаковый результат.

Подсказка: для поиска по id в Immer используйте `draft.todos.find(t => t.id === id)`.
Proxy позволяет напрямую присваивать свойства найденного объекта.
