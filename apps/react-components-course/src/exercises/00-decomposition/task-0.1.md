# Задание 0.1: Разбить монолитный ProductPage

## Цель

Взять монолитный компонент `ProductPage` (~200 строк) и декомпозировать его на четыре независимых компонента: `ProductCard`, `ReviewsList`, `AddToCartForm`, `RelatedProducts`.

## Требования

1. Создайте компонент `ProductCard`, который принимает объект `product` и отображает фото, название, описание и цену
2. Создайте компонент `ReviewsList`, который принимает массив `reviews` и отображает каждый отзыв с автором, рейтингом звёздочками и текстом
3. Создайте компонент `AddToCartForm`, который управляет количеством товара (`useState`) и имеет кнопку "В корзину" с визуальным подтверждением
4. Создайте компонент `RelatedProducts`, который принимает массив `products` и отображает их в горизонтальную плитку
5. Компонент `Task0_1` должен быть оркестратором: хранит данные в state, рендерит четыре дочерних компонента
6. Каждый компонент типизирован — никакого `any`

## Подсказки

- Сначала определите интерфейсы (`Product`, `Review`) — это поможет понять, какие props нужны
- `AddToCartForm` управляет только своим локальным state (количество, статус "добавлено")
- `ProductCard` и `ReviewsList` — dumb компоненты, у них нет state
- Начните с перемещения JSX, потом уберите лишние зависимости

## Чеклист

- [ ] Интерфейсы `Product` и `Review` определены
- [ ] `ProductCard` принимает `product: Product` и рендерит фото, название, цену
- [ ] `ReviewsList` принимает `reviews: Review[]` и рендерит список
- [ ] `AddToCartForm` имеет state для количества и статуса добавления
- [ ] `RelatedProducts` принимает `products: Product[]` и рендерит плитку
- [ ] `Task0_1` рендерит все четыре компонента
- [ ] Нет `any` в типах

## Как проверить себя

Откройте задание в браузере. Вы должны увидеть:
- Карточку товара с изображением и ценой
- Форму с полем количества и кнопкой "В корзину" (кнопка меняет текст после нажатия)
- Список отзывов со звёздочками
- Ряд похожих товаров

Попробуйте нажать "В корзину" — кнопка должна показать "Добавлено!" на 2 секунды.
