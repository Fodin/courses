# Задание 8.1: Пинг-понг генератора — визуализация caller ↔ generator

## Цель

Реализовать компонент, который наглядно показывает двустороннее взаимодействие между caller-кодом и генератором: кто сейчас активен, что передаётся через `yield`, и как значение возвращается обратно через `.next(value)`.

## Требования

1. **Два столбца** — "Caller" (левый, синий) и "Generator" (правый, фиолетовый):
   - Каждый столбец содержит отображение кода с подсветкой активной строки
   - Цвет рамки подсветки соответствует стороне (`#60a5fa` / `#a78bfa`)

2. **Индикатор активной стороны** — бейдж в шапке показывает "Активен: CALLER" или "Активен: GENERATOR"

3. **Центральная колонка со стрелками** — между столбцами отображаются:
   - Стрелка → при передаче `.next(value)` в генератор
   - Стрелка ← при `yield value` обратно caller-у
   - Объект `{ value, done }` при получении результата

4. **Шаговая навигация** — кнопка "Следующий шаг →" переводит к следующему событию в последовательности ping-pong взаимодействия

5. **Лог** — под основным блоком накапливается лог всех вызовов с результатами

6. **Сброс** — кнопка возвращает в исходное состояние (шаг 0, лог очищен)

7. **Отображение досрочного завершения** — внизу компонента справочная информация о `gen.return()` и `gen.throw()`

8. **Последовательность шагов** для генератора `pingpong()`:
   - Создание генератора
   - `.next()` → `yield 'ping'` → `{ value: 'ping', done: false }`
   - `.next('pong')` → `msg1 = 'pong'` → `yield msg1` → `{ value: 'pong', done: false }`
   - `.next('done')` → генератор завершается → `{ value: undefined, done: true }`

## Как проверить себя

1. Откройте компонент — должен отображаться шаг 1 (создание генератора), индикатор "CALLER"
2. Нажимайте "Следующий шаг" — после второго нажатия должно появиться `yield 'ping'` с индикатором "GENERATOR"
3. На шаге 4 caller должен получить `{ value: "ping", done: false }`
4. На шаге 5 в центральной колонке должна быть стрелка → с подписью `.next("pong")`
5. На последнем шаге кнопка заблокирована, показан `done: true`
6. "Сброс" возвращает к шагу 1, лог очищается
