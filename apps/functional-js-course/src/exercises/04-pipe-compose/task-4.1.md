# Задание 4.1 — Реализация pipe и compose

## Цель

Реализовать `pipe` и `compose`, понять разницу в порядке выполнения и построить интерактивный визуализатор пошагового применения функций.

## Требования

1. Реализуйте функцию `pipe(...fns)`:
   - Принимает произвольное количество функций
   - Возвращает функцию, применяющую их слева направо
   - `pipe(f, g, h)(x)` = `h(g(f(x)))`

2. Реализуйте функцию `compose(...fns)`:
   - То же что pipe, но функции применяются справа налево
   - `compose(f, g, h)(x)` = `f(g(h(x)))`

3. Создайте палитру из минимум 6 строковых функций: `trim`, `toLower`, `toUpper`, `capitalize`, `addExclaim`, `getLength`

4. Добавьте интерфейс построения пайплайна:
   - Кнопки палитры добавляют функцию в цепочку (повторное нажатие — снова добавляет)
   - Функции в цепочке можно удалять по одной
   - Переключатель `pipe`/`compose` меняет режим

5. Поле ввода строки — изменение сбрасывает результат

6. Кнопка "Выполнить" запускает пайплайн и показывает пошаговую таблицу:
   - Строка 0: исходное значение
   - Строки 1..N: имя функции + результат после неё
   - Последняя строка выделена как итог

## Чеклист

- [ ] `pipe(f, g)(x)` применяет f сначала, g потом
- [ ] `compose(f, g)(x)` применяет g сначала, f потом
- [ ] `pipe` и `compose` с одними и теми же функциями в обратном порядке дают одинаковый результат
- [ ] Таблица показывает промежуточный результат после каждого шага
- [ ] Переключатель режима перестраивает отображение цепочки
- [ ] Пустой пайплайн блокирует кнопку "Выполнить"

## Как проверить себя

Добавьте в пайплайн `trim` → `toLower` → `capitalize` и введите `'  hello world  '`.
В таблице должно быть: `'hello world'` → `'hello world'` → `'Hello world'`.

Переключите на compose. Добавьте те же функции в том же порядке — результат изменится,
так как теперь `capitalize` применится первым, а `trim` последним.

**Подсказка:** pipe использует `reduce`, compose — `reduceRight`. Всё остальное одинаково.
