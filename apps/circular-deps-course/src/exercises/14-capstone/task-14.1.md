# Задание 14.1 — Распутать модульный граф: один цикл (простое)

## Цель

На небольшом графе из двух модулей применить один подходящий приём курса и разорвать цикл.

## Что дано

- `order.ts` — тип `Order` и функция `summarize`, которая зовёт `invoiceTotal` из `invoice.ts` (🔒 только чтение).
- `invoice.ts` — функция `invoiceTotal`, которая принимает параметр типа `Order`, но импортирует этот тип обычным (не типовым) импортом из `order.ts`. Значение `order.ts` при этом нигде не используется — нужна только форма объекта.

## Требования

1. Определите диагноз: цикл `order.ts` ⇄ `invoice.ts` существует только из-за того, что `Order` используется как тип, а импортирован как значение.
2. Замените импорт в `invoice.ts` на `import type { Order } from './order'`.
3. Не меняйте `order.ts` — он уже корректен.
4. Нажмите «Проверить» — цикл должен исчезнуть из графа рантайм-импортов.

## Чеклист

- [ ] Диагностировал цикл как типовой, а не рантайм
- [ ] Импорт `Order` в `invoice.ts` помечен как `import type`
- [ ] Проверка `noRuntimeCycles()` — зелёная
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

Мысленно постройте граф рёбер: если хотя бы одно из двух рёбер цикла — `import type`, оно не участвует в рантайм-графе, и цикла как такового больше нет.
