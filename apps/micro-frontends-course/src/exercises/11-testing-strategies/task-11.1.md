# Задание 11.1: Визуализатор пирамиды тестирования

## Цель

Создать интерактивный визуализатор пирамиды тестирования для MFE-архитектуры, где каждый слой кликабелен и показывает детали тестирования, а toggles позволяют включать/выключать уровни для расчёта pipeline.

## Требования

1. Отобразить пирамиду из 5 слоёв (снизу вверх): Unit, Contract, Integration, E2E, Visual
2. Каждый слой — кликабельный элемент, при клике справа показываются:
   - Описание: что тестируется на этом уровне в контексте MFE
   - Пример кода теста (Jest/Pact/Playwright)
   - Метрики: скорость, надёжность, стоимость поддержки
3. Для каждого слоя — toggle (включить/выключить участие в pipeline)
4. Справа снизу: Coverage map — 4 MFE (Shell, Catalog, Cart, Profile) с прогресс-барами для каждого уровня тестирования
5. Disabled слои: coverage bars скрываются (ширина 0), в MFE отображается «—»
6. Итоговая статистика внизу слева: время CI (мин), Confidence (%), стоимость
7. Стиль тёмный (#0f172a фон), все стили inline

## Чеклист

- [ ] Пирамида из 5 слоёв с цветовой кодировкой
- [ ] Клик по слою отображает описание + пример кода + метрики
- [ ] Toggle-переключатель для каждого слоя
- [ ] Coverage map с прогресс-барами для 4 MFE
- [ ] При отключении слоя — bars анимированно скрываются
- [ ] Статистика: время CI, Confidence, стоимость пересчитываются
- [ ] Первый слой (Unit) выбран по умолчанию

## Как проверить себя

1. Кликните на «Contract» — должно появиться описание про Pact и пример с `PactV3`
2. Отключите «E2E» toggle — соответствующие bars в Coverage map должны схлопнуться, время CI уменьшится
3. Включите все слои — Confidence должен быть максимальным, стоимость — «высокая»
4. Отключите все кроме Unit — стоимость должна стать «низкая»
5. Проверьте, что пример кода для каждого слоя разный и соответствует его уровню
