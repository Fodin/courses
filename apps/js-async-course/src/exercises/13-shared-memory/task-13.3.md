# Задание 13.3: Atomics.waitAsync / notify

## Цель

Реализовать паттерн Producer-Consumer с использованием `Atomics.waitAsync` и `Atomics.notify`. Producer-Worker записывает данные в SharedArrayBuffer и уведомляет Consumer-Worker, который ждёт сигнала перед чтением.

## Требования

1. **Два SharedArrayBuffer**:
   - `sab` — 4 слота `Int32Array` для данных (4 числа)
   - `flagBuf` — 2 слота: `flag[0]` = флаг готовности (0/1), `flag[1]` = номер итерации

2. **Producer Worker**:
   - Записывает данные в `sab`: `arr[0..3] = i*10, i*10+1, i*10+2, i*10+3`
   - `Atomics.store(flag, 0, 1)` — устанавливает флаг
   - `Atomics.notify(flag, 0, 1)` — уведомляет одного ждущего
   - 6 итераций с паузой 300мс между ними

3. **Consumer Worker**:
   - `Atomics.waitAsync(flag, 0, 0)` — ждёт пока `flag[0] !== 0`
   - Обрабатывает `'not-equal'` (данные уже готовы) и `Promise` (ждёт)
   - После получения: читает данные, `Atomics.store(flag, 0, 0)` — сбрасывает флаг

4. **Визуализация**:
   - Три колонки: Producer | Буфер (4 ячейки) | Consumer
   - Буфер подсвечивается синим при записи, зелёным при чтении
   - Счётчики произведённых/потреблённых элементов

5. **Лог событий** — хронологический список: когда и что сделал каждый Worker.

## Чеклист

- [ ] Компонент называется `Task13_3` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован, `t('task.13.3')` используется в заголовке
- [ ] Использован настоящий `Atomics.waitAsync` (не симуляция)
- [ ] Producer корректно устанавливает флаг и вызывает `notify`
- [ ] Consumer использует `waitAsync` и корректно сбрасывает флаг после чтения
- [ ] Обработаны оба случая: `'not-equal'` и Promise
- [ ] Визуализация буфера с подсветкой записи/чтения
- [ ] Worker'ы завершаются при размонтировании
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Нажмите "Запустить демонстрацию" — логи должны чередоваться: Producer пишет → Consumer читает
2. Счётчики Producer и Consumer должны достичь 6/6 синхронно (с небольшим отставанием Consumer)
3. Числа в буфере должны меняться: [0,1,2,3] → [10,11,12,13] → [20,21,22,23] и т.д.
4. В логе порядок: "Записал [0..3]" всегда предшествует "Прочитал [0..3]" для той же итерации
