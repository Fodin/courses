# Задание 7.3 — Инверсия зависимости применяется дважды (сложное)

## Цель

Разорвать два независимых двусторонних цикла — `auth.ts ↔ session.ts` и `cache.ts ↔ metrics.ts` — применив приём внедрения зависимости в каждом из них.

## Что дано

- `auth.ts` — экспортирует `login`, вызывает `touchSession` из `session.ts` (🔒 только чтение);
- `session.ts` — функция `reLogin` импортирует `login` обратно из `auth.ts`;
- `cache.ts` — экспортирует `get`, вызывает `recordHit` из `metrics.ts` (🔒 только чтение);
- `metrics.ts` — функция `replay` импортирует `get` обратно из `cache.ts`.

## Требования

1. В `session.ts` уберите импорт `login` из `./auth`; `reLogin` должна принимать `login` третьим параметром.
2. В `metrics.ts` уберите импорт `get` из `./cache`; `replay` должна принимать `get` третьим параметром.
3. Файлы `auth.ts` и `cache.ts` менять не нужно.
4. Нажмите «Проверить» — все проверки должны стать зелёными.

## Чеклист

- [ ] `session.ts` не импортирует `auth.ts`
- [ ] `reLogin` принимает `login` параметром
- [ ] `metrics.ts` не импортирует `cache.ts`
- [ ] `replay` принимает `get` параметром
- [ ] Цикл в графе импортов отсутствует (в обоих местах)
- [ ] Пройти квиз уровня ≥ 80%
