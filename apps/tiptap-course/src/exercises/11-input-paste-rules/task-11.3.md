# Задание 11.3: Свой input rule

## Цель

Реализовать собственный input rule "с нуля" через низкоуровневый класс `InputRule`, превращающий `:)` в эмодзи 🙂 сразу при вводе.

## Требования

1. Создайте `Extension.create({ name: 'smileyInputRule', ... })`
2. Внутри `addInputRules()` верните массив с одним `new InputRule({ find: /:\)$/, handler: ({ state, range }) => {...} })`
3. В `handler` используйте `state.tr.replaceWith(range.from, range.to, state.schema.text('🙂'))` для замены совпавшего текста на эмодзи
4. Дополнительно реализуйте второе правило: `:(` → 🙁, аналогичным образом (можно вторым `InputRule` в том же массиве)
5. Подключите extension вместе со `StarterKit`

## Чеклист

- [ ] Компонент называется `Task11_3` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.11.3')` используется в заголовке
- [ ] Набор `:)` мгновенно заменяется на 🙂
- [ ] Набор `:(` мгновенно заменяется на 🙁
- [ ] Оба правила работают независимо друг от друга
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Напечатайте в редакторе `Привет :)` — сразу после закрывающей скобки должна появиться замена на 🙂
2. Напечатайте `Мне грустно :(` — должна появиться замена на 🙁
3. Убедитесь, что правило срабатывает именно в момент набора последнего символа (закрывающей скобки), а не требует дополнительных действий
