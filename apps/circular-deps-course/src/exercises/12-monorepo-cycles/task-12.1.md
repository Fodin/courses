# Задание 12.1 — Цикл между пакетами a ↔ b (простое)

## Цель

Разорвать цикл между двумя пакетами монорепозитория, эмулированными каталогами `packages/a/src` и `packages/b/src` с bare-специфаерами `@repo/a` / `@repo/b`.

## Что дано

- `packages/a/src/index.ts` — пакет `@repo/a` (🔒 только чтение). Реально использует значение `formatB` из `@repo/b` в рантайме — трогать эту связь не нужно.
- `packages/b/src/index.ts` — пакет `@repo/b`. Импортирует из `@repo/a` тип `A`, но использует его **только как тип** (аннотация возвращаемого значения `makeA`).

## Требования

1. Откройте `packages/b/src/index.ts` и найдите импорт `import { A } from '@repo/a'`.
2. Убедитесь, что `A` в этом файле нигде не используется как значение — только как тип.
3. Замените импорт на `import type { A } from '@repo/a'`.
4. Нажмите «Проверить» — цикл `@repo/a ↔ @repo/b` должен исчезнуть из графа рантайм-импортов.

## Чеклист

- [ ] Импорт `@repo/a` в `packages/b/src/index.ts` — типовой (`import type`)
- [ ] В графе рантайм-импортов нет цикла между `@repo/a` и `@repo/b`
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

Если убрать слово `type` из вашего импорта — проверка «нет рантайм-цикла» должна снова покраснеть. Если это так, вы действительно разорвали цикл именно типовым импортом, а не случайно.
