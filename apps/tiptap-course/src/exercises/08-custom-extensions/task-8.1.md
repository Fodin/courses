# Задание 8.1: Extension.create и addOptions

## Цель

Создать простой кастомный extension `MaxLength`, который через `addOptions` принимает лимит символов и предоставляет доступ к нему извне.

## Требования

1. Создайте `Extension.create<{ maxLength: number }>({ name: 'maxLength', addOptions() { return { maxLength: 280 } } })`
2. Подключите его вместе со `StarterKit`: `MaxLength.configure({ maxLength: 100 })`
3. В React-компоненте выведите значение опции через `editor.extensionManager.extensions.find(ext => ext.name === 'maxLength')?.options.maxLength`
4. Дополнительно реализуйте счётчик текущей длины текста (`editor.getText().length`) рядом с лимитом из опций — сравните визуально: `47 / 100`
5. Если текст превышает `maxLength` — покрасьте счётчик в красный (лимит здесь не блокирует ввод, только визуальный индикатор)

## Чеклист

- [ ] Компонент называется `Task8_1` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.8.1')` используется в заголовке
- [ ] `MaxLength.configure({ maxLength: 100 })` корректно передаёт опцию
- [ ] Значение опции читается из `extensionManager` и отображается в UI
- [ ] Счётчик текста работает и подсвечивается при превышении лимита
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Откройте задание — должно быть видно "Лимит: 100 символов" (или похожий текст)
2. Введите текст длиной больше 100 символов — счётчик должен окраситься в красный
3. Проверьте в коде, что значение 100 берётся именно из `.configure()`, а не захардкожено в UI отдельно
