# Задание 18.1: Квиз — Миграция и устранение неполадок

## Цель

Научиться безопасно мигрировать между пакетными менеджерами и диагностировать типичные ошибки установки: ERESOLVE, EINTEGRITY, EBADENGINE, дрейф версий.

## Требования

1. Прочитайте теорию уровня (Кратко и Подробно)
2. Пройдите квиз
3. Для каждого вопроса разберите объяснения всех вариантов
