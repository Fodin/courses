# Задание 9.1: Жизненный цикл окружений

## Цель

Создать интерактивную визуализацию трёх окружений (dev, staging, production) с возможностью симулировать деплой, rollback и остановку каждого окружения. Показать, как изменяется состояние и история деплоев.

## Требования

1. Отобразить три карточки окружений: `dev`, `staging`, `production` — каждая со своим именем, URL и текущим статусом
2. Каждая карточка показывает текущую версию (номер деплоя), дату последнего деплоя и статус (`active`, `stopped`)
3. Кнопка "Deploy" на каждой карточке — увеличивает номер версии, обновляет дату, переводит в `active`
4. Кнопка "Stop" — переводит окружение в статус `stopped`, кнопка Deploy снова должна его активировать
5. Кнопка "Rollback" — уменьшает версию на 1 (минимум версия 1), если окружение `active`
6. История деплоев — последние 3 деплоя для каждого окружения (версия + дата)
7. Визуально разделить: dev (синий), staging (жёлтый/оранжевый), production (красный)

## Чеклист

- [ ] Три карточки окружений с именем, URL и цветовым кодированием
- [ ] Текущая версия и дата последнего деплоя на каждой карточке
- [ ] Статусный бейдж: `active` (зелёный) / `stopped` (серый)
- [ ] Кнопка Deploy — обновляет версию и дату
- [ ] Кнопка Stop — переводит в stopped, деактивирует Rollback
- [ ] Кнопка Rollback — откатывает версию, недоступна при stopped и при версии 1
- [ ] История последних 3 деплоев под карточкой или внутри неё
- [ ] Кнопки Rollback и Stop заблокированы (disabled) в нерелевантных состояниях

## Как проверить себя

1. Нажми Deploy на staging — версия должна увеличиться, дата обновиться, статус стать active
2. Нажми Stop — статус должен стать stopped, кнопка Rollback должна быть недоступна
3. Нажми Deploy снова — окружение должно вернуться в active с новой версией
4. Нажми Rollback три раза — на версии 1 кнопка должна быть disabled
5. Проверь историю — должны отображаться последние 3 деплоя

## Подсказки

- Храни для каждого окружения: `version` (number), `status` ('active' | 'stopped'), `history` (массив объектов {version, date})
- `useState` с массивом из 3 объектов-окружений удобнее, чем 3 отдельных useState
- Для форматирования даты используй `new Date().toLocaleString('ru-RU', { hour: '2-digit', minute: '2-digit' })`
- `disabled` для кнопки Rollback: `env.status === 'stopped' || env.version === 1`
