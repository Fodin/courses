# Задание 12.2 — Кольцо из трёх пакетов a → b → c → a (среднее)

## Цель

Разорвать кольцо из трёх пакетов монорепозитория, применив ленивую загрузку через динамический `import()`.

## Что дано

- `packages/a/src/index.ts` — пакет `@repo/a` (🔒 только чтение). Вызывает значение `formatB` из `@repo/b` — легитимная рантайм-связь.
- `packages/b/src/index.ts` — пакет `@repo/b` (🔒 только чтение). Вызывает значение `formatC` из `@repo/c` — тоже легитимная связь.
- `packages/c/src/index.ts` — пакет `@repo/c`. Статически импортирует `describeA` из `@repo/a`, замыкая кольцо `a → b → c → a`, хотя нужен этот импорт лишь изредка — внутри редко вызываемого отладочного хелпера `debugWithA`.

## Требования

1. Откройте `packages/c/src/index.ts`.
2. Уберите статический `import { describeA } from '@repo/a'` в начале файла.
3. Внутри `debugWithA` подгрузите `@repo/a` динамически: `const { describeA } = await import('@repo/a')`.
4. Нажмите «Проверить» — кольцо `@repo/a → @repo/b → @repo/c → @repo/a` должно исчезнуть из графа рантайм-импортов.

## Чеклист

- [ ] В `packages/c/src/index.ts` нет статического импорта из `@repo/a`
- [ ] `debugWithA` загружает `@repo/a` через `await import(...)`
- [ ] В графе рантайм-импортов нет кольца `a → b → c → a`
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

Динамический `import()` не создаёт статического ребра в графе, потому что бандлер и анализаторы графа (в т.ч. `noRuntimeCycles`) видят в нём асинхронный вызов, а не строку `import ... from`. Убедитесь, что вы не оставили ни одного статического импорта `@repo/a` в файле `@repo/c`.
