# Задание 16.2: Actions Marketplace — uses, with, секреты и переменные

## Цель

Создать интерактивный браузер популярных GitHub Actions из Marketplace. Студент выбирает нужные actions, настраивает параметры и видит, как формируется корректный YAML с секретами и переменными окружения.

## Требования

1. Отобразить **каталог actions** — минимум 5 карточек:
   - `actions/checkout@v4` — клонирование кода
   - `actions/setup-node@v4` — установка Node.js
   - `actions/setup-python@v5` — установка Python
   - `actions/upload-artifact@v4` — сохранение артефактов
   - `actions/cache@v4` — кэширование зависимостей
2. При **выборе action** (клик на карточку) — показать параметры (`with:`):
   - `setup-node`: выбор `node-version` (кнопки: 18, 20, 22) и переключатель `cache: npm`
   - `setup-python`: выбор `python-version` (кнопки: 3.10, 3.11, 3.12)
   - `upload-artifact`: поля `name` и `path`, выбор `retention-days` (1, 7, 30)
3. Отобразить секцию **секретов** — добавление переменных через пару "имя секрета → значение из `secrets.*`":
   - Кнопка "Добавить секрет"
   - Текстовые поля: имя переменной окружения (напр. `AWS_KEY`) и имя секрета (напр. `AWS_ACCESS_KEY`)
   - При удалении секрета — убрать из YAML
4. Показывать итоговый **YAML шага** с выбранным action, его параметрами и секретами
5. Добавить предупреждение: секреты нельзя использовать напрямую — только через `${{ secrets.NAME }}`

## Чеклист

- [ ] Минимум 5 карточек actions с названием и описанием
- [ ] Выбор action подсвечивает карточку и показывает параметры
- [ ] Изменение параметров (node-version, cache) обновляет YAML
- [ ] Секция добавления секретов с динамическими полями
- [ ] В YAML секреты отображаются как `${{ secrets.NAME }}`
- [ ] Кнопка удаления секрета убирает строку из YAML
- [ ] Предупреждение о правилах работы с секретами

## Как проверить себя

1. Выбери `setup-node` → смени версию на 22 → в YAML должно быть `node-version: '22'`
2. Включи `cache: npm` — в YAML добавится `cache: 'npm'`
3. Выбери `upload-artifact` → задай name и path → проверь YAML
4. Добавь секрет `AWS_KEY` → `AWS_ACCESS_KEY_ID` → в YAML: `AWS_KEY: ${{ secrets.AWS_ACCESS_KEY_ID }}`
5. Удали секрет — убедись, что строка исчезла из YAML

## Подсказки

- Состояние: `selectedAction` (id выбранного action), `nodeVersion`, `useCache`, `secrets` (массив `{envName, secretName}`)
- Для динамического добавления секретов используй `[...prev, { envName: '', secretName: '' }]`
- Каждый секрет в YAML: строка `${envName}: $\{{ secrets.${secretName} \}}`
- Карточка подсвечивается через условный стиль: `border: selected ? '2px solid #1565C0' : '2px solid #e0e0e0'`
