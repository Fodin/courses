# Задание 13.2: Конструктор `_links` по состоянию

## Цель

Реализовать визуализатор условных ссылок: студент выбирает состояние ресурса (и опционально роль пользователя), а компонент рассчитывает корректный набор `_links` и показывает итоговый гипермедиа-ответ. Цель — прочувствовать правило «состояние определяет доступные действия».

## Требования

1. Переключатель состояния заказа: `pending`, `paid`, `shipped`, `delivered`, `cancelled`
2. Переключатель роли: `customer` (покупатель) и `admin` — влияет на часть ссылок (например, `refund` доступен только admin)
3. По выбранным состоянию и роли рассчитать набор `_links` (всегда есть `self`)
4. Показать итоговый JSON-ответ ресурса с блоком `_links` (href + method)
5. Рядом — список «почему именно эти ссылки»: какое правило добавило/убрало каждый переход
6. Показать «запрещённые» действия отдельно (зачёркнутыми или серыми) с пояснением, почему недоступны в этом состоянии — чтобы видеть контраст

## Чеклист

- [ ] Переключение состояния меняет набор `_links`
- [ ] Переключение роли меняет доступность ролевых ссылок (`refund` и т.п.)
- [ ] `self` присутствует всегда
- [ ] Итоговый JSON с корректными href и method
- [ ] Пояснение, почему каждая ссылка доступна
- [ ] Недоступные действия показаны отдельно с причиной

## Правила (эталон)

| Состояние | customer | admin (дополнительно) |
|---|---|---|
| `pending` | self, pay, cancel | — |
| `paid` | self, ship* | refund |
| `shipped` | self, track | refund |
| `delivered` | self, review | refund |
| `cancelled` | self | — |

`ship` логичнее показывать admin/системе, но для простоты задания допустимо у обоих. Главное правило: **оплаченный заказ не показывает `pay`, отменённый — ничего кроме `self`, `refund` — только admin**.

## Как проверить себя

1. `pending` + customer → `self, pay, cancel`.
2. Переключи на `paid` → `pay` исчез, появились `ship` (и `refund` если admin).
3. Переключи роль на admin при `paid` → добавился `refund`.
4. `cancelled` → только `self`, всё остальное в «недоступных» с пояснением.

## Подсказки

- Опиши правила как функцию `linksFor(status, role)`, возвращающую объект `_links`.
- Начинай всегда с `{ self: { href: '/orders/123' } }`, затем добавляй переходы по `status` и `role`.
- Для блока «недоступные» сравни полный список действий с полученным набором: разница и есть запрещённые.
