# Задание 7.2 — Task: асинхронная IO-монада

## Цель

Реализовать `Task<T>` — ленивую обёртку над `Promise`. Показать разницу между последовательным и параллельным выполнением через анимированный таймлайн.

## Требования

1. Реализуйте класс `Task<T>` с полем `private fork: () => Promise<T>`
2. Реализуйте `Task.of<T>(value: T): Task<T>` — через `Promise.resolve`
3. Реализуйте `map<U>(fn: (value: T) => U): Task<U>` — через `.then(fn)`, не запуская форк
4. Реализуйте `flatMap<U>(fn: (value: T) => Task<U>): Task<U>` — цепочка через `.then(v => fn(v).run())`
5. Реализуйте `run(): Promise<T>` — единственное место запуска
6. Реализуйте `Task.parallel<T>(tasks: Task<T>[]): Task<T[]>` — через `Promise.all`
7. Создайте три Task с имитацией задержки:
   - `fetchUsers` — 800ms, результат `[Alice, Bob, Carol]`
   - `fetchProducts` — 500ms, результат `[Widget, Gadget]`
   - `fetchOrders` — 1200ms, результат `[#1001, #1002, #1003]`
8. Реализуйте режим **Sequential**: flatMap-цепочка, задачи выполняются одна за другой (~2500ms)
9. Реализуйте режим **Parallel**: `Task.parallel`, все три Task одновременно (~1200ms)
10. Покажите анимированный таймлайн: полоски растут в реальном времени по мере выполнения каждого Task
11. После завершения покажите общее время и результат

## Чеклист

- [ ] Класс `Task<T>` корректно реализован
- [ ] `Task.of` создаёт Task из значения
- [ ] `map` и `flatMap` не запускают Promise немедленно
- [ ] `run()` возвращает Promise и запускает форк
- [ ] `Task.parallel` использует `Promise.all` и остаётся ленивым
- [ ] Sequential режим: задачи выполняются одна за другой
- [ ] Parallel режим: все три задачи стартуют одновременно
- [ ] Таймлайн отражает реальный прогресс каждого Task
- [ ] Переключение режима сбрасывает состояние
- [ ] Показывается общее время выполнения

## Как проверить себя

1. В Sequential режиме общее время должно быть ~2500ms (800+500+1200)
2. В Parallel режиме общее время должно быть ~1200ms (наибольший из трёх)
3. Таймлайн в Sequential должен показывать полоски друг за другом
4. Таймлайн в Parallel должен показывать полоски, стартующие одновременно
5. Результаты в обоих режимах одинаковые

## Подсказки

- Отличие от Promise: `new Task(() => fetch(...))` — никакого HTTP до `.run()`
- `flatMap` для Task: `new Task(() => this.fork().then(v => fn(v).run()))`
- Для таймлайна отслеживайте время начала каждого Task и время его завершения через `Date.now()`
- Для анимации используйте `requestAnimationFrame` или `setInterval`
