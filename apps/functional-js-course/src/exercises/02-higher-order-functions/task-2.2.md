# Задание 2.2 — createValidator: создание HOF

## Цель

Реализовать функцию высшего порядка `createValidator`, которая принимает массив
правил и возвращает функцию-валидатор. Продемонстрировать работу через интерактивную
форму с живой валидацией.

## Требования

1. Определите тип `Rule`:
   ```ts
   type Rule = {
     id: string
     label: string
     check: (value: string) => boolean
     message: string
   }
   ```
2. Реализуйте HOF `createValidator(rules: Rule[]): (value: string) => string[]`.
   Функция должна возвращать массив строк с ошибками (пустой массив = всё ок).
3. Создайте минимум 5 предустановленных правил:
   - `minLength` — минимум 3 символа
   - `maxLength` — максимум 20 символов
   - `noSpaces` — без пробелов
   - `hasUpperCase` — есть заглавная буква
   - `hasDigit` — есть цифра
4. Добавьте текстовый ввод с `live`-валидацией при каждом изменении.
5. Добавьте чекбоксы для включения/выключения каждого правила.
   При изменении набора правил — валидатор перестраивается.
6. Показать блок кода с реализацией `createValidator` и текущей конфигурацией правил.
7. Визуально отобразить статус каждого правила (pass/fail) рядом с чекбоксом.

## Чеклист

- [ ] Тип `Rule` определён
- [ ] `createValidator` принимает `Rule[]` и возвращает `(string) => string[]`
- [ ] 5 предустановленных правил реализованы и работают корректно
- [ ] Текстовый ввод с live-валидацией
- [ ] Чекбоксы для включения/выключения правил
- [ ] Ошибки отображаются как красные строки под вводом
- [ ] При всех пройденных правилах — зелёное сообщение об успехе
- [ ] Код `createValidator` виден пользователю

## Как проверить себя

1. Введите `"ab"` — должна появиться ошибка minLength (меньше 3 символов).
2. Введите `"hello world"` — должна появиться ошибка noSpaces.
3. Введите `"Hello1"` — все стандартные ошибки должны исчезнуть.
4. Снимите чекбокс с `hasDigit` и введите `"Hello"` — ошибки не должно быть.
5. Включите все правила и введите пустую строку — должны быть ошибки minLength и hasUpperCase и hasDigit.

## Подсказки

- Внутри `createValidator` используйте `rules.filter(r => !r.check(value)).map(r => r.message)`.
- Чтобы валидатор пересчитывался при изменении чекбоксов, создавайте его через
  `useMemo` или `useCallback` зависящий от активных правил.
- Для набора активных id удобно использовать `Set<string>` в стейте.
