# Задание 11.1: RSC Payload Parser

## Цель

Разобраться в структуре RSC wire format изнутри: построить интерактивный визуализатор, который принимает симулированный RSC payload (текстовые строки) и преобразует их в визуальное дерево компонентов — серверные (синие), клиентские (оранжевые) и Suspense-границы (пунктирные).

## Задание

Реализуйте `RSCPayloadParser` — компонент, который симулирует работу React Flight-клиента.

### Шаг 1. Парсинг строк payload

RSC payload — это набор строк, каждая из которых имеет формат `<id>:<type><data>`. Реализуйте функцию `parsePayloadLine(line: string): PayloadRow`, которая возвращает:

```ts
type PayloadRow =
  | { id: string; type: 'I'; chunk: string; name: string }        // client import
  | { id: string; type: 'J'; element: Record<string, unknown> }   // JSX element
  | { id: string; type: 'S'; token: string }                      // string token
  | { id: string; type: 'P'; placeholder: true }                  // pending chunk
```

### Шаг 2. Построение дерева

После парсинга всех строк постройте визуальное дерево. Правила:

- Строки типа `J` с `type: "div"` / `"h1"` / `"p"` и т.д. — серверные узлы (синие)
- Строки типа `I` — клиентские компоненты (оранжевые)
- Строки типа `S` с токеном `"react.suspense"` — Suspense-граница (пунктирная рамка)
- Строки типа `P` — "ожидающий" узел (серый, анимация пульсации)

### Шаг 3. Пошаговый режим

Добавьте кнопки "Следующий чанк" и "Сброс". При каждом нажатии обрабатывается одна строка payload — дерево строится постепенно, имитируя streaming. Счётчик: "Получено X/Y чанков".

### Шаг 4. Редактор payload

Добавьте `<textarea>` с примером payload. Студент может его редактировать и нажать "Парсить" — дерево перестроится.

### Встроенный пример payload для textarea

```
0:S"react.suspense"
1:I{"chunk":"client-abc.js","name":"LikeButton"}
2:I{"chunk":"client-def.js","name":"CommentForm"}
3:J{"type":"div","props":{"className":"page"},"children":["$4","$5"]}
4:J{"type":"header","props":{},"children":"$6"}
5:J{"type":"$0","props":{"fallback":"Loading..."},"children":"$P7"}
6:J{"type":"h1","props":{},"children":"Статья о React"}
7:P
8:J{"type":"div","props":{"className":"comments"},"children":["$9","$L2"]}
9:J{"type":"p","props":{},"children":"Первый комментарий"}
```

## Требования

1. Функция `parsePayloadLine` корректно разбирает все 4 типа строк
2. Визуальное дерево отображает: серверные элементы синим, клиентские оранжевым, Suspense пунктиром, P-placeholder серым с пульсацией
3. Пошаговый режим: кнопка "Следующий чанк" добавляет по одной строке
4. Счётчик показывает "Получено X/Y чанков"
5. Кнопка "Сброс" возвращает к начальному состоянию
6. Textarea с примером payload — редактируемая, кнопка "Парсить" перезапускает анализ
7. Легенда с объяснением цветов
8. При hover на узел — показывать исходную строку payload (title атрибут или tooltip)

## Чеклист

- [ ] `parsePayloadLine` возвращает корректный тип для каждого формата строки
- [ ] Неизвестный формат строки не падает с ошибкой (graceful fallback)
- [ ] Серверные узлы — синие карточки с типом элемента и className
- [ ] Клиентские узлы — оранжевые карточки с именем компонента и chunk-ом
- [ ] Suspense boundary — пунктирная рамка вокруг своих детей
- [ ] P-placeholder — серый узел с анимацией пульсации (`@keyframes pulse`)
- [ ] Пошаговый режим работает корректно (каждый клик = +1 строка)
- [ ] Textarea редактируется и "Парсить" обновляет дерево
- [ ] Легенда с цветовыми пояснениями присутствует

## Как проверить себя

1. Вставьте пример payload в textarea и нажмите "Парсить" — должно появиться дерево
2. Нажмите "Сброс", затем "Следующий чанк" несколько раз — дерево строится пошагово
3. Убедитесь, что `$0` в строке `J` (ссылка на Suspense-токен) рендерится как пунктирная граница
4. Удалите все строки из textarea, нажмите "Парсить" — дерево пустое, без ошибок
5. Добавьте строку с неверным форматом — компонент не должен упасть
