# Задание 13.2: Конструктор плана миграции

## Цель

Создать интерактивный инструмент для составления плана миграции монолита: ввести характеристики доменов, получить автоматическое ранжирование по приоритету извлечения и сгенерировать визуальный roadmap с фазами, рисками и рекомендациями.

## Требования

1. Отобразить таблицу доменов с редактируемыми полями: имя, размер (S/M/L/XL с LOC), API-зависимости (0–20), shared state сущности (0–10), бизнес-критичность (low/medium/high/critical), частота изменений (rare/monthly/weekly/daily)
2. Вычислять очки приоритета для каждого домена в реальном времени: высокая частота + низкая критичность + маленький размер + мало зависимостей = высокий балл
3. Сортировать домены по убыванию очков и отображать приоритетный бар рядом с каждым доменом; первый в списке отмечать иконкой 🥇
4. Поддержать добавление новых доменов (поле ввода + кнопка «Добавить», Enter тоже работает) и удаление существующих
5. Кнопка «Сгенерировать Migration Roadmap» — разбивает отсортированные домены на 3 фазы и для каждой выводит: список доменов, оценку сложности (низкая/средняя/высокая), список рисков, список рекомендаций, оценку в неделях
6. Отобразить timeline — горизонтальные блоки фаз, ширина пропорциональна числу недель, цвет соответствует сложности
7. После любого изменения таблицы roadmap сбрасывается (нужно перегенерировать)

## Чеклист

- [ ] Таблица с 6 предзаданными доменами, все поля редактируемы
- [ ] Домены сортируются по убыванию приоритетных очков при каждом изменении
- [ ] Первый домен в списке помечен иконкой 🥇
- [ ] Приоритетный бар меняет ширину при изменении параметров (зелёный/жёлтый/красный)
- [ ] Можно добавить домен через поле + кнопку или Enter
- [ ] Можно удалить любой домен кнопкой «×»
- [ ] После изменения параметров roadmap исчезает (требует повторной генерации)
- [ ] Кнопка генерации создаёт 3 фазы с доменами, сложностью, рисками, рекомендациями
- [ ] Timeline показывает горизонтальные блоки фаз с пропорциональными размерами
- [ ] Цвет фазы в timeline и в карточке соответствует сложности: зелёный/жёлтый/красный
- [ ] Карточка каждой фазы содержит риски и рекомендации

## Как проверить себя

1. Откройте задание — вы увидите таблицу с 6 доменами. Аналитика и Профиль должны быть вверху (высокий балл: некритичны, малые, мало зависимостей)
2. Измените размер «Аналитики» с S на XL — её очки должны упасть и она сместится вниз по списку
3. Верните размер обратно, нажмите «Сгенерировать Migration Roadmap» — появятся 3 фазы и timeline
4. Добавьте новый домен «Платежи» с критичностью critical и частотой daily — он должен попасть в последнюю фазу (высокая критичность снижает приоритет)
5. Измените любой параметр — roadmap должен исчезнуть, показывая что нужна перегенерация
