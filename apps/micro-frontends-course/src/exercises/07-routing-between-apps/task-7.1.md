# Задание 7.1: Симулятор навигации между MFE

## Цель

Реализовать интерактивный симулятор, который наглядно демонстрирует, как Shell-Router координирует навигацию между несколькими MFE — включая визуализацию конфликта pushState и механизм deep linking.

## Требования

1. Отобразить «браузерную строку» вверху — показывает текущий URL в формате `http://app.example.com/path`. При монтировании активного MFE показывает цветной бейдж с его названием.

2. Реализовать панель Shell навигации с четырьмя маршрутами:
   - Home (`/`) — без MFE
   - Catalog (`/catalog`) — монтирует Catalog MFE
   - Cart (`/cart`) — монтирует Cart MFE
   - Profile (`/profile`) — монтирует Profile MFE
   
   При клике: обновить URL, записать в лог события `Shell: navigate to /path`, `MFE: unmounted` (для предыдущего) и `MFE: mounted`.

3. При активном MFE показывать панель его internal routes:
   - Catalog: `/catalog`, `/catalog/search`, `/catalog/:id`
   - Cart: `/cart`, `/cart/checkout`, `/cart/confirm`
   - Profile: `/profile`, `/profile/orders`, `/profile/settings`
   
   При клике на internal route: обновить URL, записать `MFE: internal navigate to /path`.

4. Кнопка «Конфликт!» — симулирует race condition: Cart MFE пытается перейти на `/cart/checkout`, а Catalog MFE одновременно на `/catalog/42`. Показать визуальный блок с объяснением проблемы и три лог-записи (обе попытки + ошибка).

5. Кнопка «Deep link» — открывает мини-форму с полем ввода URL и примерами ссылок. При переходе: обновить URL, активировать нужный MFE, записать в лог 3 события (deep link получен, Shell распознал MFE, MFE смонтирован с initialPath).

6. Цветовой лог навигационных событий: зелёный (Shell), синий (MFE lifecycle), оранжевый (конфликт), фиолетовый (deep link), красный (ошибка). Кнопка очистки лога.

## Чеклист

- [ ] URL в адресной строке обновляется при каждом переходе
- [ ] Shell навигация монтирует/демонтирует MFE с записью в лог
- [ ] Кнопки internal routes появляются только для активного MFE
- [ ] Нажатие «Конфликт!» показывает блок с объяснением и 3 лог-записи
- [ ] Deep link открывает форму с примерами, переход активирует нужный MFE
- [ ] Каждый тип события окрашен своим цветом в логе
- [ ] Лог прокручивается к последнему событию автоматически

## Как проверить себя

1. Нажмите «Catalog» — URL должен стать `/catalog`, в логе появится 2 записи.
2. Нажмите внутри Catalog на `/catalog/search` — URL меняется на `/catalog/search`.
3. Нажмите «Cart» — Catalog MFE демонтируется, Cart MFE монтируется.
4. Нажмите «Конфликт!» — появляется оранжевый блок, 3 лог-записи.
5. Нажмите «Deep link», введите `/profile/orders`, нажмите «Перейти» — Profile MFE активируется, 3 события в логе.
