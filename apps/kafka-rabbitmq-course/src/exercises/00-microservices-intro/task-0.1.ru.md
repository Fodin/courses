# Задание 0.1: Монолит vs микросервисы

## Цель

Создать интерактивный компонент, визуализирующий процесс декомпозиции монолита на микросервисы.
Студент кликает на модули внутри монолита, и они «выходят» как независимые сервисы.

## Требования

1. Отобразить монолит как единый блок с несколькими модулями внутри (минимум 4 модуля):
   Users, Orders, Payments, Inventory, Notifications, Reports
2. При клике на модуль он плавно перемещается из монолита в секцию микросервисов
3. Каждый выделенный сервис отображается как отдельный блок с уникальным цветом
4. Прогресс-бар показывает, сколько модулей уже декомпозировано из общего числа
5. Когда все модули декомпозированы — показать congratulation-сообщение
6. Кнопка «Сбросить» возвращает все модули обратно в монолит
7. Переход должен иметь анимацию (CSS transition или CSS animation)

## Чеклист

- [ ] Монолит отображается как блок с границей
- [ ] Внутри монолита минимум 4 кликабельных модуля
- [ ] Клик переносит модуль в секцию микросервисов
- [ ] Анимация перехода работает
- [ ] Прогресс-бар обновляется динамически
- [ ] Congratulation-сообщение появляется при полной декомпозиции
- [ ] Кнопка «Сбросить» работает корректно
- [ ] Компонент использует `useLanguage` и `t('task.0.1')` для заголовка

## Как проверить себя

1. Откройте задание в браузере
2. Кликните на каждый модуль по очереди — он должен исчезнуть из монолита и появиться справа
3. Прогресс-бар должен доходить до 100% при последнем клике
4. Должно появиться поздравительное сообщение
5. Кнопка «Сбросить» должна вернуть монолит в исходное состояние
6. Убедитесь что анимация плавная (нет резких скачков)
