# Задание 3.3: Промисификация callback-API

## Цель

Создать сравнительный демонстратор: слева — callback-based API (readFile, fetchUser), справа — Promise-обёрнутые версии. Запустить обе версии параллельно и показать на timeline, что они дают идентичный результат за то же время. Показать шаблон промисификации и связь с Node.js `util.promisify`.

## Требования

1. **Две вкладки** с теорией:
   - "Шаблон промисификации" — сравнение callback API и `promisify()` обёртки
   - "util.promisify / fs.promises" — Node.js инструменты промисификации

2. **Callback API** (симулированный):
   - `callbackReadFile(filename, cb)` — вызывает `cb(null, data)` через ~600мс, при `"missing"` в имени — `cb(error, null)`
   - `callbackFetchUser(userId, cb)` — вызывает `cb(null, user)` через ~800мс, при `userId <= 0` — `cb(error, null)`

3. **Promise-обёртки** тех же функций:
   - `readFileAsync(filename)` — возвращает `Promise<string>`
   - `fetchUserAsync(userId)` — возвращает `Promise<User>`

4. **Кнопка "Запустить"** — запускает все 4 операции параллельно (2 callback + 2 promise)

5. **Timeline** — горизонтальные прогресс-бары для каждой операции:
   - Показывает длительность в мс
   - Цвет: зелёный (успех) / красный (ошибка) / синий (в процессе)
   - Под баром — результат (данные или сообщение об ошибке)

6. **Сценарии ошибок** через поля ввода:
   - Имя файла с "missing" → ошибка ENOENT
   - `userId = 0` → ошибка неверного ID

7. **Кнопки "Запустить" и "Сброс"** — управление демо

8. **Комментарий** под timeline о том, что callback и promise версии дают идентичный результат

## Как проверить себя

1. Нажмите "Запустить" с дефолтными значениями (`data.txt`, `userId=1`) — все 4 операции успешны (зелёный цвет), callback и promise версии дают одинаковый результат
2. Измените имя файла на `missing.txt`, нажмите "Запустить" — readFile (callback и promise) показывают ошибку ENOENT красным
3. Измените `userId` на `0` — fetchUser (обе версии) показывают ошибку красным
4. Убедитесь, что callback и promise версии завершаются примерно за одинаковое время
5. В вкладке "util.promisify" убедитесь, что код отображает корректный Node.js пример
