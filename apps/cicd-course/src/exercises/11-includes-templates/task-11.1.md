# Задание 11.1: include — подключение внешних конфигов

## Цель

Создать интерактивный конструктор `include`-конфигурации. Пользователь выбирает тип include (local, file, remote, template), заполняет параметры и видит итоговый YAML.

## Требования

1. Отобразить четыре типа `include` в виде переключателя или вкладок: `local`, `file`, `remote`, `template`
2. Для каждого типа показать соответствующую форму:
   - `local`: поле для ввода пути (`ci/lint.yml`)
   - `file`: поля для `project`, `ref` (с предупреждением при значении `main`), `file`
   - `remote`: поле для URL с валидацией (начинается с `https://`)
   - `template`: выпадающий список встроенных шаблонов (SAST, Dependency-Scanning, Code-Quality, Auto-DevOps)
3. Показывать возможность добавить несколько `include` (кнопка "+ Добавить ещё")
4. Отображать итоговый YAML в реальном времени по мере заполнения формы
5. Для типа `file` с `ref: 'main'` — показывать предупреждение об антипаттерне

## Чеклист

- [ ] Четыре типа include с переключением
- [ ] Форма с полями для каждого типа
- [ ] Предупреждение при ref: 'main' в типе file
- [ ] Кнопка добавления второго include (минимум 2 блока)
- [ ] Итоговый YAML обновляется в реальном времени
- [ ] YAML отображается в моноширинном шрифте, тёмный фон
- [ ] Валидация URL (remote должен начинаться с https://)

## Как проверить себя

1. Выбери тип `file`, введи `ref: main` — должно появиться предупреждение об антипаттерне
2. Добавь второй include (кнопка "+ Добавить") — YAML должен показать массив из двух элементов
3. Выбери `remote` и введи URL без `https://` — форма должна показать ошибку
4. Переключись на `template` и выбери `Security/SAST.gitlab-ci.yml` — YAML должен содержать `template: Security/SAST.gitlab-ci.yml`
5. Удали все include — YAML должен стать пустым или показать placeholder

## Подсказки

- Используй `useState` для: `includes` (массив объектов), каждый с полями `type` и параметрами
- Для генерации YAML используй функцию `buildIncludeYaml(includes)`
- Предупреждение об antpattern можно показать через условный рендер: `ref === 'main' && <Warning />`
- Для добавления includes: `setIncludes(prev => [...prev, { type: 'local', path: '' }])`
- Встроенные шаблоны GitLab: `['Security/SAST.gitlab-ci.yml', 'Security/Dependency-Scanning.gitlab-ci.yml', 'Code-Quality.gitlab-ci.yml', 'Auto-DevOps.gitlab-ci.yml']`
