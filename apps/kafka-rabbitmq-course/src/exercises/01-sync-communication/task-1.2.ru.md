# Задание 1.2: Каскадные отказы и Circuit Breaker

## Цель

Создать интерактивный симулятор каскадного отказа в цепочке микросервисов.
Студент своими руками ломает сервис, наблюдает распространение таймаутов вверх по цепочке,
а затем включает Circuit Breaker и видит, как он предотвращает катастрофу.

## Требования

1. Цепочка из 5 узлов: `Client → Service A → Service B → Service C → Service D`
2. Каждый узел отображается как карточка со статусом (Healthy / FAILED / TIMEOUT / CB Open) и временем ответа
3. Кнопка `Отказ` под каждым сервисом (кроме Client) переводит его в статус `failed`
4. Тумблер `Circuit Breaker ON/OFF` — включает/выключает защиту
5. Кнопка `Симулировать запрос` запускает анимированное прохождение запроса по цепочке:
   - Если сервис healthy — лог `Успешно (Xms)`, суммируется время
   - Если сервис failed и CB выключен — лог таймаута, распространение ошибки вверх, суммируется 3000ms за каждый узел
   - Если сервис failed и CB включён — лог `Circuit Breaker OPEN — быстрый отказ (0ms)`, остальные узлы не ждут
6. Кнопка `Сброс` возвращает все сервисы в состояние Healthy
7. Итоговый баннер: суммарное время ожидания — красный при каскаде (>5000ms), зелёный при предотвращении
8. Лог событий — прокручиваемый список строк с шагами симуляции

## Чеклист

- [ ] Цепочка из 5 узлов отображается с карточками и стрелками между ними
- [ ] Клик `Отказ` переводит сервис в красный статус `FAILED`
- [ ] Кнопка `Симулировать запрос` запускает пошаговую анимацию с логом
- [ ] Без CB: таймаут каскадирует вверх, суммарное время > 5000ms, баннер красный
- [ ] С CB включённым: при повторной симуляции отказ изолируется, баннер зелёный
- [ ] Статус узлов обновляется во время симуляции (TIMEOUT, CB Open)
- [ ] Тумблер Circuit Breaker визуально переключается (зелёный ON / серый OFF)
- [ ] Кнопка `Сброс` восстанавливает все сервисы в Healthy
- [ ] Легенда цветов статусов отображается под диаграммой
- [ ] Компонент использует `useLanguage` и `t('task.1.2')` для заголовка

## Как проверить себя

1. Откройте задание в браузере
2. Убедитесь, что все сервисы зелёные — нажмите `Симулировать запрос` → должно пройти успешно
3. Нажмите `Отказ` на `Service C`, затем `Симулировать запрос` при выключенном CB
4. Наблюдайте: лог должен показать таймаут и распространение ошибки назад
5. Суммарное время > 9000ms — баннер должен быть красным с пометкой `Каскадный отказ!`
6. Нажмите `Сброс`, снова выведите `Service C` из строя
7. Включите Circuit Breaker и снова запустите симуляцию
8. CB должен предотвратить ожидание — суммарное время около 0ms, баннер зелёный
