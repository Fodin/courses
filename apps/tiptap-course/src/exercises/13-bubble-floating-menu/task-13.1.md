# Задание 13.1: BubbleMenu при выделении

## Цель

Реализовать классический `BubbleMenu` с кнопками bold/italic/link, появляющийся при выделении текста.

## Требования

1. Создайте `editor` через `useEditor` с `StarterKit`
2. Импортируйте `BubbleMenu` из `@tiptap/react/menus`
3. Оберните кнопки Bold/Italic/Link в `<BubbleMenu editor={editor}>` (с условным рендером `{editor && ...}`)
4. Кнопки должны использовать `isActive` для подсветки (как в уровне 3)
5. Стилизуйте панель через CSS: тёмный фон, скруглённые углы, тень — типичный вид всплывающей панели

## Чеклист

- [ ] Компонент называется `Task13_1` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.13.1')` используется в заголовке
- [ ] Меню появляется автоматически при выделении текста мышкой
- [ ] Меню исчезает, когда выделение снимается
- [ ] Кнопки внутри работают корректно (toggle + isActive подсветка)
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Выделите слово мышкой — над/под выделением должна появиться панель с кнопками
2. Кликните вне текста, чтобы снять выделение — панель должна исчезнуть
3. Примените bold через панель — кнопка должна подсветиться, панель — остаться видимой (пока выделение сохраняется)
