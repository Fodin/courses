# Задание 10.1 — Ревью: найти и убрать цикл (простое)

## Цель

Провести код-ревью небольшого слайса `entities/user`, найти спрятанный рантайм-цикл между двумя файлами сегмента `model` и разорвать его минимальной правкой.

## Что дано

- `src/entities/user/model/types.ts` (только для чтения) — экспортирует `UserTypes` и импортирует значение `userValue` из `user.ts`.
- `src/entities/user/model/user.ts` (редактируется) — экспортирует `userValue`, а `UserTypes` импортирует из `types.ts` обычным (не типовым) импортом, хотя использует его только как тип аннотации возвращаемого значения.

Вместе эти два импорта замыкают цикл: `types.ts → user.ts → types.ts`.

## Требования

1. Не редактируйте `model/types.ts` — он уже корректен.
2. Найдите файл, из-за которого цикл остаётся рантайм-циклом, а не просто типовой связью.
3. Разорвите цикл минимальной правкой — импорт `UserTypes` в `user.ts` должен использоваться только на уровне типов.
4. После правки в проекте не должно быть рантайм-цикла импортов.

## Чеклист

- [ ] `model/user.ts` импортирует `UserTypes` как `import type`
- [ ] Проверка «нет рантайм-цикла» — зелёная
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

1. Нажмите «Проверить» в лаборатории — проверка должна стать зелёной.
2. Откройте «Показать эталон», если не получается — сравните свой файл с решением.
3. Объясните себе вслух, почему `import type` устраняет именно рантайм-ребро графа, а не убирает зависимость вовсе.
