# Задание 2.3: Точечная конфигурация

## Цель

Настроить отдельные extensions внутри `StarterKit` через их собственные опции (не просто включить/выключить, а изменить поведение).

## Требования

1. Создайте `editor` с `StarterKit.configure(...)`, где:
   - `heading: { levels: [1, 2] }` — разрешить только H1 и H2
   - `bulletList: { HTMLAttributes: { class: 'my-bullet-list' } }` — добавить кастомный CSS-класс спискам
   - `history: { depth: 50 }` — ограничить глубину истории undo/redo 50 шагами
2. Добавьте кнопки для вставки H1 и H2 через `editor.chain().focus().toggleHeading({ level: 1 }).run()` и аналогично для 2
3. Добавьте (для проверки) попытку применить `toggleHeading({ level: 3 })` через отдельную кнопку "H3 (недоступен)" — она должна визуально ничего не делать, так как level 3 не разрешён конфигурацией
4. Выведите текущее значение `editor.isActive('heading', { level: 1 })` и `{ level: 2 }` рядом с кнопками (подсветка активной кнопки)

## Чеклист

- [ ] Компонент называется `Task2_3` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.2.3')` используется в заголовке
- [ ] H1 и H2 создаются корректно, подсвечиваются как активные
- [ ] Попытка создать H3 не создаёт заголовок 3 уровня (можно проверить через `editor.getHTML()`)
- [ ] У маркированных списков в HTML-выводе присутствует класс `my-bullet-list`
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Нажмите кнопку H1 — текст должен стать заголовком 1 уровня, кнопка — подсветиться
2. Нажмите кнопку "H3 (недоступен)" — ничего не должно измениться
3. Создайте маркированный список — проверьте через вывод HTML, что у `<ul>` есть класс `my-bullet-list`
4. Сделайте больше 50 изменений подряд, затем нажмите `Ctrl+Z` много раз — история должна закончиться раньше, чем при обычном (неограниченном) `history`
