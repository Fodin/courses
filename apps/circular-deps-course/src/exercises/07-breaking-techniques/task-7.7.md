# Задание 7.7 — Вынос общего в третий модуль (простое)

## Цель

Разорвать двусторонний цикл `user.ts ↔ order.ts`, вынеся оба типа в новый нижележащий модуль `types.ts`.

## Что дано

- `user.ts` — импортирует `Order` из `order.ts` и объявляет `interface User`;
- `order.ts` — импортирует `User` из `user.ts` и объявляет `interface Order`;
- `types.ts` — пустая заготовка с `// TODO`, её нужно заполнить.

## Требования

1. В `types.ts` объявите `interface User` и `interface Order` (перенесите их из `user.ts`/`order.ts`).
2. В `user.ts` замените объявление интерфейса на `import type { User } from './types'` и любую функцию, использующую этот тип (например, `createEmptyUser`).
3. В `order.ts` сделайте то же самое с `Order` (и `User`, если нужен для поля `owner`).
4. Ни `user.ts`, ни `order.ts` не должны импортировать друг друга напрямую.
5. Нажмите «Проверить» — все проверки должны стать зелёными.

## Чеклист

- [ ] `types.ts` содержит `interface User` и `interface Order`
- [ ] `user.ts` импортирует тип `User` из `./types`, а не объявляет его сам
- [ ] `order.ts` импортирует тип `Order` из `./types`, а не объявляет его сам
- [ ] `user.ts` и `order.ts` не импортируют друг друга
- [ ] Пройти квиз уровня ≥ 80%
