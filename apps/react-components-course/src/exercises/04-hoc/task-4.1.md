# Задание 4.1: withLoading — HOC для состояния загрузки

## Цель

Реализовать HOC `withLoading<P>`, который оборачивает произвольный компонент и показывает спиннер пока данные загружаются. Отработать корректную типизацию с generics.

## Требования

1. Создайте HOC `withLoading<P extends object>(Component)`, который принимает компонент с пропсами типа `P`
2. Возвращаемый компонент должен принимать `P & { isLoading: boolean }` — все оригинальные пропсы плюс флаг загрузки
3. Если `isLoading === true` — рендерите спиннер (любая визуальная индикация загрузки)
4. Если `isLoading === false` — рендерите оригинальный компонент с его пропсами
5. Пропс `isLoading` не должен попадать в оригинальный компонент (деструктурируйте его отдельно)
6. Установите `displayName` в формате `withLoading(ComponentName)`
7. Продемонстрируйте работу: создайте два компонента `UserCard` и `ProductList`, оберните их `withLoading`, добавьте кнопку переключения состояния загрузки

## Подсказки

- `P & { isLoading: boolean }` — пересечение типов: все поля P плюс новые поля
- При деструктуризации `const { isLoading, ...rest } = props` — TypeScript нужно помочь: `rest as P`
- `Component.displayName ?? Component.name ?? 'Component'` — безопасное получение имени
- HOC нужно вызывать вне компонента-рендерера, иначе React каждый раз создаёт новый тип
- `React.ComponentType<P>` принимает и функциональные, и классовые компоненты

## Чеклист

- [ ] HOC корректно типизирован с `<P extends object>`
- [ ] При `isLoading=true` виден спиннер/индикатор загрузки
- [ ] При `isLoading=false` рендерится оригинальный компонент с правильными пропсами
- [ ] `isLoading` не попадает в оригинальный компонент
- [ ] `displayName` установлен корректно
- [ ] HOC создаётся вне рендер-функции
- [ ] Демонстрация работает с кнопкой переключения

## Как проверить себя

Откройте React DevTools. В дереве компонентов вы должны увидеть:
```
withLoading(UserCard)
  UserCard
withLoading(ProductList)
  ProductList
```

Попробуйте передать неверный тип пропса оригинальному компоненту — TypeScript должен выдать ошибку.
