# Задание 14.2: Визуализатор Inverted Index

## Цель

Реализовать интерактивный визуализатор, который наглядно демонстрирует, как строится inverted index: tokenization, normalization, stemming, построение индекса и поиск с TF-IDF scoring.

## Требования

1. **Ввод документов** (textarea):
   - Пользователь вводит несколько документов (каждая строка = отдельный документ)
   - Кнопка «Построить индекс»
   - Примеры документов предзаполнены

2. **Визуализация tokenization → normalization → index**:
   - Показать для каждого документа: исходный текст → токены → нормализованные → стеммированные
   - Таблица inverted index: term → список doc_ids с term frequency
   - Отсортировать термы по алфавиту

3. **Поиск по индексу**:
   - Поле ввода запроса
   - Найденные документы с подсветкой совпавших термов
   - Для многословного запроса — пересечение posting lists (AND-логика)

4. **TF-IDF scoring**:
   - Для каждого найденного документа показать TF, IDF и итоговый TF-IDF score
   - Отсортировать результаты по убыванию score
   - Визуально выделить score (прогресс-бар или цвет)

## Чеклист

- [ ] Textarea для ввода документов (каждая строка = документ)
- [ ] Кнопка «Построить индекс» запускает индексацию
- [ ] Таблица tokenization: doc → tokens → normalized → stems
- [ ] Таблица inverted index: term → doc_ids (с term frequency)
- [ ] Поле поиска с AND-логикой для многословных запросов
- [ ] Результаты поиска с подсветкой совпавших термов
- [ ] TF-IDF scoring для каждого результата (TF, IDF, итого)
- [ ] Сортировка результатов по TF-IDF score

## Как проверить себя

1. Введите 3-5 документов с пересекающимися словами
2. Проверьте: inverted index содержит все уникальные термы
3. Введите запрос из одного слова — должны найтись все документы с этим словом
4. Введите запрос из двух слов — должны найтись только документы, содержащие оба
5. Проверьте: документ с более высоким TF-IDF стоит выше в результатах
6. Проверьте: редкое слово (высокий IDF) даёт больший вклад, чем частое
7. Сравните свой визуализатор с эталонным решением (Solution)
