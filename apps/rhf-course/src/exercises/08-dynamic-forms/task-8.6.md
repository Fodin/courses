# Задание 8.6: Field Array с валидацией и контролем

## Цель

Научиться управлять Field Array программно: перемещать, менять местами, вставлять элементы, ограничивать количество.

## Требования

Создайте форму управления командой:

1. **Название команды** — текстовое поле
2. **Список участников** (useFieldArray) с полями: имя и роль (select)
3. **Ограничения**: минимум 2 участника, максимум 5
4. **Управление порядком**: кнопки "Вверх" / "Вниз" (move), "Swap" (swap)
5. **Вставка**: кнопка "Вставить в начало" (insert)
6. **Индикатор**: показать текущее количество участников и лимиты
7. **Блокировка кнопки "Добавить"** при достижении максимума

## Чеклист

- [ ] Форма с названием команды и списком участников
- [ ] Минимум 2 участника при отправке (ошибка валидации если меньше)
- [ ] Максимум 5 участников (кнопка добавления заблокирована)
- [ ] Кнопки "Вверх" / "Вниз" для перемещения участников
- [ ] Кнопка "Swap" для обмена позициями соседних участников
- [ ] Кнопка "Вставить в начало" добавляет участника на первую позицию
- [ ] Индикатор количества участников

## Как проверить себя

1. Откройте форму — 2 участника по умолчанию
2. Удалите одного и попробуйте отправить — ошибка "Минимум 2 участника"
3. Добавьте участников до 5 — кнопка "Добавить" заблокируется
4. Нажмите "Вниз" у первого участника — он переместится на второе место
5. Нажмите "Swap" — участники поменяются местами
6. Нажмите "Вставить в начало" — новый участник появляется первым
