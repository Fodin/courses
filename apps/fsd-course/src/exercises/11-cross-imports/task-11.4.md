# Задание 11.4 — Разрыв cross-import через идентификатор (простое)

## Цель

Разорвать прямую связь между двумя слайсами одного слоя без @x — просто убрать
лишнюю зависимость.

## Что дано

- `entities/order/model/types.ts` — тип `Order`, который импортирует `Customer`
  из соседнего слайса и хранит объект покупателя целиком (`customer: Customer`).

## Требования

1. Уберите импорт `@/entities/customer` из `order/model/types.ts`.
2. Замените поле `customer: Customer` на `customerId: string` — сущность
   ссылается на покупателя по идентификатору, а не встраивает его.
3. Нажмите «Проверить».

## Чеклист

- [ ] В `order/model/types.ts` нет импорта соседнего слайса
- [ ] `Order` хранит `customerId: string`
- [ ] Пройти квиз уровня ≥ 80%
