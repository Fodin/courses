# Задание 6.4 — Виджет не импортирует вверх (простое)

## Цель

Убрать импорт «вверх» по слоям: виджет не должен знать про конкретную страницу.

## Что дано

- `widgets/header/ui/Header.tsx` (редактируемый) — рядом с корректным импортом
  `entities/user` тянет `PageTitle` прямо из `pages/dashboard`.

## Требования

1. Уберите импорт `PageTitle` и его использование из `Header.tsx`.
2. Оставьте в `Header.tsx` только импорт `entities/user`.
3. Нажмите «Проверить».

## Чеклист

- [ ] `Header.tsx` не импортирует ничего из `pages`
- [ ] Импорты уважают слои: `app → pages → widgets → features → entities → shared`
- [ ] Пройти квиз уровня ≥ 80%
