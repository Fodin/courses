# Задание 9.2: Сравнение инструментов генерации

## Цель

Создать интерактивный компонент для изучения трёх основных инструментов генерации TypeScript-кода из OpenAPI: `openapi-generator`, `openapi-typescript`, `orval`. Для каждого — что генерирует, плюсы, минусы, команда запуска, пример вывода. Плюс таблица сравнения.

## Требования

1. Реализовать интерфейс `Tool` с полями: `id`, `name`, `tagline`, `color`, `generates`, `pros`, `cons`, `command`, `output`
2. Описать 3 инструмента с реалистичным содержимым
3. Кнопки выбора инструмента: активная кнопка — цвет инструмента, неактивная — серая рамка
4. Отдельная кнопка "Таблица сравнения" — переключает видимость сравнительной таблицы
5. Таблица сравнения: 8+ критериев по строкам, 3 инструмента по столбцам
6. Детальный блок: хедер с тегами "что генерирует", плюсы/минусы в 2 колонки, команда + вывод на тёмном фоне

## Что реализовать

- [ ] Интерфейс `Tool` и массив `TOOLS` (3 элемента)
- [ ] Состояние `activeTool: string` и `showTable: boolean`
- [ ] Строка кнопок инструментов + кнопка таблицы
- [ ] Таблица сравнения (условный рендер при `showTable`)
- [ ] Хедер карточки инструмента: название, tagline, бейджи "что генерирует"
- [ ] Блок плюсов (зелёный заголовок) и минусов (красный заголовок) рядом
- [ ] Два блока кода: команда (зелёный текст `#a3e635`) и вывод (синий текст `#93c5fd`)

## Содержимое инструментов

| Инструмент | Цвет | Ключевые особенности |
|---|---|---|
| `openapi-generator` | `#10b981` | Java-зависимость, 50+ языков, Mustache-шаблоны |
| `openapi-typescript` | `#3b82f6` | Node.js, только типы, openapi-fetch интеграция |
| `orval` | `#8b5cf6` | React Query хуки, MSW-моки, Zod валидация |

## Как проверить себя

- Таблица показывается/скрывается по клику кнопки "Таблица сравнения"
- При выборе `orval` хедер карточки содержит "React Query хуки" как один из генерируемых продуктов
- В минусах `openapi-generator` упоминается Java/Docker зависимость
- Кнопка активного инструмента отображается с фоном цвета инструмента
- Таблица содержит строки "Runtime зависимость" и "Генерирует хуки"
