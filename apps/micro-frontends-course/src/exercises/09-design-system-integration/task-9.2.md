# Задание 9.2 — Конструктор Design Tokens

## Цель

Реализовать интерактивный конструктор дизайн-токенов с редактором четырёх категорий, live-preview компонентов, генератором кода и выбором стратегии распространения.

## Требования

1. Реализовать редактор четырёх категорий токенов: Цвета, Отступы, Типографика, Скругления
2. **Цвета**: 6 токенов (primary, secondary, success, error, background, text), управляемых через `<input type="color">`
3. **Отступы**: 5 токенов (xs, sm, md, lg, xl) через range-слайдеры (2–80px), визуализировать как столбчатую диаграмму
4. **Типографика**: select для font-family (5 вариантов), range-слайдеры для h1–h4, body, small
5. **Скругления**: range-слайдеры для sm, md, lg (0–32px), full фиксирован 9999px, визуализация фигурами
6. Реализовать live-preview: карточка товара с кнопками «Купить» и «Подробнее», статусные бейджи — всё использует текущие токены
7. Генерировать CSS в формате `:root { --ds-color-primary: ...; ... }`
8. Генерировать JSON в формате Design Tokens Community Group (поле `value` + `type`)
9. Переключатель CSS/JSON с кнопкой «Копировать»
10. Секция стратегии распространения: три radio-варианта (npm / federated / CDN) с описанием плюсов и минусов каждого

## Чеклист

- [ ] Переключатель четырёх категорий работает
- [ ] Color picker меняет цвета в live-preview в реальном времени
- [ ] Слайдеры отступов меняют визуализацию столбцов и live-preview
- [ ] Слайдеры скруглений меняют форму фигур-превью
- [ ] Live-preview отражает ВСЕ изменения токенов (цвет кнопки, отступы, скругления, шрифт)
- [ ] CSS-экспорт содержит все токены с правильными префиксами `--ds-`
- [ ] JSON-экспорт содержит поля `value` и `type` для каждого токена
- [ ] Кнопка «Копировать» копирует код в буфер и показывает подтверждение
- [ ] Выбор стратегии отображает плюсы и минусы выбранного варианта

## Как проверить себя

1. Откройте вкладку «Цвета», измените primary на любой цвет — кнопка «Купить» в live-preview должна немедленно поменять цвет.
2. Откройте вкладку «Отступы», подвиньте слайдер md — отступы внутри карточки должны измениться.
3. Откройте вкладку «Скругления», измените lg — угол карточки в превью должен измениться.
4. Переключитесь в режим CSS, нажмите «Копировать», вставьте в редактор — должен быть валидный CSS с переменными `--ds-color-*`, `--ds-spacing-*` и т.д.
5. Переключитесь в режим JSON — структура должна соответствовать формату `{ "color": { "primary": { "value": "#...", "type": "color" } } }`.
6. Выберите стратегию «CDN» — должны появиться плюсы и минусы именно для CDN-варианта.
