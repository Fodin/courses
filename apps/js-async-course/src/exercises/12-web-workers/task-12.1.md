# Задание 12.1: Web Worker — тяжёлое вычисление

## Цель

Наглядно показать разницу между выполнением CPU-bound задачи на главном потоке и в Web Worker. В первом случае UI замирает, во втором — остаётся полностью отзывчивым. Использовать реальный Inline Worker через Blob URL.

## Требования

1. **Два режима** (вкладки): "Main Thread" и "Web Worker"

2. **Вычисление:** рекурсивный Фибоначчи fib(N), где N выбирается слайдером (30–45)

3. **Main Thread режим:**
   - Вычисление выполняется синхронно через `setTimeout(fn, 16)` (один кадр для рендера)
   - Спиннер останавливается во время вычисления
   - Кнопка "Кликни меня" не реагирует на клики

4. **Web Worker режим:**
   - Создать реальный Inline Worker через `new Blob([code])` + `URL.createObjectURL()`
   - Код воркера содержит `self.onmessage` и выполняет fib(N)
   - Спиннер продолжает крутиться — UI отзывчив
   - Кнопка "Кликни меня" работает во время вычисления

5. **Визуализация потоков:** два блока "Main Thread" и "Worker Thread" с цветовой индикацией — кто сейчас занят

6. **Метрики:** время вычисления в мс, отображается после завершения

7. **Cleanup:** `worker.terminate()` после получения результата, `clearInterval` спиннера при размонтировании

## Чеклист

- [ ] Компонент `Task12_1` использует `useLanguage` и `t('task.12.1')` в заголовке
- [ ] Слайдер N работает в диапазоне 30–45
- [ ] Создаётся реальный Web Worker через Blob URL (не симуляция)
- [ ] В режиме Main Thread: спиннер останавливается во время вычисления
- [ ] В режиме Web Worker: спиннер крутится пока воркер считает
- [ ] Кнопка "Кликни меня" с счётчиком кликов
- [ ] Визуализация двух потоков с индикацией активности
- [ ] Время вычисления отображается после завершения
- [ ] `worker.terminate()` вызывается после получения результата
- [ ] Нет TypeScript ошибок с `any`

## Как проверить себя

1. Откройте вкладку "Main Thread", выберите N=40
2. Нажмите кнопку "Кликни меня" несколько раз (счётчик увеличивается)
3. Запустите вычисление — блок "Main Thread" должен покраснеть
4. Попробуйте нажать "Кликни меня" — не сработает (UI заморожен)
5. Переключитесь на "Web Worker", снова запустите
6. Спиннер крутится, "Кликни меня" работает — Worker считает в фоне
7. По завершении — отображается результат и время
