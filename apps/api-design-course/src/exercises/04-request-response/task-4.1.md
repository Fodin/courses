# Задание 4.1 — Трансформатор JSON-ответов

## Цель

Научиться распознавать типичные проблемы в структуре JSON-ответов API и применять конвенции именования, форматирования данных и структурирования объектов.

## Требования

1. Компонент отображает не менее 5 примеров «плохих» JSON-ответов из реальных ситуаций.
2. Каждый пример сопровождается списком конкретных проблем.
3. Кнопка «Показать исправление» раскрывает правильный вариант с объяснением каждого изменения.
4. Примеры разбиты по категориям: именование, структура, форматы данных, ошибки.
5. Присутствует фильтрация по категориям.

## Чеклист

- [ ] Минимум 5 примеров плохих ответов
- [ ] Для каждого — список проблем
- [ ] Кнопка переключения на исправленный вариант
- [ ] Объяснение каждого исправления
- [ ] Категории: именование, структура, форматы данных, ошибки
- [ ] Фильтр по категориям

## Как проверить себя

Закройте теорию. Откройте компонент и попробуйте объяснить все проблемы каждого примера до нажатия кнопки «Показать исправление». Если вы нашли все проблемы и объяснили почему каждая из них плохая — задание выполнено.
