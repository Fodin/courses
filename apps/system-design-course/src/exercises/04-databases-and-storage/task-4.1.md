# Задание 4.1: Квиз — Базы данных и хранение

## Цель

Проверить понимание типов баз данных (SQL vs NoSQL), CAP-теоремы, ACID vs BASE, шардирования, репликации и индексирования.

## Требования

1. Прочитайте теорию уровня 4 (README)
2. Пройдите квиз из 5 вопросов по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ (один или несколько)
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист

- [ ] Прочитана теория по SQL vs NoSQL (Document, Key-Value, Column-Family, Graph)
- [ ] Понятна разница между ACID и BASE
- [ ] Понятна CAP-теорема и реальный выбор CP vs AP
- [ ] Знакомы с репликацией (Master-Slave, Master-Master)
- [ ] Понятны стратегии шардирования (Range, Hash, Directory)
- [ ] Знакомы с типами индексов (B-tree, Hash, Composite)
- [ ] Понятна роль connection pooling
- [ ] Пройден квиз с результатом не менее 80%

## Как проверить себя

1. Откройте квиз и ответьте на все вопросы
2. Проверьте объяснения для неправильных ответов
3. Если результат ниже 80% — перечитайте соответствующие разделы теории
