# Задание 15.1: Квиз — Тестирование

## Цель
Проверить понимание стратегий тестирования: пирамида тестов, Test Doubles, TDD и property-based тестирование.

## Требования
1. Прочитайте теорию уровня 15 (README)
2. Пройдите квиз по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист
- [ ] Прочитана теория по пирамиде тестирования (unit, integration, e2e)
- [ ] Изучен паттерн AAA (Arrange, Act, Assert)
- [ ] Разобраны Test Doubles: Mock, Stub, Spy, Fake
- [ ] Понята методология TDD (Red-Green-Refactor)
- [ ] Изучено property-based тестирование
- [ ] Пройден квиз с результатом не менее 80%

## Как проверить себя
1. Откройте квиз и ответьте на все вопросы
2. Проверьте объяснения для неправильных ответов
3. Если результат ниже 80% — перечитайте соответствующие разделы теории
