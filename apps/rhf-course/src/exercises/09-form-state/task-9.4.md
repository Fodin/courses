# Задание 9.4: Отправка только изменённых полей (Dirty Fields Only)

## Цель

Научиться использовать dirtyFields для отправки только изменённых данных (PATCH-запрос).

## Требования

Создайте форму редактирования профиля с предзаполненными данными:

1. **Поля**: имя, фамилия, email, о себе, город — все предзаполнены из "сохранённого профиля"
2. **dirtyFields**: визуально отмечать изменённые поля (индикатор "изменено")
3. **При отправке**: показать два блока:
   - PATCH (только изменённые поля из dirtyFields)
   - PUT (все данные формы)
4. **Кнопка "Сохранить"** заблокирована, если форма не изменена (isDirty === false)
5. **Живое превью**: показывать, какие поля изменены, до отправки

## Чеклист

- [ ] Форма предзаполнена данными профиля
- [ ] Возле изменённых полей — индикатор "изменено"
- [ ] Блок состояния показывает "Есть изменения" / "Без изменений"
- [ ] При изменениях отображается превью dirty-данных
- [ ] Кнопка "Сохранить" заблокирована без изменений
- [ ] После отправки — два блока: PATCH (dirty) и PUT (all)

## Как проверить себя

1. Откройте форму — все поля заполнены, кнопка "Сохранить" заблокирована
2. Измените имя — появляется индикатор "изменено", кнопка разблокируется
3. В блоке состояния видно, какие данные будут отправлены
4. Измените ещё email — в превью два изменённых поля
5. Нажмите "Сохранить" — PATCH содержит только изменённые поля, PUT — все
