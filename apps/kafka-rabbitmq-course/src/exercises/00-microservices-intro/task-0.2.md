# Задание 0.2: Карта зависимостей сервисов

## Цель

Создать интерактивный граф зависимостей между микросервисами. Клик на сервис должен наглядно
показывать его зависимости и blast radius — какие сервисы пострадают при его падении.

## Требования

1. Отобразить граф из 5-6 микросервисов в виде SVG или HTML-блоков:
   API Gateway, User Service, Order Service, Payment Service, Inventory Service, Notification Service
2. Между сервисами должны быть нарисованы линии/стрелки зависимостей
3. При клике на сервис:
   - Сам сервис подсвечивается красным (упавший)
   - Сервисы, которые зависят от него, подсвечиваются красным (напрямую затронуты)
   - Сервисы, от которых он зависит, подсвечиваются синим (его зависимости)
   - Остальные сервисы становятся полупрозрачными
4. Под графом должно появляться текстовое описание blast radius:
   список сервисов, которые перестанут работать при падении выбранного
5. Повторный клик на тот же сервис снимает выделение
6. Хотя бы один сервис должен не иметь зависимых (изолированное падение)

## Чеклист

- [ ] Граф содержит минимум 5 сервисов
- [ ] Линии зависимостей отображаются между сервисами
- [ ] Клик подсвечивает нужные сервисы разными цветами
- [ ] Незатронутые сервисы становятся полупрозрачными
- [ ] Текстовый блок описывает blast radius
- [ ] Повторный клик снимает выделение
- [ ] Легенда объясняет цвета
- [ ] Компонент использует `useLanguage` и `t('task.0.2')` для заголовка

## Как проверить себя

1. Кликните на API Gateway — должны подсветиться все сервисы, которые его используют
2. Кликните на Notification Service — он ни от чего не зависит по downstream, должно быть сообщение
   об изолированном падении (или минимальный blast radius)
3. Кликните на Order Service — должны подсветиться зависимые сервисы
4. Убедитесь что легенда показывает значение каждого цвета
5. Повторный клик на тот же сервис должен снять все выделения
