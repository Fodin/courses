# Задание 2.3: Визуализатор Consistent Hashing

## Цель

Построить интерактивный визуализатор consistent hashing — хэш-кольцо с серверами, ключами и virtual nodes. Наглядно показать, почему при добавлении/удалении серверов перемещается минимум ключей.

## Требования

1. Реализуйте хэш-кольцо (0...359 для наглядности, как градусы)
2. Отображайте серверы и ключи на кольце в табличном/текстовом виде:
   - Позиция на кольце (0-359)
   - Какой сервер обслуживает какие ключи (ближайший по часовой стрелке)
3. Кнопки для:
   - Добавления сервера (с рандомным именем)
   - Удаления сервера
   - Добавления ключа (с рандомным именем)
4. При изменении серверов покажите:
   - Сколько ключей перераспределилось
   - Процент перемещённых ключей (сравните с hash % N)
5. Реализуйте переключатель virtual nodes (вкл/выкл):
   - Без virtual nodes: 1 точка на сервер
   - С virtual nodes: 3-5 точек на сервер
6. Покажите статистику распределения: сколько ключей на каждом сервере и насколько равномерно

## Чеклист

- [ ] Хэш-кольцо отображает серверы и ключи с позициями
- [ ] Добавление сервера перераспределяет только ~1/N ключей
- [ ] Удаление сервера перераспределяет только ключи удалённого сервера
- [ ] Показана разница: consistent hashing vs hash % N по количеству перемещений
- [ ] Virtual nodes улучшают равномерность распределения
- [ ] Статистика распределения ключей по серверам видна

## Как проверить себя

1. Добавьте 3 сервера и 10 ключей — каждый ключ должен быть привязан к ближайшему серверу по часовой стрелке
2. Добавьте 4-й сервер — должно переместиться ~25% ключей (не все!)
3. Включите virtual nodes — распределение должно стать равномернее
4. Сравните: при consistent hashing переместилось ~1/N ключей, при hash % N — гораздо больше
