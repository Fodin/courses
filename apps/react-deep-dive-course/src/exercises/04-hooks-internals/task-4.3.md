# Задание 4.3: The Closure Trap

## Цель

Исследовать проблему stale closure на реальном примере с `setInterval` и освоить три способа её решения.

## Задание

Реализуй три версии компонента-таймера рядом на экране:

**Версия 1 — Баг (Stale Closure):**
- `setInterval` каждую секунду увеличивает счётчик через `setCount(count + 1)`
- Счётчик застревает на 1 (или другом маленьком числе)
- Добавь объяснение: почему это происходит

**Версия 2 — Исправление через Functional Updater:**
- Тот же `setInterval`, но `setCount(prev => prev + 1)`
- Счётчик растёт корректно
- Добавь объяснение: React передаёт актуальный `prev` из очереди

**Версия 3 — Исправление через useRef:**
- `countRef.current = count` при каждом рендере
- В `setInterval` используем `countRef.current + 1`
- Счётчик растёт корректно

## Требования

1. Три колонки на экране: "Баг", "Functional Updater", "useRef"
2. В каждой колонке:
   - Большой счётчик (видно застрял ли)
   - Кнопки "Старт" / "Стоп"
   - Блок с кратким объяснением
3. Все три таймера независимые (разные `useEffect` и `useRef`)
4. Цветовая индикация: баг — красный, исправления — зелёный
5. Кнопка "Сброс" для каждой колонки

## Чеклист

- [ ] Колонка "Баг": счётчик застревает на маленьком числе
- [ ] Колонка "Functional Updater": счётчик растёт бесконечно
- [ ] Колонка "useRef": счётчик растёт бесконечно
- [ ] Кнопки Старт/Стоп работают независимо в каждой колонке
- [ ] Кнопка Сброс сбрасывает только свою колонку
- [ ] Объяснение в каждой колонке
- [ ] Визуальное различие между багом и исправлениями

## Как проверить себя

1. Запусти все три таймера — через 5 секунд Версия 1 покажет 1, Версии 2 и 3 — 5
2. Останови и снова запусти Версию 1 — она опять застрянет на 1
3. Сбрось все три и убедись, что счётчики независимые
4. Объясни себе вслух, почему functional updater решает проблему
