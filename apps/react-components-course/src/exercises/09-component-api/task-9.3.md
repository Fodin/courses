# Задание 9.3: SelectableList — generic компонент

## Цель

Реализовать generic компонент `SelectableList<T>`, который работает с любым типом данных. Компонент не знает ничего о структуре элементов — всё управление рендерингом и ключами делегируется через props-функции.

## Требования

1. Компонент принимает generic параметр `T`
2. Props компонента:
   - `items: T[]` — массив элементов
   - `selectedItem: T | null` — выбранный элемент
   - `onSelect: (item: T) => void` — колбэк при выборе
   - `renderItem: (item: T, isSelected: boolean) => React.ReactNode` — функция рендеринга элемента
   - `keyExtractor: (item: T) => string` — функция получения уникального ключа
3. При клике на элемент вызывается `onSelect(item)`
4. Выбранный элемент визуально выделяется
5. Демонстрация: два списка с разными типами данных — `User[]` и `Product[]`. Каждый список показывает выбранный элемент ниже

## Подсказки

- Для сравнения "выбран ли элемент" используй `keyExtractor`: `keyExtractor(item) === keyExtractor(selectedItem)`
- `renderItem` принимает `isSelected: boolean` — позволяет самому caller-у менять стиль
- `T` не нужно ограничивать через `extends` — компонент работает с любым типом
- В демо создай два разных набора данных и два экземпляра компонента с разными типами

## Чеклист

- [ ] Компонент объявлен как `function SelectableList<T>(...)`
- [ ] `onSelect` типизирован как `(item: T) => void` — TypeScript знает тип при вызове
- [ ] `renderItem` принимает `(item: T, isSelected: boolean) => React.ReactNode`
- [ ] `keyExtractor` принимает `(item: T) => string`
- [ ] Выбранный элемент определяется через `keyExtractor`, не через `===`
- [ ] В демо: список пользователей с `User[]` и список товаров с `Product[]`
- [ ] TypeScript вывел `T` автоматически без явного указания `<User>` или `<Product>`
- [ ] Нет `any` в типах

## Как проверить себя

Откройте задание в браузере. Вы должны увидеть два независимых списка. При клике на элемент:
- Элемент визуально выделяется (например, синим фоном)
- Под списком появляется информация о выбранном элементе
- Выбор в одном списке не влияет на другой

Проверьте в TypeScript: в `renderItem` callback первый аргумент должен иметь правильный тип (`User` для первого списка, `Product` — для второго).
