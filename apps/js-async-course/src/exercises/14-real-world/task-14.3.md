# Задание 14.3: Real-time Dashboard

## Цель

Построить real-time дашборд с тремя метриками сервера (CPU, Memory, Req/s), используя полный async pipeline: async-генератор производит данные → Web Worker агрегирует статистику → `requestAnimationFrame` обновляет SVG-графики.

## Требования

1. **Источник данных**: async-генератор `metricStream(signal)` производит случайные метрики каждые 200ms (плавное случайное блуждание). Принимает `AbortSignal` для остановки.

2. **Web Worker агрегация**: реальный Worker (через `Blob URL`), который принимает массив метрик и возвращает `{ min, max, avg, history }` для каждого ключа (`cpu`, `memory`, `rps`).

3. **rAF render loop**: `requestAnimationFrame` запускается при старте и вызывает обновление статистики из актуальных данных. Отдельный счётчик FPS показывает реальную частоту кадров.

4. **SVG sparklines**: для каждой метрики — мини-график (sparkline) в виде ломаной линии на SVG. Показывает последние 60 значений. Плюс пунктирная линия среднего значения.

5. **Статистика под графиком**: min, max, avg за последние ~30 секунд (150 точек × 200ms).

6. **Кнопки управления**: "Старт" запускает весь pipeline. "Пауза" приостанавливает обновление UI (данные продолжают генерироваться, но не отображаются). "Стоп" полностью останавливает pipeline и очищает Worker.

7. **AbortController**: одна кнопка "Стоп" через `ctrl.abort()` останавливает и генератор, и Worker, и rAF.

8. **FPS индикатор**: показывает реальную частоту кадров. Зелёный ≥55 FPS, жёлтый ≥30, красный <30. Это демонстрирует что UI не тормозит несмотря на поток данных каждые 200ms.

## Чеклист

- [ ] Компонент называется `Task14_3` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован, `t('task.14.3')` используется в заголовке
- [ ] Async-генератор принимает `AbortSignal` и корректно останавливается при `signal.aborted`
- [ ] Worker создаётся через `new Blob([code])` + `URL.createObjectURL` — реальный Worker, не симуляция
- [ ] Worker принимает `{ metrics, key }` и отвечает `{ key, min, max, avg, history }`
- [ ] `requestAnimationFrame` используется для обновления отображения (не `setInterval`)
- [ ] SVG sparkline показывает ломаную линию по последним значениям
- [ ] FPS индикатор обновляется каждую секунду и показывает реальное значение
- [ ] "Пауза" останавливает обновление графиков, но не генератор
- [ ] "Стоп" через `ctrl.abort()` останавливает всё: генератор, Worker, rAF
- [ ] `useEffect` cleanup корректно вызывает `stop()` при размонтировании
- [ ] Нет TypeScript-ошибок `any`

## Как проверить себя

1. Нажмите "Старт" — три графика начинают обновляться в реальном времени
2. FPS индикатор должен показывать ~60 (зелёный) — UI не тормозит
3. Нажмите "Пауза" — графики перестают обновляться, но генератор работает
4. Нажмите "Продолжить" — графики сразу показывают актуальные значения
5. Нажмите "Стоп" — все графики замирают, статистика сохраняется
6. Откройте DevTools → вкладку Workers — убедитесь что Worker создаётся при старте
7. После "Стоп" Worker должен исчезнуть из списка (terminate вызван)
