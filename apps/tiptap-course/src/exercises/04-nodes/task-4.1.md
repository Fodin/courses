# Задание 4.1: Заголовки

## Цель

Построить панель кнопок H1–H3, которые переключают уровень заголовка текущего блока, с подсветкой активного уровня.

## Требования

1. Создайте `editor` с `StarterKit.configure({ heading: { levels: [1, 2, 3] } })`
2. Три кнопки H1, H2, H3, каждая вызывает `toggleHeading({ level })`
3. Подсветите активную кнопку через `isActive('heading', { level })`
4. Добавьте кнопку "Параграф" — вызывает `setParagraph()`, превращает текущий блок обратно в обычный параграф
5. Продемонстрируйте, что повторный клик на активный уровень заголовка возвращает параграф (toggle-семантика)

## Чеклист

- [ ] Компонент называется `Task4_1` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.4.1')` используется в заголовке
- [ ] H1/H2/H3 переключаются корректно, подсветка работает
- [ ] Кнопка "Параграф" возвращает обычный текстовый блок
- [ ] Уровни выше 3 недоступны (levels ограничены конфигурацией)
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Поставьте курсор в параграф, нажмите H2 — блок должен стать заголовком 2 уровня
2. Нажмите H2 ещё раз — блок должен вернуться в параграф
3. Переключитесь между H1/H2/H3 — только одна кнопка должна быть подсвечена одновременно
