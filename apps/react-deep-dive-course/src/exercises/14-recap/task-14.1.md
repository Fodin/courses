# Задание 14.1: Full Lifecycle Diagram

## Задание

Создайте интерактивную диаграмму полного жизненного цикла React. Диаграмма показывает
путь от `setState` до обновления DOM и запуска эффектов. Каждый блок кликабелен —
при клике появляется popover с кратким объяснением этапа.

---

## Цель

Визуализировать и закрепить в памяти полную цепочку React: от пользовательского действия
до момента, когда браузер отрисовал изменение и сработали эффекты.

---

## Требования

1. Диаграмма состоит из минимум 9 блоков: `setState` → `dispatchSetState` → `Scheduler` →
   `Work Loop` → `beginWork` → `Reconciliation` → `completeWork` → `Commit (Mutation)` →
   `DOM Update` → `Effects (passive)`
2. Блоки соединены стрелками, показывающими направление потока
3. При клике на блок — появляется popover/tooltip с объяснением (2-4 предложения)
4. Активный (кликнутый) блок визуально подсвечивается (другой цвет фона/рамки)
5. Блок `Commit` разделён на три подфазы: Before Mutation, Mutation, Layout — показаны
   отдельно внутри группирующего контейнера
6. Кнопка "Сбросить" снимает подсветку и закрывает popover
7. При клике на уже активный блок — popover закрывается

---

## Чеклист

- [ ] Минимум 9 кликабельных блоков с уникальными объяснениями
- [ ] Активный блок визуально отличается от остальных
- [ ] Popover показывает название этапа и объяснение
- [ ] Commit-секция содержит три подфазы (Before Mutation, Mutation, Layout)
- [ ] Кнопка "Сбросить" работает корректно
- [ ] Повторный клик по активному блоку закрывает popover
- [ ] Стрелки между блоками показывают направление потока

---

## Как проверить себя

1. Кликните на `setState` — появляется popover с объяснением `dispatchSetState`
2. Кликните на `Work Loop` — блок подсвечивается, показывается объяснение
3. Кликните на `Mutation` (внутри Commit) — работает как отдельный блок
4. Нажмите "Сбросить" — все блоки возвращаются в обычное состояние
5. Кликните дважды на один блок — popover исчезает

---

## Подсказки

- Храните `activeBlock: string | null` в useState
- Объяснения для блоков удобно хранить в объекте `const EXPLANATIONS: Record<string, { title, text }>`
- Для popover используйте `position: absolute` относительно блока или фиксированный панель снизу
- Commit-секцию можно обернуть в `div` с пунктирной рамкой и подписью "Commit Phase"
- Стрелки между блоками: символ `→` между `<div>` элементами или SVG
