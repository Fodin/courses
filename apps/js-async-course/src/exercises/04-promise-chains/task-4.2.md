# Задание 4.2: Error Propagation — визуализатор распространения ошибок

## Цель

Построить интерактивный компонент, демонстрирующий, как ошибка "пролетает" через цепочку `.then()` и ловится в `.catch()`. Студент управляет переключателями: "сломать шаг N" и "режим Recovery" — и видит, как меняется поведение цепочки.

## Требования

1. Отобразить цепочку из 5 блоков `.then()` и 1 блока `.catch()` в конце
2. Переключатели "Сломать шаг 1..5" — при выборе шага N:
   - Шаги 1..N-1 отображаются зелёными (fulfilled)
   - Шаг N — красным (rejected, throw Error)
   - Шаги N+1..5 — серыми с пометкой "пропущен (ошибка летит)"
   - `.catch()` — оранжевым с пометкой "caught"
3. Кнопка "Нет ошибки" — все шаги зелёные, `.catch()` не активирован
4. Переключатель "Recovery: ВКЛ/ВЫКЛ":
   - Если ВЫКЛ: `.catch()` ловит, цепочка завершается
   - Если ВКЛ: `.catch()` возвращает значение → появляется дополнительный `.then(afterCatch)` с зелёным состоянием
5. Code-сниппет слева обновляется при изменении переключателей, показывая ✓/✗/— для каждого шага
6. Пояснительный текст внизу описывает текущее состояние

- [ ] `.catch()` меняет цвет в зависимости от режима (caught / recovered)
- [ ] Переключатель Recovery добавляет `.then(afterCatch)` в цепочку

## Как проверить себя

1. Откройте компонент — все шаги должны быть в нейтральном состоянии ("Нет ошибки" выбран)
2. Нажмите "Шаг 1" — первый блок становится красным, остальные .then() — серыми
3. Нажмите "Шаг 3" — первые два зелёные, третий красный, четвёртый и пятый серые
4. Включите "Recovery" при выбранном "Шаг 3" — `.catch()` должен стать зелёным, появится `.then(afterCatch)` ниже
5. Нажмите "Нет ошибки" — все блоки зелёные, `.catch()` не активирован
