# Задание 0.1: Визуализатор Call Stack

## Цель

Построить интерактивный визуализатор, который показывает пошаговое выполнение цепочки вложенных функций: как фреймы появляются на стеке (push) и снимаются с него (pop). Второй режим — демонстрация роста стека при рекурсии и эффекта Stack Overflow.

## Требования

1. **Режим "Трассировка вызовов"** — показывает цепочку `a() → b() → c() → d()`:
   - Слева отображается код с подсветкой текущей активной строки
   - Справа — вертикальная стопка фреймов (последний добавленный — сверху)
   - Кнопка "Шаг вперёд" переводит к следующему событию (push или pop)
   - Каждый шаг сопровождается текстовым описанием происходящего
   - Кнопка "Сброс" возвращает в начальное состояние

2. **Режим "Глубина рекурсии"** — демонстрирует рост стека:
   - Слайдер позволяет выбрать глубину от 1 до 30
   - Отображается соответствующее количество фреймов визуально
   - При глубине > 25 отображается сообщение об ошибке `RangeError: Maximum call stack size exceeded`
   - При безопасной глубине — зелёное сообщение о корректном выполнении

3. **Визуальное оформление** — самодостаточный компонент с inline CSS:
   - Тёмная тема (фон `#0f172a`)
   - Текущий (верхний) фрейм выделяется ярче остальных
   - Плавные переходы цвета при появлении/исчезновении фреймов

4. **Подсветка кода** — номера строк и выделение активной строки через `borderLeft` синего цвета

5. **Навигация** — кнопки заблокированы (визуально) в крайних положениях (начало/конец трассировки)

6. **Оба режима** — реализованы через вкладки (tabs) без смены страницы

## Чеклист

- [ ] Компонент называется `Task0_1` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован и `t('task.0.1')` используется в заголовке
- [ ] Режим трассировки показывает как минимум 4 вложенных вызова с push/pop
- [ ] Подсветка текущей строки кода меняется при каждом шаге
- [ ] Стек отображается вертикально, верхний фрейм визуально активен
- [ ] Слайдер глубины рекурсии работает от 1 до 30
- [ ] При depth > 25 отображается визуальное предупреждение об overflow
- [ ] Кнопки "Шаг вперёд" и "Сброс" корректно меняют состояние
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Откройте компонент в браузере — должна отображаться вкладка "Трассировка вызовов"
2. Нажмите "Шаг вперёд" 4 раза — стек должен содержать 4 фрейма (`a`, `b`, `c`, `d`)
3. Нажмите ещё 4 раза — стек должен полностью очиститься
4. Нажмите "Сброс" — стек снова пустой, шаг сброшен в 0
5. Переключитесь на вкладку "Глубина рекурсии"
6. Установите слайдер в значение 10 — должно появиться 10 фреймов (зелёное сообщение)
7. Установите слайдер в значение 28 — должно появиться сообщение об ошибке RangeError
