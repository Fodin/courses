# Задание 5.3: Effect Chains Refactor (YMNAE)

## Цель

Увидеть проблему каскадных рендеров из-за Effect chains и научиться рефакторить их в один Event Handler.

## Задание

Тебе дан компонент `CardGame` — упрощённая карточная игра. Логика победы разбросана по трём `useEffect`. Компонент отображает счётчик рендеров — и он показывает **4 рендера** за один клик.

### Исходный код (с проблемой):

```tsx
function CardGame() {
  const [card, setCard] = useState<Card | null>(null)
  const [goldCardCount, setGoldCardCount] = useState(0)
  const [round, setRound] = useState(1)
  const [isGameOver, setIsGameOver] = useState(false)
  const renderCount = useRef(0)

  // Effect chain — 3 каскадных рендера после клика
  useEffect(() => {
    if (card !== null && card.isGold) {
      setGoldCardCount(c => c + 1)
    }
  }, [card])

  useEffect(() => {
    if (goldCardCount > 0 && goldCardCount % 3 === 0) {
      setRound(r => r + 1)
    }
  }, [goldCardCount])

  useEffect(() => {
    if (round > 5) {
      setIsGameOver(true)
    }
  }, [round])

  function handleDraw() {
    const isGold = Math.random() < 0.4
    setCard({ id: Date.now(), isGold })
  }

  renderCount.current++
  // ...
}
```

## Требования

1. Реализуй **две версии** компонента рядом:
   - Левая: с Effect chain (исходный вариант) — счётчик рендеров показывает 4
   - Правая: рефакторинг в один Event Handler — счётчик показывает 1
2. Обе версии функционально идентичны: тянут карту, считают золотые, повышают раунд, определяют конец игры
3. Карта отображается как цветной блок: золотая (жёлтый) / обычная (серый)
4. Счётчик рендеров — большое число, наглядно показывающее разницу
5. Кнопка "Вытянуть карту" в обоих вариантах
6. Кнопка "Новая игра" сбрасывает состояние

## Правила игры

- 40% вероятность выпадения золотой карты
- Каждые 3 золотых карты → следующий раунд (goldCardCount сбрасывается)
- После 5 раунда → "Игра окончена"

## Чеклист

- [ ] Левый вариант (с Effects) показывает счётчик рендеров +4 за каждый клик при золотой карте
- [ ] Правый вариант (один handler) показывает +1 за любой клик
- [ ] Оба варианта реализуют одну логику победы
- [ ] Счётчик рендеров живёт в `useRef` (не вызывает лишних рендеров)
- [ ] Кнопки "Вытянуть" и "Новая игра" работают в обоих вариантах
- [ ] Визуально понятна разница (цвет/размер счётчика)

## Как проверить себя

1. Запусти левый вариант, нажимай "Вытянуть" пока не выпадет золотая карта
2. Проверь, что счётчик прыгает на 2-4 за один клик (в зависимости от того, сработали ли эффекты цепочки)
3. Запусти правый вариант — счётчик всегда +1 за клик
4. Убедись, что оба варианта ведут себя одинаково (доходят до конца игры)

> **Подсказка**: в правом варианте вычисли goldCardCount, round и isGameOver локально внутри handleDraw, затем вызови все setState за один проход.
