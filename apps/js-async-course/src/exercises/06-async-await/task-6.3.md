# Задание 6.3: Sequential vs Parallel

## Цель

Реализовать визуальное сравнение последовательного `await` и `Promise.all` с анимированным timeline. Три задачи с разным временем выполнения. Наглядно показать разницу во времени: при последовательном выполнении — сумма, при параллельном — максимум.

## Требования

1. **Две вкладки:**
   - "Последовательно (await)" — задачи выполняются одна за другой
   - "Параллельно (Promise.all)" — все задачи стартуют одновременно

2. **Три задачи с фиксированными длительностями:**
   - `fetchUser` — 1000ms
   - `fetchPosts` — 1500ms
   - `fetchComments` — 800ms

3. **Анимированный timeline:**
   - Для каждой задачи — горизонтальная полоса прогресса
   - Последовательный режим: полосы заполняются одна за другой (со смещением)
   - Параллельный режим: все полосы заполняются одновременно
   - Анимация через `requestAnimationFrame`

4. **Метрики:**
   - Счётчик прошедшего времени (в ms) во время выполнения
   - Итоговое время после завершения с теоретическим значением
   - Сообщение об ускорении для параллельного режима

5. **Блок с кодом** показывает соответствующий вариант для каждого режима

6. **Управление:** кнопки "Запустить" и "Сброс"

## Чеклист

- [ ] Компонент называется `Task6_3` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован и `t('task.6.3')` используется в заголовке
- [ ] В последовательном режиме полосы заполняются поочерёдно (видно смещение)
- [ ] В параллельном режиме все три полосы растут одновременно
- [ ] После завершения показывается итоговое время
- [ ] Переключение вкладок сбрасывает анимацию
- [ ] Кнопка "Запустить" заблокирована во время анимации
- [ ] Нет утечек requestAnimationFrame при размонтировании

## Как проверить себя

1. Последовательный режим: нажмите "Запустить" — наблюдайте как полосы заполняются по очереди (~3.3с общее время)
2. Параллельный режим: нажмите "Запустить" — все три полосы растут одновременно (~1.5с)
3. Итоговое время в последовательном режиме ≈ 3300ms, в параллельном ≈ 1500ms
4. "Сброс" обнуляет все полосы и таймер
5. При переключении вкладки во время анимации — анимация корректно останавливается
