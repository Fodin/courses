# Задание 3.1: Квиз — Кэширование

## Цель

Проверить понимание паттернов кэширования, стратегий инвалидации, eviction policies и типичных проблем (stampede, penetration, avalanche).

## Требования

1. Прочитайте теорию уровня 3 (README)
2. Пройдите квиз из 5 вопросов по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ (один или несколько)
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист

- [ ] Прочитана теория по многоуровневому кэшированию
- [ ] Понятна разница между Cache-Aside и Read-Through
- [ ] Понятна разница между Write-Through и Write-Behind
- [ ] Знакомы со стратегиями инвалидации (TTL, event-based, versioning)
- [ ] Понятны eviction policies (LRU, LFU, FIFO)
- [ ] Знакомы с проблемами: cache stampede, penetration, avalanche
- [ ] Понятны HTTP cache headers (Cache-Control, ETag)
- [ ] Пройден квиз с результатом не менее 80%

## Как проверить себя

1. Откройте квиз и ответьте на все вопросы
2. Проверьте объяснения для неправильных ответов
3. Если результат ниже 80% — перечитайте соответствующие разделы теории
