# Задание 3.1: Конструктор Promise — визуализатор состояний

## Цель

Создать интерактивный визуализатор жизненного цикла промиса: три состояния как цветные плашки (pending / fulfilled / rejected), управление через кнопки, лог событий с разделением синхронного и асинхронного кода.

## Требования

1. **Три состояния** отображаются как цветные блоки:
   - `pending` — серый (`#64748b`), начальное состояние
   - `fulfilled` — зелёный (`#10b981`), с отображением значения
   - `rejected` — красный (`#ef4444`), с отображением причины
   - Активное состояние выделено рамкой и свечением

2. **Поле ввода** для значения, которое передаётся в `resolve(значение)`

3. **Три кнопки управления:**
   - `resolve("значение")` — переводит промис в fulfilled
   - `reject(new Error("Ошибка!"))` — переводит в rejected
   - `throw внутри executor` — показывает, что throw = reject

4. **Иммутабельность settled-промиса:**
   - После перехода в settled кнопки resolve/reject/throw продолжают работать, но повторный вызов игнорируется
   - При попытке повторно resolve/reject — показывается визуальный "замок" (🔒) с сообщением об игнорировании
   - В лог добавляется запись о попытке

5. **Лог событий** с временными метками (относительными от момента сброса):
   - `SYNC` (синий) — executor выполнен синхронно
   - `ASYNC` (фиолетовый) — колбэк .then()/.catch() выполнен асинхронно
   - `IGNORE` (красный) — попытка изменить settled промис проигнорирована

6. **Кнопка "Сброс"** — возвращает промис в pending, очищает лог

7. **Сниппет кода** с объяснением: executor синхронно → .then() асинхронно

- [ ] Кнопка resolve переводит в fulfilled с отображением значения
- [ ] Кнопка reject переводит в rejected с отображением "Error: Ошибка!"
- [ ] Кнопка throw переводит в rejected с отображением "Error: throw внутри executor"

## Как проверить себя

1. Откройте компонент — все три блока показаны, подсвечен `pending`
2. Введите значение `"hello"` в поле, нажмите `resolve("hello")` — блок fulfilled активируется, в логе появляются SYNC и ASYNC записи
3. Нажмите `resolve("world")` — появится IGNORE-запись и замок, блок не меняется
4. Нажмите "Сброс" — всё вернётся в начало
5. Нажмите `throw внутри executor` — активируется блок rejected
6. Проверьте порядок в логе: SYNC всегда раньше ASYNC
