# Задание 4.3 — Decision Matrix: Module Federation vs Single-SPA

## Цель

Создать интерактивную матрицу решений, которая помогает архитектору выбрать подходящий инструмент для MFE-проекта на основе набора критериев. Результат — автоматическая рекомендация с объяснением trade-offs.

## Требования

1. Минимум 8 критериев проекта, каждый с 3 вариантами ответа (radio-кнопки):
   - Runtime code sharing: нет / частично / да
   - Количество фреймворков: один / 2-3 / много
   - Строгая изоляция: нет / частично / да
   - Размер команды: 1-3 / 3-10 / 10+
   - Независимый деплой: не критично / желательно / критично
   - Legacy-код: нет / немного / много
   - Единый роутинг: нет / частично / да
   - Инфраструктурный бюджет: минимальный / средний / большой

   Каждый вариант имеет числовые баллы (0-3) для трёх инструментов:
   - Module Federation
   - Single-SPA
   - Комбинация обоих

2. Каждый критерий отображается карточкой с:
   - Заголовком и кратким описанием
   - Radio-кнопками с подписями вариантов
   - Подсветкой выбранного варианта

3. Панель результатов (рядом или снизу):
   - Горизонтальные прогресс-бары для каждого инструмента (отсортированы по убыванию баллов)
   - Формат: `Инструмент  X/MAX ████████░░`

4. Блок рекомендации — победитель по наибольшему баллу:
   - Название рекомендованного инструмента
   - Текст-обоснование (почему он подходит для данного профиля)
   - Список из 3 trade-offs (на что обратить внимание)

5. Справочная таблица ключевых отличий Module Federation vs Single-SPA:
   - Аспект / Module Federation / Single-SPA
   - Строки: Цель, Связь, Фреймворки, Конфиг, Legacy

6. Результаты обновляются мгновенно при изменении любого radio-button (без кнопки "Рассчитать").

## Checklist

- [ ] Минимум 8 критериев с понятными описаниями
- [ ] Radio-кнопки работают, выбранный вариант визуально выделен
- [ ] Баллы рассчитываются автоматически при каждом изменении
- [ ] Прогресс-бары обновляются с анимацией перехода (CSS transition)
- [ ] Рекомендация меняется при изменении критериев
- [ ] Trade-offs соответствуют рекомендованному инструменту
- [ ] Справочная таблица отображается

## Как проверить себя

- Выберите "Много фреймворков + Legacy-код" → Single-SPA должен набрать больше баллов
- Выберите "Один фреймворк + Много общего кода" → Module Federation должен победить
- Выберите смешанный профиль (большая команда + много кода + разные фреймворки) → должна рекомендоваться комбинация

## Подсказка

Функция выбора победителя должна сравнивать три значения. При ничье (одинаковые баллы у нескольких инструментов) приоритет можно отдать комбинации как наиболее гибкому варианту. Прогресс-бар реализуйте через `width: ${(value / max) * 100}%` и `transition: width 0.4s ease`.
