# Задание 17.3: CI/CD Метрики — дашборд здоровья команды

## Цель

Создать интерактивный дашборд DORA-метрик, который показывает "здоровье" CI/CD процессов команды и даёт рекомендации по улучшению.

## Требования

1. Отобразить 4 DORA-метрики: **Deployment Frequency**, **Lead Time for Changes**, **Change Failure Rate**, **Time to Restore**
2. Для каждой метрики реализовать интерактивный ввод (слайдер или кнопки выбора значения)
3. По текущим значениям определять уровень команды: **Elite**, **High**, **Medium**, **Low** — с цветовой индикацией (зелёный/синий/жёлтый/красный)
4. Показывать итоговый уровень команды (по самой слабой метрике, как в реальном DORA)
5. Для каждой метрики при значении Medium или Low показывать конкретную рекомендацию (например: "Lead Time 3 дня → внедри trunk-based development и уменьши размер MR")
6. Добавить секцию "История пайплайна" — 5 последних запусков с кнопкой "Симуляция": нажатие добавляет новый запуск (успех или ошибка случайно), пересчитывает Change Failure Rate
7. Показать блок-схему "Как улучшить Lead Time" при нажатии на эту метрику

## Чеклист

- [ ] 4 карточки DORA-метрик с текущим значением и уровнем (цвет + текст)
- [ ] Интерактивный ввод для каждой метрики (слайдер или select)
- [ ] Автоматическое определение уровня Elite/High/Medium/Low
- [ ] Итоговый уровень команды с объяснением
- [ ] Рекомендации при Medium/Low (минимум для 2 метрик)
- [ ] История из 5 запусков (зелёный/красный кружок + время)
- [ ] Кнопка "Симуляция деплоя" добавляет запуск и обновляет CFR
- [ ] Пороговые значения видны рядом с каждой метрикой

## Как проверить себя

1. Установи Deployment Frequency = "раз в неделю" — карточка становится жёлтой (Medium), появляется рекомендация
2. Установи все метрики на максимум — итоговый уровень "Elite", всё зелёное
3. Нажми "Симуляция деплоя" несколько раз — история обновляется, CFR пересчитывается
4. При CFR > 10% появляется рекомендация про тестирование или канарейку
5. Итоговый уровень команды определяется по наихудшей метрике (проверь: если 3 Elite + 1 Low = итог Low)

## Подсказки

- DORA thresholds для Deployment Frequency: Elite = несколько раз в день, High = раз в день, Medium = раз в неделю, Low = раз в месяц
- Lead Time: Elite < 1ч, High < 1 дня, Medium 1-7 дней, Low > неделя
- Change Failure Rate: Elite < 5%, High < 10%, Medium 15-45%, Low > 45%
- Time to Restore: Elite < 1ч, High < 1 дня, Medium < неделя, Low > неделя
- `useState` для: значений каждой метрики (4 state), `deployHistory` (массив boolean)
- Для истории используй `Math.random() > 0.25` — 25% вероятность ошибки при симуляции
