# Задание 4.1: Архитектура RabbitMQ

## Цель

Создать интерактивную визуальную карту архитектуры RabbitMQ — вложенную диаграмму слоёв с информационной панелью. Студент наглядно поймёт, как Erlang VM, Node, Virtual Host, Exchange, Queue и Binding соотносятся друг с другом.

## Требования

1. Определить тип `ArchLayer` — union type из шести значений: `'erlang' | 'node' | 'vhost' | 'exchange' | 'queue' | 'binding'`.
2. Определить интерфейс `LayerInfo` с полями: `id`, `label`, `emoji`, `color`, `bgColor`, `borderColor`, `description`, `details: string[]` (минимум 4 факта), `children: ArchLayer[]`.
3. Создать массив `LAYERS` с реальными данными для всех шести слоёв архитектуры.
4. Реализовать логику клика `handleClick(id: ArchLayer)`:
   - первый клик на слой: `selected = id`, `zoomed = null`
   - второй клик на тот же слой: `zoomed = id` (показать все детали)
   - клик на уже зумированный слой: `zoomed = null`, `selected = id`
5. Отобразить вложенную структуру слева: Erlang VM → Node → VHost → (Exchange + Queue рядом) → Binding. Каждый блок кликабелен, его стиль меняется при `selected` и `zoomed`.
6. Отобразить информационную панель справа:
   - если выбран слой: показать emoji, label, description
   - если только `selected`: первые 3 элемента `details` + подсказка "кликните для зума"
   - если `zoomed`: все элементы `details`
   - если `children.length > 0`: показать дочерние слои как кликабельные бейджи
   - если ничего не выбрано: заглушка с иконкой "👈" и инструкцией
7. Добавить легенду внизу панели — все шесть слоёв как маленькие кнопки с emoji и названием, кликабельны.

## Чеклист

- [ ] Тип `ArchLayer` объявлен как union type из 6 значений
- [ ] Интерфейс `LayerInfo` содержит все обязательные поля
- [ ] Массив `LAYERS` содержит 6 объектов с реальной информацией
- [ ] `handleClick` реализует трёхступенчатую логику (выбор → зум → сброс)
- [ ] Вложенная диаграмма слева отображает все 6 слоёв
- [ ] Клик на блок меняет его визуальный стиль (граница, фон)
- [ ] Информационная панель справа показывает детали выбранного слоя
- [ ] В режиме зума показываются все `details`, в обычном — только 3
- [ ] Дочерние слои в панели отображаются как кликабельные бейджи
- [ ] Легенда внизу содержит все 6 слоёв

## Как проверить себя

1. Запустите компонент и убедитесь, что при клике на "Erlang VM" справа появляется описание с 3 фактами.
2. Кликните на тот же блок повторно — должны появиться все 5+ фактов (режим зума).
3. Кликните на другой блок (например "Queue") — зум сбрасывается, показывается новый слой.
4. Нажмите на бейдж "Virtual Host" в секции "Содержит" на панели — произойдёт переход к этому слою.
5. Нажмите кнопку "Binding" в легенде внизу — должна выбраться соответствующая карточка.
6. Убедитесь, что второй vhost (/staging) отображается как пунктирный блок с подписью "изолирован".
