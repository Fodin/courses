## Goal

Verify understanding of key decisions when designing a search engine: inverted index, TF-IDF/BM25, Elasticsearch sharding, typeahead with Trie.

## Requirements

1. Read the level 14 theory (README)
2. Complete the 4-question quiz on key concepts
3. For each question, select the correct answer
4. Try to answer without peeking at the theory
