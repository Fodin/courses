# Задание 3.1: Bold / Italic / Strike

## Цель

Построить панель с тремя кнопками форматирования (Bold, Italic, Strike), каждая из которых подсвечивается, когда соответствующий mark активен на текущем выделении.

## Требования

1. Создайте `editor` через `useEditor` с `StarterKit`
2. Добавьте три кнопки: **B** (bold), _I_ (italic), ~~S~~ (strike)
3. Каждая кнопка вызывает соответствующий `toggleX()` через `chain().focus()....run()`
4. Каждая кнопка визуально подсвечивается (например, другим фоном), если `editor.isActive('...')` возвращает `true`
5. Кнопки должны быть отключены, пока `editor === null`

## Чеклист

- [ ] Компонент называется `Task3_1` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.3.1')` используется в заголовке
- [ ] Все три кнопки переключают форматирование (toggle, не set)
- [ ] Подсветка активной кнопки корректно работает при перемещении курсора
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Выделите текст, нажмите Bold — текст должен стать жирным, кнопка — подсветиться
2. Не снимая выделение, кликните в другое место текста без форматирования — подсветка кнопки должна исчезнуть
3. Нажмите Bold ещё раз на исходном тексте — форматирование должно сняться
4. Проверьте комбинацию: примените Bold и Italic одновременно к одному тексту — обе кнопки должны быть подсвечены
