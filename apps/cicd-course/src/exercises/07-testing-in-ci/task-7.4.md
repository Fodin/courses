# Задание 7.4: Параллельный запуск тестов

## Цель

Создать интерактивный симулятор параллельного выполнения тестов. Показать разницу между последовательным и параллельным запуском, дать возможность настраивать количество шардов и наблюдать, как меняется итоговое время пайплайна.

## Требования

1. Показать набор тестов: 20 условных тестов с разным временем выполнения (1-5 секунд каждый)
2. Реализовать два режима: "Последовательный" (1 шард) и "Параллельный" (N шардов)
3. Слайдер или кнопки для выбора количества шардов (1, 2, 4, 8)
4. Визуализация распределения тестов по шардам — каждый шард как горизонтальная полоска, тесты — блоки внутри
5. Показать итоговое время для каждого режима и экономию времени
6. Кнопка "Запустить симуляцию" — анимирует выполнение тестов (полоски прогресса заполняются)
7. Показать YAML с правильным использованием `parallel: N` и `--shard=$CI_NODE_INDEX/$CI_NODE_TOTAL`

## Чеклист

- [ ] Набор из 12-20 тестов с отображением их относительного размера/времени
- [ ] Кнопки или слайдер для выбора количества шардов (1, 2, 4, 8)
- [ ] Визуализация распределения тестов по шардам (горизонтальные полосы)
- [ ] Отображение времени выполнения каждого шарда
- [ ] Итоговое время (= время самого медленного шарда) и сравнение с последовательным
- [ ] Индикатор экономии времени в процентах
- [ ] Анимация выполнения при нажатии "Запустить"
- [ ] YAML с parallel: N и правильной командой для шардинга

## Как проверить себя

1. При 1 шарде итоговое время должно равняться сумме всех тестов
2. При 4 шардах итоговое время должно быть примерно в 4 раза меньше
3. При 8 шардах экономия должна быть больше 70% по сравнению с 1 шардом
4. Нажми "Запустить" — все шарды должны выполняться параллельно (анимация одновременная)
5. В YAML при parallel: 4 должна быть команда с `--shard=$CI_NODE_INDEX/$CI_NODE_TOTAL`

## Подсказки

- Тесты: массив объектов `{id, name, duration}` где duration — число секунд (1-5)
- Распределение по шардам: `tests.filter((_, i) => i % shards === shardIndex)`
- Время шарда = сумма duration его тестов; итоговое время = Math.max(...shardTimes)
- Для анимации используй `useState` для `running` (boolean) и `setTimeout` для сброса
- Прогресс можно показать через CSS transition на width (0% → 100%) с задержкой
- Экономия: `Math.round((1 - parallelTime / sequentialTime) * 100)` %
