# Task 3.1: Quiz — Caching

## Objective

Test understanding of caching patterns, invalidation strategies, eviction policies, and common problems (stampede, penetration, avalanche).

## Requirements

1. Read the Level 3 theory (README)
2. Take a quiz of 5 questions on key concepts
3. For each question, select the correct answer (one or more)
4. Try to answer without looking at the theory

## Checklist

- [ ] Read the theory on multi-level caching
- [ ] Understand the difference between Cache-Aside and Read-Through
- [ ] Understand the difference between Write-Through and Write-Behind
- [ ] Familiar with invalidation strategies (TTL, event-based, versioning)
- [ ] Understand eviction policies (LRU, LFU, FIFO)
- [ ] Familiar with problems: cache stampede, penetration, avalanche
- [ ] Understand HTTP cache headers (Cache-Control, ETag)
- [ ] Completed the quiz with a score of at least 80%

## How to Check Yourself

1. Open the quiz and answer all questions
2. Check the explanations for incorrect answers
3. If the score is below 80% — re-read the relevant theory sections
