# Задание 3.4: Полная панель инструментов

## Цель

Собрать все marks из предыдущих заданий (bold, italic, strike, code, link) в единый переиспользуемый компонент `Toolbar`, построенный декларативно через массив конфигураций, а не набор копипасты.

## Требования

1. Создайте `editor` с `StarterKit.configure({ link: { openOnClick: false, autolink: true } })`
2. Вынесите панель в отдельный компонент `Toolbar({ editor })`
3. Внутри `Toolbar` опишите массив конфигураций кнопок вида:
   ```ts
   interface ToolbarButtonConfig {
     label: string
     isActive: () => boolean
     onClick: () => void
   }
   ```
4. Отрендерите кнопки через `.map()` по этому массиву — никакого дублирования JSX для каждой кнопки
5. Для link-кнопки отдельно обработайте случай запроса URL (она не укладывается в простую toggle-схему — можно вынести отдельной кнопкой вне общего массива, либо обработать особым случаем внутри)
6. Компонент `Toolbar` должен возвращать `null`, если `editor` ещё не создан

## Чеклист

- [ ] Компонент `Task3_4` экспортируется, использует внутри себя компонент `Toolbar`
- [ ] `useLanguage` импортирован и `t('task.3.4')` используется в заголовке
- [ ] Кнопки строятся через `.map()` по конфигурационному массиву, а не через 5 одинаковых JSX-блоков
- [ ] Все 5 кнопок (bold, italic, strike, code, link) работают корректно
- [ ] `Toolbar` — самостоятельный переиспользуемый компонент, принимающий `editor` как проп
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Проверьте по очереди все 5 кнопок на разных участках текста
2. Убедитесь, что подсветка активных кнопок работает независимо друг от друга (можно применить сразу несколько marks)
3. Откройте код компонента и убедитесь, что кнопки не скопированы вручную 5 раз, а генерируются из массива конфигураций
