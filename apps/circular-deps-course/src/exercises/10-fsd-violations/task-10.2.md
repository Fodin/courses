# Задание 10.2 — Ревью: цикл через 3 файла (среднее)

## Цель

Найти цикл, растянутый на три файла слайса `entities/order`, среди readonly-файлов «шума», и разорвать его правкой одного файла.

## Что дано

- `src/entities/order/model/order.ts` (только для чтения) — `createOrder` использует `formatOrder` из `lib/format.ts`.
- `src/entities/order/lib/format.ts` (только для чтения) — `formatOrder` использует константу `CURRENCY_LABEL` из `model/types.ts`.
- `src/entities/order/lib/currency.ts` (только для чтения) — **шум**, вообще не участвует в цикле, но выглядит похоже.
- `src/entities/order/model/types.ts` (редактируется) — экспортирует `Order` и `CURRENCY_LABEL`, но также импортирует `createOrder` из `order.ts` обычным импортом ради `typeof`.

Цепочка `order.ts → format.ts → types.ts → order.ts` замыкает трёхзвенный цикл.

## Требования

1. Не редактируйте `order.ts`, `lib/format.ts` и `lib/currency.ts` — они уже корректны (либо не участвуют в цикле).
2. Определите, какое именно ребро цикла лишнее — импорт `createOrder` в `types.ts` нужен только для `typeof`.
3. Сделайте этот импорт типовым, не меняя поведение остальных файлов.
4. После правки в проекте не должно быть рантайм-цикла импортов.

## Чеклист

- [ ] `model/types.ts` импортирует `createOrder` как `import type`
- [ ] `currency.ts` и остальные readonly-файлы не изменены
- [ ] Проверка «нет рантайм-цикла» — зелёная
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

1. Нажмите «Проверить» — проверка должна стать зелёной.
2. Откройте «Показать эталон», если не получается.
3. Нарисуйте на бумаге граф из четырёх файлов и убедитесь, что `currency.ts` действительно не участвует ни в одном ребре.
