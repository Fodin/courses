# Задание 9.1: Semigroup и Monoid

## Цель

Реализовать интерфейсы `Semigroup<T>` и `Monoid<T>`, набор конкретных инстансов, функции `fold` / `foldMap` и продемонстрировать их работу в интерактивном плейграунде.

## Требования

1. Объявите интерфейсы:
   ```ts
   interface Semigroup<T> { concat: (a: T, b: T) => T }
   interface Monoid<T> extends Semigroup<T> { empty: T }
   ```

2. Реализуйте следующие инстансы:
   - `Sum` — числа, операция `+`, `empty = 0`
   - `Product` — числа, операция `*`, `empty = 1`
   - `All` — булевы значения, операция `&&`, `empty = true`
   - `Any` — булевы значения, операция `||`, `empty = false`
   - `Min` — числа, операция `Math.min`, `empty = Infinity`
   - `Max` — числа, операция `Math.max`, `empty = -Infinity`
   - `First<T>` — только Semigroup, всегда возвращает первый аргумент (без `empty`)

3. Реализуйте функции:
   ```ts
   const fold    = <T,>(M: Monoid<T>, xs: T[]): T => ...
   const foldMap = <A, M,>(monoid: Monoid<M>, f: (a: A) => M, xs: A[]): M => ...
   ```

4. Создайте интерактивный плейграунд:
   - Выпадающий список для выбора моноида
   - Поле ввода значений через запятую (числа или true/false)
   - Отображение пошаговой редукции: `concat(empty, a) → concat(result1, b) → ...`
   - Проверка ассоциативности для первых трёх элементов: вычислить `(a ∘ b) ∘ c` и `a ∘ (b ∘ c)`, показать что равны

## Checklist

- [ ] Интерфейсы `Semigroup<T>` и `Monoid<T>` объявлены корректно
- [ ] Все 6 инстансов Monoid реализованы с правильными `empty`
- [ ] `First` реализован как Semigroup (не Monoid) — `empty` отсутствует
- [ ] `fold` использует `reduce` с начальным значением `M.empty`
- [ ] `foldMap` реализован через `fold` и `map` (не вручную)
- [ ] Плейграунд показывает пошаговое выполнение
- [ ] Пустой массив возвращает `empty` (проверьте: пустое поле ввода)
- [ ] Проверка ассоциативности показывает равенство двух вариантов группировки

## Как проверить себя

Откройте плейграунд, выберите `Sum`, введите `3, 5, 2`:
- Шаг 1: acc = 0 (empty)
- Шаг 2: concat(0, 3) = 3
- Шаг 3: concat(3, 5) = 8
- Шаг 4: concat(8, 2) = 10

Выберите `Product`, введите `2, 3, 4`:
- Результат должен быть 24

Выберите `Any`, введите `false, false, true`:
- Результат должен быть true

Выберите `Min`, введите `7, 2, 9`:
- Результат должен быть 2

Проверка ассоциативности для `Sum` с `[3, 5, 2]`:
- `(3 + 5) + 2 = 10`
- `3 + (5 + 2) = 10`
- Равны: да
