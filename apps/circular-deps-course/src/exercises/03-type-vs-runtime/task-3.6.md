# Задание 3.6 — Распутать смешанный модуль на types и runtime (сложное)

## Цель

Собрать все приёмы уровня воедино: в одном рефакторинге отделить типы от
рантайм-кода сразу в двух модулях, сохранив единственную настоящую
рантайм-зависимость между ними.

## Что дано

- `shop.ts` (редактируется) — экспортирует тип `Product`, а также рантайм-код
  (`TAX_RATE`, `applyTax`, `priceProductInCart`); импортирует `CartItem` из
  `cart.ts` обычным импортом, хотя использует его только как тип параметра.
- `cart.ts` (редактируется) — экспортирует тип `CartItem`, а также рантайм-код
  (`DEFAULT_CURRENCY`, `summarize`); импортирует из `shop.ts` сразу два
  символа отдельными строками: `Product` (только как тип) и `applyTax`
  (реально вызывается внутри `summarize`).
- `types.ts` (редактируется) — пустая заготовка с `TODO`.
- `receipt.ts` (только чтение) — сторонний потребитель, уже написан в
  целевом стиле: типы берёт из `./types`, а `summarize` — из `./cart` как
  значение. Меняйте только `shop.ts`, `cart.ts` и `types.ts`.

## Требования

1. Перенесите `interface Product` (из `shop.ts`) и `interface CartItem` (из
   `cart.ts`) в общий `types.ts`.
2. В `shop.ts` замените импорт `CartItem` из `./cart` на `import type` из
   `./types`.
3. В `cart.ts` замените импорт `Product` из `./shop` на `import type` из
   `./types` (для `CartItem` тоже используйте `./types`), а импорт `applyTax`
   из `./shop` оставьте как значение — это единственная настоящая
   рантайм-связь между модулями.
4. После рефакторинга `shop.ts` не должен импортировать из `cart.ts` вообще.
5. Нажмите «Проверить».

## Чеклист

- [ ] `types.ts` содержит оба интерфейса — `Product` и `CartItem`
- [ ] `shop.ts` импортирует `CartItem` из `types.ts` как тип и ничего не
      импортирует из `cart.ts`
- [ ] `cart.ts` импортирует типы из `types.ts`, а `applyTax` — как значение
      из `shop.ts`
- [ ] Ни одного рантайм-цикла в графе не осталось
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

Постройте итоговый граф вручную: `shop.ts → types.ts` (тип), `cart.ts →
types.ts` (тип), `cart.ts → shop.ts` (значение `applyTax`), `receipt.ts →
types.ts` (тип), `receipt.ts → cart.ts` (значение `summarize`). Ни одной
стрелки в обратную сторону — граф ацикличен целиком, а не только в
рантайм-срезе.
