# Задание 4.3: Выбор базы данных (DB Recommender)

## Цель

Создать интерактивный инструмент, который на основе параметров проекта рекомендует оптимальный тип базы данных с развёрнутым объяснением.

## Требования

1. Реализуйте ввод параметров через слайдеры/переключатели:
   - **Read/Write ratio** — от «в основном чтение» до «в основном запись»
   - **Consistency** — от «eventual (допускаем устаревшие данные)» до «strong (ACID обязателен)»
   - **Data structure** — переключатель: tabular (таблицы), document (вложенные JSON), key-value, graph (связи)
   - **Scale** — от «тысячи записей» до «миллиарды записей»
2. На основе комбинации параметров выдавайте рекомендацию:
   - Тип БД (PostgreSQL, MongoDB, Redis, Cassandra, Neo4j)
   - Объяснение, почему этот тип подходит
   - Предупреждения о возможных проблемах
3. Покажите «уверенность» рекомендации (высокая/средняя/низкая)
4. Покажите альтернативные варианты с пояснением, когда они лучше

## Чеклист

- [ ] 4 параметра с визуальными метками
- [ ] Рекомендация обновляется при изменении любого параметра
- [ ] Включает: тип БД, объяснение, предупреждения
- [ ] Уровень уверенности рекомендации
- [ ] Альтернативные варианты
- [ ] Крайние значения дают логичные результаты

## Как проверить себя

1. Read-heavy + strong consistency + tabular → PostgreSQL
2. Write-heavy + eventual + tabular → Cassandra
3. Read-heavy + eventual + document → MongoDB
4. Key-value + любой scale → Redis
5. Graph data structure → Neo4j
6. Strong consistency + миллиарды записей → PostgreSQL + sharding (с предупреждением о сложности)
