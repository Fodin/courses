# Задание 4.2 — Конструктор root config Single-SPA

## Цель

Создать визуальный конструктор, который позволяет добавлять микрофронтенд-приложения и в реальном времени генерирует корректный `root-config.js` с вызовами `registerApplication()`.

## Требования

1. Список приложений: каждое приложение отображается как карточка с четырьмя редактируемыми полями:
   - **Имя** (text): уникальное, только строчные буквы/цифры/дефис, начинается с буквы
   - **Framework** (select): React, Vue, Angular, Svelte, Vanilla
   - **activeWhen** (text): URL-путь, начинается с `/`, нет дублирующихся маршрутов
   - **Загрузчик** (select): `System.import()` или `import()`

2. Цветной индикатор слева от карточки, цвет соответствует выбранному фреймворку.

3. Под полями каждого приложения — предпросмотр сгенерированной loading function:
   ```
   app: () => System.import('@company/catalog')
   ```

4. Валидация в реальном времени (красный border + сообщение об ошибке под полем):
   - Имя пустое → "Имя не может быть пустым"
   - Имя не соответствует паттерну → "Только строчные буквы, цифры и дефис"
   - Имя дублируется → "Имя должно быть уникальным"
   - activeWhen не начинается с `/` → "Должен начинаться с /"
   - activeWhen дублируется → "Пересечение маршрутов с другим приложением"

5. Кнопка "Удалить" у каждой карточки.

6. Кнопка "+ Добавить приложение" добавляет пустую карточку.

7. Кнопка переключения видимости кода ("Показать/Скрыть код").

8. Сгенерированный `root-config.js` включает:
   - `import { registerApplication, start } from 'single-spa'`
   - `registerApplication({ name, app, activeWhen })` для каждого приложения
   - Специальный случай: `activeWhen: '/'` → генерировать предикат `location => location.pathname === '/'`
   - `start({ urlRerouteOnly: true })`
   - При наличии ошибок код отображается с opacity 0.5

## Checklist

- [ ] Все четыре поля редактируются inline
- [ ] Цветной индикатор фреймворка отображается
- [ ] Предпросмотр loading function обновляется при изменении имени и загрузчика
- [ ] Все валидации работают в реальном времени
- [ ] Добавление и удаление карточек работает
- [ ] Для activeWhen: '/' генерируется предикат-функция, а не строка
- [ ] Сгенерированный код корректен и включает start()
- [ ] При ошибках код затемнён

## Как проверить себя

- Добавьте два приложения с одинаковым именем — у обоих должна появиться ошибка
- Добавьте два приложения с одинаковым activeWhen — оба получат ошибку пересечения
- Установите activeWhen `/` — в коде должна появиться функция `location => location.pathname === '/'`
- Смените загрузчик с SystemJS на import — в предпросмотре и коде должен измениться вызов

## Подсказка

Для валидации пересечений маршрутов соберите массив всех activeWhen и проверьте, встречается ли текущее значение более одного раза. Используйте `filter(r => r === app.activeWhen).length > 1`.
