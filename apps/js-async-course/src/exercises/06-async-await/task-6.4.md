# Задание 6.4: Антипаттерны async/await

## Цель

Создать интерактивный каталог из пяти антипаттернов `async/await` в формате "До/После". Каждый антипаттерн — карточка с переключателем между плохим (красный) и хорошим (зелёный) вариантом кода и объяснением проблемы.

## Требования

1. **Пять антипаттернов:**
   - `await` в `forEach` — не ждёт промисы, нужен `for...of`
   - Забытый `await` — промис вместо значения, `if (promise)` всегда `true`
   - Последовательный `await` независимых задач — вместо `Promise.all`
   - `async` без `await` — лишняя обёртка в промис
   - Пустой `catch` — ошибки глотаются молча

2. **Для каждого антипаттерна:**
   - Название и краткое описание проблемы
   - Переключатель "Плохо (до)" / "Хорошо (после)"
   - Блок кода с красной или зелёной подсветкой левой границы
   - Метка над кодом с описанием что именно плохо/хорошо
   - Объяснение — почему это проблема и как правильно

3. **Навигация:**
   - Навигационные кнопки-пилюли с номерами (1–5) для прямого перехода
   - Кнопки "Предыдущий" и "Следующий"
   - Счётчик "X / 5"

4. **При переходе** между антипаттернами — автоматический сброс на вид "Плохо"

## Чеклист

- [ ] Компонент называется `Task6_4` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован и `t('task.6.4')` используется в заголовке
- [ ] Все 5 антипаттернов реализованы с кодом "до" и "после"
- [ ] Переключатель "Плохо/Хорошо" меняет цвет границы блока кода
- [ ] При переходе к следующему антипаттерну — сброс на "Плохо"
- [ ] Кнопки "Предыдущий/Следующий" заблокированы на крайних позициях
- [ ] Объяснение присутствует для каждого антипаттерна

## Как проверить себя

1. На первом антипаттерне (`await` в `forEach`) нажмите "Хорошо" — код должен смениться на `for...of` с зелёной границей
2. Нажмите "Следующий" — переход ко второму, вид автоматически сбрасывается на "Плохо"
3. Кликните кнопку "5" в навигации — сразу переходит к пятому антипаттерну
4. На последнем антипаттерне кнопка "Следующий" неактивна
5. Для каждого антипаттерна читаемое объяснение присутствует под кодом
