# Задание 8.6 — Узел из нескольких cross-import'ов между слайсами (сложное)

## Цель

Распутать плотный узел cross-import'ов между четырьмя слайсами одного слоя, устранив сразу несколько циклов.

## Что дано

Четыре слайса слоя `entities` — `user`, `order`, `product`, `review` — опутаны семью cross-import'ами:

- `src/entities/user/model/user.ts` (редактируется) — импортирует из `order` и `review`.
- `src/entities/order/model/order.ts` (редактируется) — импортирует из `product` и `user`.
- `src/entities/product/model/product.ts` (редактируется) — импортирует из `review`.
- `src/entities/review/model/review.ts` (редактируется) — импортирует из `product` и `user`.

Эти рёбра образуют сразу три двухузловых цикла: `user ↔ order`, `user ↔ review`, `product ↔ review`.

## Требования

1. Уберите ВСЕ импорты между слайсами `user`, `order`, `product`, `review` — во всех четырёх файлах.
2. Каждая функция должна получать нужные ей данные соседних слайсов через параметры вместо прямых импортов.
3. Публичные функции (`describeUser`, `getLastOrder`, `getProductTitle`, `getLatestReview` и другие) должны сохранить сигнатуру, отражающую содержательный смысл, но без импортов между слайсами.
4. После правки в проекте не должно остаться ни одного рантайм-цикла.
5. Ни один из четырёх слайсов не должен импортировать другой слайс того же слоя.

## Чеклист

- [ ] `entities/user` не импортирует `order` и `review`
- [ ] `entities/order` не импортирует `product` и `user`
- [ ] `entities/product` не импортирует `review`
- [ ] `entities/review` не импортирует `product` и `user`
- [ ] Проверка «нет рантайм-цикла» — зелёная
- [ ] Проверка «импорты уважают слои и изоляцию слайсов» — зелёная
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

1. Нажмите «Проверить» — обе проверки должны стать зелёными.
2. Нарисуйте граф из 4 слайсов и 7 исходных стрелок — после правки должно остаться 0 стрелок между слайсами.
3. Сравните с эталоном через «Показать эталон», если застряли.
