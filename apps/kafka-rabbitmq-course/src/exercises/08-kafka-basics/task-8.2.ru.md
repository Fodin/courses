# Задание 8.2: Append-only лог

## Цель

Реализовать интерактивную визуализацию append-only лога Kafka: добавление записей, чтение с произвольного offset и наглядное представление принципа неизменяемости.

## Требования

1. Определить интерфейс `LogRecord` с полями:
   - `offset: number` — монотонно возрастающий номер записи (начиная с 0)
   - `key: string` — ключ сообщения
   - `value: string` — JSON-значение
   - `timestamp: string` — строка вида `"2024-01-15 10:00:00"`
   - `size: number` — размер в байтах (примерный: длина ключа + длина значения + 10)

2. Инициализировать лог пятью готовыми записями (offset 0..4) с ключами `user-1`, `user-2`, `user-1`, `order-1`, `user-3`.

3. Реализовать карточки с концептами (отображаются над логом):
   - "Append-only" — записи только добавляются в конец, изменений нет
   - "Offset" — каждая запись имеет уникальный монотонный номер, начиная с 0
   - "Immutable" — написанные данные неизменяемы, consumer читает любой диапазон

4. Реализовать визуализацию лога:
   - Горизонтальный ряд карточек, каждая отображает `offset`, `key` и размер в байтах
   - После последней записи — стрелка `→` и пунктирный блок "след. запись"
   - Клик на карточку: выделяет запись и показывает детальную панель ниже (key, value, timestamp, size)
   - Цветовая кодировка по позиции consumer offset: зелёный (прочитано), жёлтый (текущая позиция), серый (не прочитано)

5. Реализовать управление consumer offset:
   - Кнопки "от offset=N" для каждой записи в логе
   - Нажатие устанавливает `consumerOffset = N` и добавляет в лог операций записи `[SEEK]` и `[READ]`
   - Текст под кнопками: "Consumer читает с offset=N. Прочитано: X сообщений."

6. Реализовать форму добавления новой записи:
   - Поля ввода: `key` (monospace, ширина 120px) и `value` (растягивается)
   - Кнопка "Append": вычисляет следующий offset, создаёт запись и добавляет в конец лога
   - Подсказка: "Новая запись будет добавлена в конец лога с offset=N"
   - В лог операций добавляет строку `[APPEND] offset=N key="..." → записано в конец лога`

7. Реализовать лог операций (тёмный терминал с зелёным текстом):
   - Хранит до 15 последних записей
   - Кнопка "Очистить" сбрасывает лог

## Проверочный список

- [ ] При загрузке отображается лог из 5 записей (offset 0..4)
- [ ] Клик на запись показывает детальную панель с key, value, timestamp, size
- [ ] Кнопки "от offset=N" правильно перемещают позицию consumer и окрашивают прочитанные записи
- [ ] Форма "Записать сообщение" добавляет новую запись с offset = records.length
- [ ] После добавления записи стрелка "→" и блок "след. запись" сдвигаются вправо
- [ ] Лог операций показывает [SEEK], [READ] и [APPEND] события
- [ ] Три карточки концептов (Append-only, Offset, Immutable) отображаются над логом

## Как проверить себя

1. Нажми кнопку "от offset=2" — записи 0 и 1 должны окраситься зелёным (прочитано), запись 2 — жёлтым (текущая позиция), в лог операций появятся строки `[SEEK]` и `[READ]`.
2. Введи новый key и value, нажми Append — запись появится в конце с offset=5.
3. Кликни на любую карточку — появится детальная панель с полной информацией о записи.
