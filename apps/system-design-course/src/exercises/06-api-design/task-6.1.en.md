# Task 6.1: Quiz — API Design

## Objective

Test understanding of API styles (REST, GraphQL, gRPC), pagination, rate limiting, versioning, and idempotency.

## Requirements

1. Read the Level 6 theory (README)
2. Complete the quiz of 5 questions on key concepts
3. For each question, select the correct answer (single or multiple)
4. Try to answer without looking at the theory

## Checklist

- [ ] Understand the difference between REST, GraphQL, and gRPC — when to use each
- [ ] Familiar with Richardson Maturity Model (Level 0–3)
- [ ] Understand the difference between offset and cursor pagination
- [ ] Familiar with rate limiting algorithms (token bucket, sliding window, fixed window)
- [ ] Understand how idempotency keys work and why they're needed
- [ ] Familiar with API versioning strategies
- [ ] Understand OAuth2 authorization code flow
- [ ] Quiz completed with a score of at least 80%

## How to Check Yourself

1. Open the quiz and answer all questions
2. Check the explanations for incorrect answers
3. If the score is below 80% — reread the relevant theory sections
