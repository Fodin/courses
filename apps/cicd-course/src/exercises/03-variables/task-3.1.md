# Задание 3.1: Каталог предопределённых переменных

## Цель

Создать интерактивный каталог предопределённых переменных GitLab CI с фильтрацией по категориям и поиском. Это упражнение поможет запомнить, какие переменные существуют и для чего они используются.

## Требования

1. Отобразить минимум 20 предопределённых переменных в виде таблицы или карточек
2. Каждая переменная должна содержать:
   - Имя переменной (например, `CI_COMMIT_SHA`)
   - Категорию (commit, pipeline, job, project, runner, merge-request)
   - Описание на русском языке
   - Пример значения
3. Реализовать фильтрацию по категориям через кнопки-фильтры
4. Реализовать поиск по имени переменной и описанию (регистронезависимый)
5. При выборе категории "Все" отображать все переменные
6. Показывать количество найденных переменных

## Чеклист

- [ ] Массив с 20+ переменными, каждая с полями name, category, description, example
- [ ] Кнопки фильтрации по 6 категориям + кнопка "Все"
- [ ] Активная категория визуально выделена
- [ ] Поле поиска фильтрует одновременно с категорией
- [ ] Счётчик "Найдено: N переменных"
- [ ] При пустых результатах поиска — информативное сообщение
- [ ] Имена переменных в моноширинном шрифте

## Как проверить себя

1. Выберни категорию "commit" — должны отображаться только переменные CI_COMMIT_*
2. Введи в поиск "sha" — должны найтись CI_COMMIT_SHA и CI_COMMIT_SHORT_SHA
3. Выбери категорию "project" и введи "registry" — должны найтись только переменные проекта, связанные с registry
4. Очисти поиск — должны вернуться все переменные выбранной категории
5. Выбери "merge-request" — должны появиться переменные CI_MERGE_REQUEST_*

## Подсказки

- Используй `useState` для хранения активной категории и строки поиска
- Применяй `Array.filter()` последовательно: сначала по категории, потом по строке поиска
- Метод `toLowerCase()` поможет сделать поиск регистронезависимым
- Для выделения активной кнопки фильтра используй условный стиль: `backgroundColor: activeCategory === cat ? '#1565C0' : '#e0e0e0'`
