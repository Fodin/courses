# Задание 0.1 — Карта слоёв FSD

Это вводный уровень без редактора кода. Ваша задача — разобраться в базовой карте FSD.

## Что сделать

1. Изучите теорию (вкладки «Кратко» и «Подробно»).
2. В интерактивной карте справа кликните по каждому слою и запомните:
   - за что он отвечает;
   - какие слои ему **разрешено** импортировать (только нижние).
3. Пройдите квиз уровня.

## Проверьте себя

- [ ] Могу перечислить 6 слоёв сверху вниз без подсказки
- [ ] Понимаю правило однонаправленности (импорт только «вниз»)
- [ ] Знаю, почему `entities/user` не может импортировать `entities/product`
- [ ] Пройти квиз уровня ≥ 80%
