# Задание 8.1: Кластер Kafka — брокеры и контроллер

## Цель

Реализовать интерактивную визуализацию кластера Apache Kafka из трёх брокеров, показывающую распределение партиций (leader/follower), статус ISR и выбор нового контроллера при отказе.

## Требования

1. Определить типы `Partition`, `Broker` и инициализировать три брокера с партициями:
   - Каждый брокер содержит поля `id`, `host`, `port`, `isController`, `rack`, `partitions`, `color`, `bgColor`
   - Партиции имеют поля `id`, `topic`, `role` (`'leader' | 'follower'`), `isr`
   - Брокер-1 — начальный контроллер (`isController: true`), остальные два — follower

2. Реализовать переключение режима `'kraft' | 'zookeeper'` через кнопки KRaft Mode / ZooKeeper Mode:
   - В режиме KRaft показывать иконку ⚙️ и надпись "KRaft Controller / built-in Raft"
   - В режиме ZooKeeper показывать иконку 🐘 и надпись "ZooKeeper / external cluster"

3. Реализовать кликабельные карточки брокеров:
   - Клик на брокер раскрывает панель с его партициями
   - Повторный клик скрывает панель
   - У контроллера отображается бейдж "CONTROLLER" в правом верхнем углу

4. Реализовать функцию `simulateControllerFailover()`:
   - Находит текущего контроллера
   - Случайным образом выбирает нового из оставшихся брокеров
   - Обновляет флаг `isController` у всех брокеров
   - Добавляет в лог строки о падении старого контроллера и избрании нового
   - В сообщении лога указывает режим: `KRaft Raft consensus` или `ZooKeeper election`

5. Реализовать лог событий кластера:
   - Хранит последние 12 записей
   - Каждая запись снабжена временной меткой `[HH:MM:SS]`
   - Кнопка "Очистить" сбрасывает лог

6. Показывать информационную панель с описанием текущего режима (KRaft или ZooKeeper).

## Проверочный список

- [ ] Кластер из трёх брокеров отображается в виде карточек с хостом и стойкой (rack)
- [ ] Брокер с `isController: true` имеет бейдж CONTROLLER
- [ ] Клик на брокер показывает список его партиций с ролями (★ Leader / ○ Follower) и ISR-статусом
- [ ] Переключение режима KRaft ↔ ZooKeeper меняет иконку и описание в панели
- [ ] Кнопка "Симулировать падение контроллера" меняет контроллера и пишет в лог
- [ ] Лог содержит временную метку и информацию об избранном контроллере
- [ ] Кнопка "Сбросить кластер" возвращает начальное состояние
- [ ] Кнопка "Очистить" очищает лог событий

## Как проверить себя

1. Нажми "Симулировать падение контроллера" несколько раз — бейдж CONTROLLER должен перемещаться между брокерами, а в логе появляться записи вида `Broker-1 упал. Broker-3 стал новым контроллером`.
2. Переключи режим на ZooKeeper — в логе должно появиться `ZooKeeper election` вместо `KRaft Raft consensus`.
3. Кликни на каждый брокер и убедись, что партиции отображаются корректно с ролями leader/follower и зелёным/красным ISR-статусом.
