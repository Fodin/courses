# Задание 9.2 — Глубокие импорты (среднее)

## Цель

Убрать «глубокие» импорты: обращаться к чужому слайсу только через его public API.

## Что дано

- Слайс `entities/user` уже закрыт корректным `index.ts` (🔒 только чтение);
- `widgets/user-panel/ui/UserPanel.tsx` — виджет, который тянет внутренности сущности
  напрямую: `@/entities/user/ui/UserCard` и `@/entities/user/model/types`.

## Требования

1. Перепишите импорты в `UserPanel.tsx` так, чтобы `UserCard` и `User` приходили из
   `@/entities/user` (public API), а не из внутренних сегментов.
2. Нажмите «Проверить».

## Чеклист

- [ ] В `UserPanel.tsx` нет путей с `/ui/` или `/model/` к чужому слайсу
- [ ] Импорт идёт через `@/entities/user`
- [ ] Пройти квиз уровня ≥ 80%
