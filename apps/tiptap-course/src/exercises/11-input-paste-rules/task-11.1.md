# Задание 11.1: Markdown input rules

## Цель

Продемонстрировать и объяснить встроенные markdown input rules из `StarterKit` — заголовки, bold, списки — через интерактивный редактор с подсказками.

## Требования

1. Создайте `editor` через `useEditor` с `StarterKit`
2. Выведите список подсказок над редактором: `## ` → заголовок H2, `**текст**` → bold, `* ` или `- ` → маркированный список, `1. ` → нумерованный список, `> ` → цитата
3. Дайте пользователю пустой редактор, чтобы он мог опробовать все правила
4. Добавьте кнопку "Вставить примеры" — программно вставляет текст, показывающий, как выглядит результат после применения всех правил (например, через `insertContent` с уже готовым HTML)

## Чеклист

- [ ] Компонент называется `Task11_1` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.11.1')` используется в заголовке
- [ ] Список подсказок присутствует и корректен
- [ ] `## ` в начале строки создаёт заголовок 2 уровня
- [ ] `**текст**` создаёт bold
- [ ] `* ` создаёт маркированный список
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. В пустой строке напечатайте `## ` (решётка-решётка-пробел) — блок должен мгновенно стать заголовком H2
2. Напечатайте `**жирный**` — текст должен стать жирным, а звёздочки исчезнуть
3. В начале новой строки напечатайте `- ` — должен появиться маркированный список
4. В начале новой строки напечатайте `1. ` — должен появиться нумерованный список
