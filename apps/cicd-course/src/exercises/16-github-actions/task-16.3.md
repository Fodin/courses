# Задание 16.3: Matrix Strategy — параллельное тестирование

## Цель

Создать интерактивный визуализатор matrix strategy. Студент добавляет параметры матрицы, видит, сколько джобов будет создано, и управляет опциями `fail-fast` и `max-parallel`. Наглядно показать разницу между include/exclude.

## Требования

1. Отобразить **три оси матрицы**:
   - `os` — мультивыбор: `ubuntu-latest`, `windows-latest`, `macos-latest`
   - `node-version` — мультивыбор: `18`, `20`, `22`
   - `experimental` — необязательный toggle (добавляет четвёртую версию `24`)
2. Отобразить **счётчик джобов**: "Будет создано: N джобов" — произведение выбранных значений
3. Визуализировать **матричную сетку**: строки = ОС, столбцы = версии Node, ячейки = отдельные джобы
4. Добавить переключатели:
   - `fail-fast` (on/off) — при включении подсветить, что первый провал остановит все
   - `max-parallel` — числовой ввод (1–12), показать сколько джобов выполняется одновременно
5. Добавить секцию **exclude** — возможность отметить конкретные ячейки матрицы как исключённые
6. Показывать итоговый **YAML** с `strategy.matrix`, `fail-fast` и `max-parallel`

## Чеклист

- [ ] Мультивыбор OS (минимум 2 значения по умолчанию)
- [ ] Мультивыбор node-version (минимум 2 значения по умолчанию)
- [ ] Счётчик джобов обновляется при изменении выборок
- [ ] Визуальная сетка: строки × столбцы = джобы
- [ ] Переключатель `fail-fast` меняет YAML
- [ ] Поле `max-parallel` с валидацией (1 ≤ n ≤ total jobs)
- [ ] Клик на ячейку матрицы добавляет комбинацию в `exclude`
- [ ] Исключённые ячейки визуально зачёркнуты / серые

## Как проверить себя

1. Выбери 2 ОС × 3 версии Node → счётчик должен показать "6 джобов"
2. Добавь third ось через `experimental` → счётчик вырастет до 8
3. Кликни на ячейку "windows-latest / 18" → она станет серой, в YAML появится `exclude:`
4. Выключи `fail-fast` → в YAML: `fail-fast: false`
5. Установи `max-parallel: 2` → в YAML добавится `max-parallel: 2`

## Подсказки

- Состояние: `selectedOS` (string[]), `selectedNode` (string[]), `failFast` (boolean), `maxParallel` (number), `excluded` (массив пар `{os, node}`)
- Количество джобов: `selectedOS.length * selectedNode.length` минус исключения
- Для отрисовки сетки: `selectedOS.map(os => selectedNode.map(node => cell))`
- Проверка исключения: `excluded.some(e => e.os === os && e.node === node)`
- YAML для exclude:
  ```
  exclude:
    - os: windows-latest
      node-version: '18'
  ```
