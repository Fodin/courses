# Задание 8.3: Hook Composition — useDataTable

## Задание

Реализовать слоистую архитектуру кастомных хуков для управления табличными данными. Три независимых хука, объединённых в четвёртый.

## Цель

Понять принцип composable hooks — как маленькие, изолированные хуки с одной ответственностью объединяются в сложную функциональность. Научиться правильно выстраивать зависимости между хуками через `useMemo` и `useEffect`.

## Требования

### Хук 1: usePagination(total, pageSize)

Возвращает:
- `page` — текущая страница (с 1)
- `totalPages` — общее количество страниц
- `hasNext`, `hasPrev` — можно ли листать
- `next()`, `prev()`, `goTo(page)` — навигация
- `reset()` — сброс на страницу 1

### Хук 2: useSort\<T\>(data, initialKey, initialDir?)

Возвращает:
- `sorted` — отсортированный массив (через `useMemo`)
- `key`, `dir` — текущий ключ сортировки и направление
- `toggle(key)` — переключить сортировку: если тот же ключ — сменить направление, иначе — новый ключ + 'asc'

### Хук 3: useFilter\<T\>(data, fields)

Возвращает:
- `filtered` — отфильтрованный массив (через `useMemo`)
- `query` — текущий запрос
- `setQuery` — изменить запрос

Фильтрация: case-insensitive поиск по указанным полям.

### Хук 4: useDataTable\<T\>(data, fields, pageSize?)

Объединяет все три. При изменении `query` — сбрасывает пагинацию на страницу 1.

Возвращает:
- `data` — данные текущей страницы
- `filter` — `{ query, setQuery }`
- `sort` — `{ key, dir, toggle }`
- `pagination` — весь объект usePagination

### Демо

Интерактивная таблица с 50 записями (пользователи с именем, городом, возрастом):
- Поле поиска (фильтрует по имени и городу)
- Заголовки колонок кликабельны (сортировка + индикатор ▲/▼)
- Кнопки пагинации
- Показывать "X–Y из N записей"

## Чеклист

- [ ] `usePagination` работает изолированно, не знает о данных
- [ ] `useSort` использует `useMemo` для сортировки (не пересчитывает при каждом рендере)
- [ ] `useFilter` использует `useMemo` для фильтрации
- [ ] `useDataTable` сбрасывает пагинацию при изменении `query`
- [ ] Порядок применения: сначала фильтр, потом сортировка, потом пагинация
- [ ] Таблица показывает правильный диапазон записей на странице
- [ ] Клик по заголовку переключает направление сортировки
- [ ] При поиске "пар" из 50 записей показываются только подходящие + пагинация пересчитывается

## Как проверить себя

1. Введите запрос в поиск — страница сбрасывается на 1, записи фильтруются
2. Кликните по заголовку "Имя" — отсортируется по имени А→Я
3. Кликните ещё раз — отсортируется Я→А
4. Перейдите на страницу 3, затем введите что-то в поиск — должна вернуться страница 1
5. Убедитесь, что "X–Y из N" корректно обновляется при фильтрации
