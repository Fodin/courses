# Задание 0.3: Калькулятор trade-offs

## Цель

Создать интерактивный калькулятор, который по набору критериев проекта динамически
рекомендует архитектурный подход: монолит, микросервисы или модульный монолит.

## Требования

1. Отобразить минимум 5 критериев для оценки (слайдеры или кнопки выбора значений 1-5):
   - Размер команды
   - Частота деплоев
   - Критичность изоляции отказов
   - Потребность в масштабировании
   - Зрелость инфраструктуры
2. Для каждого критерия — короткое описание что означает значение 1 и значение 5
3. При изменении любого критерия динамически пересчитывать результат
4. Показывать два прогресс-бара: скор монолита и скор микросервисов (в процентах)
5. На основе расчёта выводить одну из трёх рекомендаций:
   - **Монолит** — явное преимущество монолита
   - **Микросервисы** — явное преимущество микросервисов
   - **Модульный монолит** — нет явного победителя (промежуточный вариант)
6. Рекомендация должна содержать краткое обоснование (2-3 предложения)

## Чеклист

- [ ] Минимум 5 критериев с возможностью выбора значения
- [ ] Каждый критерий имеет описание значений
- [ ] Динамический пересчёт при изменении любого критерия
- [ ] Два прогресс-бара (монолит vs микросервисы) с анимацией
- [ ] Три возможных результата (монолит / модульный монолит / микросервисы)
- [ ] Текстовое обоснование рекомендации
- [ ] Компонент использует `useLanguage` и `t('task.0.3')` для заголовка

## Как проверить себя

1. Выставьте все критерии в 1 — должна быть рекомендация «Монолит»
2. Выставьте все критерии в 5 — должна быть рекомендация «Микросервисы»
3. Выставьте смешанные значения — должна появиться рекомендация «Модульный монолит»
4. Прогресс-бары должны анимированно изменяться при каждом изменении критерия
5. Убедитесь, что рекомендация содержит осмысленное обоснование для каждого из трёх вариантов
