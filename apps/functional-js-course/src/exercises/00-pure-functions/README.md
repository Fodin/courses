# Чистые функции

## Что такое чистая функция

Чистая функция — это функция, которая:

1. **Возвращает одинаковый результат для одинаковых аргументов** (детерминированность)
2. **Не производит наблюдаемых побочных эффектов** (не изменяет ничего вне себя)

Представьте торговый автомат: кладёте те же монеты — получаете тот же товар. Всегда. Автомат не запоминает, сколько раз вы уже покупали, и не меняет цены на ходу.

Нечистая функция имела бы стрелки к "внешнему миру" и обратно — глобальным переменным, базе данных, таймеру, консоли.

## Примеры

```ts
// Чистая — результат зависит только от аргументов
function add(a: number, b: number): number {
  return a + b
}

// Чистая — создаёт новый объект, не трогает оригинал
function setDone(task: Task): Task {
  return { ...task, done: true }
}

// Нечистая — читает внешнее состояние
let taxRate = 0.2
function calcPrice(price: number): number {
  return price * (1 + taxRate) // зависит от taxRate снаружи
}

// Нечистая — мутирует аргумент
function sortInPlace(arr: number[]): number[] {
  return arr.sort() // sort() мутирует массив!
}

// Нечистая — побочный эффект (запись в консоль)
function logAndReturn(x: number): number {
  console.log(x) // наблюдаемый эффект
  return x
}

// Нечистая — недетерминированность
function randomId(): string {
  return Math.random().toString(36).slice(2)
}
```

## Почему это важно

**Тестируемость.** Чистую функцию можно протестировать без моков, без настройки окружения:

```ts
expect(add(2, 3)).toBe(5) // всё — больше ничего не нужно
```

**Предсказуемость.** Прочитав вызов `calculateTotal(items)`, вы знаете: результат зависит только от `items`. Никаких сюрпризов.

**Параллелизм.** Чистые функции можно безопасно вызывать параллельно — они не конкурируют за общее состояние.

**Кэширование (memoization).** Если аргументы не изменились — можно вернуть сохранённый результат.

## Виды побочных эффектов

| Эффект | Пример |
|---|---|
| Мутация аргумента | `arr.sort()`, `obj.field = x` |
| Мутация глобального состояния | `counter++` |
| Ввод/вывод | `console.log`, `fetch`, `fs.write` |
| Недетерминированность | `Math.random()`, `Date.now()` |
| Исключения | `throw new Error(...)` |

## Ключевая идея

Побочные эффекты неизбежны — программы должны взаимодействовать с миром. Цель FP не убрать эффекты, а **изолировать их**: держать логику в чистых функциях, а эффекты — на границах системы.

```ts
// Плохо: логика и эффект перемешаны
function processImpure(order) {
  order.total = order.items.reduce(...)  // мутация
  console.log('done')                    // эффект
  return order
}

// Хорошо: логика чистая, эффект снаружи
function processPure(order) {
  return { ...order, total: order.items.reduce(...) }
}
// Вызывающий код решает, когда логировать:
const result = processPure(order)
console.log('done')
```

## Частые ошибки новичков

**Мутация через Array.sort()**

```ts
// Нечистая — мутирует входной массив
const sorted = arr.sort((a, b) => a - b)

// Чистая — сначала копируем
const sorted = [...arr].sort((a, b) => a - b)
```

**Чтение глобального времени внутри функции**

```ts
// Нечистая
function timestamp(data) {
  return { ...data, at: Date.now() }
}

// Чистая — время приходит снаружи
function timestamp(data, now: number) {
  return { ...data, at: now }
}
```
