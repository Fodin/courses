# Задание 8.3: Topics и Partitions

## Цель

Реализовать интерактивную демонстрацию партиционирования сообщений в Kafka: создание topics, отправка сообщений с ключами и визуализация того, как ключ определяет партицию через хэш-функцию.

## Требования

1. Определить типы `TopicConfig` и `Message83`:
   - `TopicConfig`: `name`, `partitions`, `replicationFactor`, `color`, `bgColor`
   - `Message83`: `id`, `key`, `value`, `partition`, `offset`, `color`

2. Инициализировать два topics: `orders` (3 партиции, RF=2) и `payments` (2 партиции, RF=2).

3. Реализовать функцию `hashKey(key: string, partitions: number): number`:
   - Вычисляет хэш строки (Murmur2-подобный алгоритм: для каждого символа `hash = ((hash << 5) - hash + charCodeAt) | 0`)
   - Возвращает `Math.abs(hash) % partitions`
   - Одинаковый ключ всегда попадает в одну и ту же партицию

4. Реализовать панель статистики (три карточки):
   - "Topics" — общее количество topics
   - "Всего партиций" — сумма партиций по всем topics
   - "Сообщений" — суммарное количество отправленных сообщений

5. Реализовать переключение между topics через кнопки-таблетки:
   - Активный topic выделяется цветом фона и жирным шрифтом
   - Отображается название и количество партиций: `orders (3p)`

6. Реализовать форму создания нового topic:
   - Поле ввода имени, select для количества партиций (варианты: 1, 2, 3, 4, 6, 8)
   - Кнопка "Создать Topic" добавляет topic в список и переключает на него
   - Кнопка недоступна (серая), если имя пустое или уже существует

7. Реализовать визуализацию партиций выбранного topic:
   - Заголовок: "Topic: <name> — N партиций, replication factor: RF"
   - Горизонтальный ряд колонок (по одной на партицию)
   - Каждая колонка: заголовок "Partition N (X msg)" + список карточек сообщений
   - В пустой партиции текст "Нет сообщений"
   - Каждая карточка сообщения показывает `offset=N`, `key`, `value` (с обрезкой)

8. Реализовать форму отправки сообщения:
   - Поля: `key` (влияет на партицию), `value`
   - Кнопка "Отправить"
   - Функция `sendMessage`: вычисляет партицию через `hashKey`, определяет offset как количество существующих сообщений в этой партиции, добавляет сообщение
   - В лог добавляет две строки:
     ```
     [SEND] topic=orders key="user-1" → partition=2 offset=0
       hash("user-1") % 3 = 2
     ```

9. Реализовать лог отправки (тёмный терминал):
   - Хранит до 16 последних записей
   - Кнопка "Очистить" сбрасывает лог

## Проверочный список

- [ ] Два начальных topic (`orders`, `payments`) отображаются как кнопки-таблетки
- [ ] Статистика (topics / партиции / сообщения) обновляется при добавлении topic и сообщений
- [ ] Форма создания topic добавляет новый topic с выбранным количеством партиций
- [ ] При отправке сообщения с одним и тем же ключом оно всегда попадает в одну партицию
- [ ] Лог показывает результат хэширования: `hash("user-1") % 3 = 2`
- [ ] Каждая партиция отображает собственный offset (начиная с 0 для каждой партиции)
- [ ] Переключение между topics показывает партиции выбранного topic

## Как проверить себя

1. Отправь несколько сообщений с ключом `user-1` в topic `orders` — все они должны попасть в одну и ту же партицию.
2. Отправь сообщение с другим ключом (например `order-999`) — оно попадёт в другую партицию.
3. Создай новый topic `events` с 4 партициями — счётчик "Всего партиций" увеличится, появится новый topic с четырьмя пустыми колонками.
