# Задание 3.2 — Частичное применение

## Цель

Реализовать функцию `partial(fn, ...presetArgs)` и показать несколько практических примеров
её использования. Добавить переключатель "partial vs curry" с объяснением разницы.

## Требования

1. Реализуйте `partial(fn, ...presetArgs)`:
   - Возвращает функцию, которая принимает оставшиеся аргументы
   - Вызывает `fn` с объединёнными `[...presetArgs, ...remainingArgs]`
   - Типизируйте через дженерики (без `any`)

2. Реализуйте четыре демонстрационных примера:
   - `double = partial(multiply, 2)` — ввод числа, результат умножения
   - `addTax = partial(multiply, 1.2)` — ввод цены, результат с НДС 20%
   - `greetUser = partial(greet, 'Привет')` — ввод имени, готовое приветствие
   - `formatRuDate = partial(formatDate, 'ru-RU')` — ввод даты YYYY-MM-DD, локализованный вывод

3. Для каждого примера — карточка с:
   - Заголовком (итоговая переменная и вызов `partial`)
   - Исходной сигнатурой функции
   - Текстом зафиксированного аргумента
   - Полем ввода для оставшегося аргумента
   - Живым результатом под полем

4. Добавьте переключатель "partial / curry":
   - Режим `partial`: показывает реализацию `partial`
   - Режим `curry`: показывает как то же самое делается через `curry`, объясняет разницу

## Чеклист

- [ ] Функция `partial` работает со строками, числами, датами
- [ ] Все четыре карточки отображают результат в реальном времени
- [ ] При некорректной дате `formatRuDate` показывает понятное сообщение об ошибке
- [ ] Переключатель partial/curry переключает блок кода с реализацией
- [ ] Есть текстовое пояснение разницы между двумя подходами

## Как проверить себя

Введите число `100` в карточке `addTax` — результат должен быть `120`.
Введите `Мария` в карточке `greetUser` — должно появиться `Привет, Мария!`.
Введите `2024-06-01` в карточку `formatRuDate` — должна появиться дата в русском формате.
Переключитесь в режим `curry` и убедитесь что объяснение разницы присутствует.

**Подсказка:** `partial` — это то же что `fn.bind(null, ...presetArgs)`, только без привязки `this`.
Реализация: `return (...rest) => fn(...presetArgs, ...rest)`.
