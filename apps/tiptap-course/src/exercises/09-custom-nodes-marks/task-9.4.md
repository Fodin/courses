# Задание 9.4: Atom/leaf-нода

## Цель

Реализовать неделимую инлайн-ноду `badge` ("бейдж") — маленький визуальный элемент внутри текста, который курсор не может "войти", только обойти.

## Требования

1. Создайте `Node.create({ name: 'badge', group: 'inline', inline: true, atom: true, ... })`
2. `addAttributes()` — `label` (default `'NEW'`)
3. `parseHTML()`/`renderHTML()` — сериализация в `<span data-badge>{label}</span>`
4. Команда `addCommands()` → `insertBadge: (label?: string) => ({ commands }) => commands.insertContent({ type: this.name, attrs: { label } })`
5. В React-компоненте кнопка "Вставить бейдж" вызывает `editor.chain().focus().insertBadge('NEW').run()`
6. Стилизуйте `[data-badge]` — маленькая цветная "таблетка" с текстом внутри строки

## Чеклист

- [ ] Компонент называется `Task9_4` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.9.4')` используется в заголовке
- [ ] Бейдж вставляется в текущую позицию курсора внутри текста
- [ ] Курсор нельзя поставить "внутрь" бейджа — только до или после (используйте стрелки клавиатуры для проверки)
- [ ] `Backspace`/`Delete` рядом с бейджем удаляет его целиком, а не по одному символу
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Поставьте курсор в середину предложения, нажмите "Вставить бейдж" — должен появиться визуальный элемент прямо в тексте
2. Попробуйте кликнуть точно на бейдж — курсор должен встать до или после него, не "внутрь"
3. Нажмите стрелку вправо/влево рядом с бейджем — курсор должен перепрыгивать через него целиком, а не посимвольно
4. Нажмите `Backspace` сразу после бейджа — он должен удалиться одним нажатием
