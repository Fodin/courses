# Задание 11.2: Streaming Simulator

## Цель

Понять механику chunked streaming в RSC: как страница появляется постепенно, section за section, имитируя поведение React с Suspense-границами и Transfer-Encoding: chunked.

## Задание

Реализуйте `StreamingSimulator` — компонент, который симулирует загрузку страницы через 4 секции с задержками, прогресс-баром и возможностью воспроизвести анимацию заново.

### Секции страницы (фиксированные)

```ts
const SECTIONS = [
  { id: 'header',   label: 'Header',   delay: 0,    color: '#3b82f6' },
  { id: 'hero',     label: 'Hero',     delay: 800,  color: '#8b5cf6' },
  { id: 'content',  label: 'Content',  delay: 1800, color: '#10b981' },
  { id: 'comments', label: 'Comments', delay: 3200, color: '#f59e0b' },
]
```

### Шаг 1. Состояния секции

Каждая секция проходит через три состояния:
- `'waiting'` — серый skeleton (полоски-заглушки), метка "Ожидание..."
- `'loading'` — skeleton с анимацией shimmer, метка "Получен чанк..."
- `'ready'` — финальный контент с цветным фоном, метка с названием секции

### Шаг 2. Запуск симуляции

Кнопка "Запустить streaming". При клике — все секции переходят в `'waiting'`, затем через `setTimeout` с соответствующими `delay`:
1. Сначала секция переходит в `'loading'` (shimmer, 400ms)
2. Затем в `'ready'` (финальный контент)

### Шаг 3. Прогресс-бар

Над секциями — прогресс-бар, который показывает процент полученных чанков. Формула: `(готовых секций / всего секций) * 100`. Анимация width transition.

Рядом с прогресс-баром — текст "Получено X/4 чанков".

### Шаг 4. Кнопка Replay

Кнопка "Повторить" (или иконка ↺) появляется после завершения (все секции `'ready'`). Клик — сбрасывает всё и запускает заново. Кнопка "Запустить" блокируется во время симуляции (`disabled`).

### Шаг 5. Информационная панель

Под прогресс-баром — маленькая панель `Transfer-Encoding: chunked`, которая показывает "лог" получения чанков в реальном времени:
```
[0ms]   → chunk 1: Header (shell)
[800ms] → chunk 2: Hero section
...
```

## Требования

1. 4 секции с состояниями `waiting` / `loading` / `ready`
2. Состояние `loading` сопровождается shimmer-анимацией (CSS @keyframes)
3. Переход `waiting → loading → ready` через setTimeout с задержками из `SECTIONS`
4. Прогресс-бар с плавной анимацией `width` (CSS transition)
5. Счётчик чанков: "Получено X/4 чанков"
6. Лог получения чанков с временными метками (относительно старта)
7. Кнопка "Запустить" недоступна во время симуляции
8. Кнопка "Повторить" появляется только после завершения
9. Корректная очистка таймеров при размонтировании (useEffect cleanup)

## Чеклист

- [ ] Секции отображаются в порядке: Header, Hero, Content, Comments
- [ ] Состояние `waiting` — серый placeholder без анимации
- [ ] Состояние `loading` — shimmer (анимация градиента слева направо)
- [ ] Состояние `ready` — цветная карточка с контентом секции
- [ ] Прогресс-бар корректно обновляется по мере готовности секций
- [ ] Лог показывает временные метки в мс относительно начала
- [ ] После "Повторить" — новый цикл с теми же задержками
- [ ] useEffect возвращает cleanup-функцию, очищающую таймеры
- [ ] Нет лишних re-render (таймеры запускаются один раз)

## Как проверить себя

1. Нажмите "Запустить streaming" — Header появится сразу, остальные с задержками
2. Следите за прогресс-баром: он должен дойти до 100% только когда все секции `ready`
3. Проверьте лог: временные метки должны соответствовать `delay` из `SECTIONS`
4. Нажмите "Повторить" — анимация должна начаться заново с нуля
5. Откройте DevTools → Elements: секции появляются в DOM постепенно (каждая в своё время)
