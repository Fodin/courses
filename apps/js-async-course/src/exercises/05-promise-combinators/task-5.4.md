# Задание 5.4: Promise.any — первый успешный

## Цель

Реализовать визуализацию `Promise.any` с практическим CDN-сценарием: три сервера с разной задержкой и переключателями online/offline. Студент должен увидеть разницу между `race` (первый любой) и `any` (первый fulfilled), а также `AggregateError` когда все серверы offline.

## Требования

1. **3 CDN-сервера**: CDN Primary, CDN Secondary, CDN Tertiary с разными цветами
2. **Настройки каждого сервера**:
   - Слайдер задержки (300–3000мс)
   - Переключатель ONLINE / OFFLINE
3. **Трек серверов** — горизонтальные прогресс-бары:
   - ONLINE-сервер: цветной прогресс, при завершении — зелёный с меткой ПОБЕДА
   - OFFLINE-сервер: серый прогресс, при завершении — красный с меткой OFFLINE
   - Rejected серверы игнорируются — `any` продолжает ждать следующего
4. **Предупреждение** при всех offline: «Все серверы offline — будет AggregateError»
5. **Результат**:
   - Зелёный блок: первый fulfilled — `"asset.js from CDN Name"`
   - Красный блок при AggregateError:
     - Заголовок «AggregateError (все серверы offline)»
     - Показ массива `errors[]` с причиной каждого
     - Пояснение что AggregateError — ES2021 с полем `.errors`
6. **Блок сравнения** `Promise.race vs Promise.any` с кодом

## Как проверить себя

1. Все ONLINE, Primary=1200мс, Secondary=800мс, Tertiary=600мс. Запустите — победит Tertiary (600мс)
2. Tertiary→OFFLINE. Запустите — Tertiary отклонён, побеждает Secondary (800мс) — `any` дождался следующего
3. Secondary и Tertiary→OFFLINE. Побеждает Primary — единственный ONLINE
4. Все→OFFLINE. Запустите — AggregateError с тремя ошибками
5. Проверьте что errors[] в блоке результата содержит сообщение от каждого сервера
