# Задание 9.3: Real-time event stream

## Цель

Реализовать симулятор потока биржевых котировок через async-генератор. Показать концепцию backpressure: когда потребитель медленнее производителя — источник либо ждёт, либо события пропускаются (при паузе).

## Требования

1. **Генератор потока** — функция, которая через `setInterval` или `delay`-цикл производит тики котировок (символ, цена, изменение в %). Событие генерируется каждые 300мс

2. **Потребитель** — обрабатывает каждое событие за 200мс (медленнее источника). Из-за этого образуется backpressure — генератор ждёт потребителя перед следующим тиком

3. **Бегущая лента событий** — показывает последние 30 событий: время, символ, цена, изменение в %
   - Положительное изменение — зелёным цветом
   - Отрицательное — красным

4. **Мини-график (sparkline)** — линейный график последних 20 значений цены через SVG `<polyline>`. Цвет линии зависит от направления последнего тика

5. **Счётчики**: "Обработано N событий" и "Пропущено M событий" (при паузе — события от источника не попадают в очередь)

6. **Три кнопки**: "Старт" (запускает поток), "Пауза" / "Продолжить" (переключает), "Стоп" (прерывает генератор)

7. **Backpressure при паузе** — при нажатии "Пауза" счётчик пропущенных событий растёт. При возобновлении — обработка продолжается с текущего момента (без обработки накопленных)

## Чеклист

- [ ] Компонент называется `Task9_3` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован, `t('task.9.3')` используется в заголовке
- [ ] Источник генерирует события с периодом ~300мс
- [ ] Потребитель обрабатывает каждое событие с задержкой ~200мс
- [ ] Лента событий показывает последние 30 записей (новые добавляются сверху)
- [ ] Sparkline-график отображает последние 20 значений через SVG polyline
- [ ] "Пауза" увеличивает счётчик пропущенных событий
- [ ] "Стоп" очищает таймеры и освобождает ресурсы
- [ ] При повторном "Старт" — счётчики и история сбрасываются
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Нажмите "Старт" — через секунду появятся первые котировки в ленте
2. Числа должны мигать зелёным (рост) и красным (падение)
3. График обновляется с каждым новым тиком
4. Нажмите "Пауза" — счётчик "Обработано" перестаёт расти, "Пропущено" увеличивается
5. Нажмите "Продолжить" — обработка возобновляется без накопленных пропущенных событий
6. Нажмите "Стоп" — поток прекращается, кнопка "Старт" снова активна
