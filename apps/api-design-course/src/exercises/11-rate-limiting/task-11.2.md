# Задание 11.2: Конструктор Retry-стратегии

## Цель

Реализовать визуализатор exponential backoff с jitter. Компонент должен наглядно показывать, как меняется задержка между попытками, и сравнивать стратегии с jitter и без него.

## Требования

1. Настраиваемые параметры: `baseDelay` (100–5000мс), `maxDelay` (1000–60000мс), `maxRetries` (1–8), `jitter` (checkbox вкл/выкл)
2. Настройка «Успех на попытке» — кнопки #2, #3, #4, #5 (симулируем разное число 429 перед успехом)
3. Timeline попыток: для каждой попытки — цветной кружок с номером, полоска задержки (ширина пропорциональна delay), значение задержки, статус (200/429)
4. Блок сравнения: карточка «Без jitter» (суммарное время, предупреждение о thundering herd) и «С jitter» (суммарное время, пометка о равномерном распределении)
5. Кнопка «Запустить симуляцию» — анимированно добавляет попытки одну за другой
6. После симуляции — лог в тёмном терминальном стиле (bg #1e293b)

## Чеклист

- [ ] Формула `min(maxDelay, baseDelay × 2^attempt)` реализована корректно
- [ ] С jitter: задержка умножается на `random(0.5, 1.0)`
- [ ] Timeline показывает полоски пропорциональной ширины
- [ ] Карточки сравнения с/без jitter обновляются при изменении параметров
- [ ] Кнопки «Успех на попытке» меняют число неудачных попыток
- [ ] Симуляция анимирована (попытки появляются поочерёдно)
- [ ] Лог в стиле терминала

## Как проверить себя

1. base=1000, max=32000, retries=5 — задержки: 1с, 2с, 4с, 8с, 16с, 32с(cap)
2. Включи/выключи jitter — суммарное время меняется
3. Нажми «Запустить симуляцию» — попытки появляются с паузами
4. «Успех на попытке #3» — в симуляции 2 раза 429, затем 200

## Подсказки

- Функция расчёта: `Math.min(max, base * Math.pow(2, attempt - 1))`
- Для анимации используй `setTimeout` с накопленной задержкой: каждая попытка добавляется позже предыдущей
- Ширина полоски: `Math.max(20, Math.min(200, delay / maxDelay * 200))` — чтобы очень маленькие задержки всё равно были видны
