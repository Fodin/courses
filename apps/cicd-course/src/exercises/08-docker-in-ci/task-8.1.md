# Задание 8.1: Docker-in-Docker — сравнение методов сборки

## Цель

Создать интерактивную визуализацию трёх методов сборки Docker-образов в CI: Docker-in-Docker (dind), Kaniko и Docker socket mount. Пользователь выбирает метод и видит характеристики, YAML-конфиг и предупреждения.

## Требования

1. Отобразить три карточки методов: **dind**, **Kaniko**, **socket mount** — с кратким описанием
2. При выборе метода показывать сравнительную таблицу характеристик: privileged mode, скорость, безопасность, сложность настройки
3. Показывать готовый YAML-конфиг для выбранного метода (GitLab CI)
4. Для dind — добавить переключатель TLS on/off, YAML должен обновляться
5. Для методов с рисками безопасности (dind с отключённым TLS, socket mount) показывать предупреждение
6. Добавить индикатор уровня безопасности: красный / жёлтый / зелёный в зависимости от выбранного метода и настроек

## Чеклист

- [ ] Три карточки методов с иконками или цветовым кодированием
- [ ] При клике на карточку — она подсвечивается как активная
- [ ] Таблица сравнения обновляется при смене метода
- [ ] YAML-блок (моноширинный шрифт, тёмный фон) меняется под выбранный метод
- [ ] Для dind — переключатель TLS on/off влияет на YAML и на индикатор безопасности
- [ ] Предупреждение (жёлтый или красный блок) при небезопасной конфигурации
- [ ] Индикатор безопасности с цветом и текстом уровня

## Как проверить себя

1. Выбери dind с TLS включённым — YAML содержит `DOCKER_TLS_CERTDIR: '/certs'`, индикатор жёлтый
2. Отключи TLS у dind — YAML меняется на порт 2375, появляется красное предупреждение
3. Выбери Kaniko — нет предупреждений, индикатор зелёный, в YAML нет `privileged`
4. Выбери socket mount — появляется предупреждение об опасности доступа к host socket
5. Переключи обратно на dind с TLS — предупреждение исчезает

## Подсказки

- Используй `useState` для: `selectedMethod` (строка), `tlsEnabled` (boolean)
- YAML собирай через функцию `buildYaml(method, tlsEnabled)`
- Для таблицы сравнения удобно хранить данные как объект: `{ dind: { privileged: true, ... }, kaniko: { ... } }`
- Уровень безопасности: socket mount = danger, dind без TLS = danger, dind с TLS = warning, kaniko = safe
