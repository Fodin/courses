# Задание 12.1: addKeyboardShortcuts

## Цель

Реализовать extension со своим набором горячих клавиш: `Mod-Shift-x` — strike, `Mod-Shift-c` — очистка форматирования (комбинация из уровня 5).

## Требования

1. Создайте `Extension.create({ name: 'customShortcuts', addKeyboardShortcuts() {...} })`
2. `'Mod-Shift-x'` → `this.editor.chain().focus().toggleStrike().run()`
3. `'Mod-Shift-c'` → `this.editor.chain().focus().unsetAllMarks().clearNodes().run()`
4. Подключите extension вместе со `StarterKit`
5. Выведите список активных шорткатов в UI под редактором (просто текстовая справка, без динамического чтения из extension)

## Чеклист

- [ ] Компонент называется `Task12_1` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.12.1')` используется в заголовке
- [ ] `Mod-Shift-x` переключает зачёркивание выделенного текста
- [ ] `Mod-Shift-c` очищает форматирование
- [ ] Список шорткатов отображается в UI
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Выделите текст, нажмите `Ctrl+Shift+X` (или `Cmd+Shift+X` на Mac) — текст должен зачеркнуться
2. Отформатируйте текст (bold, заголовок), выделите его и нажмите `Ctrl+Shift+C` — форматирование должно исчезнуть
3. Убедитесь, что обычные встроенные шорткаты (`Ctrl+B` для bold) продолжают работать без конфликтов
