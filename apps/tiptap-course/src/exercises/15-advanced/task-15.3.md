# Задание 15.3: Программное управление выделением

## Цель

Реализовать простое "оглавление" (table of contents), генерируемое из заголовков документа, с кликабельными пунктами, которые устанавливают курсор/выделение на соответствующий заголовок через `setTextSelection`.

## Требования

1. Создайте `editor` через `useEditor` с `StarterKit`, начальный контент — документ с 4-5 заголовками разных уровней и текстом между ними
2. Постройте список оглавления, обходя `editor.state.doc` через `descendants` и собирая все ноды `heading` вместе с их `pos` и текстом
3. По клику на пункт оглавления вызывайте `editor.chain().focus().setTextSelection(pos).scrollIntoView().run()` (`pos` — позиция начала соответствующего заголовка)
4. Дополнительно реализуйте кнопку "Выделить весь документ" — `editor.commands.selectAll()`
5. Оглавление должно обновляться при изменении заголовков документа (используйте `onUpdate` для пересчёта списка)

## Чеклист

- [ ] Компонент называется `Task15_3` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.15.3')` используется в заголовке
- [ ] Оглавление корректно строится из всех заголовков документа
- [ ] Клик по пункту оглавления переводит курсор к соответствующему заголовку и прокручивает к нему
- [ ] Кнопка "Выделить весь документ" выделяет весь текст
- [ ] Оглавление актуализируется при добавлении/удалении/переименовании заголовков
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Откройте задание — оглавление должно содержать все заголовки из начального документа
2. Кликните на пункт оглавления в середине списка — редактор должен прокрутиться и поставить курсор точно в начало соответствующего заголовка
3. Измените текст одного из заголовков — соответствующий пункт оглавления должен обновиться
4. Нажмите "Выделить весь документ" — весь текст должен выделиться синим
