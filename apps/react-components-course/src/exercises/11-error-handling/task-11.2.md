# Задание 11.2: Гранулярные boundaries с retry-механизмом

## Цель

Построить страницу с четырьмя независимыми виджетами, каждый из которых обёрнут в собственный Error Boundary. Добавить retry-механизм с ограничением попыток и счётчиком.

## Требования

1. Используйте `ErrorBoundary` из задания 11.1 (или реализуйте повторно)
2. Создайте четыре независимых виджета: `WeatherWidget`, `NewsWidget`, `StockWidget`, `CalendarWidget`
3. Каждый виджет имеет внутренний state: показывает контент или может быть «сломан» кнопкой
4. Создайте компонент `RetryFallback` — принимает `FallbackProps` и дополнительно `maxRetries: number`
   - Хранит счётчик попыток в собственном state
   - Показывает: сообщение об ошибке, счётчик «Попытка X из N», кнопку «Повторить»
   - Когда попытки исчерпаны: показывает «Виджет недоступен. Обратитесь в поддержку.» без кнопки
5. Оберните каждый виджет в `ErrorBoundary` с `RetryFallback` (maxRetries=3)
6. Добавьте `key`-механизм: кнопка «Перезагрузить все» сбрасывает все boundaries и все счётчики попыток
7. Разместите виджеты в сетке 2×2 (можно через CSS grid или flexbox)

## Подсказки

- `RetryFallback` — функциональный компонент, `ErrorBoundary` — class-компонент. Смешивать можно и нужно
- Для сброса ErrorBoundary через внешний key: `<ErrorBoundary key={retryKey}>` — смена key пересоздаёт весь boundary
- Счётчик попыток в `RetryFallback` сбрасывается автоматически при пересоздании компонента (смена key)
- Симулируйте ошибку через state: `const [broken, setBroken] = useState(false); if (broken) throw new Error(...)`

## Чеклист

- [ ] Четыре виджета в сетке 2×2
- [ ] У каждого виджета кнопка «Сломать»
- [ ] `RetryFallback` показывает счётчик попыток
- [ ] После исчерпания попыток кнопка «Повторить» исчезает
- [ ] Кнопка «Перезагрузить все» сбрасывает все виджеты и счётчики
- [ ] Падение одного виджета не затрагивает остальные три

## Как проверить себя

1. Сломайте WeatherWidget — появляется RetryFallback с «Попытка 0 из 3»
2. Нажмите «Повторить» три раза — виджет восстанавливается (симулируем успех при retry)
3. Сломайте виджет и нажимайте «Повторить» не нажимая «Сломать» — после 3 попыток кнопка пропадает
4. Сломайте два виджета, нажмите «Перезагрузить все» — оба восстанавливаются
5. NewsWidget, StockWidget, CalendarWidget работают независимо
