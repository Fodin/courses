# Task 3.3 — Guess the Status Code

## Goal

Consolidate knowledge of status codes through practical scenarios. Be able to choose the correct code for a specific situation and explain why other options don't fit.

## Requirements

1. The component shows 10 scenarios from real API situations.
2. For each scenario — 3 answer options (one correct, two incorrect).
3. After selection — an explanation of the correct answer is shown immediately.
4. For incorrect options — an explanation of why they don't fit.
5. A progress indicator shows the score (correct / total).

## Checklist

- [ ] 10 scenarios
- [ ] Navigation between scenarios (forward/backward)
- [ ] Scenario number and total score indicator
- [ ] Explanation after each answer
- [ ] Explanation for incorrect options
- [ ] Reset button for retaking

## How to Check Yourself

Complete all 10 scenarios without hints. If you scored 8+ out of 10 — excellent. If less — return to the theory for the error scenarios. Special attention: 401 vs 403, 400 vs 422, 409 vs 422, 500 vs 502 vs 504.
