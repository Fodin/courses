# Задание 8.1: Диагностика и исправление лишних рендеров в чат-приложении

## Цель

Научиться диагностировать лишние ре-рендеры с помощью render counters и устранять их комбинацией `React.memo` и структурных изменений.

## Контекст

Перед тобой простое чат-приложение с тремя компонентами:

- `MessageList` — список сообщений (тяжёлый, рендерит много элементов)
- `MessageInput` — поле ввода нового сообщения
- `OnlineUsers` — панель онлайн-пользователей

Сейчас при вводе каждого символа в поле сообщения ре-рендерятся **все** три компонента, хотя `MessageList` и `OnlineUsers` не зависят от вводимого текста.

## Требования

1. Добавь render counters во все три компонента (`useRef` + счётчик в JSX) — это позволит видеть количество рендеров
2. Убедись что проблема реальна: понаблюдай за счётчиками при вводе текста
3. Перенеси state поля ввода (`inputText`) в сам компонент `MessageInput` — это структурное решение (state down)
4. Защити `MessageList` через `React.memo` — он получает стабильный проп `messages`
5. Защити `OnlineUsers` через `React.memo` — он получает стабильный проп `users`
6. Проверь что после оптимизации при вводе текста ре-рендерится только `MessageInput`
7. Кнопка "Отправить" добавляет сообщение в список и очищает поле ввода

## Подсказки

- Render counter: `const renderCount = useRef(0); renderCount.current++`
- Отображай счётчик прямо в компоненте: небольшой бейдж в углу
- `React.memo` оборачивает компонент целиком: `const MyComp = React.memo(function MyComp(...) { ... })`
- При переносе state в `MessageInput`, для отправки используй проп `onSend: (text: string) => void`
- Используй `useCallback` для `onSend` в родителе — иначе `React.memo` на `MessageInput` не поможет

## Чеклист

```
[ ] Render counters добавлены во все три компонента и видны в UI
[ ] State inputText перенесён внутрь MessageInput (state down)
[ ] MessageList обёрнут в React.memo
[ ] OnlineUsers обёрнут в React.memo
[ ] onSend стабилизирован через useCallback в родителе
[ ] При вводе текста ре-рендерится только MessageInput (счётчик растёт только у него)
[ ] Отправка сообщения работает: текст появляется в MessageList, поле очищается
[ ] После отправки рендерится MessageList (новые данные) — это ожидаемо и правильно
```

## Как проверить себя

Открой компонент в браузере. При вводе текста в поле сообщения: счётчик `MessageInput` должен расти, счётчики `MessageList` и `OnlineUsers` — оставаться на месте. При нажатии "Отправить" — обновятся все счётчики (это нормально: данные изменились).
