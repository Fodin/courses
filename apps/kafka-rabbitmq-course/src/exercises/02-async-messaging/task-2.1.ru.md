# Задание 2.1: Sync vs Async — визуальное сравнение

## Цель

Реализовать параллельную анимацию, которая наглядно показывает разницу между синхронной цепочкой вызовов и асинхронной коммуникацией через очередь. Пользователь должен видеть, как temporal coupling блокирует сервисы в sync-модели и как async-модель освобождает отправителя от ожидания.

---

## Требования

1. Создайте компонент с двумя параллельными панелями: "Синхронный вызов" слева и "Асинхронная очередь" справа
2. В синхронной панели отобразите цепочку сервисов (минимум 4): Order Service -> Payment Service -> Inventory Service -> Notification Service
3. Каждый сервис в цепочке переходит через состояния: `idle` -> `waiting` -> `processing` -> `done`
4. При запуске синхронной анимации сервисы активируются строго последовательно — каждый ждёт завершения предыдущего
5. В асинхронной панели первый сервис (Order Service) завершает работу быстро, кладёт сообщение в очередь (Message Queue) и сразу переходит в `done`
6. Workers в асинхронной панели начинают работу параллельно после того, как очередь получила сообщение
7. После завершения обеих анимаций отображайте реально измеренное время в миллисекундах для каждой модели
8. Добавьте кнопку запуска под каждой панелью, которая блокируется во время выполнения
9. Визуально выделите состояния: ожидание (жёлтый), обработка (синий), готово (зелёный)
10. Добавьте итоговый блок с объяснением ключевого вывода

---

## Чеклист

- [ ] Два отдельных useState-управляемых массива для sync и async сервисов
- [ ] Функция `runSync` корректно имитирует последовательную блокирующую обработку через `await + setTimeout`
- [ ] Функция `runAsync` показывает быстрый возврат Order Service и параллельную работу workers
- [ ] Цветовые состояния применяются через transition для плавной анимации
- [ ] Измерение времени через `Date.now()` и отображение результата после завершения
- [ ] Кнопки заблокированы (`disabled`) во время выполнения анимации
- [ ] Компонент работает корректно в темной и светлой теме
- [ ] Стрелки-разделители между сервисами в вертикальной цепочке

---

## Как проверить себя

1. Нажмите "Запустить синхронно" — сервисы должны активироваться строго один за другим, предыдущие уходят в `done`, следующие были в `waiting`
2. Нажмите "Запустить асинхронно" — Order Service должен завершиться первым (за ~300мс), затем Message Queue, затем Workers стартуют параллельно
3. Итоговое время async должно быть значительно меньше sync-времени (т.к. workers работают параллельно, а не последовательно)
4. Кнопка не должна быть кликабельна во время анимации
5. Блок с выводом должен появляться только после завершения анимации

### Ожидаемый результат

```
Sync:  [Order: done] -> [Payment: done] -> [Inventory: done] -> [Notification: done]
       Время: ~3200ms (сумма всех шагов)

Async: [Order: done] -> [Queue: done] -> [Payment: done | Inventory: done]
       Время: ~1800ms (Order + max(workers))
```
