# Задание 9.1: Batching Explorer

## Цель

Экспериментально убедиться, что React 18 применяет автоматический батчинг во всех контекстах: в обработчиках событий, в `setTimeout`, в `Promise.then`. Визуальный счётчик рендеров докажет, что несколько `setState` в одном "хвосте выполнения" порождают ровно 1 рендер.

## Требования

1. Создать компонент `BatchingExplorer` с тремя независимыми счётчиками состояния: `counterA`, `counterB`, `counterC` (все начинаются с 0)
2. Добавить счётчик рендеров через `useRef` — инкрементировать его в теле функции компонента при каждом вызове; отображать текущее значение
3. Добавить три кнопки:
   - **"Event Handler"** — вызывает `setCounterA(v => v + 1)`, `setCounterB(v => v + 1)`, `setCounterC(v => v + 1)` последовательно в одном обработчике
   - **"setTimeout"** — оборачивает те же три вызова в `setTimeout(() => { ... }, 0)`
   - **"Promise.then"** — оборачивает три вызова в `Promise.resolve().then(() => { ... })`
4. После каждого клика отображать "Рендеров после клика: N" — это значение должно быть равно 1 во всех трёх случаях в React 18
5. Добавить кнопку "Сбросить" которая обнуляет все три счётчика и счётчик рендеров
6. Добавить блок "История рендеров" — лог с временными метками каждого рендера (через `useRef` массив, обновляемый в теле компонента), чтобы визуально подтвердить батчинг

## Чеклист

- [ ] Три отдельных `useState` для `counterA`, `counterB`, `counterC`
- [ ] `useRef` для счётчика рендеров, инкрементируется в теле компонента (не в эффекте)
- [ ] Кнопка "Event Handler": три `setState` в одном обработчике без таймаутов
- [ ] Кнопка "setTimeout": три `setState` внутри `setTimeout(..., 0)`
- [ ] Кнопка "Promise.then": три `setState` внутри `Promise.resolve().then(...)`
- [ ] Во всех трёх случаях счётчик рендеров увеличивается ровно на 1 за клик
- [ ] Лог рендеров обновляется с временной меткой при каждом рендере
- [ ] Кнопка "Сбросить" работает корректно

## Как проверить себя

1. Нажмите "Event Handler" — счётчик рендеров вырастет на 1, все три значения увеличатся
2. Нажмите "setTimeout" — результат тот же: +1 рендер, все три значения выросли
3. Нажмите "Promise.then" — снова +1 рендер
4. Откройте DevTools → React Profiler → включите запись и понажимайте кнопки: вы увидите ровно 1 коммит на каждый клик, а не 3
5. Посмотрите на лог рендеров: временные метки должны показывать один рендер на клик (одна запись, не три)
6. Сравните поведение в React 17 (если есть доступ): в `setTimeout` и `Promise.then` было бы 3 рендера
