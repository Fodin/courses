# Задание 3.3: Link mark

## Цель

Настроить mark `Link` (входит в `StarterKit` в Tiptap v3), реализовать установку и снятие ссылки на выделенный текст через простую форму ввода URL.

## Требования

1. Настройте `StarterKit.configure({ link: { openOnClick: false, autolink: true } })`
2. Добавьте кнопку "Добавить ссылку" — по клику показывайте `prompt()` (или встроенное текстовое поле) для ввода URL
3. Если URL введён — примените `editor.chain().focus().extendMarkRange('link').setLink({ href: url }).run()`
4. Добавьте кнопку "Убрать ссылку", видимую только когда `editor.isActive('link')` — по клику вызывайте `unsetLink()`
5. Ссылки должны автоматически создаваться при вставке/вводе URL благодаря `autolink: true`

## Чеклист

- [ ] Компонент называется `Task3_3` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.3.3')` используется в заголовке
- [ ] Кнопка "Добавить ссылку" запрашивает URL и применяет его к выделению
- [ ] Кнопка "Убрать ссылку" появляется только при активном link mark и корректно снимает его
- [ ] Ввод чистого URL текстом автоматически превращает его в ссылку (autolink)
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Выделите слово, нажмите "Добавить ссылку", введите `https://tiptap.dev` — слово должно стать ссылкой
2. Кликните курсором внутри ссылки — должна появиться кнопка "Убрать ссылку"
3. Нажмите "Убрать ссылку" — форматирование ссылки должно исчезнуть
4. Введите в новую строку `https://example.com` и нажмите пробел — текст должен автоматически превратиться в ссылку
