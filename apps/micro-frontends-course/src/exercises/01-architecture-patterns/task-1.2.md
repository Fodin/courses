# Задание 1.2: Конструктор ADR

## Цель

Реализовать пошаговую форму для создания Architecture Decision Record (ADR) — формального документа, фиксирующего архитектурное решение для микрофронтенд-системы.

## Требования

1. Реализуйте пошаговый мастер из 6 шагов с навигацией Назад/Далее:
   - **Шаг 1:** Тип композиции (client-side, server-side, edge-side, build-time) — выбор одного варианта
   - **Шаг 2:** Стратегия split (vertical, horizontal, hybrid) — выбор одного варианта
   - **Шаг 3:** Shared-библиотеки (React, Router, Design System, State Manager, HTTP Client) — множественный выбор
   - **Шаг 4:** Коммуникация (Custom Events, Shared State, URL, Props/Callbacks) — множественный выбор
   - **Шаг 5:** Деплой (independent, coordinated, monorepo) — выбор одного варианта
   - **Шаг 6:** Результат — сгенерированный ADR
2. На каждом шаге отображайте краткое описание каждого варианта (плюсы и минусы)
3. Панель навигации по шагам сверху показывает пройденные шаги с галочкой
4. На шаге результата детектируйте и показывайте конфликты между выборами:
   - Server-side composition + Shared State → проблема гидрации
   - Build-time composition + независимые деплои → противоречие
   - Shared State Manager + Vertical split → конкуренция за стор
   - Shared State + независимые деплои → несовместимость версий
   - Нет shared React + client-side → дублирование бандла
   - Horizontal split + независимые деплои → блокировка layout-командой
5. Генерируйте ADR-документ в формате Markdown с разделами: Title, Status, Context, Decision, Consequences
6. Кнопка "Скопировать ADR" копирует текст в буфер обмена и подтверждает копирование

## Чеклист

- [ ] Навигация по шагам работает в обе стороны
- [ ] Пройденные шаги отмечены галочкой в панели навигации
- [ ] Каждый вариант при клике выделяется визуально (рамка + фон)
- [ ] Шаги 3 и 4 поддерживают множественный выбор
- [ ] На шаге результата конфликты отображаются в предупреждающем блоке
- [ ] ADR-документ содержит все разделы и отражает сделанные выборы
- [ ] Кнопка "Скопировать ADR" работает и показывает подтверждение

## Как проверить себя

- Выберите "server-side" и "Shared State" — на шаге результата должно появиться предупреждение о гидрации
- Выберите "build-time" и "independent" деплой — должно появиться предупреждение о противоречии
- Пройдите все шаги с консистентными выборами — предупреждений быть не должно, ADR должен отражать выборы
- Нажмите "Скопировать ADR" — кнопка должна подтвердить копирование
