# Задание 8.3: FilterPanel — useCallback + React.memo для множества контролов

## Цель

Научиться применять `useCallback` совместно с `React.memo` для оптимизации панелей с множеством независимых контролов, каждый из которых получает свой обработчик `onChange`.

## Контекст

Перед тобой `FilterPanel` с пятью независимыми фильтрами: категория, ценовой диапазон, рейтинг, наличие скидки, сортировка. Каждый фильтр — отдельный компонент (`CategoryFilter`, `PriceFilter`, `RatingFilter`, `DiscountFilter`, `SortFilter`), каждый получает свой `onChange`.

Сейчас при изменении любого одного фильтра ре-рендерятся **все пять** — потому что в родителе создаются новые функции `onChange` при каждом рендере.

## Требования

1. Добавь render counters в каждый из пяти компонентов фильтров
2. Убедись что проблема реальна: смени любой фильтр и посмотри на счётчики
3. Оберни каждый компонент фильтра в `React.memo`
4. Стабилизируй каждый `onChange`-обработчик через `useCallback` в родителе `FilterPanel`
5. Убедись что при изменении одного фильтра ре-рендерится только он один
6. Отображай текущие значения всех фильтров внизу панели (для проверки что фильтрация работает)

## Подсказки

- `useCallback` для каждого обработчика: `const handleCategoryChange = useCallback((value: string) => { setFilters(prev => ({ ...prev, category: value })) }, [])`
- Setter из `useState` стабилен — его не нужно добавлять в зависимости `useCallback`
- Используй функциональную форму setState: `setFilters(prev => ({ ...prev, field: value }))` — это важно когда зависимости пустые
- `React.memo` нужен на ВСЕХ пяти фильтрах — иначе стабилизация `onChange` бессмысленна
- Порядок: сначала добавь memo, потом useCallback — и наблюдай как счётчики перестают расти

## Чеклист

```
[ ] Render counters добавлены во все 5 компонентов фильтров и видны в UI
[ ] Все 5 компонентов обёрнуты в React.memo
[ ] Все 5 onChange-обработчиков стабилизированы через useCallback
[ ] useCallback использует функциональный setState (prev => ...) — не прямое чтение state
[ ] При изменении Category ре-рендерится только CategoryFilter
[ ] При изменении Price ре-рендерится только PriceFilter
[ ] То же для Rating, Discount, Sort
[ ] Значения всех фильтров отображаются и обновляются корректно
```

## Как проверить себя

Открой компонент. Измени категорию — счётчик растёт только у `CategoryFilter`. Измени рейтинг — только у `RatingFilter`. Все остальные счётчики остаются на месте. При этом значения фильтров под панелью корректно обновляются.
