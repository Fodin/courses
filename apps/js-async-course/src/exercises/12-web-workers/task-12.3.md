# Задание 12.3: Transferable Objects

## Цель

Показать разницу между клонированием (копированием) и передачей (transfer) ArrayBuffer через `postMessage`. При transfer отправитель теряет доступ к буферу (byteLength становится 0), но операция происходит мгновенно. При clone — буфер копируется целиком, что занимает время пропорционально размеру.

## Требования

1. **Два режима** (вкладки): "Копировать (Clone)" и "Передать (Transfer)"

2. **Слайдер размера:** 1–50 MB, выбор размера ArrayBuffer

3. **Clone режим:**
   - `postMessage(buffer)` — без списка Transferable
   - После отправки: `buffer.byteLength` остаётся прежним (буфер скопирован)
   - Лог показывает время операции (включает копирование)

4. **Transfer режим:**
   - `postMessage(buffer, [buffer])` — с Transferable-списком
   - После отправки: `buffer.byteLength === 0` (буфер передан Worker'у)
   - Лог показывает что операция практически мгновенная
   - Явно демонстрировать: `buffer.byteLength` изменился на 0

5. **Визуализация памяти:**
   - Два блока "Главный поток" и "Worker" с цветными полосками
   - В Clone: обе стороны показывают буфер (у каждого своя копия)
   - В Transfer: у главного потока — пустой блок, у Worker — полный

6. **Метрики:** время операции в мс, итоговый byteLength у отправителя

7. **Прогресс-бар** во время выполнения

## Как проверить себя

1. Выберите размер 20 MB и режим "Копировать"
2. Запустите — лог покажет время (заметное для большого буфера)
3. `buffer.byteLength` после = прежний размер (буфер не тронут)
4. Переключитесь на "Передать", тот же размер
5. Запустите — лог покажет время ≈ 0 мс (мгновенно!)
6. `buffer.byteLength` после = 0 — буфер "detached"
7. Блок "Главный поток" должен показывать "пусто (передан)"
