# Задание 7.3: Калькулятор SLO / Error Budget

## Цель

Создать интерактивный калькулятор, который показывает допустимый downtime и error budget для разных уровней SLO и периодов.

## Требования

1. **Выбор SLO:**
   - 99% (две девятки)
   - 99.9% (три девятки)
   - 99.99% (четыре девятки)
   - 99.999% (пять девяток)
2. **Выбор периода:**
   - День (24 часа)
   - Месяц (30 дней)
   - Квартал (90 дней)
   - Год (365 дней)
3. **Расчёт и отображение:**
   - Допустимый downtime (в минутах/часах/днях — в зависимости от масштаба)
   - Error budget в запросах (при заданном RPS)
   - Ввод RPS (requests per second) для расчёта error budget
4. **Burn rate визуализация:**
   - Ввод текущего уровня ошибок (например, 0.05%)
   - Расчёт burn rate = (текущий error rate) / (допустимый error rate)
   - Визуальный индикатор: зелёный (burn rate < 1), жёлтый (1-5), красный (> 5)
   - Сколько времени осталось до исчерпания бюджета при текущем burn rate
5. **Сравнительная таблица** всех SLO с downtime для выбранного периода

## Чеклист

- [ ] Выбор SLO: 99%, 99.9%, 99.99%, 99.999%
- [ ] Выбор периода: день, месяц, квартал, год
- [ ] Расчёт допустимого downtime с правильными единицами
- [ ] Ввод RPS и расчёт error budget в запросах
- [ ] Burn rate: ввод текущего error rate
- [ ] Визуализация burn rate (цветовая шкала)
- [ ] Расчёт оставшегося времени до исчерпания бюджета
- [ ] Сравнительная таблица SLO

## Как проверить себя

1. SLO 99.9%, период — месяц: допустимый downtime ≈ 43.2 минуты
2. SLO 99.99%, период — год: допустимый downtime ≈ 52.6 минуты
3. SLO 99.9%, RPS = 1000: error budget = 1000 * 0.001 * (секунд в периоде) запросов
4. Burn rate 1.0 при SLO 99.9%: бюджет израсходуется ровно за выбранный период
5. Burn rate 10.0: бюджет закончится за 1/10 периода
