# Задание 12.1: Декодер JWT

## Цель

Реализовать интерактивный декодер JWT, который наглядно показывает устройство Bearer-токена: три части, claims в payload, срок жизни и тот факт, что payload **не зашифрован**, а лишь закодирован Base64URL.

## Требования

1. Текстовое поле для вставки JWT (по умолчанию — валидный пример токена)
2. Разбить токен по точкам на три части и подсветить их разными цветами: header, payload, signature
3. Декодировать header и payload из Base64URL и показать как форматированный JSON
4. Распарсить ключевые claims и показать таблицей: `sub`, `iss`, `exp`, `iat`, `scope`/`role` с человекочитаемым пояснением каждого
5. Вычислить статус срока действия по `exp`: «действителен» (зелёный) или «истёк» (красный), показать оставшееся время
6. Блок-предупреждение: payload читается кем угодно — не класть в него секреты; подпись лишь защищает от подделки
7. Показать, как токен уходит в запросе: строка `Authorization: Bearer <token>`
8. При вставке невалидного токена (не 3 части / битый Base64) — аккуратное сообщение об ошибке, без падения

## Чеклист

- [ ] Поле ввода с примером токена по умолчанию
- [ ] Токен разбит на 3 части с цветовой подсветкой
- [ ] header и payload декодированы в читаемый JSON
- [ ] Таблица claims с пояснениями (sub, iss, exp, iat, scope/role)
- [ ] Статус exp: действителен/истёк + оставшееся время
- [ ] Предупреждение про «payload не зашифрован»
- [ ] Показан заголовок `Authorization: Bearer ...`
- [ ] Невалидный токен обрабатывается без краша

## Как проверить себя

1. Вставь пример токена — увидишь header `{"alg":"HS256"}` и payload с claims.
2. Поменяй один символ в payload — JSON изменится, но «подпись» останется прежней (демонстрация: подпись на сервере не сойдётся → токен отвергнут).
3. Возьми токен с `exp` в прошлом — статус станет «истёк».
4. Очисти поле или введи мусор — увидишь сообщение об ошибке, а не белый экран.

## Подсказки

- Base64URL отличается от обычного Base64: `-` вместо `+`, `_` вместо `/`, без `=` в конце. Перед `atob` замените символы и добавьте padding.
- `exp` и `iat` — это Unix timestamp в **секундах**; для сравнения с `Date.now()` (миллисекунды) умножьте на 1000.
- Разбор: `const [h, p, s] = token.split('.')`. Если частей не три — это не JWT.
- Декод: `JSON.parse(atob(base64urlToBase64(part)))` в `try/catch`.
