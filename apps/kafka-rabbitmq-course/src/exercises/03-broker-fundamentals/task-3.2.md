# Task 3.2 — Протокол AMQP: инспектор фреймов

## Цель

Создать интерактивный инспектор AMQP-фреймов, который позволяет изучить низкоуровневую структуру протокола AMQP 0-9-1. Пользователь выбирает команду (basic.publish, basic.consume, basic.ack, connection.start) и видит её разбивку на фреймы с полным описанием каждого поля.

## Требования

1. Реализовать навигацию по 4 AMQP-командам: `basic.publish`, `basic.consume`, `basic.ack`, `connection.start`. Активная кнопка выделяется цветом.
2. Под навигацией — строка с описанием выбранной команды (иконка + название + описание).
3. При выборе команды отображать список её фреймов в виде карточек (тип фрейма, channel-id, название, количество полей).
4. Тип фрейма отображать в виде цветного бейджа: METHOD (синий), HEADER (фиолетовый), BODY (зелёный).
5. Клик на карточку фрейма — раскрывает таблицу со всеми полями: название поля, размер, значение, описание.
6. Отображать байтовую схему универсальной структуры AMQP фрейма: type(1б) | channel(2б) | size(4б) | payload(Nб) | frame-end(1б).
7. Внизу показывать блок заметок для выбранной команды (список текстовых пунктов с выделением).
8. При переключении команды — сбрасывать выбранный фрейм.

## Чеклист

- [ ] 4 кнопки команд, активная визуально выделена
- [ ] Описание команды обновляется при переключении
- [ ] Карточки фреймов для каждой команды отображаются
- [ ] Бейджи типов фреймов (METHOD / HEADER / BODY) правильных цветов
- [ ] Клик на фрейм раскрывает таблицу полей с 4 столбцами
- [ ] Байтовая схема фрейма отображается в терминальном стиле
- [ ] Блок заметок отображается для каждой команды
- [ ] При переключении команды таблица полей скрывается
- [ ] Повторный клик на фрейм скрывает таблицу

## Как проверить себя

1. Переключитесь между командами — описание и фреймы должны меняться.
2. Для `basic.publish` должны быть 3 фрейма: Method, Header, Body.
3. Для `basic.ack` должен быть 1 фрейм с полем `delivery-tag`.
4. Для `connection.start` channel-id в фрейме должен быть 0 (зарезервирован).
5. Кликните на фрейм — таблица полей должна появиться. Кликните снова — должна исчезнуть.
6. Байтовая схема должна быть видна постоянно (не зависит от выбора фрейма).
