# Задание 6.1: Maybe / Option

## Цель

Реализовать тип `Maybe<T>` как tagged union и набор функций для работы с ним. Построить интерактивную демонстрацию, которая сравнивает традиционные `if`-проверки с Maybe-цепочками.

## Требования

1. Реализуйте тип и конструкторы:
   - `type Maybe<T> = { tag: 'Some'; value: T } | { tag: 'None' }`
   - `Some<T>(value: T): Maybe<T>`
   - `None: Maybe<never>`

2. Реализуйте следующие функции:
   - `fromNullable<T>(v: T | null | undefined): Maybe<T>` — превращает `null`/`undefined` в `None`
   - `map<T, U>(m: Maybe<T>, fn: (v: T) => U): Maybe<U>` — применяет функцию если `Some`
   - `flatMap<T, U>(m: Maybe<T>, fn: (v: T) => Maybe<U>): Maybe<U>` — для вложенных Maybe
   - `getOrElse<T>(m: Maybe<T>, fallback: T): T` — значение или fallback

3. Создайте три пресета пользователя (тип `User` с вложенными опциональными полями address и subscription).

4. Реализуйте компонент с двумя колонками:
   - Левая: "Традиционный if/null" — вложенные `if`-проверки для city, zip, plan
   - Правая: "Maybe chain" — те же данные через `fromNullable` → `flatMap` → `getOrElse`

5. Добавьте блок "Шаги Maybe-цепочки", который показывает промежуточные состояния (`Some(...)` или `None`) для каждой операции.

6. При отсутствии данных в левой колонке — показывайте предупреждение с потенциальными TypeError.

## Чеклист

- [ ] `Some(value)` создаёт `{ tag: 'Some', value }`
- [ ] `None` возвращает `{ tag: 'None' }`
- [ ] `fromNullable(null)` и `fromNullable(undefined)` возвращают `None`
- [ ] `fromNullable('hello')` возвращает `Some('hello')`
- [ ] `flatMap` на `None` всегда возвращает `None` без вызова функции
- [ ] `getOrElse(None, 'N/A')` возвращает `'N/A'`
- [ ] Переключение пресетов обновляет оба столбца
- [ ] Блок шагов показывает актуальные промежуточные значения

## Как проверить

1. Выберите "Полные данные" — оба столбца должны показать одинаковые значения (Москва, 101000, Pro)
2. Выберите "Без индекса и плана" — zip должен быть N/A, plan — N/A, предупреждений нет
3. Выберите "Без адреса" — city и zip должны быть N/A, предупреждение о потенциальном TypeError в левой колонке
4. В блоке шагов проверьте, что шаг `flatMap` возвращает `None` когда `address = undefined`
