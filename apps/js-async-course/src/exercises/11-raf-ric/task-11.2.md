# Задание 11.2: rAF и Event Loop — анатомия кадра

## Цель

Построить визуализацию анатомии браузерного кадра: показать порядок фаз (JS → rAF → Style → Layout → Paint → Composite) и как в него вписываются rAF-колбэки. Дать интуитивное понимание где именно в Event Loop работает `requestAnimationFrame`.

## Требования

1. **Легенда фаз** — отображает все фазы кадра с цветовой маркировкой:
   - JS (желтый), rAF (фиолетовый), Style (синий), Layout (голубой), Paint (зелёный), Composite (розовый)
   - Текущая активная фаза выделяется рамкой и увеличенным масштабом

2. **Описание текущей фазы** — блок под легендой, описывающий что происходит на каждой фазе

3. **Симуляция анимации** — кнопка "Старт" запускает цикл кадров:
   - Каждый кадр проходит все фазы по очереди с визуальной задержкой
   - Пауза в конце кадра ("Idle") перед следующим

4. **История кадров** — столбчатая диаграмма последних 8 кадров:
   - Высота столбца пропорциональна длительности
   - Кадры >24ms выделяются красным (потенциальный jank)
   - Отображается длительность в ms и номер кадра

5. **Настройки**:
   - Выбор количества rAF в кадре: 1, 3, 5
   - Переключатель "Тяжёлый rAF" — добавляет ~8ms нагрузки, делая кадры длиннее

6. **Пояснение** — блок о том, что rAF выполняется до Style/Layout/Paint

## Как проверить себя

1. Нажмите "Старт" — легенда должна анимировать фазы по кругу
2. Убедитесь в порядке: JS → rAF → Style → Layout → Paint → Composite → Idle
3. После нескольких кадров появится гистограмма
4. Включите "Тяжёлый rAF" — гистограмма должна показать более длинные кадры (красный цвет)
5. Измените количество rAF на 5 — кадры станут чуть длиннее
6. Нажмите "Стоп" — анимация должна остановиться, фаза вернётся в "idle"
