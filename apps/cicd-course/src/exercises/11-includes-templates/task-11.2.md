# Задание 11.2: extends и !reference — наследование и переиспользование джобов

## Цель

Создать интерактивный демонстратор слияния конфигов. Пользователь видит базовый шаблон и дочерний джоб, настраивает поля и наблюдает результат deep merge в реальном времени.

## Требования

1. Отобразить два блока: **Шаблон** (`.base-job`) и **Дочерний джоб** слева, **Результат** справа
2. В блоке шаблона предусмотреть редактируемые поля:
   - `image` (строка)
   - `variables` (пары ключ-значение, минимум 2)
   - `before_script` (список команд)
   - `script` (список команд)
3. В блоке дочернего джоба — такие же поля (часть может быть пустой)
4. Результирующий блок показывает итог deep merge: для `variables` — слияние поключично, для `script`/`before_script` — замена дочерним
5. Визуально выделить в результате: унаследованные поля (один цвет), переопределённые (другой цвет), добавленные (третий цвет)
6. Добавить вкладку "!reference": показать пример, где `before_script` берётся из двух разных шаблонов

## Чеклист

- [ ] Два колонки: шаблон+дочерний слева, результат справа
- [ ] Редактируемые поля image, variables (минимум 2 пары), before_script, script
- [ ] Результат обновляется в реальном времени при изменении полей
- [ ] Цветовое кодирование: унаследовано / переопределено / добавлено
- [ ] Легенда цветов
- [ ] Вкладка или секция с примером !reference

## Как проверить себя

1. Оставь `script` в дочернем пустым — результат должен показать `script` из шаблона
2. Заполни `script` в дочернем — результат должен показать ТОЛЬКО дочерний script (замена!)
3. Добавь новую переменную в дочерний (которой нет в шаблоне) — результат должен содержать переменные из обоих
4. Измени значение существующей переменной в дочернем — результат должен показать дочернее значение
5. Переключись на вкладку `!reference` — пример должен показывать корректный синтаксис

## Подсказки

- Deep merge для `variables` (словарь): `{ ...parent.variables, ...child.variables }`
- Для списков (`script`, `before_script`): если дочерний непустой — берём дочерний, иначе — родительский
- Цветовое кодирование: `#E3F2FD` (синий, унаследовано), `#FFF3E0` (оранжевый, переопределено), `#E8F5E9` (зелёный, добавлено)
- Для сравнения переменных: ключ из дочернего, которого нет у родителя = "добавлено"; ключ есть у обоих, значения разные = "переопределено"
