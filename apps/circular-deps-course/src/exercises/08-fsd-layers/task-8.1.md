# Задание 8.1 — Импорт вверх рождает цикл слоёв (простое)

## Цель

Найти и убрать импорт «вверх» по иерархии слоёв FSD, из-за которого образуется рантайм-цикл.

## Что дано

- `src/features/add-to-cart/model/cart.ts` (только для чтения) — экспортирует `getLastAddedProduct()`, сам корректно (типом) импортирует `User` из `entities/user`.
- `src/entities/user/model/user.ts` (редактируется) — экспортирует интерфейс `User` и функцию `greetUser`, но внутри **вызывает** `getLastAddedProduct` из `features/add-to-cart` — это импорт «вверх» по иерархии слоёв.

Вместе эти два импорта замыкаются в цикл: `entities → features → entities`.

## Требования

1. Не редактируйте `features/add-to-cart/model/cart.ts` — он уже корректен.
2. Уберите импорт `getLastAddedProduct` из `entities/user/model/user.ts`.
3. Функция `greetUser` должна получать нужное значение (например, «последний добавленный товар») через параметр, а не через прямой импорт вышестоящего слоя.
4. После правки в проекте не должно быть рантайм-цикла импортов.
5. Все импорты должны идти строго «вниз» по иерархии `app → pages → widgets → features → entities → shared`.

## Чеклист

- [ ] `entities/user/model/user.ts` больше не импортирует ничего из `features`
- [ ] `greetUser` принимает нужные данные параметром
- [ ] Проверка «нет рантайм-цикла» — зелёная
- [ ] Проверка «импорты уважают слои» — зелёная
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

1. Нажмите «Проверить» в лаборатории — обе проверки должны стать зелёными.
2. Откройте «Показать эталон», если не получается — сравните свой файл с решением.
3. Объясните себе вслух, почему исходный импорт был направлен «вверх», а не «вниз».
