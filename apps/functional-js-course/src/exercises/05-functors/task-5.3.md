# Задание 5.3: Практические функторы

## Цель

Реализовать три функтора с реальным применением: `Lazy` для отложенных вычислений, `Validated` для валидации с накоплением ошибок, `EventMapper` для трансформации событий.

## Требования

### Functor 1: Lazy

1. Реализуйте класс `Lazy<T>`:
   - `static of<T>(thunk: () => T): Lazy<T>` — оборачивает функцию-фабрику
   - `map<U>(fn: (x: T) => U): Lazy<U>` — добавляет трансформацию в цепочку (без выполнения!)
   - `run(): T` — выполняет всю цепочку

2. Демо:
   - Показать код: `Lazy.of(() => ...).map(...).map(...)`
   - До `run()`: отобразить "Вычисление отложено"
   - Кнопка "run()" запускает цепочку и показывает результат

### Functor 2: Validated

1. Реализуйте класс `Validated<T>`:
   - `static of<T>(value: T): Validated<T>` — создаёт валидный контейнер
   - `map<U>(fn: (x: T) => U): Validated<U>` — применяется только если `isValid === true`
   - `validate(predicate, errorMsg): Validated<T>` — проверяет условие; при ошибке устанавливает `isValid = false` и добавляет ошибку

2. Демо:
   - Поле ввода email
   - Цепочка валидации: trim → проверка длины → проверка `@` → проверка `.` → toLowerCase
   - Вывод: успех с нормализованным значением или список ошибок

### Functor 3: EventMapper

1. Реализуйте класс `EventMapper<T>`:
   - `static of<T>(payload: T): EventMapper<T>`
   - `map<U>(fn: (payload: T) => U): EventMapper<U>`

2. Демо:
   - Кнопка генерирует mock-событие `{ type: 'click', x, y, timestamp }`
   - `EventMapper.of(event).map(центрировать).map(нормализовать)`
   - Таблица: исходные x/y → преобразованные x/y → norm (расстояние от центра)

## Чеклист

- [ ] `Lazy.map` не выполняет вычисление — только описывает его
- [ ] `Lazy.run()` выполняет всю цепочку
- [ ] `Validated.map` пропускается при `isValid = false`
- [ ] `Validated.validate` сохраняет ошибку и блокирует дальнейшие map
- [ ] `EventMapper.map` не мутирует оригинальный payload
- [ ] Все три демо интерактивны и наглядны

## Как проверить

**Lazy:**
1. Убедитесь, что при создании `Lazy` в консоли нет вычислений
2. Нажмите "run()" — результат должен появиться

**Validated:**
1. Введите пустую строку → ошибка "Email не может быть пустым"
2. Введите "test" → ошибка "Email должен содержать @"
3. Введите "  User@Example.COM  " → успех с результатом "user@example.com"

**EventMapper:**
1. Нажмите "Сгенерировать событие" несколько раз
2. Убедитесь, что координаты в таблице центрированы (от -400 до +400 по x)
3. `norm` = евклидово расстояние от центра
