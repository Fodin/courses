# Задание 9.2: foldMap для агрегации

## Цель

Применить `foldMap` с различными моноидами для агрегации реальных данных — таблицы заказов. Результат — интерактивный дашборд с метриками, обновляющимися при фильтрации.

## Требования

1. Объявите тип заказа:
   ```ts
   type OrderStatus = 'completed' | 'cancelled' | 'pending'
   interface Order {
     id: number; customer: string; amount: number
     status: OrderStatus; date: string
   }
   ```

2. Подготовьте не менее 10 заказов с разными статусами и суммами.

3. Реализуйте следующие агрегации через `foldMap`:
   - **Общая выручка** — `foldMap(Sum, o => o.amount, completedOrders)`
   - **Есть ли отменённые** — `foldMap(Any, o => o.status === 'cancelled', orders)`
   - **Максимальный заказ** — `foldMap(Max, o => o.amount, orders)`
   - **Минимальный completed** — `foldMap(Min, o => o.amount, completedOrders)`
   - **Количество выполненных** — `foldMap(Sum, o => o.status === 'completed' ? 1 : 0, orders)`

4. Создайте интерфейс:
   - Кнопки-фильтры для каждого статуса (включить/выключить)
   - Дашборд из карточек для каждой метрики: название, моноид, значение, формула
   - Таблица заказов с фильтрацией
   - Кнопка "Добавить заказ" — добавляет случайный заказ, метрики пересчитываются

5. Метрики должны пересчитываться при изменении фильтров (используйте `useMemo`).

## Checklist

- [ ] Тип `Order` и массив данных объявлены корректно
- [ ] Все 5 агрегаций реализованы через `foldMap` (не вручную через `reduce`)
- [ ] Карточки дашборда отображают название моноида и формулу
- [ ] При выключении фильтра "completed" — выручка и мин. completed показывают "—"
- [ ] При выключении фильтра "cancelled" — "есть отменённые" показывает "нет"
- [ ] Кнопка добавления заказа работает, метрики обновляются
- [ ] Пустой отфильтрованный список не вызывает ошибок

## Как проверить себя

При включённых всех фильтрах:
- Выручка > 0 (только completed-заказы)
- "Есть отменённые" = да
- Максимальный заказ — наибольшая сумма среди всех видимых
- Минимальный completed — наименьшая сумма среди видимых completed

Выключите фильтр "cancelled":
- "Есть отменённые" должно стать "нет"
- Остальные метрики могут измениться если таблица изменилась

Добавьте несколько заказов — счётчик в заголовке таблицы должен расти, метрики обновляться.
