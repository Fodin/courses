# Задание 2.1 — Визуализатор lifecycle загрузки remote

## Цель

Создать интерактивную анимацию, которая показывает все этапы загрузки remote-модуля в Module Federation: от первого HTTP-запроса до рендеринга компонента в DOM.

## Требования

1. Отобразить минимум 5 шагов загрузки:
   - Запрос `remoteEntry.js`
   - Парсинг манифеста
   - Загрузка JS-чанков remote
   - Shared resolution (проверка/переиспользование зависимостей)
   - Рендеринг компонента

2. Кнопка "Загрузить remote" запускает пошаговую анимацию:
   - Каждый шаг последовательно переходит: `pending → loading → done`
   - Шаг подсвечивается при активной загрузке
   - По завершении отображается общее "время" (симулированное)

3. Для каждого шага показывать:
   - Название и описание
   - Статус (иконка или текст: ожидание / загрузка... / N мс)

4. Network waterfall — горизонтальные полоски:
   - Каждый файл/запрос — отдельная строка с именем, размером и полоской
   - Полоски появляются по мере прохождения шагов
   - Разные цвета для разных типов файлов (entry, chunk, shared и т.д.)

5. Кнопка "Сбросить" возвращает всё в начальное состояние

## Checklist

- [ ] Минимум 5 шагов с названиями и описаниями
- [ ] Анимация запускается по кнопке
- [ ] Каждый шаг имеет три состояния: pending / loading / done
- [ ] Network waterfall отображает файлы с полосками
- [ ] Кнопка сброса работает корректно
- [ ] При повторном запуске анимация начинается сначала

## Как проверить себя

- Нажмите "Загрузить remote" и убедитесь, что шаги подсвечиваются последовательно
- Шаг "Shared resolution" должен объяснять, почему React не загружается повторно
- В waterfall полоски для `shared (reuse)` должны быть короткими (0 KB)
- После завершения должно отобразиться суммарное время
- Сброс должен вернуть все шаги в состояние "ожидание"

## Подсказка

Используйте `setTimeout` с нарастающей задержкой для имитации последовательности. Состояние каждого шага храните в массиве `StepStatus[]`.
