# Задание 4.2: Визуализатор шардирования

## Цель

Построить интерактивный визуализатор, который показывает, как разные стратегии шардирования распределяют данные по шардам, и выявляет hot spots.

## Требования

1. Сгенерируйте набор данных (20 записей): `user_id`, `region` (US/EU/Asia), `created_at` (дата)
2. Реализуйте три стратегии шардирования с переключением:
   - **Range** — по диапазону `user_id` (1-7 → Shard 1, 8-14 → Shard 2, 15-20 → Shard 3)
   - **Hash** — `hash(user_id) % 3` для равномерного распределения
   - **Geographic** — по региону (US → Shard 1, EU → Shard 2, Asia → Shard 3)
3. Визуализируйте распределение по шардам:
   - Покажите количество записей в каждом шарде (число + прогресс-бар)
   - Подсветите hot spots (шард с >50% данных)
4. Покажите таблицу данных с указанием, на какой шард попала каждая запись
5. Покажите метрики: стандартное отклонение распределения, наличие hot spots

## Чеклист

- [ ] Генерация 20 записей с user_id, region, created_at
- [ ] Переключение между тремя стратегиями (Range, Hash, Geographic)
- [ ] Визуализация распределения по 3 шардам (прогресс-бары)
- [ ] Hot spots подсвечены визуально (красный/оранжевый)
- [ ] Таблица данных с привязкой к шарду
- [ ] Hash-стратегия даёт наиболее равномерное распределение
- [ ] Geographic показывает неравномерность при неравном количестве регионов

## Как проверить себя

1. Range: записи распределены по диапазонам user_id — равномерно ли?
2. Hash: записи распределены по hash(user_id) % 3 — должно быть наиболее равномерно
3. Geographic: если большинство пользователей из US — Shard 1 будет hot spot
4. Переключите стратегию — распределение должно измениться мгновенно
5. Hot spots подсвечены для стратегий с неравномерным распределением
