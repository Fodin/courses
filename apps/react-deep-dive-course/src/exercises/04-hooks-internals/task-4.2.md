# Задание 4.2: useState Under the Hood

## Цель

Реализовать упрощённую версию `useState` поверх глобального массива — чтобы понять, как React хранит состояние хуков между рендерами.

## Задание

Реализуй функцию `myUseState<T>` и компонент, который её использует:

1. `myUseState` хранит состояние в глобальном массиве `stateStorage`
2. Глобальный курсор `cursor` указывает на текущий слот в массиве
3. При первом вызове (слот пустой) — инициализирует значением `initialValue`
4. При повторных вызовах — возвращает текущее значение из слота
5. Возвращает `[value, setter]`, где setter обновляет слот и вызывает re-render
6. Кнопка "Re-render" сбрасывает курсор в 0 и перерисовывает компонент

## Требования

1. Глобальные переменные:
   ```ts
   const stateStorage: unknown[] = []
   let cursor = 0
   ```
2. Функция `myUseState<T>(initialValue: T): [T, (newValue: T) => void]`
3. Компонент с двумя вызовами `myUseState`:
   - Первый: счётчик кликов (начальное значение 0)
   - Второй: имя пользователя (начальное значение 'React')
4. Кнопки: "+1" для счётчика, "Сменить имя" для имени
5. Кнопка "Re-render" — показывает, что `cursor` сбрасывается в 0
6. Вывод отладочной информации: `stateStorage: [count, name]`, `cursor: N`

## Чеклист

- [ ] `stateStorage` — массив, хранящий состояние между рендерами
- [ ] `cursor` сбрасывается в 0 перед каждым рендером
- [ ] Первый `myUseState(0)` всегда читает `stateStorage[0]`
- [ ] Второй `myUseState('React')` всегда читает `stateStorage[1]`
- [ ] Setter обновляет нужный слот и вызывает перерисовку
- [ ] Отладочный вывод показывает текущее содержимое `stateStorage`
- [ ] При нажатии "+1" меняется только первое значение в массиве
- [ ] При нажатии "Сменить имя" меняется только второе значение

## Как проверить себя

1. Нажми "+1" — stateStorage[0] должен вырасти, stateStorage[1] не меняется
2. Нажми "Сменить имя" — stateStorage[1] меняется, stateStorage[0] не меняется
3. Посмотри на cursor в отладке — он всегда 2 после рендера (два хука)
4. Сравни с тем, как работает настоящий linked list в fiber
