# Задание 6.2: Система нотификаций

## Цель

Реализовать систему toast-нотификаций с очередью, auto-dismiss по таймеру, поддержкой типов (info/success/warning/error) и ручным закрытием.

## Требования

1. Определите тип `Notification` с полями: `id: string`, `message: string`, `type: 'info' | 'success' | 'warning' | 'error'`, `duration: number`
2. Создайте `NotificationContext` с интерфейсом `{ notify, dismiss }`:
   - `notify(message, type?, duration?)` — добавляет нотификацию в очередь
   - `dismiss(id)` — удаляет нотификацию по ID
3. Реализуйте хук `useNotifications()` с проверкой на null
4. В `NotificationProvider`:
   - Храните массив активных нотификаций в state
   - Для каждой нотификации с `duration > 0` запускайте таймер auto-dismiss
   - Таймеры храните в `useRef<Map<string, ReturnType<typeof setTimeout>>>`
   - При `dismiss` — очищайте таймер через `clearTimeout`
   - При размонтировании — очищайте все таймеры через `useEffect` cleanup
   - Оберните `notify` и `dismiss` в `useCallback`
5. Реализуйте `NotificationContainer` — позиционируется фиксированно в правом верхнем углу, отображает стек нотификаций, у каждой кнопка закрытия
6. Каждый тип нотификации имеет свой цвет фона, цвет рамки и иконку
7. Нотификация с `duration = 0` не закрывается автоматически

## Подсказки

- Уникальный ID: `` `notif-${Date.now()}-${Math.random().toString(36).slice(2, 7)}` ``
- `useCallback` для `dismiss` с пустым массивом зависимостей, для `notify` — с зависимостью `[dismiss]`
- Паттерн очистки ref в useEffect: `const timers = timersRef.current; return () => timers.forEach(clearTimeout)`
- `NotificationContainer` удобно рендерить прямо внутри `NotificationProvider`, не вынося в корень приложения

## Чеклист

- [ ] Нотификации разных типов отображаются с разными цветами
- [ ] Auto-dismiss работает через заданное время
- [ ] Нотификацию можно закрыть вручную кнопкой
- [ ] При `duration = 0` нотификация остаётся до ручного закрытия
- [ ] Таймеры корректно очищаются при ручном закрытии (нет повторного вызова dismiss)
- [ ] `useNotifications()` используется в демо-компоненте для вызова `notify`
- [ ] Нотификации отображаются стеком, не перекрывая друг друга

## Как проверить себя

Нажмите несколько кнопок подряд — нотификации должны накапливаться стеком. Быстро нажмите кнопку ошибки (6с) и успеха (4с) — успех должен исчезнуть раньше. Нажмите "постоянная" — она не должна исчезать сама. Закройте постоянную вручную и убедитесь, что другие нотификации не затронуты.
