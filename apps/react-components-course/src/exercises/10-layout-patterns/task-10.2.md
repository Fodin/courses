# Задание 10.2: Modal на createPortal

## Цель

Реализовать компонент `Modal` на основе `createPortal`, поддерживающий стекинг нескольких модалок, закрытие по Escape, закрытие по клику на оверлей и блокировку прокрутки страницы.

## Требования

1. `Modal` рендерится через `createPortal` в `document.body`

2. Поддерживает стекинг нескольких модалок:
   - Можно открыть модалку поверх другой модалки
   - Каждая следующая модалка имеет больший `z-index`
   - Закрытие работает для верхней модалки (последней открытой)

3. Закрытие по клику на оверлей:
   - Клик по тёмному фону закрывает модалку
   - Клик по содержимому модалки не закрывает

4. Закрытие по нажатию Escape:
   - Закрывает верхнюю (последнюю) открытую модалку
   - Слушатель добавляется только когда модалка открыта

5. Блокировка прокрутки:
   - При открытой модалке `document.body` имеет `overflow: hidden`
   - При закрытии всех модалок прокрутка восстанавливается
   - При нескольких открытых модалках прокрутка не восстанавливается до закрытия всех

6. `Modal` принимает пропсы:
   - `isOpen: boolean`
   - `onClose: () => void`
   - `title?: string`
   - `children: ReactNode`

## Подсказки

- Используй `useEffect` для подписки на `keydown` и управления `body.style.overflow`
- Не забудь `return` с cleanup в `useEffect`
- Для стекинга: каждой модалке передавай `zIndex` через prop или вычисляй по индексу в стеке
- Простой способ стекинга в демо: три состояния `isOpen1`, `isOpen2`, `isOpen3` + кнопки "Открыть ещё одну" внутри каждой модалки
- Для блокировки скролла при нескольких модалках: глобальный счётчик вне компонента или `useRef` с подсчётом

## Чеклист

- [ ] `Modal` использует `createPortal` в `document.body`
- [ ] Оверлей тёмный, полупрозрачный, по всему экрану
- [ ] Клик на оверлей закрывает, клик на контент — нет
- [ ] Escape закрывает модалку
- [ ] При открытой модалке прокрутка заблокирована
- [ ] При закрытии прокрутка восстановлена
- [ ] Можно открыть модалку поверх модалки (вторая поверх первой)
- [ ] Очищаются event listeners при закрытии/размонтировании

## Как проверить себя

Откройте модалку, попробуйте прокрутить страницу — прокрутки нет. Нажмите Escape — модалка закрылась, прокрутка вернулась. Откройте вложенную модалку — оба условия выполняются. Закройте внутреннюю — прокрутка всё ещё заблокирована. Закройте все — прокрутка свободна.
