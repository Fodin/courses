# Задание 6.4: Маски и форматирование

## Цель

Научиться использовать Controller для создания масок ввода и форматирования значений.

## Требования

Создайте форму оплаты с тремя полями и маскированным вводом:

1. **Телефон** — маска `+7 (XXX) XXX-XX-XX`, при вводе автоматически подставляются скобки, пробелы, дефисы
2. **Номер карты** — форматирование группами по 4 цифры: `0000 0000 0000 0000`
3. **Сумма** — форматирование как валюта с разделителем разрядов: `1 234.56`
4. Используйте `Controller` для перехвата `onChange` и форматирования значений
5. Валидация через `zod`: телефон и карта по регулярному выражению, сумма > 0

## Чеклист

- [ ] Телефон форматируется автоматически при вводе цифр
- [ ] Номер карты разбивается на группы по 4
- [ ] Сумма форматируется с пробелами-разделителями
- [ ] Нельзя ввести буквы в поля телефона и карты
- [ ] Валидация работает с отформатированными значениями
- [ ] Форма не отправляется с невалидными данными

## Как проверить себя

1. Начните вводить цифры в поле телефона — маска подставляется автоматически
2. Введите 16 цифр в поле карты — видите `1234 5678 9012 3456`
3. Введите `1234567` в сумму — видите `1 234 567`
4. Нажмите «Оплатить» с пустыми полями — ошибки валидации
