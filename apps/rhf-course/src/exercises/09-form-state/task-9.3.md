# Задание 9.3: Программное управление — setValue, setError, trigger

## Цель

Научиться программно управлять формой: заполнять поля, устанавливать ошибки и запускать валидацию.

## Требования

Создайте форму с полями: имя, email, телефон, город.

1. **setValue** — кнопка "Заполнить из профиля", которая программно заполняет все поля данными из мок-объекта
2. **setError** — после отправки формы имитировать серверную ошибку (например, "email уже зарегистрирован") и показать её в форме через setError
3. **trigger** — кнопка "Проверить email", которая вручную запускает валидацию только для поля email; кнопка "Проверить всё" для валидации всех полей
4. Все три метода должны корректно обновлять состояние формы

## Чеклист

- [ ] Кнопка "Заполнить из профиля" заполняет все поля через setValue
- [ ] Поля обновляются визуально после setValue
- [ ] Кнопка "Проверить email" вызывает trigger('email')
- [ ] Кнопка "Проверить всё" вызывает trigger() без аргументов
- [ ] При отправке с email "taken@example.com" — серверная ошибка через setError
- [ ] Ошибка setError отображается как обычная ошибка валидации

## Как проверить себя

1. Откройте пустую форму
2. Нажмите "Проверить всё" — появятся ошибки валидации на всех полях
3. Нажмите "Заполнить из профиля" — все поля заполняются
4. Нажмите "Проверить email" — ошибок нет (email валидный)
5. Измените email на "taken@example.com" и отправьте — серверная ошибка
