# Задание 8.3: Генератор как конечный автомат (State Machine)

## Цель

Реализовать компонент, демонстрирующий использование генераторов как конечных автоматов (FSM). Каждый `yield` = состояние, `.next(action)` = переход. Два демо: светофор (простой цикл) и кофемашина (4 состояния с осмысленными действиями).

## Требования

1. **Переключатель вкладок** — "Светофор" и "Кофемашина" без перезагрузки страницы

2. **Вкладка "Светофор"**:
   - Код генератора `trafficLight()` с пояснением
   - Диаграмма состояний: три цветных круга (red → green → yellow) с подсветкой текущего
   - Метка текущего состояния с расшифровкой ("КРАСНЫЙ — Стоп", "ЗЕЛЁНЫЙ — Идти", "ЖЁЛТЫЙ — Внимание")
   - Лог переходов: `red → switch → green`, и т.д.
   - Кнопки: "Переключить" и "Сброс"
   - При нажатии "Переключить" вызывается `gen.next()` на настоящем генераторе через `useRef`

3. **Вкладка "Кофемашина"**:
   - Код генератора `coffeeMachine()` с состояниями `idle → selecting → brewing → ready`
   - Горизонтальная диаграмма состояний: 4 блока с подсветкой текущего
   - Метка текущего состояния с описанием ("Ожидание", "Выбор напитка...", "Варится кофе...", "Готово!")
   - Лог переходов: `idle → select → selecting`, и т.д.
   - Кнопка действия меняет надпись в зависимости от текущего состояния:
     - idle → "Выбрать напиток"
     - selecting → "Начать варку"
     - brewing → "Готово (авто)"
     - ready → "Забрать напиток"
   - Кнопка "Сброс"
   - Пояснительный текст внизу: почему генератор идеален для FSM

4. **Общее требование**: оба генератора — настоящие бесконечные (`while(true)`), хранятся в `useRef`

## Чеклист

- [ ] Компонент называется `Task8_3` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован, `t('task.8.3')` используется в заголовке
- [ ] Переключение вкладок работает без сброса состояния каждой машины
- [ ] Светофор: три цветных круга, текущее состояние светится/подсвечено
- [ ] Светофор: последовательность red → green → yellow → red корректна
- [ ] Кофемашина: 4 блока состояний, правильная последовательность переходов
- [ ] Кофемашина: кнопка action меняет текст в зависимости от текущего состояния
- [ ] Лог переходов отображает `from → action → to` для каждого шага
- [ ] `useRef` хранит генераторы, `useState` — текущее состояние машины
- [ ] Сброс пересоздаёт генератор и очищает лог

## Как проверить себя

1. Светофор: нажмите "Переключить" 3 раза — состояния: red → green → yellow → red
2. Светофор: лог должен показать 3 записи `→ switch →`
3. Нажмите "Сброс" — возврат к red, лог очищен
4. Переключитесь на "Кофемашина" — начальное состояние `idle`, кнопка "Выбрать напиток"
5. Нажмите кнопку действия 4 раза: idle → selecting → brewing → ready → idle
6. Лог должен содержать: `idle → select → selecting`, `selecting → brew → brewing`, и т.д.
7. Убедитесь, что светофор сохранил состояние при переключении вкладок
