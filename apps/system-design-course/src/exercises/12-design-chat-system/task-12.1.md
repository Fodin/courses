## Цель

Проверить понимание ключевых решений при проектировании мессенджера: WebSocket vs polling, message delivery statuses, fan-out стратегии, presence service, offline sync.

## Требования

1. Прочитайте теорию уровня 12 (README)
2. Пройдите квиз из 5 вопросов по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ (есть вопросы с несколькими правильными)
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист

- [ ] Прочитана теория по проектированию Chat System
- [ ] Понятна разница между WebSocket, Long Polling и SSE для real-time коммуникации
- [ ] Понятно, как маршрутизировать сообщение между WebSocket Gateway серверами через Redis
- [ ] Понятен протокол delivery statuses: SENT → DELIVERED → READ
- [ ] Понятна разница между fan-out on write и fan-out on read для групповых чатов
- [ ] Понятен heartbeat-механизм presence service и subscription model для fan-out
- [ ] Пройден квиз с результатом не менее 80%
