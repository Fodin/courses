# Задание 1.1: HTML и JSON вывод

## Цель

Реализовать редактор, который в реальном времени показывает своё содержимое в двух форматах — HTML и JSON — с помощью `onUpdate`.

## Требования

1. Создайте `editor` через `useEditor` с `StarterKit`
2. Заведите два состояния через `useState`: `html` (строка) и `json` (объект)
3. В `onUpdate` обновляйте оба состояния: `editor.getHTML()` и `editor.getJSON()`
4. Инициализируйте оба состояния сразу при создании (можно вызвать `onCreate` аналогично `onUpdate`, либо задать начальные значения `useState` через сериализованный начальный `content`)
5. Под редактором выведите два блока: "HTML" (текст в `<pre>`) и "JSON" (через `JSON.stringify(json, null, 2)` в `<pre>`)
6. Оба блока должны обновляться при каждом изменении текста без перезагрузки страницы

## Чеклист

- [ ] Компонент называется `Task1_1` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.1.1')` используется в заголовке
- [ ] `onUpdate` обновляет оба state (html и json)
- [ ] `onCreate` (или аналогичная логика) заполняет state при первом рендере, а не только после первого изменения
- [ ] HTML и JSON выводятся в читаемом виде (JSON — с отступами)
- [ ] Нет TypeScript-ошибок типа `any` (используйте тип `JSONContent` из `@tiptap/react` для JSON-состояния)

## Как проверить себя

1. Откройте задание — сразу должны быть видны HTML и JSON начального контента
2. Введите текст — оба блока должны немедленно обновиться
3. Выделите текст и сделайте его жирным — в HTML должен появиться тег `<strong>`, в JSON — mark `bold`
4. Удалите весь текст — HTML должен показать пустой параграф, JSON — соответствующую пустую структуру
