# Задание 1.4: Браузер vs Node.js Event Loop

## Цель

Построить сравнительный визуализатор двух разных реализаций Event Loop — браузерной (HTML spec) и серверной (libuv в Node.js) — с интерактивным изучением фаз и демонстрацией разного поведения одного кода.

## Требования

1. **Два режима** — вкладки "Браузер" и "Node.js"

2. **Браузер** — показывает последовательность: Call Stack → Microtasks → rAF → Style/Layout/Paint → Macrotask → repeat

3. **Node.js** — показывает 6 фаз libuv (Timers → Pending I/O → Idle → Poll → Check → Close) плюс process.nextTick и Promise microtasks

4. **Интерактивные фазы** — клик по фазе открывает её описание (что происходит, какие API задействованы)

5. **Уникальные API** — блок с двумя колонками: "Только браузер" (rAF, rIC, MutationObserver) и "Только Node.js" (process.nextTick, setImmediate, libuv)

6. **Сравнительный код** — один фрагмент кода с `setTimeout`, `setImmediate`, `Promise`, `process.nextTick`, `console.log`; рядом показан вывод в каждой среде

- [ ] Вкладки "Браузер" и "Node.js" переключаются корректно
- [ ] В режиме "Браузер" показаны фазы включая rAF и Render
- [ ] В режиме "Node.js" показаны все 6 фаз libuv + nextTick + microtasks
- [ ] Клик по фазе открывает её описание
- [ ] Блок уникальных API заполнен корректно для обоих окружений
- [ ] Показан вывод кода для браузера и Node.js рядом

## Как проверить себя

1. Откройте вкладку "Браузер" — должны быть видны 5 фаз
2. Нажмите на "requestAnimationFrame" — должно появиться описание
3. Переключитесь на "Node.js" — должны быть видны все 6 фаз libuv
4. Нажмите на "process.nextTick" — описание должно объяснять его особый приоритет
5. Найдите сравнительный код — вывод должен отличаться в браузере и Node.js
6. Убедитесь, что в Node.js nextTick выводится ДО Promise
