# Задание 3.1 — Разорвать цикл через import type (простое)

## Цель

Научиться отличать ребро графа, которое используется только как тип, от
настоящей рантайм-зависимости, и убрать первое из рантайм-графа одной правкой.

## Что дано

- `a.ts` (только чтение) — реально импортирует значение `bValue` из `b.ts`.
- `b.ts` (редактируется) — импортирует интерфейс `A` из `a.ts` обычным
  импортом, хотя использует его только как тип возвращаемого значения.

Из-за этого в скомпилированном JS образуется рантайм-цикл `a.ts ⇄ b.ts`.

## Требования

1. Откройте `b.ts` и определите, как используется `A`.
2. Замените `import { A } from './a'` на `import type { A } from './a'`.
3. Ничего больше не меняйте — `bValue` и структура файла должны остаться
   прежними.
4. Нажмите «Проверить».

## Чеклист

- [ ] `b.ts` импортирует `A` через `import type`
- [ ] Рантайм-цикл между `a.ts` и `b.ts` отсутствует
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

Мысленно скомпилируйте оба файла в JS: если хотя бы в одном из них после
удаления всех `import type` не осталось `import` друг у друга — цикла в
рантайме нет.
