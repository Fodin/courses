# Задание 3.1 — Справочник статус-кодов

## Цель

Изучить все ключевые HTTP-статус-коды, их группировку и правильные сценарии применения. Научиться быстро находить нужный код для конкретной ситуации.

## Требования

1. Компонент отображает все статус-коды из пяти групп: 1xx, 2xx, 3xx, 4xx, 5xx.
2. Кнопки-фильтры позволяют показывать только коды из выбранной группы.
3. Строка поиска фильтрует коды по числу, названию или описанию.
4. Каждый код имеет цветовое оформление в соответствии со своей группой.
5. Клик по карточке раскрывает подробности: когда использовать и конкретный пример.

## Чеклист

- [ ] Все группы: 1xx, 2xx, 3xx, 4xx, 5xx
- [ ] Фильтрация по группе (кнопки)
- [ ] Текстовый поиск по коду, имени, описанию
- [ ] Цветовая кодировка по группам
- [ ] Раскрывающиеся карточки с деталями
- [ ] Секции "Когда использовать" и "Пример"

## Как проверить себя

Закройте теорию. Найдите в справочнике коды: 201, 204, 401, 403, 409, 422, 429. Для каждого — прочитайте описание и воспроизведите ситуацию, в которой он используется. Если можете объяснить разницу между 401/403 и 400/422 без подсказок — задание выполнено.
