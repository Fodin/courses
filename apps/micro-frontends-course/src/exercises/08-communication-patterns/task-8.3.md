# Задание 8.3: Выбор паттерна коммуникации

## Цель

Реализовать интерактивный тренажёр выбора паттерна коммуникации: 6 реальных сценариев из практики микрофронтендов, где нужно выбрать оптимальный подход и получить подробную обратную связь.

## Требования

1. 6 сценариев с заголовком и подробным описанием
2. 5 вариантов паттернов: Custom Events, Shared State, URL/localStorage, Props через Shell, Orchestrator
3. Пользователь выбирает паттерн для текущего сценария
4. После нажатия "Проверить" — отображается вердикт (верно/неверно)
5. Показать объяснение правильного ответа (зелёный блок)
6. Показать объяснение почему популярный неправильный выбор — ошибка (оранжевый блок)
7. Шпаргалка по всем 5 паттернам в виде карточек
8. Кнопка "Следующий сценарий →" с переходом по кольцу
9. При смене сценария — сбрасывается выбор и результат
10. Навигационные кнопки для прямого перехода к любому сценарию

## Чеклист

- [ ] Навигация: 6 кнопок выбора сценария, активная выделена синим
- [ ] Карточка сценария с заголовком "Сценарий N: {название}" и описанием
- [ ] 5 кнопок паттернов, выбранная подсвечивается цветом паттерна
- [ ] Кнопка "Проверить" появляется после выбора паттерна
- [ ] Кнопка "Проверить" скрывается после отображения результата
- [ ] Зелёный баннер "Верно!" или красный "Неверно. Правильный ответ: ..."
- [ ] Зелёный блок: "Почему {правильный паттерн}?" + объяснение
- [ ] Оранжевый блок: "Почему не стоит {неправильный паттерн}?" + объяснение
- [ ] Шпаргалка: 2-колоночная сетка, 5 карточек с цветной левой полосой
- [ ] Кнопка "Следующий сценарий →" переходит к следующему (циклически)
- [ ] При смене сценария через навигацию — выбор и результат сбрасываются
- [ ] Все стили inline

## Как проверить

1. Выберите сценарий 1 "Каталог добавляет товар в корзину"
2. Выберите "Shared State" — нажмите Проверить — должно быть "Неверно", правильный ответ Custom Events
3. Прочитайте объяснение почему Custom Events правильно и почему Shared State — ошибка
4. Нажмите "Следующий сценарий →" — переход к сценарию 2
5. Выберите "Shared State" для сценария 2 — должно быть "Верно!"
6. Проверьте каждый сценарий: убедитесь что правильный ответ соответствует логике выбора паттерна
7. Нажмите на кнопку сценария 4 — выбор предыдущего сценария должен сброситься
