# Задание 5.3: Cache vs Artifacts — выбираем правильно

## Цель

Создать интерактивную decision matrix, которая для каждого сценария предлагает студенту выбрать: cache или artifacts — и объясняет правильный ответ.

## Требования

1. Отобразить 8 сценариев использования по одному (или все сразу в виде карточек)
2. Для каждого сценария показать описание задачи и два варианта: "Cache" и "Artifacts"
3. При выборе варианта — показать, верно ли это, и объяснить почему
4. После ответа на все сценарии — показать итоговый счёт и сводную таблицу
5. Кнопка "Сначала" для повтора квиза

Сценарии для использования:
- Передать собранный `dist/` из build в deploy
- Ускорить `npm install` между пайплайнами
- Сохранить результаты JUnit-тестов для отображения в MR
- Переиспользовать Maven-зависимости из `.m2/`
- Передать Docker image digest из build в sign-job
- Сохранить логи падения для постмортема
- Хранить pip-пакеты между запусками
- Передать coverage-report из test в report-job

## Чеклист

- [ ] 8 сценариев с описанием на русском языке
- [ ] Для каждого сценария — две кнопки: "Cache" и "Artifacts"
- [ ] После выбора — цветовая индикация: зелёный (верно) / красный (неверно)
- [ ] Объяснение правильного ответа (2-3 предложения)
- [ ] Прогресс: "Сценарий 3 из 8" или прогресс-бар
- [ ] Итоговый экран: счёт, краткая сводка по каждому ответу
- [ ] Кнопка "Сначала" сбрасывает все ответы

## Как проверить себя

1. Ответь "Artifacts" на сценарий "Передать dist/ из build в deploy" — должно быть верно
2. Ответь "Cache" на сценарий "Ускорить npm install" — должно быть верно
3. Намеренно ответь неверно — убедись, что объяснение полезно и понятно
4. Пройди все 8 сценариев — должен появиться итоговый экран
5. Нажми "Сначала" — всё должно сброситься

## Подсказки

- Данные сценариев храни в массиве: `{ id, description, correct: 'cache'|'artifacts', explanation }`
- `useState` для: `currentIndex` (номер текущего сценария), `answers` (массив ответов), `showResults` (показать итог)
- При правильном ответе `backgroundColor: '#e8f5e9'`, при неверном — `'#ffebee'`
- Для итогового экрана посчитай `answers.filter(a => a.isCorrect).length`
