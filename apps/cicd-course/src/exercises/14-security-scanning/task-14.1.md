# Задание 14.1: SAST — статический анализ кода

## Цель

Реализовать интерактивный конструктор SAST-конфигурации для GitLab CI. Пользователь выбирает язык, анализатор и параметры — компонент генерирует готовый `.gitlab-ci.yml` фрагмент.

## Требования

1. Отобразить выбор **языка** (JavaScript, Python, Go) — при смене меняется подходящий анализатор
2. Показать **режим подключения**: через GitLab-шаблон (`include: template:`) или вручную (`image: semgrep/semgrep`)
3. При выборе ручного режима — показать поле ввода для `SEMGREP_RULES` (по умолчанию `p/owasp-top-ten`)
4. Отобразить поле для `SAST_EXCLUDED_PATHS` с возможностью добавлять/удалять пути через чекбоксы (`spec`, `test`, `vendor`, `node_modules`)
5. Показать переключатель `allow_failure: true / false` с предупреждением при `false`
6. Отображать сгенерированный YAML-конфиг, обновляющийся в реальном времени
7. Показать таблицу анализаторов по языкам: язык → инструмент → что находит

## Чеклист

- [ ] Три кнопки выбора языка: JavaScript, Python, Go
- [ ] Две кнопки режима: Шаблон GitLab / Ручная настройка
- [ ] В ручном режиме — поле ввода для SEMGREP_RULES
- [ ] Чекбоксы для SAST_EXCLUDED_PATHS (минимум 4 варианта)
- [ ] Переключатель allow_failure с предупреждающим текстом при false
- [ ] YAML-блок обновляется при каждом изменении
- [ ] Таблица с 3 строками: язык, анализатор, что находит

## Как проверить себя

1. Выбери Python в шаблонном режиме — в YAML должен появиться `include: template: Security/SAST.gitlab-ci.yml` и `SAST_ANALYZERS: bandit`
2. Переключись на ручной режим — YAML должен измениться на `image: semgrep/semgrep` со скриптом
3. Добавь `vendor` в исключения — YAML должен содержать `SAST_EXCLUDED_PATHS: 'test,vendor'` (или что выбрано)
4. Переключи `allow_failure: false` — должно появиться предупреждение о блокировке MR

## Подсказки

- Храни состояние в `useState`: `language`, `mode` ('template' | 'manual'), `excludedPaths` (массив), `semgrepRules`, `allowFailure`
- Функция генерации YAML принимает все параметры и возвращает строку
- При шаблонном режиме YAML короткий (include + variables), при ручном — полный джоб
- Для таблицы анализаторов используй массив объектов и `.map()`
