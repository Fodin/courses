# Задание 7.1: Retry с exponential backoff

## Цель

Реализовать функцию `retry` с экспоненциальным откатом и опциональным jitter. Подключить её к симулятору нестабильного API и визуализировать историю попыток.

## Требования

1. **Функция `retry(fn, options)`** принимает:
   - `fn` — async-функция, которую нужно повторять
   - `options.maxRetries` — максимальное число повторных попыток (не включая первую)
   - `options.baseDelay` — начальная задержка в ms
   - `options.factor` — множитель для backoff (по умолчанию 2)
   - `options.jitter` — boolean, добавляет случайность ±50% к задержке

2. **Функция `simulateApi(errorRate)`** — возвращает промис, который с вероятностью `errorRate%` отклоняется с ошибкой, иначе резолвится

3. **Слайдеры для настройки**: вероятность ошибки, maxRetries, baseDelay, factor

4. **Переключатель jitter** ON/OFF

5. **Timeline попыток** — отображает каждую попытку со статусом:
   - `pending` — выполняется
   - `error` — провал
   - `success` — успех
   - `waiting` — ожидание перед следующей попыткой (показывает задержку в ms)

6. **Панель "Задержки по плану"** — рассчитывает и показывает ожидаемые задержки для каждой попытки до запуска

## Чеклист

- [ ] Компонент называется `Task7_1` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован и `t('task.7.1')` используется в заголовке
- [ ] Функция `retry` реализована с корректным exponential backoff
- [ ] Jitter изменяет задержку случайным образом в диапазоне ±50%
- [ ] После исчерпания попыток выбрасывается ошибка
- [ ] Timeline отображает все события в реальном времени по мере их наступления
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Установите вероятность ошибки 100%, maxRetries = 3, baseDelay = 200ms, factor = 2
2. Запустите — должно пройти 4 попытки (1 исходная + 3 повторных): ошибка, ожидание 200ms, ошибка, 400ms, ошибка, 800ms, ошибка
3. Установите вероятность ошибки 0% — должна пройти первая же попытка
4. Включите Jitter и запустите несколько раз — задержки должны отличаться при каждом запуске
5. При factor = 1.5, baseDelay = 100ms: задержки ≈ 100ms, 150ms, 225ms, 337ms...
