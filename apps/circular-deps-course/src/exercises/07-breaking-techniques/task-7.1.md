# Задание 7.1 — Инверсия зависимости: внедрение через параметр (простое)

## Цель

Разорвать двусторонний цикл `cart.ts ↔ pricing.ts`, убрав обратный импорт и внедрив нужную функцию параметром.

## Что дано

- `cart.ts` — экспортирует `checkout`, импортирует `applyDiscount` из `pricing.ts` (🔒 только чтение);
- `pricing.ts` — экспортирует `applyDiscount`, но его функция `checkoutWithLog` импортирует `checkout` обратно из `cart.ts` — это и создаёт цикл.

## Требования

1. В `pricing.ts` уберите импорт `checkout` из `./cart`.
2. Функция `checkoutWithLog` должна принимать `checkout` вторым параметром (тип — функция `(items) => items`).
3. Внутри `checkoutWithLog` вызывайте параметр `checkout`, а не глобальную импортированную функцию.
4. Нажмите «Проверить» — все проверки должны стать зелёными.

## Чеклист

- [ ] `pricing.ts` не импортирует `cart.ts`
- [ ] `checkoutWithLog` принимает `checkout` параметром
- [ ] Цикл в графе импортов отсутствует
- [ ] Пройти квиз уровня ≥ 80%
