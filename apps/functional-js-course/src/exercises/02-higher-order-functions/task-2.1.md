# Задание 2.1 — Pipeline: filter → map → reduce

## Цель

Реализовать интерактивный визуализатор пайплайна трёх стандартных HOF:
`filter`, `map`, `reduce`. Пользователь управляет параметрами через ползунки
и видит как данные трансформируются на каждом этапе.

## Требования

1. Задайте массив из 6-8 продуктов с полями `name`, `price`, `category`.
2. Реализуйте **Stage 1 — filter**: фильтрация по минимальной цене.
   - Ползунок от 0 до 1000 задаёт минимальную цену.
   - Продукты, прошедшие фильтр, отображаются цветом; отфильтрованные — серым с перечёркиванием.
3. Реализуйте **Stage 2 — map**: применение скидки к отфильтрованным продуктам.
   - Ползунок от 0 до 50 задаёт процент скидки.
   - Для каждого продукта показывается исходная цена (перечёркнута) и новая.
4. Реализуйте **Stage 3 — reduce**: суммирование цен после скидки.
   - Показать итоговую сумму крупно.
   - Показать формулу: `a + b + c = total`.
5. Все три этапа реактивно обновляются при движении ползунков.
6. Под каждым этапом показывается соответствующий код на JavaScript.

## Чеклист

- [ ] Массив продуктов с 6-8 элементами
- [ ] `useState` для `minPrice` и `discount`
- [ ] Stage 1: `filter` работает корректно, прошедшие/отфильтрованные видны визуально
- [ ] Stage 2: `map` применяет скидку к результату filter
- [ ] Stage 3: `reduce` считает сумму результата map
- [ ] Итоговый пайплайн показан как блок кода с актуальными значениями параметров
- [ ] Все три этапа обновляются синхронно при изменении ползунков

## Как проверить себя

1. Поставьте минимальную цену 200 — дешёвые товары должны стать серыми и перечёркнутыми.
2. Увеличьте скидку до 50% — цены в Stage 2 должны уменьшиться вдвое.
3. Поставьте минимальную цену 9999 — Stage 3 должен показать 0 (нет элементов).
4. Снизьте минимальную цену до 0 со скидкой 0% — сумма должна равняться сумме всех исходных цен.

## Подсказки

- `filter` возвращает новый массив, примените его к исходному `PRODUCTS`.
- `map` применяется к результату `filter`, а не к исходному массиву.
- В коде-подсказке под каждым этапом можно динамически подставлять текущие значения ползунков.
- Для перечёркнутого текста используйте `textDecoration: 'line-through'`.
