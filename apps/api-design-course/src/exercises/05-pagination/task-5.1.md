# Задание 5.1 — Визуализатор пагинации

## Цель

Наглядно продемонстрировать разницу между offset и cursor-пагинацией, включая проблему consistency при вставке/удалении элементов.

## Требования

1. Компонент показывает массив из 30 элементов с постраничным просмотром (по 5 элементов).
2. Реализованы два режима: offset (page/limit) и cursor (after/first) с переключением.
3. URL текущего запроса отображается в виде строки, обновляется при смене страницы.
4. Есть кнопка «Вставить элемент» — симуляция добавления нового элемента в начало списка.
5. В режиме offset при переходе на следующую страницу после вставки показан задублированный элемент (выделен красным).
6. В режиме cursor вставка не влияет на пагинацию — элементы не дублируются, показано пояснение.
7. Кнопки «Назад» / «Вперёд» заблокированы на первой / последней странице соответственно.

## Чеклист

- [ ] Переключатель между offset и cursor режимами
- [ ] Строка с текущим URL запроса (page/limit или after/first)
- [ ] Отображение 5 элементов на странице
- [ ] Кнопки «Назад» и «Вперёд» с блокировкой на краях
- [ ] Кнопка вставки нового элемента
- [ ] В offset-режиме: красная подсветка дубликата после вставки и перехода на стр. 2
- [ ] В cursor-режиме: пояснение что вставка не влияет на курсор

## Как проверить себя

1. Откройте компонент в offset-режиме.
2. Вставьте новый элемент кнопкой «Вставить элемент».
3. Перейдите на страницу 2 — должен появиться красный дубликат.
4. Переключитесь на cursor-режим.
5. Нажмите «Вставить элемент» снова — при листании дубликатов быть не должно.
