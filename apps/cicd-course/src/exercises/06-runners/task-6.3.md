# Задание 6.3: Настройка self-hosted раннера

## Цель

Создать пошаговый wizard регистрации GitLab Runner, который проведёт пользователя через весь процесс и сгенерирует готовый config.toml.

## Требования

1. Определи тип `WizardStep` как union: `'url' | 'token' | 'executor' | 'tags' | 'settings' | 'result'`

2. Реализуй 6 шагов wizard-а:
   - **Шаг 1 (url)**: Ввод GitLab instance URL (https://gitlab.com или self-hosted). Валидация: должен начинаться с https://
   - **Шаг 2 (token)**: Ввод registration token (начинается с glrt- или длина > 20 символов). Показывай где его найти: Settings > CI/CD > Runners
   - **Шаг 3 (executor)**: Выбор executor (Docker / Shell / Kubernetes) с кратким описанием каждого
   - **Шаг 4 (tags)**: Ввод тегов через запятую. Автозаполнение: docker, linux, shell, windows, production, staging. Добавить чекбокс "Принимать джобы без тегов"
   - **Шаг 5 (settings)**: Дополнительные настройки в зависимости от executor: для Docker — default image и privileged, для Shell — ничего особого, для Kubernetes — namespace и image
   - **Шаг 6 (result)**: Финальный экран с сгенерированной командой `gitlab-runner register` и содержимым `config.toml`

3. Показывай прогресс: визуальный индикатор шагов (1 из 6, 2 из 6...)

4. Кнопки "Назад" и "Далее". "Далее" активна только при валидных данных текущего шага

5. На шаге result показывай:
   - Команду регистрации с флагами `--non-interactive`
   - Содержимое config.toml в блоке кода
   - Кнопку "Скопировать" для каждого блока (имитация: меняет текст на "Скопировано!")

6. Разные executor-ы генерируют разный config.toml

## Ожидаемый результат

- 6 шагов wizard-а с навигацией
- Валидация на каждом шаге (кнопка Далее заблокирована при неверных данных)
- Итоговый экран с реальной командой регистрации и config.toml

## Чеклист

- [ ] 6 шагов реализованы и переключаются корректно
- [ ] Шаг 1: валидация URL (https://)
- [ ] Шаг 2: валидация токена (длина или формат glrt-)
- [ ] Шаг 3: выбор executor с описанием
- [ ] Шаг 4: ввод тегов + чекбокс runUntagged
- [ ] Шаг 5: специфичные настройки для выбранного executor-а
- [ ] Шаг 6: корректная генерация команды и config.toml
- [ ] Кнопка "Скопировать" работает (меняет текст)
- [ ] Кнопка "Далее" заблокирована при незаполненных обязательных полях

## Как проверить себя

Пройди весь wizard: введи https://gitlab.com, любой токен длиной > 20 символов, выбери Docker, добавь теги "docker,linux", укажи image "alpine:latest". На шаге 6 должен появиться config.toml с `executor = "docker"` и `image = "alpine:latest"`. Нажми "Скопировать" — текст кнопки должен измениться на "Скопировано!".
