# Задание 10.1: Симулятор Deploy Pipeline

## Цель

Реализовать интерактивный симулятор деплоя для четырёх MFE с поддержкой пошагового canary rollout и rollback.

## Требования

1. Отобразить карточки четырёх MFE: Shell (v2.3.1 → v2.4.0), Catalog (v1.5.2 → v1.6.0), Cart (v3.0.0 → v3.1.0), Profile (v1.2.0 → v1.3.0)
2. Кнопка "Деплой" на каждой карточке запускает pipeline из трёх этапов с прогресс-баром:
   - Build (2 сек), Test (1.5 сек), Publish (1 сек)
3. После Publish автоматически включается canary на 5% трафика
4. В режиме canary показывать текущий процент и кнопки "Promote" / "Rollback":
   - Promote повышает процент поэтапно: 5% → 25% → 50% → 100%
   - При достижении 100% деплой считается завершённым
   - Rollback возвращает MFE в исходное состояние (idle)
5. Реестр версий: таблица со столбцами MFE, Текущая версия, Предыдущая, Статус, Задеплоен
6. Лог событий: хронологический список последних 30 событий (Build запущен, Publish завершён, Canary promoted, Rollback и т.д.)
7. Кнопка "Сбросить" после завершённого деплоя или rollback

## Чеклист

- [ ] Карточки четырёх MFE с цветовой идентификацией
- [ ] Pipeline запускается кнопкой "Деплой", кнопка заблокирована во время pipeline
- [ ] Прогресс-бар плавно заполняется во время каждого этапа
- [ ] Поэтапный переход между Build → Test → Publish автоматически
- [ ] Canary-блок с визуализацией текущего процента (4 шага: 5/25/50/100%)
- [ ] Кнопка Promote недоступна при 100%
- [ ] Rollback меняет статус на "Rolled back" и через 2 секунды возвращает в idle
- [ ] Реестр версий обновляется при завершении деплоя
- [ ] Лог событий с временными метками и цветовой разметкой (info/success/error/warning)
- [ ] Несколько MFE можно деплоить одновременно (независимые pipelines)
- [ ] Только inline-стили, никаких CSS-файлов

## Как проверить себя

1. Нажмите "Деплой Cart v3.1.0" — прогресс-бар должен анимироваться через Build → Test → Publish
2. После Publish появляется canary на 5% — нажмите Promote трижды для достижения 100%
3. После 100% статус меняется на "Deployed", в реестре обновляется текущая версия
4. Запустите деплой Shell и нажмите Rollback при canary 5% — лог должен показать "Rollback v2.4.0 → v2.3.1"
5. Одновременно запустите деплой Catalog и Profile — они должны работать параллельно
