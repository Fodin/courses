# Задание 3.3: Компонент `<Stepper>` — wizard-паттерн

## Цель

Реализовать многошаговый wizard-компонент с декларативным API. Пользователь описывает шаги декларативно, компонент управляет навигацией между ними.

## Требования

1. Создать контекст `StepperContext` с полями: `currentStep: number`, `totalSteps: number`, функции `next()`, `prev()`, `goTo(step: number)`, флаг `isCompleted: boolean`
2. Реализовать `StepperRoot` — корневой компонент; принимает `initialStep?: number` (по умолчанию 0), `onComplete?: () => void`, `children`; вычисляет `totalSteps` из количества `Stepper.Step` среди children
3. Реализовать `Stepper.Step` — принимает `title: string`, `children` и опциональный `stepIndex: number` (проставляется автоматически); отображается только когда `currentStep === stepIndex`
4. Реализовать `Stepper.Controls` — компонент кнопок навигации; показывает:
   - Кнопку "Назад" (disabled на первом шаге)
   - Кнопку "Далее" / "Завершить" (на последнем шаге — "Завершить", при клике вызывает `onComplete`)
5. Реализовать `Stepper.Progress` — визуальный индикатор прогресса: список точек/кружков, где текущий шаг выделен, пройденные — отмечены галочкой
6. `next()` не должен выходить за пределы последнего шага; `prev()` — за пределы первого
7. Если `currentStep >= totalSteps`, устанавливать `isCompleted = true` и показывать сообщение об успешном завершении
8. Собрать `Stepper` через `Object.assign` с sub-компонентами `Step`, `Controls`, `Progress`

## Подсказки

- Для подсчёта `totalSteps` и простановки `stepIndex` используйте `React.Children.map` внутри `StepperRoot`: клонируйте каждый `Stepper.Step` через `React.cloneElement`, добавляя `stepIndex`
- Альтернатива без cloneElement: хранить `totalSteps` как число, а `Stepper.Step` сам читает контекст и рендерит `children` только если `currentStep` совпадает с его позицией — но тогда `stepIndex` нужно передавать явно
- `Stepper.Progress` может принимать `totalSteps` и `currentStep` из контекста — рендерит массив через `Array.from({ length: totalSteps })`
- Не забудьте вызвать `onComplete?.()` при клике "Завершить" — опциональный вызов

## Чеклист

- [ ] `StepperContext` содержит `currentStep`, `totalSteps`, `next`, `prev`, `goTo`, `isCompleted`
- [ ] `StepperRoot` корректно считает количество шагов
- [ ] `Stepper.Step` отображается только на своём шаге
- [ ] `Stepper.Controls`: кнопка "Назад" заблокирована на первом шаге
- [ ] `Stepper.Controls`: кнопка "Далее" → "Завершить" на последнем шаге
- [ ] `Stepper.Progress` визуально показывает текущий шаг
- [ ] После завершения показывается сообщение об успехе
- [ ] `Stepper` собран через `Object.assign`

## Как проверить себя

Создайте Stepper с 3 шагами и проверьте:
- На первом шаге кнопка "Назад" заблокирована
- Навигация вперёд/назад работает корректно
- На последнем шаге кнопка называется "Завершить"
- После клика "Завершить" показывается сообщение об успехе или срабатывает `onComplete`
- Индикатор прогресса отражает текущий шаг
