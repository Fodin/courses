# Задание 3.2 — Найти типовое ребро в цикле из трёх файлов (среднее)

## Цель

Научиться классифицировать каждое ребро более длинного цикла по отдельности и
находить именно то, которое можно (и нужно) сделать типовым.

## Что дано

- `a.ts` (только чтение) — импортирует значение `cValue` из `c.ts`.
- `c.ts` (только чтение) — импортирует значение `bValue` из `b.ts`.
- `b.ts` (редактируется) — импортирует интерфейс `A` из `a.ts` обычным
  импортом, хотя использует его только как тип параметра.

Цикл `a.ts → c.ts → b.ts → a.ts` целиком состоит из трёх рёбер, но опасно из
них только одно.

## Требования

1. Пройдитесь по цепочке `a → c → b → a` и определите, какое ребро — не
   рантайм-зависимость, а типовая аннотация.
2. Исправьте только это ребро на `import type` в `b.ts`.
3. Не трогайте `a.ts` и `c.ts` — их значения (`cValue`, `bValue`) реально
   используются в рантайме.
4. Нажмите «Проверить».

## Чеклист

- [ ] Определено, какое ребро цикла типовое
- [ ] `b.ts` импортирует `A` через `import type`
- [ ] Рантайм-цикл `a.ts → c.ts → b.ts → a.ts` отсутствует
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

Постройте цепочку импортов вручную: `a.ts` использует `cValue` как значение
(`export const aValue = 'a:' + cValue`) — трогать нельзя. `c.ts` аналогично
использует `bValue` — трогать нельзя. Только в `b.ts` `A` встречается лишь в
типовой позиции (`function describe(a: A)`).
