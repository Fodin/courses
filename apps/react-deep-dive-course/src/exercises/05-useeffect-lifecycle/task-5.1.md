# Задание 5.1: Effect Timeline

## Цель

Построить интерактивный визуализатор временной шкалы выполнения `useEffect` и `useLayoutEffect` — увидеть своими глазами, в каком порядке происходят render, paint и callbacks.

## Задание

Реализуй компонент, который:

1. При нажатии кнопки "Запустить" вызывает `setState`, запуская цикл render
2. Логирует четыре события в хронологическом порядке:
   - `"render"` — в теле компонента (во время рендера)
   - `"useLayoutEffect callback"` — в `useLayoutEffect`
   - `"browser paint"` — через `requestAnimationFrame` внутри `useLayoutEffect`
   - `"useEffect callback"` — в `useEffect`
3. Отображает события в виде вертикального таймлайна с пронумерованными точками
4. Кнопка "Очистить" сбрасывает лог

## Требования

1. Компонент содержит `useLayoutEffect` (запускается до paint) и `useEffect` (после paint)
2. Событие `"render"` добавляется в лог через `useRef` (не через `useState`, чтобы не вызывать лишних рендеров)
3. `"browser paint"` логируется через `requestAnimationFrame` внутри `useLayoutEffect` — это ближайший момент после paint
4. Каждое событие в таймлайне имеет:
   - Порядковый номер (1, 2, 3, 4...)
   - Цветную точку (разные цвета для разных типов событий)
   - Название события
   - Временную метку (timestamp в мс от начала серии)
5. Кнопка "Запустить снова" позволяет добавить ещё одну серию событий для сравнения
6. После нескольких кликов лог показывает повторяющийся паттерн

## Чеклист

- [ ] `useLayoutEffect` логирует своё событие раньше, чем `useEffect`
- [ ] `"browser paint"` (requestAnimationFrame) приходит между `useLayoutEffect` и `useEffect`
- [ ] `"render"` всегда первый в каждой серии
- [ ] Временные метки показывают реальный порядок (мс)
- [ ] Вертикальный таймлайн с цветовым кодированием
- [ ] Кнопки "Запустить" и "Очистить" работают
- [ ] Cleanup от `useLayoutEffect` и `useEffect` логируется при следующем запуске

## Как проверить себя

1. Нажми "Запустить" — в таймлайне появятся 4 события
2. Нажми ещё раз — перед новой серией появятся cleanup-события
3. Убедись: порядок всегда `render → useLayoutEffect → (paint) → requestAnimationFrame → useEffect`
4. Сравни временные метки — `requestAnimationFrame` должен быть между layout и passive effect
