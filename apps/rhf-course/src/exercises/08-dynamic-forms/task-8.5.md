# Задание 8.5: Вложенные Field Arrays (массив внутри массива)

## Цель

Научиться создавать вложенные динамические списки с помощью useFieldArray.

## Требования

Создайте конструктор курсов с вложенной структурой:

1. **Название курса** — текстовое поле
2. **Модули** — динамический список (useFieldArray), каждый модуль содержит:
   - Название модуля
   - **Уроки** — вложенный динамический список (ещё один useFieldArray), каждый урок содержит:
     - Название урока
     - Длительность
3. **Кнопки управления** на обоих уровнях: добавление и удаление
4. **Валидация**: минимум 1 модуль, минимум 1 урок в каждом модуле, все поля обязательны

## Чеклист

- [ ] Форма с полем "Название курса"
- [ ] Список модулей с возможностью добавления/удаления
- [ ] Внутри каждого модуля — список уроков с добавлением/удалением
- [ ] Валидация на всех уровнях (курс, модули, уроки)
- [ ] При отправке все данные выводятся в консоль
- [ ] Вложенный useFieldArray работает независимо в каждом модуле

## Как проверить себя

1. Откройте форму — видите поле "Название курса" и один модуль с одним уроком
2. Добавьте второй модуль — появляется новый блок с полем модуля и уроком
3. Добавьте уроки в первый модуль — уроки добавляются только в первый модуль
4. Удалите урок — он исчезает только из своего модуля
5. Нажмите "Сохранить" без заполнения — ошибки валидации
6. Заполните и отправьте — в консоли вложенная структура данных
