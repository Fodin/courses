# Задание 1.1: Визуализатор топологии MFE

## Цель

Построить интерактивный инструмент, который наглядно показывает, как страница делится между командами при разных стратегиях разделения микрофронтендов.

## Требования

1. Отобразите карту страницы из 5 зон: Header, Nav/Sidebar, Content Main, Content Aside, Footer
2. Каждая зона содержит выпадающий список для назначения команды (Team Catalog, Team Cart, Team User, Team Search, не назначено)
3. Добавьте переключатель режима: **Vertical Split** и **Horizontal Split**
4. При переключении режима применяется пресет назначений, иллюстрирующий разницу подходов:
   - Vertical: одна команда владеет несколькими связанными зонами
   - Horizontal: команды делят страницу по слоям
5. Отображайте таблицу: команда → количество зон → список зон
6. Анализируйте текущее распределение и показывайте предупреждения при проблемных конфигурациях:
   - Header и Footer у разных команд (горизонтальный split)
   - Команда владеет более чем 2 зонами (вертикальный split)
   - Нет ни одного назначения
7. При консистентной конфигурации показывайте зелёное подтверждение

## Чеклист

- [ ] Карта страницы с 5 зонами визуально напоминает реальную раскладку страницы (header сверху, footer снизу)
- [ ] Выпадающий список в каждой зоне меняет цвет рамки и фон в соответствии с цветом команды
- [ ] Переключатель Vertical/Horizontal меняет пресет назначений
- [ ] Таблица статистики обновляется при каждом изменении назначения
- [ ] Предупреждения появляются при конфликтующих назначениях
- [ ] Компонент не требует пропсов, работает полностью на useState

## Как проверить себя

- Назначьте разные команды на Header и Footer в режиме Horizontal — должно появиться предупреждение
- Назначьте одну команду на все 5 зон в режиме Vertical — должно появиться предупреждение о нарушении границ домена
- Переключитесь между режимами — пресеты должны наглядно показывать разницу подходов
- Снимите все назначения — должно появиться предупреждение об отсутствии назначений
