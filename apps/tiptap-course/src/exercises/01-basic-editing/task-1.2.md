# Задание 1.2: Editable toggle

## Цель

Реализовать переключатель "Редактировать / Только чтение", который через `editor.setEditable()` включает и выключает возможность редактирования документа.

## Требования

1. Создайте `editor` через `useEditor` с `StarterKit`
2. Заведите state `isEditable` (булево, изначально `true`)
3. Добавьте кнопку-переключатель ("Режим: Редактирование" / "Режим: Просмотр")
4. По клику переключайте `isEditable` и вызывайте `editor.setEditable(newValue)` внутри `useEffect`, реагирующего на изменение `isEditable`
5. Визуально отметьте текущий режим (например, разным цветом рамки контейнера редактора: зелёная — редактируемый, серая — только чтение)
6. В режиме "только чтение" попытка печатать не должна изменять текст

## Чеклист

- [ ] Компонент называется `Task1_2` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.1.2')` используется в заголовке
- [ ] Кнопка переключает состояние `isEditable`
- [ ] `editor.setEditable()` вызывается через `useEffect` с зависимостью от `isEditable` (и `editor`)
- [ ] В режиме "только чтение" текст редактора нельзя изменить
- [ ] Визуальная индикация текущего режима присутствует
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. По умолчанию редактор должен быть редактируемым — попробуйте напечатать текст
2. Нажмите кнопку переключения — рамка должна изменить цвет
3. Попробуйте печатать снова — текст не должен добавляться (курсор может стоять, но ввод не проходит)
4. Нажмите кнопку ещё раз — редактирование должно снова заработать
