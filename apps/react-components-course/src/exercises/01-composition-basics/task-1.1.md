# Задание 1.1 — Card с children и слотами

## Цель

Создать переиспользуемый компонент `Card`, который принимает `header`, `children` и `footer` как слоты, и продемонстрировать его гибкость тремя разными вариантами использования.

## Требования

1. Реализовать компонент `Card` с пропсами:
   - `children: React.ReactNode` — основное содержимое (обязательный)
   - `header?: React.ReactNode` — шапка карточки (необязательный)
   - `footer?: React.ReactNode` — подвал карточки (необязательный)
2. Шапка и подвал должны рендериться **только если переданы** — пустых контейнеров быть не должно
3. Реализовать три варианта карточек через один и тот же компонент `Card`:
   - **Карточка профиля** — с аватаром и именем в `header`, биографией в `children`, кнопкой "Подписаться" в `footer`
   - **Карточка уведомления** — только `children` (без header и footer), с иконкой и текстом
   - **Карточка товара** — с названием в `header`, описанием и ценой в `children`, двумя кнопками ("В корзину", "Купить") в `footer`
4. Каждый вариант должен выглядеть визуально отличимо (разные данные, разный контент слотов)
5. Использовать inline styles — CSS-модули не нужны

## Подсказки

- Тип слота: `React.ReactNode` — принимает JSX, строки, числа, `null`
- Проверка слота: `{header && <div className="card-header">{header}</div>}`
- Можно вынести стили карточки в константу объекта и переиспользовать
- Три карточки должны быть отрендерены рядом для наглядного сравнения

## Чеклист

- [ ] Компонент `Card` принимает `children`, `header`, `footer`
- [ ] Слоты `header` и `footer` опциональны и не рендерят пустые контейнеры
- [ ] Карточка профиля использует все три слота
- [ ] Карточка уведомления использует только `children`
- [ ] Карточка товара использует все три слота с другим контентом
- [ ] Компонент не содержит жёстко прописанного контента — только структуру

## Как проверить себя

Удалите `footer` из карточки уведомления и убедитесь, что в DOM не появляется пустого `<div>`. Затем добавьте в `header` карточки профиля вместо строки полноценный JSX — компонент должен это принять без изменений.
