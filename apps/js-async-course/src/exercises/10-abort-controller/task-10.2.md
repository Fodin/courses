# Задание 10.2: AbortSignal.timeout и составные сигналы

## Цель

Реализовать демонстрацию двух причин отмены операции: ручная пользовательская отмена и автоматический таймаут. Использовать `AbortSignal.any([userSignal, AbortSignal.timeout(ms)])` — кто первый сработает, тот и выигрывает.

## Требования

1. **Два слайдера**:
   - Слайдер таймаута (500–6000мс): задаёт `AbortSignal.timeout(ms)`
   - Слайдер задержки сервера (500–6000мс): как долго сервер отвечает
   - При изменении любого слайдера — сбрасывать состояние

2. **Составной сигнал**:
   - `const combined = AbortSignal.any([userController.signal, AbortSignal.timeout(timeoutMs)])`
   - Передаётся в симулированный запрос
   - Подсказка: если `serverDelay < timeout` — операция успешна; иначе `TimeoutError`

3. **Два визуальных таймера**:
   - Автотаймаут: прогресс-бар обратного отсчёта (заполняется от 0 до таймаута)
   - Пользовательский: надпись "Нажмите Отменить вручную" + прошедшее время
   - Когда один срабатывает — помечается как победитель (СРАБОТАЛ)

4. **Результат операции**:
   - При успехе: зелёное сообщение
   - При `TimeoutError`: жёлтое сообщение с объяснением
   - При `AbortError`: красное сообщение с объяснением
   - Показать `signal.reason` (TimeoutError vs AbortError)

5. **Кнопки**:
   - "Запустить операцию" — активна только в состоянии `idle`/`done`
   - "Отменить вручную" — активна только при `running`
   - "Сброс" — всегда активна

6. **Подсказка-предсказание**: до запуска показывать, кто "победит" при текущих настройках слайдеров

- [ ] Таймер обратного отсчёта обновляется во время операции

## Как проверить себя

1. Установите таймаут 2000мс, задержку сервера 1000мс. Запустите — операция успешна
2. Установите таймаут 1000мс, задержку сервера 3000мс. Запустите — таймаут выиграет, `TimeoutError`
3. Установите таймаут 5000мс, задержку сервера 5000мс. Запустите и нажмите "Отменить вручную" — `AbortError`
4. Проверьте, что в результате показывается правильная `signal.reason`
5. Убедитесь, что победитель (таймаут или пользователь) помечен в UI
