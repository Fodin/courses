# Задание 2.3: Time Slicing Demo

## Цель

Наглядно показать разницу между синхронным рендером (блокирует браузер) и рендером чанками (Time Slicing). Измерить frame drops через `requestAnimationFrame`, показать FPS-счётчик во время рендера.

## Задание

Создай компонент `Task2_3`, который:

1. Рендерит список из 10 000 элементов двумя способами:
   - **Синхронный**: все элементы добавляются за один tick (блокирует UI)
   - **Chunked**: элементы добавляются порциями по 100 штук через `setTimeout(fn, 0)` между чанками
2. Во время рендера показывает **FPS-счётчик** (через `requestAnimationFrame`)
3. Считает **frame drops** (кадры, где время между RAF > 33ms, т.е. FPS < 30)
4. Показывает **время рендера** для каждого режима
5. После завершения показывает итоговую статистику

## Требования

1. FPS-измерение через RAF:
   ```ts
   // Запускаем RAF-цикл до завершения рендера
   // Считаем frameDrop = elapsed > 33ms
   let lastTime = performance.now()
   function measureFrame() {
     const now = performance.now()
     const elapsed = now - lastTime
     if (elapsed > 33) frameDrops++
     fps = Math.round(1000 / elapsed)
     lastTime = now
     rafId = requestAnimationFrame(measureFrame)
   }
   ```
2. Синхронный режим:
   ```ts
   // Блокирует UI: всё в одном цикле
   const items = Array.from({ length: 10000 }, (_, i) => i)
   setItems(items)  // один setState → один рендер, но тяжёлый
   ```
3. Chunked режим:
   ```ts
   // Рендер порциями по 100 элементов
   // Между чанками — setTimeout(fn, 0) для отдачи управления
   ```
4. Каждый элемент списка — это строка с тяжёлыми вычислениями:
   ```ts
   // Имитация тяжёлого компонента: фибоначчи или просто длинная строка
   function expensiveItem(i: number): string {
     return `Item #${i}: ${new Array(50).fill('x').join('')}`
   }
   ```
5. Кнопки "Синхронный рендер" и "Chunked рендер" — обе запускают новый тест
6. Во время теста кнопки неактивны, показывается прогресс-бар
7. После теста: время рендера, frame drops, минимальный FPS

## Интерфейс

```
[Синхронный рендер]  [Chunked рендер]

Статус: рендеринг... (3500 / 10000)
FPS: 12  |  Frame drops: 8

--- Результат ---
Синхронный:  1247ms  |  Frame drops: 15  |  Min FPS: 4
Chunked:      893ms  |  Frame drops: 1   |  Min FPS: 57
```

## Чеклист

- [ ] Синхронный рендер ощутимо блокирует UI (кнопки не реагируют во время рендера)
- [ ] Chunked рендер не блокирует (прогресс-бар обновляется плавно)
- [ ] FPS-счётчик обновляется в реальном времени через RAF
- [ ] Frame drops считаются правильно (elapsed > 33ms)
- [ ] Время рендера измеряется через `performance.now()`
- [ ] После завершения видна разница в метриках
- [ ] Прогресс-бар показывает прогресс чанков (только для Chunked)

## Как проверить себя

1. Нажми "Синхронный рендер" — интерфейс должен "зависнуть" на 0.5-2 секунды
2. Нажми "Chunked рендер" — интерфейс должен оставаться отзывчивым
3. FPS при синхронном должен упасть до 0-10 (или "N/A" если браузер заморожен)
4. FPS при chunked должен оставаться выше 30 большую часть времени
5. Результаты зависят от мощности компьютера, но разница всегда заметна
