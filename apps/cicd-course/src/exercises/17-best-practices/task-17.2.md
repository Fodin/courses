# Задание 17.2: Pipeline as Code — редактор структуры

## Цель

Создать интерактивный редактор, демонстрирующий принципы организации `.gitlab-ci.yml`: структуру через `include`, DRY через `extends`, и читаемость через документирование.

## Требования

1. Отобразить начальный "плохой" пайплайн: 4 джоба с повторяющимися блоками `image`, `tags`, `cache` (дублирование видно явно)
2. Реализовать кнопку **"Применить extends"** — трансформирует конфиг, выводя общий блок `.node-job:` и сокращённые джобы с `extends: .node-job`
3. Реализовать кнопку **"Разбить на файлы"** — показывает, как конфиг разделился бы на `main.yml`, `test.yml`, `build.yml` с вкладками переключения
4. Показывать счётчик строк кода "до" и "после" каждой трансформации
5. При наведении на дублирующийся блок в "до"-версии подсвечивать его красным, показывать tooltip "Дублирование: это есть в N джобах"
6. После каждой трансформации показывать краткое объяснение: что изменилось и почему это лучше
7. Добавить раздел "Документирование" — два варианта одного джоба: без комментариев и с комментариями; переключатель показывает разницу

## Чеклист

- [ ] Начальный конфиг с явным дублированием (минимум 3 повторяющихся блока)
- [ ] Кнопка "Применить extends" с трансформацией конфига
- [ ] Счётчик строк до/после (и процент сокращения)
- [ ] Кнопка "Разбить на файлы" с вкладками файлов
- [ ] Подсветка дублирований в исходном конфиге (красный цвет или рамка)
- [ ] Текстовое объяснение после каждой трансформации
- [ ] Секция "Документирование": два варианта джоба с переключателем
- [ ] Все YAML-блоки в моноширинном шрифте на тёмном фоне

## Как проверить себя

1. В начальном состоянии видны 4 блока с одинаковыми `image`, `tags`, `cache`
2. После "Применить extends" — один блок `.node-job` и компактные джобы
3. Счётчик строк уменьшился (например: 48 строк → 28 строк, -42%)
4. После "Разбить на файлы" — три вкладки, в `main.yml` только `include` и `stages`
5. В секции документирования видно, что с комментариями читаемость значительно выше

## Подсказки

- Храни конфиги как строки в константах, переключай через `useState` режим отображения
- Для вкладок файлов используй `activeTab` в state, кнопки-переключатели сверху
- Счётчик строк: `config.split('\n').length`
- Для подсветки дублирований: оберни повторяющиеся блоки в `<span>` с красным `backgroundColor` + title-атрибутом для tooltip
- `useState` для: `step` (0 | 1 | 2), `activeTab` (string), `docMode` ('without' | 'with')
