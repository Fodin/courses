# Задание 8.1: Квиз — URL Shortener

## Цель

Проверить понимание ключевых решений при проектировании URL Shortener: алгоритмы генерации коротких кодов, выбор между 301/302 redirect, обработка коллизий, capacity estimation.

## Требования

1. Прочитайте теорию уровня 8 (README)
2. Пройдите квиз из 4 вопросов по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист

- [ ] Прочитана теория по проектированию URL Shortener
- [ ] Понятна разница между Base62 от счётчика и обрезанным MD5
- [ ] Понятна разница между 301 и 302 redirect
- [ ] Понятно, как считать capacity estimation (QPS, storage)
- [ ] Понятна обработка коллизий при custom alias
- [ ] Пройден квиз с результатом не менее 75%

## Как проверить себя

1. Откройте квиз и ответьте на все вопросы
2. Проверьте объяснения для неправильных ответов
3. Если результат ниже 75% — перечитайте соответствующие разделы теории
