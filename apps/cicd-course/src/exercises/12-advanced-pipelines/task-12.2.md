# Задание 12.2: Multi-project pipelines

## Цель

Создать интерактивную визуализацию multi-project pipeline. Показать кросс-репо trigger, передачу переменных между проектами и цепочку зависимостей между независимыми репозиториями.

## Требования

1. Отобразить три репозитория: `api`, `frontend`, `e2e-tests` в виде отдельных блоков
2. Показать trigger-цепочку: `api` запускает `frontend` и `e2e-tests`, `frontend` — только при успехе `api`
3. Реализовать поле ввода (или готовые варианты) для namespace проекта в `trigger: project:`
4. Добавить настройку передаваемых переменных (`API_VERSION`, `DEPLOY_ENV`) — показывать их в YAML
5. Реализовать симуляцию запуска: кнопка "Запустить" последовательно "запускает" каждый downstream pipeline
6. Генерировать YAML trigger-джоба на основе настроек

## Чеклист

- [ ] Три блока-репозитория с названиями и иконками
- [ ] Стрелки между репозиториями, показывающие направление trigger
- [ ] Поле или селект для `trigger: project:` (namespace проекта)
- [ ] Поле выбора ветки (`branch:`) — main или кастомная
- [ ] Переключатель strategy: depend
- [ ] Секция переменных: чекбоксы или поля для API_VERSION и DEPLOY_ENV
- [ ] YAML-блок с актуальным конфигом
- [ ] Кнопка "Симулировать запуск" с анимацией активации downstream репозиториев

## Как проверить себя

1. Измени namespace проекта — YAML должен обновиться с новым путём
2. Включи API_VERSION в переменные — убедись, что YAML содержит `variables: API_VERSION: ...`
3. Убери strategy: depend — визуально должно показать, что api не ждёт результатов downstream
4. Нажми "Симулировать запуск" — поочерёдно (или параллельно, в зависимости от depend) должны активироваться downstream блоки
5. Измени branch с main на release — YAML должен содержать `branch: release`

## Подсказки

- Используй `useState` для: `projectPath` (строка), `branch` (строка), `strategyDepend` (boolean), `variables` (объект), `simulationStep` (число для анимации)
- Для симуляции запуска используй `setTimeout` с задержкой 500-1000ms между шагами
- Цветовое кодирование репозиториев при симуляции: серый → синий (запущен) → зелёный (завершён)
- Предлагай готовые namespace: `mygroup/frontend`, `mygroup/e2e-tests` через кнопки быстрого выбора
