# Задание 1.2 — Исправь ошибки в URL

## Цель

Научиться распознавать типичные антипаттерны в URL: глаголы в пути, неверный регистр, неправильные HTTP-методы, действия в query params.

## Требования

1. Компонент показывает список из 8–10 URL с типичными ошибками.
2. Каждый элемент содержит: «плохой» URL с методом и метку типа ошибки.
3. По умолчанию правильный вариант скрыт.
4. Кнопка «Показать ответ» раскрывает исправленный URL, метод и объяснение.
5. Кнопка «Показать все ответы» раскрывает все сразу.
6. Ошибки охватывают разные категории: глаголы, регистр, множественное число, RPC-стиль.

## Чеклист

- [ ] Минимум 8 URL с ошибками
- [ ] Каждый URL имеет метку типа ошибки
- [ ] Исправленный вариант включает правильный метод
- [ ] Объяснение объясняет «почему так правильно», а не только «что изменить»
- [ ] Кнопка «Показать все ответы» работает
- [ ] Покрыты разные типы ошибок

## Как проверить себя

Посмотрите на каждый «плохой» URL и сформулируйте ошибку самостоятельно, прежде чем нажать «Показать ответ». Если ваша формулировка совпадает с объяснением — вы освоили материал.
