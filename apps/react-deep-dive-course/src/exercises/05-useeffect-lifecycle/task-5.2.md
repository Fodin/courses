# Задание 5.2: Event Handler vs Effect (YMNAE)

## Цель

Научиться распознавать ситуации, когда `useEffect` использован неправильно вместо Event Handler — и наоборот. Применить Golden Rule: "Потому что компонент показан → Effect. Потому что пользователь действовал → Handler."

## Задание

Тебе дан компонент с четырьмя карточками-сценариями. **Два из них реализованы неправильно.** Найди ошибки и исправь их.

### Сценарии:

**Карточка 1 — "Welcome Banner"**
При монтировании компонента отправляет аналитику `analytics.track('banner_shown')`.

```tsx
// Текущая реализация:
function WelcomeBanner() {
  const [shown, setShown] = useState(false)

  function handleMount() {
    analytics.track('banner_shown')
    setShown(true)
  }

  // ❓ Есть ли здесь проблема?
  useEffect(() => { handleMount() }, [])
  // ...
}
```

**Карточка 2 — "Like Button"**
При нажатии кнопки "Лайк" отправляет `POST /api/likes`.

```tsx
// Текущая реализация:
function LikeButton({ postId }) {
  const [liked, setLiked] = useState(false)

  useEffect(() => {
    if (liked) {
      fetch(`/api/likes/${postId}`, { method: 'POST' })
    }
  }, [liked, postId])

  return <button onClick={() => setLiked(true)}>Лайк</button>
}
```

**Карточка 3 — "Live Chat"**
Подписывается на WebSocket при открытии компонента чата.

```tsx
// Текущая реализация:
function LiveChat({ roomId }) {
  useEffect(() => {
    const ws = new WebSocket(`wss://chat.example.com/${roomId}`)
    ws.onmessage = (e) => addMessage(JSON.parse(e.data))
    return () => ws.close()
  }, [roomId])
  // ...
}
```

**Карточка 4 — "Settings Form"**
Сохраняет настройки в localStorage при нажатии кнопки "Сохранить".

```tsx
// Текущая реализация:
function SettingsForm() {
  const [theme, setTheme] = useState('dark')

  useEffect(() => {
    localStorage.setItem('theme', theme)
  }, [theme])

  return (
    <div>
      <select value={theme} onChange={e => setTheme(e.target.value)}>...</select>
      <button>Сохранить</button>
    </div>
  )
}
```

## Требования

1. Определи, какие **два** сценария реализованы неправильно
2. Для каждого неправильного сценария:
   - Объясни словами, в чём проблема
   - Покажи исправленную реализацию
3. Для правильных сценариев объясни, почему они правильны
4. Оформи каждую карточку визуально:
   - Статус: "Правильно" (зелёный) / "Неправильно" (красный) — переключается кнопкой
   - Блок с объяснением
   - Кнопка "Показать решение" раскрывает исправленный код
