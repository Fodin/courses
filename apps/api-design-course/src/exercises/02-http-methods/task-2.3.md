# Задание 2.3 — CRUD endpoints для ресурса tasks

## Цель

Изучить полный эталонный набор REST endpoints для одного ресурса (task-менеджер). Закрепить связь между HTTP-методом, URL, статус-кодом ответа и структурой тела запроса/ответа.

## Требования

1. Компонент отображает таблицу из 6 эталонных endpoints для ресурса `/tasks`.
2. Для каждого endpoint показаны: метод, URL, описание, HTTP-статус ответа.
3. При клике на строку раскрываются примеры тела запроса (если есть) и тела ответа в JSON.
4. Отдельный раскрываемый блок с примерами query params для GET /tasks (фильтрация, пагинация, сортировка).
5. Блок «Проверь себя» с вопросами для самоконтроля.

## Чеклист

- [ ] 6 endpoints: GET /tasks, POST /tasks, GET /tasks/:id, PUT /tasks/:id, PATCH /tasks/:id, DELETE /tasks/:id
- [ ] Примеры JSON для запроса и ответа
- [ ] Правильные статус-коды (200, 201, 204)
- [ ] Query params для фильтрации и пагинации
- [ ] Вопросы для самопроверки

## Как проверить себя

Закройте таблицу и попробуйте воспроизвести все 6 endpoints по памяти: метод, URL, статус. Затем откройте каждую строку и проверьте примеры запроса/ответа.
