# Задание 6.2 — Конструктор Import Map

## Цель

Создать визуальный конструктор для формирования `importmap.json` — браузерного механизма управления модульными путями. Конструктор должен поддерживать секции `imports` и `scopes`, генерировать готовый JSON и HTML-тег, валидировать введённые данные.

## Требования

1. Секция **Imports** — список глобальных маппингов (specifier → URL):
   - Форма добавления с полями: specifier и URL
   - Кнопка «Пресеты React/Router» добавляет 4 записи: react, react-dom, react-dom/client, react-router-dom из esm.sh
   - Каждую запись можно удалить
2. Секция **Scopes** — список областей с локальными маппингами:
   - Форма добавления scope path (например `/app-cart/`)
   - Внутри каждого scope — форма добавления маппингов (specifier → URL)
   - Scope и отдельные маппинги можно удалять
3. Три вкладки (tab):
   - **Редактор** — визуальное управление imports и scopes
   - **importmap.json** — сгенерированный JSON в реальном времени
   - **HTML тег** — готовый `<script type="importmap">` с JSON внутри
4. Валидация с выводом ошибок:
   - URL должен быть корректным (парсится через `new URL()`)
   - Specifier не должен дублироваться в пределах одной секции
   - Scope path должен начинаться с `/`
5. На вкладке «HTML тег» — информационный блок с правилами использования importmap

## Чеклист

- [ ] Можно добавить запись в imports через форму или через пресеты
- [ ] Можно удалить любую запись из imports
- [ ] Можно добавить scope с произвольным path
- [ ] Внутри scope можно добавлять и удалять маппинги
- [ ] JSON на вкладке «importmap.json» обновляется после каждого изменения
- [ ] HTML тег на вкладке «HTML тег» обновляется после каждого изменения
- [ ] Ошибка появляется при некорректном URL
- [ ] Ошибка появляется при дублировании specifier
- [ ] Ошибка появляется при scope path без ведущего `/`
- [ ] При отсутствии данных вкладки показывают подсказку

## Как проверить себя

1. Нажмите «Пресеты React/Router» → в imports появятся 4 записи, JSON на вкладке обновится
2. Добавьте scope `/app-legacy/` с маппингом `lodash → https://esm.sh/lodash@3.10.1`
3. Перейдите на вкладку «importmap.json» → JSON должен содержать обе секции `imports` и `scopes`
4. Перейдите на вкладку «HTML тег» → должен быть корректный `<script type="importmap">`
5. Добавьте запись с некорректным URL (например `not-a-url`) → должно появиться сообщение об ошибке
6. Добавьте дубль specifier `react` → должна появиться ошибка о дублировании
7. Удалите все записи → вкладки JSON и HTML показывают подсказку

## Подсказки

- Проверка URL: `try { new URL(s); return true } catch { return false }`
- Scope path без `/` в начале — частая ошибка; предупредите об этом явно
- Для уникальных ID записей используйте счётчик (`let uid = 0; const nextId = () => String(++uid)`)
- JSON генерируется динамически: если imports пустые — не включайте ключ `imports` в JSON (чистый вывод)
- `Object.fromEntries(entries.map(e => [e.specifier, e.url]))` — удобный способ преобразовать массив маппингов в объект
