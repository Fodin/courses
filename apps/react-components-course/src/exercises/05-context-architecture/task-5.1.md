# Задание 5.1: Фабрика createStrictContext

## Цель

Реализовать универсальную generic-фабрику `createStrictContext<T>`, которая создаёт типобезопасный контекст с хуком, выбрасывающим понятную ошибку при использовании вне провайдера. Применить фабрику для создания `ThemeContext` и `UserContext`.

## Требования

1. Реализуйте функцию `createStrictContext<T>(displayName: string)`, которая:
   - Создаёт `React.createContext<T | undefined>(undefined)`
   - Устанавливает `Context.displayName = displayName` для React DevTools
   - Создаёт хук `useCtx(): T`, который выбрасывает `Error` если значение `undefined`
   - Возвращает кортеж `[Context, useCtx] as const`

2. С помощью фабрики создайте `ThemeContext` и `ThemeProvider`:
   - Тип значения: `{ mode: 'light' | 'dark'; toggleMode: () => void }`
   - Провайдер мемоизирует значение через `useMemo`
   - Экспортируйте хук `useTheme`

3. С помощью фабрики создайте `UserContext` и `UserProvider`:
   - Тип значения: `{ user: { name: string; role: string } | null; login: (name: string) => void; logout: () => void }`
   - Провайдер мемоизирует значение через `useMemo`
   - Экспортируйте хук `useUser`

4. Продемонстрируйте работу:
   - Компонент `ThemeDemo` использует `useTheme()` и показывает текущую тему с кнопкой переключения
   - Компонент `UserDemo` использует `useUser()` и показывает форму логина или данные пользователя
   - Оба компонента обёрнуты в соответствующие провайдеры

5. Продемонстрируйте ошибку вне провайдера:
   - Добавьте кнопку "Вызвать ошибку" — она должна показать `ErrorBoundary` с понятным сообщением

## Подсказки

- `as const` в возвращаемом значении фабрики сохраняет тип кортежа, а не массива
- Сообщение ошибки должно подсказывать, какой Provider забыли добавить
- `useMemo` в провайдере принимает зависимость только от данных, которые меняются

## Чеклист

- [ ] `createStrictContext<T>` — generic функция, принимает `displayName: string`
- [ ] Хук выбрасывает `Error` с понятным сообщением при вызове вне провайдера
- [ ] `Context.displayName` установлен
- [ ] `ThemeProvider` мемоизирует значение через `useMemo`
- [ ] `UserProvider` мемоизирует значение через `useMemo`
- [ ] `ThemeDemo` показывает текущую тему и кнопку переключения
- [ ] `UserDemo` показывает форму логина и данные пользователя
- [ ] Нет `any` в типах

## Как проверить себя

Откройте задание в браузере. Вы должны увидеть:
- Блок темы с кнопкой "Переключить тему" — при нажатии текст меняется с "Светлая" на "Тёмная"
- Блок пользователя с полем ввода имени и кнопкой "Войти" — после входа показываются имя и роль
- При нажатии "Вызвать ошибку" — ErrorBoundary показывает сообщение о забытом провайдере

Попробуйте убрать обёртку в провайдер и убедитесь, что хук выбрасывает ошибку с понятным текстом.
