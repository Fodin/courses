# Задание 7.8 — Вынос общего в третий модуль: цикл длиной 3 (среднее)

## Цель

Разорвать цикл длиной 3 (`product.ts → order.ts → customer.ts → product.ts`), вынеся все три типа в новый модуль `shared.ts`.

## Что дано

- `product.ts` — импортирует `Order` из `order.ts`, объявляет `interface Product`;
- `order.ts` — импортирует `Customer` из `customer.ts`, объявляет `interface Order`;
- `customer.ts` — импортирует `Product` из `product.ts`, объявляет `interface Customer`;
- `shared.ts` — пустая заготовка с `// TODO`.

## Требования

1. В `shared.ts` объявите все три типа: `Product`, `Order`, `Customer` (можно оставить их взаимно ссылающимися друг на друга — внутри одного файла это не создаёт цикл модулей).
2. В `product.ts`, `order.ts`, `customer.ts` замените объявления интерфейсов на `import type { ... } from './shared'` и оставьте только функции-фабрики.
3. Ни один из трёх файлов не должен импортировать другой напрямую.
4. Нажмите «Проверить» — все проверки должны стать зелёными.

## Чеклист

- [ ] `shared.ts` содержит `Product`, `Order` и `Customer`
- [ ] `product.ts`, `order.ts`, `customer.ts` импортируют типы из `./shared`
- [ ] Ни один из трёх файлов не импортирует другой напрямую
- [ ] Цикл в графе импортов отсутствует
- [ ] Пройти квиз уровня ≥ 80%
