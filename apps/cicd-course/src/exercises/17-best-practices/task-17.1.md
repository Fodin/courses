# Задание 17.1: Pipeline Performance — интерактивный профайлер

## Цель

Создать визуализацию, которая демонстрирует разницу между последовательным пайплайном и оптимизированным (с `needs`, `rules:changes`, `GIT_DEPTH`). Пользователь настраивает пайплайн и видит расчётное время выполнения.

## Требования

1. Отобразить набор джобов: `install`, `lint`, `test:unit`, `test:e2e`, `build`, `deploy` — каждый с условным временем выполнения (в секундах)
2. Реализовать переключатель режима: **Sequential** (все джобы последовательно по stages) vs **Optimized** (с `needs` DAG)
3. В Optimized-режиме `lint`, `test:unit`, `test:e2e` стартуют одновременно после `install`, `build` ждёт все три, `deploy` ждёт `build`
4. Показывать общее расчётное время для каждого режима и процент экономии
5. Реализовать переключатели оптимизаций: `GIT_DEPTH: 1` (экономит 30 сек на каждом джобе), `rules:changes` (пропускает test:e2e если выключен toggle "Frontend changed")
6. При выборе каждого джоба показывать соответствующий фрагмент YAML (с `needs` или без)
7. Визуализировать временну́ю шкалу джобов (горизонтальные полосы с шириной пропорциональной времени)

## Чеклист

- [ ] Минимум 6 джобов с разным временем выполнения
- [ ] Переключатель Sequential / Optimized с пересчётом времени
- [ ] Временна́я шкала (Gantt-подобная) — полосы джобов, параллельные джобы на одном уровне
- [ ] Счётчик общего времени и % экономии
- [ ] Переключатель GIT_DEPTH (влияет на время всех джобов)
- [ ] Toggle "Frontend changed" (управляет rules:changes для test:e2e)
- [ ] YAML-блок с конфигом выбранного джоба (с `needs` в optimized-режиме)
- [ ] Цветовое кодирование по стадиям (install, test, build, deploy)

## Как проверить себя

1. В Sequential-режиме все джобы расположены последовательно, общее время = сумма всех
2. В Optimized-режиме `lint`, `test:unit`, `test:e2e` параллельны — общее время заметно меньше
3. Включи GIT_DEPTH: 1 — время каждого джоба уменьшается, итоговое время пересчитывается
4. Выключи "Frontend changed" — `test:e2e` пропускается, время уменьшается
5. Нажми на джоб `build` в Optimized-режиме — в YAML должно быть `needs: [lint, test:unit, test:e2e]`

## Подсказки

- Для временно́й шкалы используй `display: flex` с `position: relative` — блоки с `margin-left` пропорциональным времени начала
- В Sequential-режиме каждый джоб начинается после предыдущего (время начала = сумма предыдущих)
- В Optimized-режиме считай `startTime` для каждого джоба по DAG: `max(endTime зависимостей)`
- `useState` для: `mode` ('sequential' | 'optimized'), `useGitDepth` (boolean), `frontendChanged` (boolean), `selectedJob` (string | null)
