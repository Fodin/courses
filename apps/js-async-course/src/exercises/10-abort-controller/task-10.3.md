# Задание 10.3: Отмена в React useEffect

## Цель

Реализовать search-компонент, который демонстрирует правильное использование `AbortController` в `useEffect`. Сравнить два режима: с отменой и без — наглядно показать проблему race condition.

## Требования

1. **Два режима** (вкладки):
   - "С AbortController" — правильный подход
   - "Без AbortController" — демонстрация race condition

2. **Поисковый input**:
   - Каждое изменение значения запускает новый "fetch" (симулятор с задержкой 500–2000мс)
   - При переключении режима — сбрасывать input и состояние

3. **Режим "С AbortController"**:
   - В `useEffect`: создаётся `new AbortController()`, передаётся в симулированный fetch
   - Cleanup-функция вызывает `controller.abort()`
   - При изменении query — предыдущий запрос отменяется, новый начинается
   - Только последний запрос обновляет `results`
   - `AbortError` в `catch` — тихо игнорируется (это нормально)

4. **Режим "Без AbortController"**:
   - В `useEffect`: просто `fetch` без cleanup
   - Все запросы выполняются до конца
   - Старый медленный запрос может прийти позже быстрого нового
   - При обнаружении race condition — показывать красное предупреждение

5. **Timeline запросов** (визуализация):
   - Горизонтальные полосы для каждого запроса
   - Отменённые — серые с зачёркнутым текстом
   - Успешные — зелёные
   - В процессе — синие
   - Показывать: ID запроса, строку запроса, статус, длительность

6. **Результаты поиска**:
   - Показывать последние результаты (список тегов/бейджей)
   - В режиме без AbortController — результаты могут "прыгать" при race condition

7. **Подсказка с кодом** внизу:
   - Показывать актуальный код для текущего режима (с/без cleanup)

## Чеклист

- [ ] Компонент называется `Task10_3` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован и `t('task.10.3')` используется в заголовке
- [ ] `AbortController` создаётся внутри `useEffect` (не снаружи!)
- [ ] Cleanup-функция (`return () => controller.abort()`) реализована в режиме "С"
- [ ] В режиме "Без" cleanup не вызывается — все запросы завершаются
- [ ] Timeline корректно показывает отменённые (серые) и успешные (зелёные) запросы
- [ ] `AbortError` в catch не показывается как ошибка пользователю
- [ ] При переключении вкладок состояние сбрасывается
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. В режиме "С AbortController": быстро напечатайте "abc" — в timeline должны быть 3 запроса, первые два серые (отменены), последний зелёный (успех)
2. В режиме "Без AbortController": быстро напечатайте "abc" — все 3 запроса выполнятся, может появиться предупреждение о race condition
3. Убедитесь, что в режиме "С" результаты всегда соответствуют текущему запросу
4. В режиме "Без" подождите — старый медленный запрос может перезаписать результаты
5. Проверьте, что переключение между режимами сбрасывает все запросы и результаты
