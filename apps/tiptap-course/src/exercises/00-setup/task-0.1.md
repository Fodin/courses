# Задание 0.1: Первый редактор

## Цель

Создать простейший работающий Tiptap-редактор в React: подключить `useEditor`, `EditorContent` и минимальный набор extensions, вывести начальный контент.

## Требования

1. Импортируйте `useEditor` и `EditorContent` из `@tiptap/react`
2. Импортируйте `StarterKit` из `@tiptap/starter-kit`
3. Создайте редактор через `useEditor({ extensions: [StarterKit], content: ... })`
4. Начальный контент (`content`) — HTML-строка с заголовком и параграфом, например `<h2>Привет, Tiptap!</h2><p>Это мой первый редактор.</p>`
5. Отрендерите `<EditorContent editor={editor} />` внутри контейнера
6. Редактор должен быть **редактируемым** — текст можно печатать и стирать сразу после загрузки страницы

## Чеклист

- [ ] Компонент называется `Task0_1` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.0.1')` используется в заголовке
- [ ] `editor` создаётся через `useEditor` с `StarterKit`
- [ ] Есть проверка `editor` на `null` перед рендером `EditorContent` (или EditorContent рендерится безусловно — Tiptap сам обработает `null`)
- [ ] Начальный контент виден на экране при загрузке
- [ ] В редакторе можно печатать текст мышкой/клавиатурой
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Откройте задание — должен появиться блок с заголовком и параграфом
2. Кликните внутрь текста и начните печатать — текст должен появляться
3. Выделите слово и нажмите `Ctrl+B` (или `Cmd+B` на Mac) — слово должно стать жирным (это работает "из коробки" благодаря `StarterKit`)
4. Обновите страницу — редактор должен пересоздаться с тем же начальным контентом
