# Задание 2.5: Режимы валидации

## Цель

Изучить режимы валидации (`mode`) в `useForm` и понять, как они влияют на момент срабатывания ошибок.

## Требования

Создайте форму с переключением режимов валидации:

1. Кнопки переключения между режимами: `onSubmit`, `onBlur`, `onChange`, `onTouched`, `all`
2. Форма с двумя полями: `username` (обязательно, минимум 3 символа) и `email` (обязательно, паттерн email)
3. При переключении режима форма должна пересоздаваться с новым `mode`
4. Показывайте описание текущего режима над формой
5. Кнопка «Сбросить» для очистки формы

## Чеклист

- [ ] Все 5 режимов доступны для выбора
- [ ] `onSubmit` — ошибки появляются только после нажатия «Отправить»
- [ ] `onBlur` — ошибки появляются при потере фокуса
- [ ] `onChange` — ошибки появляются при каждом вводе символа
- [ ] `onTouched` — ошибки появляются при первом blur, далее при каждом изменении
- [ ] `all` — ошибки появляются и при blur, и при onChange
- [ ] Форма пересоздаётся при смене режима

## Как проверить себя

1. Выберите `onSubmit` — начните вводить невалидные данные, ошибок нет до нажатия «Отправить»
2. Выберите `onChange` — ошибки появляются сразу при вводе
3. Выберите `onBlur` — введите невалидное значение, кликните на другое поле — ошибка появляется
4. Выберите `onTouched` — первая ошибка при blur, далее обновляется при каждом вводе
5. Выберите `all` — ошибки срабатывают и при blur, и при onChange
