# Задание 3.2: Custom-переменные и визуализатор приоритетов

## Цель

Создать интерактивный визуализатор цепочки приоритетов переменных GitLab CI. Пользователь задаёт значение переменной на разных уровнях и видит, какое значение "победит" в итоге.

## Требования

1. Отобразить 5 уровней переменных в виде вертикальной цепочки (или горизонтального стека):
   - Instance (наименьший приоритет)
   - Group
   - Project
   - Global `.gitlab-ci.yml` (global `variables:`)
   - Job (наивысший приоритет)
2. На каждом уровне — поле ввода для задания значения переменной `APP_ENV`
3. Кнопка "Определить победителя" — находит уровень с наивысшим приоритетом, у которого задано значение
4. "Победитель" выделяется визуально (рамка, цвет, иконка)
5. Показывать итоговое значение крупно и понятно
6. Кнопка "Сбросить" — очищает все поля

## Чеклист

- [ ] 5 уровней с полями ввода и лейблами
- [ ] Порядок уровней соответствует реальному приоритету GitLab CI
- [ ] Визуальное разделение уровней (фон, граница, цвет лейбла)
- [ ] Кнопка "Определить победителя" находит правильный уровень
- [ ] Уровень-победитель выделен (например, зелёной рамкой и бейджем "ПОБЕДИТЕЛЬ")
- [ ] Итоговое значение показывается отдельным блоком
- [ ] Если ни одно значение не задано — предупреждение
- [ ] Кнопка "Сбросить" работает

## Как проверить себя

1. Задай значение только на уровне Instance → победитель — Instance
2. Задай значения на Instance и Project → победитель — Project
3. Задай значения на всех уровнях → победитель — Job
4. Задай значения на Global и Pipeline → победитель — Pipeline
5. Нажми "Сбросить" → все поля очищены, результат сброшен

## Подсказки

- Храни уровни как массив объектов: `{ id, label, priority, value }`. Чем выше `priority` — тем выше приоритет
- Для нахождения победителя: отфильтруй уровни с непустым `value`, затем найди максимальный `priority` через `reduce` или `sort`
- Используй один `useState` для хранения значений всех уровней: объект `{ instance: '', group: '', project: '', global: '', job: '' }`
- Визуальное выделение победителя: добавь условный стиль `border: winnerId === level.id ? '2px solid #2E7D32' : '2px solid transparent'`
