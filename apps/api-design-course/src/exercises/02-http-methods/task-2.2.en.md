# Task 2.2 — Pick a Method for the Scenario

## Goal

Consolidate the skill of choosing the right HTTP method for real practical situations. Learn to justify the choice based on method semantics, not intuition.

## Requirements

1. The component displays 8–10 practical scenarios with context descriptions.
2. For each scenario, the user selects a method from a list (GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS).
3. After selecting, you can click "Check" for one scenario or "Check all" for all at once.
4. On a correct answer — a green field with an explanation. On incorrect — red, with the correct answer and explanation.
5. A "Reset" button returns to the start.
6. At the end — a final score (correct / total).

## Checklist

- [ ] At least 8 scenarios covering all 7 methods
- [ ] Method selection buttons (all 7 options)
- [ ] Checking individual scenarios and all at once
- [ ] Explanation for correct and incorrect answers
- [ ] Final score
- [ ] Reset to initial state

## How to Check Yourself

Complete all scenarios without hints. Pay attention to scenarios where you made mistakes: read the explanation and try to formulate the rule in your own words.
