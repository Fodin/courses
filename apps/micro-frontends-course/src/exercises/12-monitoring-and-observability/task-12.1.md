# Задание 12.1: Симулятор Error Boundary и Circuit Breaker

## Цель

Создать интерактивный симулятор, демонстрирующий разницу между приложением с Error Boundary и без него, а также показывающий работу Circuit Breaker в трёх состояниях: Closed, Open, Half-Open.

## Требования

1. Отобразить три MFE-блока (Каталог, Корзина, Профиль) внутри Shell-обёртки
2. Реализовать переключатель «Error Boundary: ВКЛ / ВЫКЛ»:
   - ВЫКЛ: любая ошибка кладёт всё приложение (красный экран краша с кнопкой перезапуска)
   - ВКЛ: ошибочный MFE показывает fallback-блок, остальные продолжают работать
3. На каждом MFE — кнопка «Инъекция ошибки»
4. Circuit Breaker для каждого MFE:
   - Порог: 3 ошибки → переход Closed → Open
   - В состоянии Open: кнопка «Попробовать снова» (проверяет таймаут, переходит в Half-Open)
   - В состоянии Half-Open: кнопка «Восстановить» → переход в Closed
   - Цветовая индикация: Closed = зелёный, Open = красный, Half-Open = жёлтый
5. Лог ошибок: timestamp, название MFE, team-тег, сообщение об ошибке, состояние circuit breaker
6. Темный стиль (#0f172a фон), все стили inline

## Чеклист

- [ ] Shell с тремя MFE-блоками с цветовыми метками
- [ ] Переключатель Error Boundary влияет на поведение при ошибке
- [ ] «Красный экран» при краше без Error Boundary
- [ ] Fallback-блок при ошибке с Error Boundary
- [ ] Кнопка «Инъекция ошибки» на каждом MFE
- [ ] Circuit Breaker отображает текущее состояние (Closed/Open/Half-Open)
- [ ] Переход Closed → Open после 3 ошибок
- [ ] Кнопка «Попробовать снова» в состоянии Open
- [ ] Кнопка «Восстановить» в состоянии Half-Open
- [ ] Лог: timestamp, MFE, team, error message, circuit state
- [ ] Кнопка «Сбросить всё» возвращает к начальному состоянию

## Как проверить себя

1. Выключите Error Boundary → нажмите «Инъекция ошибки» на любом MFE — должен появиться красный экран краша
2. Перезапустите → включите Error Boundary → нажмите «Инъекция ошибки» на Каталог — только Каталог показывает fallback, Корзина и Профиль работают
3. Нажмите «Инъекция ошибки» 3 раза на одном MFE — Circuit Breaker переходит в Open
4. В состоянии Open нажмите «Попробовать снова» — переход в Half-Open
5. В состоянии Half-Open нажмите «Восстановить» — переход в Closed
6. Проверьте лог — каждая запись должна содержать team-тег (team-catalog / team-cart / team-profile)
