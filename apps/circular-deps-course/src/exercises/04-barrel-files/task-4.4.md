# Задание 4.4 — Самозамыкание на общем типе через barrel (простое)

## Цель

Увидеть, что self-import цикл через barrel возникает не только у значений, но и у типов, и что фикс тот же — прямой импорт вместо barrel.

## Что дано

- `src/index.ts` — barrel, реэкспортирует `Size`, `Widget` из `widget.ts` и `Panel` из `panel.ts` (только для чтения).
- `src/widget.ts` — объявляет тип `Size` и функцию `Widget` (только для чтения).
- `src/panel.ts` — использует тип `Size`, но импортирует его через `./index` вместо прямого пути к `widget.ts`.

Barrel реэкспортирует `panel.ts`, поэтому импорт `Size` через `./index` замыкает цикл `panel → index → panel`.

## Требования

1. В `panel.ts` замени импорт `Size` на прямой путь `./widget`.
2. `index.ts` и `widget.ts` не трогай.
3. После правки в графе зависимостей не должно быть циклов.

## Чеклист

- [ ] `panel.ts` импортирует `Size` из `'./widget'`
- [ ] `index.ts` и `widget.ts` не изменены
- [ ] Цикл `panel → index → panel` исчез
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

Проверки в лаборатории (`noRuntimeCycles`, импорт `panel.ts` из `./widget`) должны стать зелёными. Обрати внимание: неважно, что импортируется — значение или тип, self-import цикл через barrel лечится одинаково.
