# Задание 4.4 — Изоляция сущностей (простое)

## Цель

Убрать прямую связь между двумя сущностями одного слоя.

## Что дано

- `entities/order/model/types.ts` — тип `Order`, который импортирует `User` из
  соседнего слайса и хранит покупателя целиком (`buyer: User`).

## Требования

1. Уберите импорт `@/entities/user` из `order/model/types.ts`.
2. Замените поле `buyer: User` на `userId: string` — заказ ссылается на покупателя по
   идентификатору, а не встраивает его.
3. Нажмите «Проверить».

## Чеклист

- [ ] В `order/model/types.ts` нет импорта соседнего слайса
- [ ] `Order` хранит `userId: string`
- [ ] Пройти квиз уровня ≥ 80%
