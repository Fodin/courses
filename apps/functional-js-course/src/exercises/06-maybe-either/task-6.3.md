# Задание 6.3: Комбинирование монад

## Цель

Соединить `Maybe` и `Either` в единый pipeline. Реализовать функцию конвертации `maybeToEither` и построить пошаговый визуализатор, показывающий состояние каждого шага.

## Требования

1. Используйте реализации `Maybe` и `Either` из заданий 6.1 и 6.2.

2. Определите функцию конвертации:
   - `maybeToEither<T>(m: Maybe<T>, error: string): Either<string, T>`

3. Реализуйте четыре функции pipeline:
   - `parseUserId(input: string): Either<string, number>` — парсинг строки в число (не пусто, isNaN, > 0)
   - `findUser(id: number): Maybe<DbUser>` — поиск в mock-массиве (3 пользователя: id 1, 2, 3)
   - `getSubscription(user: DbUser): Maybe<DbSubscription>` — поиск подписки (у пользователя id=2 нет subscriptionId)
   - `formatPlan(sub: DbSubscription): string` — форматирование строки плана

4. Реализуйте `runPipeline(input: string)`, которая запускает все 4 шага и возвращает объект с состоянием каждого шага: `'ok' | 'fail' | 'skipped'`.

5. Компонент должен содержать:
   - Поле ввода userId
   - Набор preset-кнопок: `"abc"`, `"999"`, `"2"`, `"1"`, `"3"`
   - Вертикальный список из 4 блоков-шагов: зелёный (ok), красный (fail), серый (skipped)
   - Каждый блок показывает: название функции, типы входа/выхода, результат или сообщение об ошибке
   - Блок mock DB с таблицами пользователей и подписок

6. Mock данные:
   - Users: `[{id:1, name:'Алиса', subscriptionId:101}, {id:2, name:'Борис'}, {id:3, name:'Галина', subscriptionId:102}]`
   - Subscriptions: `[{id:101, plan:'Pro', status:'active'}, {id:102, plan:'Basic', status:'expired'}]`

## Чеклист

- [ ] `parseUserId('abc')` возвращает `Left`
- [ ] `parseUserId('0')` возвращает `Left` (не положительное)
- [ ] `parseUserId('1')` возвращает `Right(1)`
- [ ] `findUser(999)` возвращает `None`
- [ ] `findUser(1)` возвращает `Some({...})`
- [ ] `getSubscription({id:2, name:'Борис'})` возвращает `None`
- [ ] `maybeToEither(None, 'msg')` возвращает `Left('msg')`
- [ ] При вводе `"abc"`: шаг 1 красный, шаги 2-4 серые
- [ ] При вводе `"999"`: шаг 1 зелёный, шаг 2 красный, шаги 3-4 серые
- [ ] При вводе `"2"`: шаги 1-2 зелёные, шаг 3 красный, шаг 4 серый
- [ ] При вводе `"1"`: все шаги зелёные

## Как проверить

1. Нажмите preset `"abc"` — только первый блок красный с ошибкой парсинга
2. Нажмите preset `"999"` — первый зелёный `Right(999)`, второй красный "не найден"
3. Нажмите preset `"2"` — первые два зелёные, третий красный "нет подписки"
4. Нажмите preset `"1"` — все четыре зелёные, форматированный план
5. Нажмите preset `"3"` — все зелёные, plan = `"Basic (истекла)"`
