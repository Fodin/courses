# Задание 1.3 — Accordion через композицию

## Цель

Реализовать компонент `Accordion` и `AccordionItem` через паттерн композиции — без передачи массива конфигов, с управлением состоянием открытия/закрытия в каждом элементе.

## Требования

1. Реализовать компонент `AccordionItem` с пропсами:
   - `title: React.ReactNode` — заголовок секции (кликабельный)
   - `children: React.ReactNode` — раскрываемый контент
   - `defaultOpen?: boolean` — открыт ли элемент по умолчанию (по умолчанию `false`)
2. `AccordionItem` управляет своим состоянием открытия через `useState`
3. При клике на заголовок — контент раскрывается или скрывается
4. Реализовать компонент `Accordion` — обёртка-контейнер, принимает только `children: React.ReactNode`
5. Продемонстрировать использование: создать FAQ с минимум 4 вопросами:
   - Первый вопрос открыт по умолчанию (`defaultOpen={true}`)
   - Остальные закрыты
   - Один из вопросов имеет в `title` не строку, а JSX с бейджем или иконкой
   - Один из ответов содержит список `<ul>`/`<li>`, а не просто текст
6. Визуально: стрелка/индикатор показывает открытое/закрытое состояние (можно символом ▼/▲ или текстом)

## Подсказки

- Состояние хранится в `AccordionItem`, а не в `Accordion`: `const [isOpen, setIsOpen] = useState(defaultOpen ?? false)`
- `Accordion` — просто `<div>` с визуальным оформлением, он не управляет дочерними элементами
- Скрытие контента: можно через условный рендеринг `{isOpen && <div>...</div>}` или через `display: none`
- Для анимации можно использовать transition на `maxHeight`, но это необязательно
- Заголовок-кнопка: `<button onClick={() => setIsOpen(prev => !prev)}>` — семантически корректно

## Чеклист

- [ ] `AccordionItem` принимает `title`, `children`, `defaultOpen?`
- [ ] Клик по заголовку переключает видимость контента
- [ ] `Accordion` является просто контейнером без логики
- [ ] Демо содержит минимум 4 вопроса
- [ ] Первый вопрос открыт по умолчанию
- [ ] Один `title` содержит JSX (не просто строку)
- [ ] Один ответ содержит список `<ul>/<li>`
- [ ] Индикатор (стрелка/символ) отражает текущее состояние

## Как проверить себя

Откройте несколько вопросов одновременно — они должны быть независимы (открытие одного не закрывает другой). Это принципиальное отличие от конфигурационного подхода, где часто закрывают всё при открытии нового. Убедитесь, что `Accordion` не содержит никакой логики — только визуальный контейнер.
