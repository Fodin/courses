# Задание 5.3: Своя простая команда

## Цель

Реализовать функцию "Очистить форматирование", комбинирующую несколько встроенных команд в одну цепочку, без создания полноценного кастомного extension.

## Требования

1. Создайте `editor` через `useEditor` с `StarterKit`
2. Начальный контент должен содержать заголовок, bold/italic текст и список
3. Реализуйте функцию `clearFormatting(editor: Editor)`, вызывающую `editor.chain().focus().unsetAllMarks().clearNodes().run()`
4. Добавьте кнопку "Очистить форматирование", вызывающую эту функцию
5. Дополнительно реализуйте функцию `applyHighlightHeading(editor: Editor)`, которая одной цепочкой превращает текущий блок в заголовок H2 **и** делает его текст жирным: `editor.chain().focus().toggleHeading({ level: 2 }).toggleBold().run()`, вызываемую отдельной кнопкой "Заголовок + Bold"

## Чеклист

- [ ] Компонент называется `Task5_3` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.5.3')` используется в заголовке
- [ ] Кнопка "Очистить форматирование" снимает все marks и превращает блоки в параграфы
- [ ] Кнопка "Заголовок + Bold" одной цепочкой применяет оба изменения
- [ ] Обе функции принимают `editor: Editor` как параметр, а не читают его из замыкания напрямую в JSX-обработчике (для переиспользуемости)
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Отформатируйте разные части текста (bold, italic, заголовок, список)
2. Выделите весь текст, нажмите "Очистить форматирование" — все должно стать обычными параграфами без marks
3. Поставьте курсор в параграф, нажмите "Заголовок + Bold" — блок должен одновременно стать заголовком H2 и получить жирное начертание
