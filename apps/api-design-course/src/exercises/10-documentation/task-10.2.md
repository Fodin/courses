# Задание 10.2: Сравнение инструментов документации

## Цель

Изучить три основных инструмента для документирования API: Swagger UI, Redoc и Stoplight — и научиться выбирать подходящий для конкретного проекта.

## Требования

1. Реализовать два режима отображения (тумблер): "Карточки" и "Сравнение"
2. В режиме "Карточки":
   - Три таба для переключения между инструментами (Swagger UI, Redoc, Stoplight)
   - Каждая карточка содержит: цветной заголовок, описание UI с фичами, список плюсов и минусов, блок "Когда использовать"
   - Кнопка "Показать пример настройки" — раскрывает блок с кодом конфигурации
3. В режиме "Сравнение":
   - Таблица с критериями по строкам и инструментами по колонкам
   - Критерии: Try it out, Mock-сервер, Дизайн, Open Source, Self-host, Совместная работа, Design-first, Сложность настройки, Цена
4. Каждый инструмент должен иметь уникальный цвет (Swagger — зелёный, Redoc — фиолетовый, Stoplight — жёлтый)

## Инструменты для сравнения

**Swagger UI** — интерактивная документация с Try it out из OpenAPI-спецификации  
**Redoc** — красивый трёхколоночный layout, отличный дизайн  
**Stoplight** — полная платформа: редактор + документация + mock-сервер + линтинг

## Чеклист

- [ ] Тумблер переключения режимов (Карточки / Сравнение)
- [ ] Три таба для Swagger UI / Redoc / Stoplight
- [ ] Карточка с плюсами, минусами и рекомендацией для каждого
- [ ] Раскрываемый блок с примером конфигурации
- [ ] Таблица сравнения в режиме "Сравнение"
- [ ] Уникальные цвета для каждого инструмента

## Как проверить себя

1. Переключитесь между тремя инструментами — карточки должны меняться
2. Нажмите "Показать пример настройки" для каждого инструмента — код должен раскрываться
3. Переключитесь в режим "Сравнение" — должна появиться таблица
4. Проверьте, что в таблице корректно отражена информация (например, Try it out у Swagger бесплатно, у Redoc — платно)
