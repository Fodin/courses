# Задание 9.3: Настройка генерации типов

## Цель

Создать интерактивный чеклист — пошаговую инструкцию по настройке `openapi-typescript` в реальном проекте. 6 шагов: установка, package.json скрипты, стратегия gitignore, типизированный клиент, React-компонент, CI/CD пайплайн. Прогресс-бар и чекбоксы.

## Требования

1. Реализовать интерфейс `ChecklistItem` с полями: `id`, `step`, `title`, `description`, `code`, `lang`
2. Создать 6 шагов с реалистичным кодом: bash, json, typescript, yaml
3. Прогресс-бар в процентах — обновляется при отметке шагов
4. Левая панель: список шагов с кликабельными строками и чекбоксами
5. Правая панель: детальный вид активного шага с кодом
6. Кнопки "Назад" и "Отметить и продолжить" для навигации по шагам

## Что реализовать

- [ ] Интерфейс `ChecklistItem` и массив `SETUP_STEPS` (6 элементов)
- [ ] Состояние `checked: Set<string>` и `activeStep: string`
- [ ] Прогресс-бар: ширина = `(checked.size / SETUP_STEPS.length) * 100%`, зелёный при 100%
- [ ] Счётчик: "N из 6 шагов выполнено", при 100% добавить "🎉 Настройка завершена!"
- [ ] Левый список: клик на строку → меняет `activeStep`, клик на чекбокс → toggle в `checked`
- [ ] Правый блок: номер шага, заголовок, описание, кнопка отметить, код с подсветкой
- [ ] Цвета языков: `bash` → `#a3e635`, `json` → `#fbbf24`, `typescript` → `#93c5fd`, `yaml` → `#f0abfc`
- [ ] Кнопка "Отметить и продолжить" одновременно делает toggle + переходит к следующему шагу

## Шаги настройки

| Шаг | ID | Язык |
|---|---|---|
| 1 | `install` | bash |
| 2 | `script` | json |
| 3 | `gitignore` | bash |
| 4 | `client` | typescript |
| 5 | `usage` | typescript |
| 6 | `ci` | yaml |

## Как проверить себя

- При отметке всех 6 шагов прогресс-бар зеленеет и появляется надпись "🎉 Настройка завершена!"
- Клик на чекбокс в списке (левая панель) не меняет активный шаг
- Кнопка "Отметить и продолжить" отмечает текущий шаг И переходит к следующему
- На последнем шаге кнопка "Отметить и продолжить" не отображается (только "Назад")
- На первом шаге кнопка "Назад" не отображается
- Шаг 4 (`client`) содержит пример с `openapi-fetch` и `createClient<paths>`
