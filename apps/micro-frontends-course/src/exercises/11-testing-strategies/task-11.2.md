# Задание 11.2: Конструктор тест-плана

## Цель

Создать интерактивный конструктор тест-плана для MFE-системы: настроить уровни тестирования для каждого MFE, выбрать mock-стратегию и CI trigger, сгенерировать test matrix в формате JSON.

## Требования

1. Список MFE с возможностью добавить новый (input + кнопка) и удалить существующий (кнопка «×»)
2. Для каждого MFE — чекбоксы: Unit / Contract / Integration / E2E / Visual
3. Select «Mock-стратегия»: real remotes / mock remotes / hybrid
4. Select «CI trigger»: Every PR / Nightly / Pre-release / Manual
5. Кнопка «Сгенерировать test matrix» запускает валидацию и генерацию
6. Валидация (блокирует генерацию при ошибках типа `error`):
   - `error`: каждый MFE обязан иметь Unit тест
   - `warning`: при 2+ MFE рекомендуется Contract testing хотя бы у одного
   - `warning`: рекомендуется E2E хотя бы для одного MFE
7. Результат генерации:
   - Pipeline: список стадий с указанием MFE и времени
   - Рекомендации по оптимизации (если pipeline > 40 мин, если много MFE с real remotes и т.д.)
   - JSON с `mockStrategy`, `ciTrigger`, `pipeline`, `matrix`
8. При изменении любого параметра — сгенерированный результат сбрасывается

## Чеклист

- [ ] Добавление MFE через input (Enter или кнопка), удаление через «×»
- [ ] Чекбоксы уровней тестирования для каждого MFE
- [ ] Выбор mock-стратегии и CI trigger
- [ ] Валидация: error для отсутствующего Unit, warnings для contract/e2e
- [ ] Генерация pipeline с этапами и временем
- [ ] Рекомендации: минимум 1 при pipeline > 40 мин
- [ ] JSON вывод с правильной структурой
- [ ] Изменение параметров сбрасывает результат

## Как проверить себя

1. Снимите Unit у «Cart» → нажмите генерацию → должна появиться ошибка «Cart: обязателен Unit тест»
2. Добавьте новый MFE «Payment» и включите ему только E2E → снова ошибка Unit
3. Восстановите Unit у всех, снимите Contract у всех → предупреждение про contract при 2+ MFE
4. Включите все уровни для всех MFE → pipeline должен превысить 40 мин, появится рекомендация
5. Выберите «Mock remotes» + 4+ MFE → рекомендация рассмотреть hybrid
6. Измените CI trigger → JSON обновляется после повторной генерации
