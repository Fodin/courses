# Задание 8.1: Визуализатор $ref

## Цель

Создать интерактивный компонент, который показывает граф зависимостей между OpenAPI-схемами e-commerce API. При клике на схему отображается её YAML-определение и связи с другими схемами.

## Требования

1. Отрисовать 5 схем: `User`, `Address`, `Order`, `OrderItem`, `Product`
2. Каждая схема — кликабельная карточка с цветовой индикацией
3. При выборе схемы показывать:
   - На какие схемы она ссылается через `$ref`
   - Какие схемы ссылаются на неё
   - YAML-определение схемы в блоке с тёмным фоном
4. Выделять связанные схемы подсветкой при выборе
5. Для каждой схемы показывать количество `$ref`-ссылок в виде бейджа

## Что реализовать

- [ ] Массив `SCHEMA_NODES` с полями: `id`, `label`, `color`, `refs: string[]`, `yaml: string`
- [ ] Состояние `selectedId: string | null`
- [ ] Вычислять `referencedBy` — кто ссылается на выбранную схему
- [ ] Применять разные стили к: выбранной схеме, схемам куда она ссылается, схемам которые ссылаются на неё
- [ ] Показывать YAML в правой колонке при выборе
- [ ] Повторный клик снимает выделение

## Связи между схемами

```
Order → User
Order → OrderItem
OrderItem → Product
User → Address
```

## Как проверить себя

- При клике на `Order` подсвечиваются `User` и `OrderItem`
- При клике на `Product` в блоке связей видно, что на него ссылается `OrderItem`
- При клике на `Address` видно, что на неё ссылается `User`
- Схемы без ссылок (`Address`, `Product`) показывают соответствующее сообщение
- Повторный клик на ту же схему снимает выделение
