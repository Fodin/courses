# Задание 2.2: Listeners и порты

## Цель

Понять концепцию множественных listener-ов в Mosquitto 2.x и научиться составлять конфигурацию для различных сценариев. Реализовать конструктор конфигурации listener-ов с генерацией готового фрагмента `mosquitto.conf`.

---

## Требования

1. Определи интерфейс `ListenerConfig` с полями: `id`, `port`, `bindAddress`, `protocol` (`'mqtt' | 'websockets'`), `tls`, `description`, `useCase`, `color`, `bg`

2. Создай массив `listenerPresets` минимум из 5 пресетов:
   - MQTT только localhost (127.0.0.1:1883)
   - MQTT для LAN (192.168.1.1:1883)
   - MQTT+TLS (0.0.0.0:8883)
   - WebSocket для браузеров (192.168.1.1:9001)
   - Secure WebSocket WSS (0.0.0.0:9883)

3. Отобрази пресеты как карточки с чекбоксами. При выборе нескольких — они комбинируются. Нельзя снять последний выбранный пресет.

4. Реализуй функцию `generateListenerConfig(listeners: ListenerConfig[]): string`, которая генерирует фрагмент `mosquitto.conf` для выбранных listener-ов. TLS-listener должен включать `cafile`, `certfile`, `keyfile`, `tls_version`.

5. Кнопка "Показать конфиг" раскрывает сгенерированный конфиг в стиле терминала

6. Добавь справочную таблицу стандартных MQTT-портов (1883, 8883, 9001, 9883)

---

## Чеклист

- [ ] Определён интерфейс `ListenerConfig` со всеми полями
- [ ] 5+ пресетов с реалистичными описаниями
- [ ] Карточки с чекбоксами для множественного выбора
- [ ] Визуальное выделение активных карточек (бордер, фон)
- [ ] Нельзя снять выбор с единственного активного пресета
- [ ] Список активных listener-ов с адресами и протоколами
- [ ] Функция `generateListenerConfig` генерирует корректный конфиг
- [ ] TLS-listener включает 4 строки: cafile, certfile, keyfile, tls_version
- [ ] Кнопка переключения видимости конфига
- [ ] Справочная таблица портов
- [ ] Корректная TypeScript типизация

---

## Как проверить себя

1. Видишь 5 карточек с пресетами?
2. Первый пресет выбран по умолчанию, остальные — нет?
3. Выбери "MQTT+TLS" — карточка подсветилась?
4. Нажми "Показать конфиг" — видишь `listener 8883` и блок TLS-параметров?
5. Убери все пресеты кроме одного — последний нельзя снять?
6. В таблице снизу 4 строки с портами 1883, 8883, 9001, 9883?
