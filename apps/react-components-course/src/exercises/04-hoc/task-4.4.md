# Задание 4.4: Рефакторинг withWindowSize → useWindowSize

## Цель

Провести рефакторинг HOC `withWindowSize` в хук `useWindowSize`. Сравнить оба подхода в одном компоненте и сформулировать, когда каждый уместен.

## Требования

1. Дан готовый HOC `withWindowSize<P>`:
   - Добавляет пропсы `windowWidth: number` и `windowHeight: number`
   - Слушает событие `resize` через `useEffect`
   - Удаляет слушатель при размонтировании
2. Используйте `withWindowSize` для компонента `ResponsiveLayoutHOC` — он меняет раскладку в зависимости от ширины
3. Реализуйте хук `useWindowSize()`:
   - Возвращает `{ width: number, height: number }`
   - Та же логика с `resize`, но без HOC-обёртки
4. Реализуйте компонент `ResponsiveLayoutHook`, который использует `useWindowSize()` напрямую — функционально идентичен `ResponsiveLayoutHOC`
5. Отобразите оба варианта рядом и добавьте блок сравнения с итогами:
   - Количество строк кода
   - Удобство тестирования
   - Прозрачность в DevTools
   - Переиспользование логики
6. Добавьте вывод текущих `width × height` в обоих вариантах — они должны быть одинаковы

## Подсказки

- HOC для `withWindowSize` использует `useEffect` и `useState` внутри возвращаемого компонента — это нормально
- Хук `useWindowSize` — просто вынесенные `useState` + `useEffect` из HOC
- Breakpoints для компонента: `< 640px` — мобильный, `640-1024px` — планшет, `> 1024px` — десктоп
- SSR-совместимость: при инициализации используйте `typeof window !== 'undefined' ? window.innerWidth : 0`

## Чеклист

- [ ] HOC `withWindowSize` типизирован и работает
- [ ] `ResponsiveLayoutHOC` меняет UI в зависимости от ширины
- [ ] Хук `useWindowSize` реализован с той же логикой
- [ ] `ResponsiveLayoutHook` функционально идентичен HOC-версии
- [ ] Оба компонента показывают одинаковые размеры окна
- [ ] Блок сравнения подходов присутствует
- [ ] Cleanup (удаление слушателя) реализован в обоих вариантах

## Как проверить себя

Измените размер окна браузера — оба компонента должны:
1. Обновить отображаемые `width × height` синхронно
2. Переключить раскладку при пересечении брейкпоинта 640px / 1024px

Откройте React DevTools: у HOC-версии вы увидите дополнительный слой `withWindowSize(ResponsiveLayoutHOC)`, у хук-версии — прямо `ResponsiveLayoutHook` без обёрток.
