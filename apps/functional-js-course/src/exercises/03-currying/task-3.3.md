# Задание 3.3 — Point-free конвейер

## Цель

Реализовать каррированные утилиты `prop`, `filterBy`, `mapWith` и функцию `pipe`.
Показать разницу между verbose и point-free стилями на одних данных с одинаковым результатом.

## Требования

1. Реализуйте каррированные утилиты:
   - `prop(key)(obj)` — возвращает `obj[key]`
   - `filterBy(pred)(arr)` — возвращает `arr.filter(pred)`
   - `mapWith(fn)(arr)` — возвращает `arr.map(fn)`
   - `pipe(...fns)(x)` — применяет функции слева направо, передавая результат следующей

2. Создайте массив пользователей (минимум 6-8 объектов) с полями `name`, `age`, `active`, `city`.
   Часть пользователей должна иметь `active: false`.

3. Добавьте переключатель "Verbose / Point-free":
   - Режим **Verbose**: отображает код с `.filter(u => u.active).map(u => u.name).sort(...)`
   - Режим **Point-free**: отображает код через `pipe(filterBy(prop('active')), mapWith(prop('name')), sortBy)`

4. Оба режима должны давать **одинаковый результат**: имена активных пользователей, отсортированные по алфавиту.

5. Отобразите исходные данные (список всех пользователей) с визуальным различием активных и неактивных.

6. Отобразите результат как нумерованный список имён.

## Чеклист

- [ ] `prop`, `filterBy`, `mapWith`, `pipe` реализованы с нуля (без сторонних библиотек)
- [ ] Verbose и point-free результаты идентичны
- [ ] Список пользователей визуально различает активных (непрозрачные) и неактивных (прозрачные)
- [ ] Переключение режимов не влияет на результат — только на отображаемый код
- [ ] Под результатом есть текстовое пояснение когда использовать каждый стиль

## Как проверить себя

Переключайтесь между Verbose и Point-free — список имён должен оставаться неизменным.
Убедитесь что `filterBy(prop('active'))` отбирает тех же пользователей что и `.filter(u => u.active)`.
Проверьте сортировку: имена должны идти по алфавиту (с учётом кириллицы).

**Подсказка:** `prop('active')` возвращает функцию `obj => obj['active']`.
Передавая её в `filterBy`, получаем `filterBy(obj => obj['active'])` — то же что предикат `u => u.active`.
Это и есть каррирование в действии.
