# Задание 2.3 — Конструктор конфига Remote

## Цель

Создать форму для настройки remote-приложения: что экспортировать наружу (`exposes`) и как настроить shared-зависимости. Форма должна предупреждать о типичных ошибках конфигурации.

## Требования

1. Форма содержит четыре секции:
   - **name**: имя remote (используется в `window.<name>` и как ключ в host)
   - **filename**: имя файла точки входа (default `remoteEntry.js`)
   - **exposes**: список экспортируемых модулей
   - **shared**: совместные зависимости

2. Управление exposes:
   - Каждая запись: поле `key` (напр. `./App`) + поле `path` (напр. `./src/App.tsx`)
   - Кнопка "Добавить Expose", кнопка удаления
   - Валидация: ключ должен начинаться с `"./"`

3. Shared — аналогично заданию 2.2 (пресет + кастомные + singleton + version)

4. Расширенная валидация (два уровня):
   - **Ошибки** (блокирующие): пустой `name`, пустой `filename`, нет exposes, ключ без `"./"`
   - **Предупреждения** (советы): `singleton: false` для `react`/`react-dom`, нет shared-зависимостей

5. Live-preview:
   - Генерирует `vite.config.ts` для remote
   - Дополнительно показывает "Как использовать в host" — примеры `React.lazy(() => import(...))`

## Checklist

- [ ] Форма содержит все 4 секции
- [ ] Ключи в `exposes` валидируются на наличие `"./"`
- [ ] При `singleton: false` для `react`/`react-dom` — предупреждение (не ошибка)
- [ ] Ошибки и предупреждения отображаются раздельно (разные стили)
- [ ] Live-preview обновляется в реальном времени
- [ ] Блок "Как использовать в host" генерирует корректные `React.lazy` вызовы
- [ ] Пустой `path` в expose вызывает ошибку

## Как проверить себя

- Введите ключ expose без `"./"` (напр. `App`) — должна появиться ошибка
- Снимите `singleton` с `react` — предупреждение без блокировки (конфиг всё равно генерируется)
- Удалите все shared-зависимости — предупреждение о возможном дублировании React
- Проверьте блок "Как использовать в host" — имена компонентов должны соответствовать ключам exposes

## Разница между ошибкой и предупреждением

| Ситуация | Уровень |
|---|---|
| Пустой `name` | Ошибка — конфиг невалиден |
| Ключ expose без `"./"` | Ошибка — Module Federation не примет такой конфиг |
| `singleton: false` для react | Предупреждение — конфиг рабочий, но рискованный |
| Нет shared зависимостей | Предупреждение — конфиг рабочий, но неэффективный |
