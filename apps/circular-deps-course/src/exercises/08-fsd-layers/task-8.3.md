# Задание 8.3 — Несколько нарушений направления образуют один цикл (сложное)

## Цель

Восстановить однонаправленность импортов сразу в нескольких файлах, устранив кольцо из четырёх слоёв.

## Что дано

Четыре модуля связаны в кольцо `shared → entities → features → widgets → shared`:

- `src/widgets/auth-widget/ui/AuthWidget.tsx` (только для чтения) — импортирует `formatUserName` из `shared/lib` (импорт «вниз», разрешён).
- `src/shared/lib/format-user.ts` (редактируется) — импортирует `DEFAULT_USER_NAME` из `entities/user` (импорт «вверх», запрещён).
- `src/entities/user/model/user.ts` (редактируется) — импортирует `isAuthEnabled` из `features/auth` (импорт «вверх», запрещён).
- `src/features/auth/model/auth.ts` (редактируется) — импортирует `AuthWidget` из `widgets/auth-widget` (импорт «вверх», запрещён).

Три «восходящих» ребра плюс одно «нисходящее» замыкают кольцо в цикл.

## Требования

1. Не редактируйте `widgets/auth-widget/ui/AuthWidget.tsx` — он уже корректен.
2. Уберите импорт `DEFAULT_USER_NAME` из `shared/lib/format-user.ts` — `shared` не должен знать о `entities`.
3. Уберите импорт `isAuthEnabled` из `entities/user/model/user.ts` — `entities` не должен знать о `features`.
4. Уберите импорт `AuthWidget` из `features/auth/model/auth.ts` — `features` не должен знать о `widgets`.
5. Каждый файл должен продолжать корректно экспортировать нужные символы, только без зависимости от вышестоящих слоёв.
6. После правки в проекте не должно быть рантайм-цикла импортов, а все импорты — идти строго «вниз».

## Чеклист

- [ ] `shared/lib/format-user.ts` не импортирует ничего из `entities`
- [ ] `entities/user/model/user.ts` не импортирует ничего из `features`
- [ ] `features/auth/model/auth.ts` не импортирует ничего из `widgets`
- [ ] Проверка «нет рантайм-цикла» — зелёная
- [ ] Проверка «импорты уважают слои» — зелёная
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

1. Нажмите «Проверить» — обе проверки должны стать зелёными.
2. Выпишите на бумаге все 4 ребра кольца и явно отметьте, какие из них «вверх» — их должно стать 0.
3. Сравните с эталоном через «Показать эталон», если застряли.
