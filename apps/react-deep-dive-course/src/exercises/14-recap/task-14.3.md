# Задание 14.3: React Source Code Navigator

## Задание

Создайте интерактивный справочник ключевых концепций курса с маппингом на файлы
исходного кода React. Каждая концепция представлена карточкой: название, описание,
файл в репозитории React, ключевые функции внутри файла.

---

## Цель

Построить мост между концепциями, изученными в курсе, и реальными файлами React.
После этого задания вы знаете, куда смотреть в исходниках, когда что-то непонятно.

---

## Требования

1. Минимум **8 концепций** с карточками: Fiber Node, Work Loop, Reconciliation,
   Hooks Dispatcher, Effects Commit, Scheduler, Lanes, Suspense
2. Каждая карточка содержит:
   - Название концепции
   - Уровень курса где разбиралась (например, "Уровень 01")
   - Файл в репозитории React (относительный путь от `packages/`)
   - 3-5 ключевых функций/констант из этого файла
   - Краткое (2-3 предложения) описание
3. При клике на карточку — она "раскрывается" и показывает дополнительный контент:
   - Ссылку на GitHub (формируется из пути к файлу)
   - Список ключевых функций с однострочными комментариями
4. Фильтрация по уровню курса (кнопки: "Все", "01-05", "06-10", "11-14")
5. Поиск по названию концепции (input фильтрует карточки в реальном времени)
6. Открытая карточка закрывается при повторном клике

---

## Чеклист

- [ ] Минимум 8 карточек с заполненными данными
- [ ] Каждая карточка: название + уровень + файл + функции + описание
- [ ] Клик раскрывает карточку с дополнительными деталями
- [ ] Повторный клик закрывает карточку
- [ ] Фильтрация по уровням (кнопки) работает
- [ ] Поиск фильтрует карточки в реальном времени
- [ ] GitHub-ссылка формируется корректно (не обязана открываться — просто показывает URL)

---

## Как проверить себя

1. Нажмите на карточку "Fiber Node" — она раскрывается, видны функции и ссылка
2. Нажмите ещё раз — карточка закрывается
3. Введите "hook" в поиск — остаются только карточки со "hook" в названии
4. Нажмите "11-14" в фильтре — остаются только карточки уровней 11-14
5. Сбросьте фильтр "Все" — все карточки снова видны

---

## Подсказки

- Данные: константа `const CONCEPTS: Concept[]` вне компонента
- Тип: `interface Concept { id, name, level, file, functions: string[], description, githubPath }`
- GitHub URL: `https://github.com/facebook/react/blob/main/${concept.githubPath}`
- Состояние открытой карточки: `useState<string | null>` с id концепции
- Фильтры уровней: `['all', '01-05', '06-10', '11-14']` с условием на `concept.level`
