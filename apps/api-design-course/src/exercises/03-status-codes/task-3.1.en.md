# Task 3.1 — Status Code Reference

## Goal

Study all key HTTP status codes, their grouping, and correct usage scenarios. Learn to quickly find the right code for a specific situation.

## Requirements

1. The component displays all status codes from five groups: 1xx, 2xx, 3xx, 4xx, 5xx.
2. Filter buttons allow showing only codes from a selected group.
3. A search bar filters codes by number, name, or description.
4. Each code is color-coded according to its group.
5. Clicking a card expands details: when to use and a specific example.

## Checklist

- [ ] All groups: 1xx, 2xx, 3xx, 4xx, 5xx
- [ ] Filtering by group (buttons)
- [ ] Text search by code, name, description
- [ ] Color coding by groups
- [ ] Expandable cards with details
- [ ] "When to use" and "Example" sections

## How to Check Yourself

Close the theory. Find these codes in the reference: 201, 204, 401, 403, 409, 422, 429. For each — read the description and reproduce the situation in which it is used. If you can explain the difference between 401/403 and 400/422 without hints — the task is completed.
