# Задание 14.2: Architecture Decision Tree

## Задание

Реализуйте интерактивное дерево архитектурных решений для React. Пользователь начинает
с вопроса "Мне нужно..." и последовательно выбирает ветки, пока не доходит до листового
узла — конкретного решения с кодовым примером.

---

## Цель

Закрепить навык выбора правильного инструмента React для конкретной задачи. Дерево
охватывает все ключевые сценарии курса.

---

## Требования

1. Начальный узел: "Мне нужно..." с минимум 5 вариантами первого уровня
2. Минимум **10 листовых решений** (итоговых ответов)
3. Листовые узлы показывают:
   - Название решения (например, `useMemo`)
   - Краткое объяснение (1-2 предложения)
   - Минимальный кодовый пример (блок кода)
4. Кнопка "Назад" на каждом шаге (кроме корневого)
5. Кнопка "Начать заново" на листовых узлах
6. Хлебные крошки (breadcrumbs) показывают путь от корня до текущего узла
7. Текущий выбранный путь визуально запомнен (подсветка активных кнопок)

---

## Чеклист

- [ ] Минимум 5 веток на первом уровне
- [ ] Минимум 10 листовых узлов с решением + объяснением + кодом
- [ ] Хлебные крошки обновляются при каждом шаге
- [ ] Кнопка "Назад" возвращает на предыдущий уровень
- [ ] "Начать заново" сбрасывает дерево в начало
- [ ] Код в листовых узлах отформатирован (моноширинный шрифт, фон)
- [ ] Можно пройти все 10+ путей

---

## Как проверить себя

1. Выберите "вычислить из данных" → появляется второй вопрос или листовой узел
2. Дойдите до `useSyncExternalStore` через ветку "синхронизировать с внешними данными"
3. Нажмите "Назад" — вернулись на один шаг
4. Хлебные крошки показывают пройденный путь
5. "Начать заново" возвращает в начало

---

## Подсказки

- Структура дерева: `type TreeNode = { id, question?, options? } | { id, solution, explanation, code }`
- Состояние: `const [path, setPath] = useState<string[]>([])` — массив id выбранных узлов
- Текущий узел: `path.reduce((node, id) => node.options.find(o => o.id === id), ROOT)`
- Хлебные крошки: пройти path и собрать метки каждого узла

---

## Дерево решений (минимальная структура)

```
"Мне нужно..."
  ├─ "вычислить значение из props/state"
  │    ├─ "вычисление лёгкое (<1ms)" → const x = compute(data)
  │    └─ "вычисление тяжёлое (>1ms)" → useMemo
  ├─ "синхронизировать с внешним store/API браузера"
  │    ├─ "это внешний store" → useSyncExternalStore
  │    └─ "это browser API (online, matchMedia)" → useSyncExternalStore
  ├─ "реагировать на действие пользователя"
  │    ├─ "нужна анимация/transition" → useTransition + startTransition
  │    └─ "обычный обработчик" → event handler (без useEffect)
  ├─ "предотвратить лишние ре-рендеры"
  │    ├─ "дочерний компонент" → React.memo + стабильные props
  │    └─ "от контекста" → разделить Context по частоте изменений
  ├─ "работать с DOM напрямую"
  │    ├─ "до отрисовки браузера" → useLayoutEffect
  │    └─ "после отрисовки" → useEffect
  └─ "загрузить данные"
       ├─ "Server Component" → async/await в компоненте
       └─ "Client Component" → useEffect + AbortController
```
