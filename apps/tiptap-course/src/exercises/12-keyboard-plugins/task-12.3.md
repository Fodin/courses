# Задание 12.3: Хоткей + плагин вместе

## Цель

Скомбинировать оба механизма уровня в одном extension: горячая клавиша переключает режим "подсветки длинных строк" (декорация), реализованная через ProseMirror-плагин с изменяемым состоянием.

## Требования

1. Создайте `Extension.create({ name: 'longLineHighlighter', ... })` с `addStorage()` → `{ enabled: false }`
2. `addKeyboardShortcuts()` → `'Mod-Shift-l'` переключает `this.storage.enabled` и вызывает `this.editor.view.dispatch(this.editor.state.tr)` (пустая транзакция, чтобы триггернуть пересчёт decorations)
3. `addProseMirrorPlugins()` → плагин с `props.decorations(state)`, который **если `this.storage.enabled === true`**, подсвечивает все текстовые блоки длиннее 80 символов через `Decoration.node` с классом `long-line`
4. Если `enabled === false` — возвращает `null`/пустой `DecorationSet`
5. В UI отобразите текущее состояние (включено/выключено) и подскажите шорткат

## Чеклист

- [ ] Компонент называется `Task12_3` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.12.3')` используется в заголовке
- [ ] `Mod-Shift-l` включает/выключает подсветку
- [ ] Длинные абзацы (>80 символов) подсвечиваются, только когда режим включён
- [ ] UI корректно отражает текущее состояние режима
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Введите длинный абзац текста (больше 80 символов) — по умолчанию подсветки быть не должно
2. Нажмите `Ctrl+Shift+L` — длинный абзац должен подсветиться
3. Введите короткий текст в новом абзаце — он не должен подсвечиваться, даже когда режим включён
4. Нажмите `Ctrl+Shift+L` ещё раз — подсветка должна исчезнуть
