# Задание 6.5: Controller Transform

## Цель

Научиться оборачивать кастомные компоненты с нестандартными значениями через Controller.

## Требования

Создайте форму настроек с тремя кастомными компонентами:

1. **Рейтинг** — компонент звёзд (1-5), клик по звезде сохраняет число в форму
2. **Цвет темы** — палитра из 6 кругов-цветов, клик сохраняет hex-строку (`#ef4444`)
3. **Уведомления** — кастомный toggle-переключатель, сохраняет `boolean`
4. Каждый компонент обёрнут в `Controller` с `render`-пропом
5. Покажите текущие значения формы как JSON для наглядности
6. Валидация: рейтинг >= 1, цвет обязателен

## Чеклист

- [ ] Звёзды подсвечиваются при наведении и клике
- [ ] Выбранный цвет выделен рамкой
- [ ] Toggle переключается между вкл/выкл
- [ ] Все значения корректно сохраняются в форму
- [ ] JSON-превью обновляется при изменении любого поля
- [ ] Валидация: без рейтинга и цвета форма не отправляется

## Как проверить себя

1. Нажмите на 3-ю звезду — рейтинг = 3, JSON обновился
2. Нажмите на синий круг — цвет = `#3b82f6`, JSON обновился
3. Нажмите toggle — уведомления = true, JSON обновился
4. Нажмите «Сохранить» без выбора рейтинга — ошибка валидации
