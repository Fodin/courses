# Задание 0.2: Детектор побочных эффектов

## Цель

Научиться распознавать побочные эффекты и нечистоту в реальных сниппетах кода, обосновывая свой ответ.

## Требования

1. Создайте набор из 8 карточек с кодовыми сниппетами. Каждая карточка показывает однострочную (или короткую) функцию.
2. По умолчанию все карточки помечены как "Pure". По клику на карточку метка переключается на "Impure" и обратно.
3. Пока пользователь не нажал "Проверить", карточки без взаимодействия отображаются нейтрально; карточки, с которыми взаимодействовали, подсвечиваются синей рамкой.
4. После нажатия кнопки "Проверить":
   - Правильно классифицированные карточки получают зелёную рамку
   - Неправильно классифицированные — красную
   - Под кодом каждой карточки появляется объяснение (почему функция чистая или нечистая)
5. Добавьте счётчик "Правильно: X / 8" после проверки.
6. Добавьте кнопку "Попробовать снова" для сброса.
7. После нажатия "Проверить" клики по карточкам не изменяют их метку.

## Чеклист

- [ ] Реализованы 8 карточек с корректными ответами:
  - `(x) => x * 2` — Pure
  - `(x) => { arr.push(x); return x }` — Impure (мутация внешнего массива)
  - `() => Math.random()` — Impure (недетерминированность)
  - `(x) => console.log(x)` — Impure (побочный эффект I/O)
  - `(a, b) => a + b` — Pure
  - `() => new Date().getTime()` — Impure (зависимость от времени)
  - `(obj) => ({ ...obj, done: true })` — Pure
  - `(arr) => arr.sort()` — Impure (мутация аргумента)
- [ ] Переключение метки работает корректно до нажатия "Проверить"
- [ ] После "Проверить" клики заблокированы
- [ ] Объяснение каждой карточки поясняет именно причину нечистоты / чистоты
- [ ] Счётчик правильных ответов отображается корректно

## Как проверить себя

1. Не трогая ни одну карточку, нажмите "Проверить" — вы получите 5/8 (чистые по умолчанию, три нечистых не пойманы).
2. Переключите все карточки на правильные ответы согласно чеклисту и нажмите "Проверить" — счётчик должен показать 8/8.
3. Попробуйте отметить `(arr) => arr.sort()` как Pure и проверьте — объяснение должно сказать про мутацию.
