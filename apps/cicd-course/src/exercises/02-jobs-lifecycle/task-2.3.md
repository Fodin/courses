# Задание 2.3: retry и timeout

## Цель

Реализовать интерактивный конфигуратор retry-стратегий и таймаутов с симуляцией нестабильного (flaky) джоба.

## Требования

1. **Конфигуратор retry**:
   - Слайдер или input для `max` (0–5 попыток)
   - Чекбоксы для типов ошибок `when`: `runner_system_failure`, `script_failure`, `stuck_or_timeout_failure`, `api_failure`
   - Превью YAML-конфига, обновляемое в реальном времени

2. **Конфигуратор timeout**:
   - Input для значения таймаута (в секундах, для демо)
   - Визуальная прогресс-шкала, показывающая оставшееся время при выполнении

3. **Симуляция flaky джоба**:
   - Слайдер "вероятность успеха" (0%–100%)
   - Кнопка **"Запустить"** — симулирует выполнение джоба
   - При каждой попытке: рандомно success или failure (по вероятности)
   - Если failure и тип ошибки попадает под `retry.when` — автоматический перезапуск
   - Таймер прогресса для каждой попытки

4. **Статистика выполнения**:
   - Сколько всего попыток было
   - Сколько раз сработал retry
   - Итоговый результат: success / failed after N attempts

## Ожидаемый результат

```
Конфигурация:
  retry.max: 2
  retry.when: [runner_system_failure, script_failure]
  timeout: 30s

Симуляция (вероятность успеха: 60%):
  Попытка 1/3: ████████░░ running... → FAILED (script_failure) → retry
  Попытка 2/3: ████████░░ running... → SUCCESS ✅

Статистика: 2 попытки, 1 retry, итог: SUCCESS
```

## Подсказки

- Используй `useState` для конфига, статистики и лога попыток
- Симуляцию сделай через `setTimeout` с паузой 1–2 секунды на попытку
- Тип ошибки выбирай случайно из списка `when` (или `script_failure` если список пуст)
- Прогресс-шкала: `width: ${(elapsed / timeout) * 100}%` с обновлением через `setInterval`
- Кнопка "Запустить" должна быть disabled пока идёт симуляция (`isRunning` state)

## Проверь себя

- [ ] YAML превью обновляется при изменении любого параметра конфигурации
- [ ] Retry происходит автоматически когда тип ошибки совпадает с `retry.when`
- [ ] Retry не происходит если тип ошибки не в списке `retry.when`
- [ ] После исчерпания `max` попыток джоб финально помечается как failed
- [ ] Таймаут визуально показан как шкала прогресса
- [ ] Статистика корректно считает попытки и retry
- [ ] При вероятности 100% джоб всегда проходит с первой попытки
