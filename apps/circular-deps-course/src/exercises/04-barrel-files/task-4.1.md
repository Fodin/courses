# Задание 4.1 — Self-import цикл через собственный barrel (простое)

## Цель

Научиться распознавать и чинить самый простой случай цикла через barrel: модуль внутри папки берёт значение соседа через собственный `index.ts` вместо прямого импорта.

## Что дано

- `src/index.ts` — barrel, реэкспортирует `aValue` из `a.ts` и `bValue` из `b.ts` (только для чтения).
- `src/a.ts` — импортирует `bValue` через `./index` (barrel), хотя `b.ts` лежит рядом.
- `src/b.ts` — простой модуль без зависимостей (только для чтения).

Из-за импорта `a.ts` через `./index` возникает цикл: `a → index → a` (barrel реэкспортирует сам `a.ts`).

## Требования

1. Замени импорт в `a.ts` так, чтобы `bValue` бралась напрямую из `./b`, а не через `./index`.
2. Не меняй `index.ts` и `b.ts` — barrel как публичная точка входа снаружи пакета должен остаться рабочим.
3. После правки в графе зависимостей не должно быть циклов.

## Чеклист

- [ ] `a.ts` импортирует `bValue` из `'./b'`
- [ ] `index.ts` и `b.ts` не изменены
- [ ] Цикл `a → index → a` исчез
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

Открой вкладку с проверками в лаборатории — обе проверки (`noRuntimeCycles`, импорт `a.ts` из `./b`) должны стать зелёными. Если сомневаешься — сравни с эталоном через кнопку «Показать решение».
