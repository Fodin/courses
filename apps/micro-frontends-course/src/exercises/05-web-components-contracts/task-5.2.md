# Задание 5.2 — Конструктор контракта Web Component

## Цель

Создать пошаговый конструктор, который позволяет описать публичный API Custom Element (атрибуты, свойства, события, CSS Custom Properties, слоты) и генерирует TypeScript-интерфейс и скелет класса в реальном времени.

## Требования

1. **Навигация по шагам** — 7 шагов с возможностью переходить между ними:
   - Шаг "Имя" → "Атрибуты" → "Свойства" → "События" → "CSS Vars" → "Слоты" → "Результат"
   - Пройденные шаги визуально отмечены (другой цвет)

2. **Шаг "Имя"** — текстовый input для имени Custom Element
   - Валидация: имя должно содержать дефис (`my-element`, не `myelement`)
   - Валидация: только lowercase и цифры
   - Показывать предварительный вид класса: `my-catalog-card` → `MyCatalogCard`
   - Сообщение об ошибке если имя неверное, сообщение об успехе если верное

3. **Шаг "Атрибуты"** — список атрибутов с полями:
   - Имя (строка), Тип (`string` / `number` / `boolean`), Default value
   - Кнопки добавить/удалить атрибут
   - Минимум 0 атрибутов (опционально)

4. **Шаг "Свойства"** — список JS-свойств с полями:
   - Имя (строка), TypeScript тип (свободный input), Описание
   - Кнопки добавить/удалить свойство

5. **Шаг "События"** — список CustomEvent с полями:
   - Имя события (строка), Payload type (TS тип для `detail`)
   - Кнопки добавить/удалить событие

6. **Шаг "CSS Vars"** — список CSS Custom Properties с полями:
   - Имя (должно начинаться с `--`), Default value
   - Валидация: имя начинается с `--`
   - Кнопки добавить/удалить

7. **Шаг "Слоты"** — список слотов с полями:
   - Имя (пустое = default slot), Описание
   - Кнопки добавить/удалить

8. **Live preview** (правая колонка) — обновляется при каждом изменении:
   - Вкладка "TypeScript Interface" — интерфейсы для атрибутов, свойств, событий, комментарии для CSS vars и слотов
   - Вкладка "Class Skeleton" — полный скелет `class MyElement extends HTMLElement { ... }` с `observedAttributes`, `connectedCallback`, геттерами/сеттерами, хелперами для emit событий

9. **Валидация** на шаге "Результат":
   - Ошибка: имя не содержит дефис
   - Ошибка: дублирующиеся имена атрибутов
   - Ошибка: дублирующиеся имена свойств
   - Ошибка: CSS Custom Property не начинается с `--`

10. Все стили — inline (без CSS-файлов)

## Чеклист

- [ ] Пошаговая навигация — 7 шагов
- [ ] Имя с дефисом проходит валидацию, без дефиса — ошибка
- [ ] Атрибуты, свойства, события, CSS vars, слоты добавляются и удаляются
- [ ] При добавлении атрибута тип-select работает (string/number/boolean)
- [ ] TypeScript Interface генерируется и обновляется live
- [ ] Class Skeleton генерируется и обновляется live
- [ ] Скелет класса содержит `observedAttributes`, `connectedCallback`, геттеры/сеттеры для свойств
- [ ] Скелет содержит emit-хелперы для каждого события
- [ ] Валидация ошибок на шаге "Результат"

## Как проверить себя

1. Введите имя `my-catalog-card` — должен появиться класс `MyCatalogCard`
2. Введите имя `mycatalogcard` (без дефиса) — должна появиться ошибка
3. Добавьте атрибут `item-id` типа `string` — в интерфейсе появится `itemId?: string`
4. Добавьте свойство `items` типа `Item[]` — в скелете появятся getter/setter
5. Добавьте событие `catalog:selected` с payload `{ id: string }` — появится emit-хелпер
6. Добавьте CSS var без `--` — должна быть ошибка валидации
7. Добавьте слот `footer` с описанием — появится в комментарии к классу
