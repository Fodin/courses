# Задание 8.2: Конструктор Event Contract

## Цель

Создать интерактивный конструктор для описания типизированных контрактов коммуникации между MFE: добавление MFE и их событий (emit/listen), shared state slices, валидация и генерация TypeScript-кода.

## Требования

1. Список MFE с возможностью добавлять и удалять
2. Для каждого MFE: редактировать имя, добавлять и удалять события
3. Каждое событие имеет три поля: имя (mfe:action), направление (emit/listen), тип payload
4. Секция Shared State Slices: имя slice, тип, владелец (owner MFE), список читателей
5. Валидация в реальном времени: orphan emitter (отправляет, никто не слушает), orphan listener (слушает, никто не отправляет)
6. Зелёный баннер "Контракт валиден" когда предупреждений нет
7. Кнопка "Сгенерировать TypeScript" создаёт код: EventMap interface, EventBus class с типизированными emit/on, SharedState interface
8. Сгенерированный код отображается в тёмном блоке preformatted

## Чеклист

- [ ] Кнопка "+ Добавить MFE" добавляет пустой MFE с именем "newMFE"
- [ ] Кнопка "Удалить MFE" удаляет MFE (правый угол карточки)
- [ ] Поле ввода имени MFE (редактируемое)
- [ ] Кнопка "+ Событие" добавляет пустую строку события в MFE
- [ ] Строка события: input для имени + select emit/listen + input для payload type + кнопка удаления
- [ ] Select emit отображается синим, listen — зелёным
- [ ] Секция Shared State: имя | тип | owner | readers (через запятую)
- [ ] Валидация: orphan emitter → оранжевое предупреждение
- [ ] Валидация: orphan listener → оранжевое предупреждение
- [ ] Зелёный баннер при отсутствии предупреждений
- [ ] Начальное состояние: 2 MFE (catalog, cart) с событиями emit/listen
- [ ] Кнопка "Сгенерировать TypeScript" генерирует корректный TS-код
- [ ] EventMap содержит только emit-события
- [ ] EventBus имеет типизированные emit() и on() с unsubscribe
- [ ] SharedState interface включает все слайсы с комментариями owner
- [ ] Все стили inline

## Как проверить

1. Начальное состояние: 2 MFE, нет предупреждений (catalog emit + cart listen для catalog:add-to-cart)
2. Добавьте новый MFE, добавьте ему событие с direction "emit" — должно появиться предупреждение "никто не слушает"
3. Добавьте этому же событию listener в другом MFE — предупреждение должно исчезнуть
4. Нажмите "Сгенерировать TypeScript" — должен появиться валидный TS-код
5. В EventMap должны быть только emit-события (не listen)
6. EventBus должен иметь emit() и on() с generic-типами
7. Если есть SharedState slices — должен быть сгенерирован интерфейс SharedState
