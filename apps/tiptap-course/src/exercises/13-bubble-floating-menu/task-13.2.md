# Задание 13.2: FloatingMenu на пустой строке

## Цель

Реализовать `FloatingMenu` с кнопками для вставки блоков (заголовок, список, цитата), появляющийся, когда курсор находится на пустой строке.

## Требования

1. Создайте `editor` через `useEditor` с `StarterKit`
2. Импортируйте `FloatingMenu` из `@tiptap/react/menus`
3. Внутри `<FloatingMenu editor={editor}>` разместите три кнопки: "H2" (`toggleHeading({ level: 2 })`), "Список" (`toggleBulletList()`), "Цитата" (`toggleBlockquote()`)
4. Начальный контент должен содержать несколько заполненных параграфов и один пустой параграф в конце
5. Стилизуйте панель отдельно от BubbleMenu — например, горизонтальный ряд иконок слева от текста

## Чеклист

- [ ] Компонент называется `Task13_2` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.13.2')` используется в заголовке
- [ ] Меню появляется только когда курсор на пустой строке
- [ ] Меню не появляется, когда строка содержит текст
- [ ] Все три кнопки корректно применяют форматирование
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Поставьте курсор в пустой параграф в конце документа — должна появиться панель
2. Начните печатать текст — панель должна исчезнуть, как только строка перестанет быть пустой
3. Удалите весь текст в строке до пустой — панель должна снова появиться
4. Нажмите кнопку "H2" на пустой строке — она должна превратиться в заголовок
