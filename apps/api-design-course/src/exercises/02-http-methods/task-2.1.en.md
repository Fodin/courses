# Task 2.1 — HTTP Methods Matrix

## Goal

Study and memorize the properties of all key HTTP methods: safety, idempotency, request/response body presence, and typical usage. Use filtering to compare method groups.

## Requirements

1. The component displays a table of all HTTP methods: GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS.
2. For each method, four properties are shown: safety, idempotency, request body presence, response body presence.
3. Filter buttons allow displaying only safe, only idempotent, safe+idempotent, or all methods.
4. Clicking a row expands an explanation of the selected method's properties.
5. Methods are visually distinguished by color.

## Checklist

- [ ] Table with 7 HTTP methods
- [ ] Columns: method, safe, idempotent, request body, response body, usage
- [ ] Filters: all / safe / idempotent / safe+idempotent
- [ ] Click on row — detailed method description
- [ ] Color coding for methods

## How to Check Yourself

Without looking at the theory, answer: which methods are safe? Which are idempotent? Why is POST not idempotent? Check using filters and detail cards.
