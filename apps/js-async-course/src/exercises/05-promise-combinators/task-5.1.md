# Задание 5.1: Promise.all — параллельные загрузки

## Цель

Реализовать интерактивную визуализацию `Promise.all` с пятью параллельными «загрузками» и переключателями сбоя для каждой. Студент должен наглядно увидеть поведение fail-fast и понять, что Promise.all не отменяет уже запущенные промисы.

## Требования

1. **Пять загрузок** с прогресс-барами и разной скоростью:
   - Каждая загрузка имеет имя (Alpha, Beta, ...) и цветной прогресс-бар
   - Прогресс анимируется в реальном времени от 0 до 100%
   - После завершения прогресс-бар становится зелёным (fulfilled) или красным (rejected)

2. **Переключатели сбоев** — для каждой из пяти загрузок кнопка-тоггл «OK / СБОЙ»:
   - В режиме СБОЙ загрузка завершается ошибкой вместо значения
   - Тоггл меняет состояние до запуска (не во время)

3. **Поведение Promise.all**:
   - Без сбоев: все прогресс-бары дожидаются 100%, итог — массив значений
   - С хотя бы одним сбоем: после завершения первого упавшего — результат rejected
   - Оставшиеся загрузки помечаются «Продолжают выполняться (Promise.all не отменяет)»

4. **Блок результата** с разными стилями:
   - Зелёный блок при успехе: `Promise.all fulfilled: [...]`
   - Красный блок при ошибке: `Promise.all rejected (fail-fast): <сообщение>`
   - Пояснение что промисы всё равно продолжились

5. **Кнопки**: «Запустить Promise.all» и «Сброс»

6. **Сниппет кода** под визуализацией — показывает реальный API

## Чеклист

- [ ] Компонент называется `Task5_1` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован, заголовок берётся из `t('task.5.1')`
- [ ] Все 5 прогресс-баров анимируются параллельно
- [ ] Переключатели сбоев работают до запуска
- [ ] При наличии сбоя — показывается fail-fast поведение с красным результатом
- [ ] При отсутствии сбоев — зелёный массив всех значений
- [ ] Есть пояснение что оставшиеся промисы продолжают работать
- [ ] Кнопка «Сброс» возвращает всё в начальное состояние
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Откройте компонент — 5 прогресс-баров в состоянии ожидания
2. Нажмите «Запустить» без включённых сбоев — все 5 анимируются и становятся зелёными, результат — массив из 5 строк
3. Включите СБОЙ для Beta, нажмите «Запустить» — после завершения Beta появится красный блок; другие загрузки должны показать «Продолжают выполняться»
4. Включите СБОЙ для нескольких — первый упавший определяет rejected
5. «Сброс» — всё обнуляется
