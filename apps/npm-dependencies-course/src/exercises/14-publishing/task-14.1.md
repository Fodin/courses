# Задание 14.1: Квиз — Публикация пакетов

## Цель

Проверить понимание процесса публикации npm-пакетов: управление версиями через npm version, dist-tags и каналы обновлений, контроль содержимого пакета через поле files и npm pack, отличия deprecate от unpublish и политику 72 часов.

## Требования

1. Прочитайте теорию уровня (Кратко и Подробно)
2. Пройдите квиз
3. Для каждого вопроса разберите объяснения всех вариантов
