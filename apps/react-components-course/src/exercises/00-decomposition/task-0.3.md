# Задание 0.3: Декомпозиция Dashboard по ответственностям

## Цель

Разбить монолитный `Dashboard` на четыре компонента с чёткими зонами ответственности: `DashboardFilters` (управление фильтрами), `DashboardStats` (карточки со статистикой), `SalesChart` (визуализация графика через HTML/CSS), `DataTable` (таблица данных).

## Требования

1. Создайте интерфейс `DashboardFilters` с полями `period: 'day' | 'week' | 'month'` и `category: string`
2. Создайте компонент `FilterPanel`, который:
   - Принимает `filters` и `onChange`
   - Рендерит select для периода и select для категории
   - Не хранит state — только вызывает `onChange`
3. Создайте компонент `StatsCards`, который принимает массив `stats: StatItem[]` (название, значение, изменение в %) и отображает карточки. Положительное изменение — зелёное, отрицательное — красное
4. Создайте компонент `SalesChart`, который принимает массив `data: ChartPoint[]` (label, value) и рисует простой bar chart через `div` с CSS высотой
5. Создайте компонент `DataTable`, который принимает `rows: TableRow[]` и отображает таблицу с сортировкой по одному столбцу (локальный state: `sortField`, `sortDir`)
6. Компонент `Task0_3` — оркестратор: хранит `filters` в state, передаёт их дочерним компонентам, генерирует данные на основе фильтров

## Подсказки

- `FilterPanel` — dumb компонент: только контроллируемые inputs
- `StatsCards` и `SalesChart` — dumb компоненты без state
- `DataTable` может иметь локальный UI-state для сортировки — это нормально
- Данные можно генерировать статически или через простую функцию `generateData(filters)`
- Bar chart: высота `div` = `(value / maxValue) * 200px`

## Чеклист

- [ ] Интерфейсы `DashboardFilters`, `StatItem`, `ChartPoint`, `TableRow` определены
- [ ] `FilterPanel` — контролируемый компонент без собственного state
- [ ] `StatsCards` рендерит карточки с цветовой индикацией изменения
- [ ] `SalesChart` рисует bar chart через CSS высоты
- [ ] `DataTable` поддерживает сортировку по столбцу
- [ ] При смене фильтров данные обновляются
- [ ] `Task0_3` управляет state фильтров и координирует все компоненты

## Как проверить себя

1. Измените период фильтра — данные в таблице и графике должны измениться
2. Нажмите на заголовок столбца таблицы — строки должны отсортироваться
3. Повторное нажатие — обратная сортировка
4. Убедитесь, что смена фильтра не сбрасывает сортировку таблицы (состояния независимы)
