# Задание 9.2: Modal с discriminated props

## Цель

Реализовать компонент `Modal`, у которого три режима — `alert`, `confirm`, `form`. Для каждого режима TypeScript должен требовать свой набор обязательных пропсов. Использовать неправильную комбинацию должно быть невозможно на этапе компиляции.

## Требования

1. Тип `ModalProps` — discriminated union с тремя вариантами:
   - `variant: 'alert'` — обязательны: `message: string`, `onClose: () => void`
   - `variant: 'confirm'` — обязательны: `message: string`, `onConfirm: () => void`, `onCancel: () => void`
   - `variant: 'form'` — обязательны: `title: string`, `children: React.ReactNode`, `onSubmit: () => void`, `onCancel: () => void`
2. Компонент рендерит модальное окно с оверлеем
3. Каждый вариант имеет свой набор кнопок и содержимое
4. Демонстрация: три кнопки открывают три разных модалки. Переключение между вариантами через state

## Подсказки

- Объявляй union как `type ModalProps = AlertModalProps | ConfirmModalProps | FormModalProps`
- Дискриминирующее поле — `variant`; TypeScript сужает тип в каждой ветке `if (props.variant === 'confirm') { ... }`
- Для оверлея используй `position: fixed, inset: 0`
- Не нужно дополнительное состояние "открыт/закрыт" в самом Modal — управляй из родителя через условный рендер

## Чеклист

- [ ] `ModalProps` — discriminated union с полем `variant`
- [ ] Для `variant: 'confirm'` TypeScript требует `onConfirm` и `onCancel`
- [ ] Для `variant: 'form'` TypeScript требует `children` и `onSubmit`
- [ ] Попытка передать `message` в `variant: 'form'` вызывает ошибку TypeScript
- [ ] `alert` — показывает сообщение и кнопку "Закрыть"
- [ ] `confirm` — показывает сообщение и кнопки "Подтвердить" / "Отмена"
- [ ] `form` — показывает title, children и кнопки "Отправить" / "Отмена"
- [ ] В демо: три отдельных кнопки открывают три разных модалки

## Как проверить себя

Откройте задание в браузере. Вы должны увидеть три кнопки. При нажатии:
- "Показать Alert" — модалка с сообщением и одной кнопкой закрытия
- "Показать Confirm" — модалка с двумя кнопками; нажатие "Подтвердить" логирует действие
- "Показать Form" — модалка с формой (произвольный children) и кнопкой "Отправить"

Клик на оверлей может закрывать модалку (опционально, бонусное требование).
