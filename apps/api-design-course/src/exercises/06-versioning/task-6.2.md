# Задание 6.2: Timeline миграции API-версии

## Цель

Создать интерактивный timeline, который показывает процесс deprecation и sunset для API-версии:
от релиза новой версии до полного удаления старой.

## Требования

1. Показать timeline из 5 этапов: Релиз v2, Deprecation Notice, Sunset Date, Migration Guide, Удаление v1
2. Реализовать горизонтальный прогресс-бар с кружками-этапами
3. При клике на кружок или кнопку — переключаться на этот этап
4. Для каждого этапа показать:
   - Название и иконку
   - Описание что происходит
   - HTTP-заголовок, который сервер возвращает на этом этапе
5. Кнопки "Назад" / "Вперёд" для последовательного прохода
6. Блок с пояснением про RFC 8594

## Чеклист

- [ ] Горизонтальный timeline с заполняющейся линией прогресса
- [ ] Кружки-этапы кликабельны
- [ ] Пройденные этапы отображают иконку, не пройденные — пустой круг
- [ ] Цвет прогресса и рамки карточки меняется на цвет текущего этапа
- [ ] Заголовок ответа отображается в тёмном кодовом блоке
- [ ] Кнопка "Скрыть/Показать" для заголовка
- [ ] Кнопки навигации заблокированы на первом/последнем шаге
- [ ] Информационный блок с RFC 8594

## Как проверить себя

- Начальный шаг — Релиз v2 (зелёный). Заголовок: `X-API-Version: 2.0`
- Шаг Deprecation (жёлтый). Заголовок: `Deprecation: Tue, 01 Jan 2025 00:00:00 GMT`
- Шаг Sunset (оранжевый). Заголовок: `Sunset: Tue, 01 Jul 2025 00:00:00 GMT`
- Шаг Migration Guide (синий). Заголовок: `Link: <...>; rel="successor-version"`
- Последний шаг — Удаление v1 (красный). Показывает `HTTP/1.1 410 Gone`
- Кнопка "Вперёд" заблокирована на последнем шаге
