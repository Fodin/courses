# Задание 2.1: Обзор StarterKit

## Цель

Построить редактор с богатым начальным контентом, демонстрирующим все основные ноды и marks из `StarterKit`, и вывести список реально подключённых extensions.

## Требования

1. Создайте `editor` через `useEditor` с `StarterKit` (без конфигурации)
2. Задайте `content`, включающий: заголовок, параграф с **bold**, _italic_, ~~strike~~ и `code`, маркированный список, нумерованный список, blockquote, code block, horizontal rule
3. Под редактором выведите список имён активных extensions через `editor.extensionManager.extensions.map(ext => ext.name)`
4. Список должен отображаться как маркированный `<ul>`

## Чеклист

- [ ] Компонент называется `Task2_1` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.2.1')` используется в заголовке
- [ ] Начальный контент включает минимум 8 разных типов элементов (см. требования)
- [ ] Список активных extensions выводится и обновляется корректно
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Откройте задание — должны быть видны все перечисленные типы контента
2. Список extensions должен включать `doc`, `paragraph`, `text`, `bold`, `italic`, `heading`, `bulletList`, `codeBlock` и другие
3. Убедитесь, что `Ctrl+Z` (undo) работает — значит, `history` тоже в списке
