# Задание 4.2 — Envelope vs Flat

## Цель

Разобраться в двух подходах к структурированию API-ответов: envelope-паттерне и flat-стиле. Понять, когда каждый из них оправдан.

## Требования

1. Компонент показывает один и тот же ответ в двух стилях: envelope и flat.
2. Тумблер позволяет переключаться между подходами.
3. Предусмотрены четыре сценария: коллекция, одиночный ресурс, ошибка, создание ресурса.
4. Под каждым примером — комментарий: что это означает для клиента в данном контексте.
5. Блок плюсов и минусов каждого подхода обновляется при переключении тумблера.

## Чеклист

- [ ] Тумблер Envelope / Flat
- [ ] Минимум 3 сценария: коллекция, одиночный ресурс, ошибка
- [ ] Переключение между сценариями
- [ ] Комментарий к каждой комбинации подход+сценарий
- [ ] Плюсы и минусы обоих подходов
- [ ] Предупреждение о недопустимости смешения стилей

## Как проверить себя

Можете ли вы без подсказки ответить: в каком случае envelope оправдан, а в каком — избыточен? Если да, объясните это на примере двух конкретных endpoints вашего последнего проекта.
