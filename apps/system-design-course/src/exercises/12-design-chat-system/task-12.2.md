# Задание 12.2: Симулятор доставки сообщений

## Цель

Реализовать интерактивный симулятор мессенджера с двумя клиентами, статусами доставки (sent → delivered → read), offline-режимом и очередью недоставленных сообщений.

## Требования

1. **Два клиента** (Alice и Bob) — каждый может отправлять сообщения другому
2. **Статусы доставки** — каждое сообщение отображает текущий статус:
   - ✓ SENT — сервер принял сообщение
   - ✓✓ DELIVERED — сообщение доставлено на устройство получателя
   - ✓✓ READ (синие) — получатель прочитал сообщение
3. **Кнопка Online/Offline** для каждого клиента — переключает режим
4. **Offline-очередь** — сообщения, отправленные офлайн-получателю, копятся в очереди
5. **Reconnect** — при переходе в Online все накопленные сообщения доставляются
6. **Кнопка "Прочитать"** — ставит READ-статус на все доставленные сообщения в чате

## Чеклист

- [ ] Два клиента могут обмениваться сообщениями
- [ ] Статус SENT появляется мгновенно после отправки
- [ ] Статус DELIVERED появляется, если получатель онлайн
- [ ] Статус остаётся SENT, если получатель офлайн
- [ ] При переходе получателя в Online — все SENT-сообщения становятся DELIVERED
- [ ] Кнопка «Прочитать» переводит DELIVERED в READ
- [ ] Offline-очередь отображается визуально (количество ожидающих сообщений)
- [ ] UI показывает текущий статус каждого клиента (Online/Offline)

## Как проверить себя

1. Отправьте сообщение от Alice к Bob (оба онлайн) — статус должен стать DELIVERED
2. Переключите Bob в Offline, отправьте сообщение — статус должен быть SENT
3. Переключите Bob обратно в Online — статус должен стать DELIVERED
4. Нажмите «Прочитать» у Bob — статус должен стать READ (синие галочки)
5. Проверьте, что offline-очередь показывает правильное количество сообщений
