# Задание 14.9: Вложенные формы и поля

## Цель

Научиться работать с глубоко вложенными объектами и разделять форму на переиспользуемые подформы.

## Требования

1. Создайте форму регистрации компании с вложенной структурой:
   - Название компании (строка)
   - Адрес (вложенный объект: страна, город, улица, индекс)
   - Контакты: основной и для биллинга (каждый — объект с именем и email)
2. Вынесите адрес и контакт в отдельные компоненты-подформы
3. Используйте `FormProvider` / `useFormContext` для доступа к форме из подкомпонентов
4. Реализуйте чекбокс «Копировать основной контакт в биллинг»
5. Поля регистрируются через точечную нотацию (`address.city`, `contacts.primary.email`)
6. При сабмите покажите итоговый JSON с вложенной структурой

## Чеклист

- [ ] Форма содержит вложенные объекты (address, contacts.primary, contacts.billing)
- [ ] Подформы — отдельные компоненты, использующие useFormContext
- [ ] Точечная нотация в register для вложенных полей
- [ ] Чекбокс «Копировать в биллинг» работает через setValue
- [ ] Валидация работает на всех уровнях вложенности
- [ ] Ошибки отображаются корректно для вложенных полей
- [ ] При сабмите данные сохраняют вложенную структуру

## Как проверить себя

1. Нажмите Submit с пустой формой — ошибки должны появиться на всех уровнях
2. Заполните основной контакт, поставьте чекбокс — биллинг должен скопироваться
3. Заполните все поля и отправьте — JSON должен содержать вложенные объекты
4. Проверьте что подформы переиспользуемы (один компонент для primary и billing)
