# Задание 12.2: addProseMirrorPlugins и decorations

## Цель

Реализовать плагин, автоматически подсвечивающий все вхождения слова "TODO" в тексте через `Decoration`, без изменения самого документа.

## Требования

1. Создайте `Extension.create({ name: 'highlightTodo', addProseMirrorPlugins() {...} })`
2. Внутри плагина реализуйте `props.decorations(state)`, обходящий документ через `state.doc.descendants(...)`, ищущий регулярным выражением `/TODO/g` все текстовые узлы
3. Для каждого совпадения создавайте `Decoration.inline(from, to, { class: 'todo-highlight' })`
4. Верните `DecorationSet.create(state.doc, decorations)`
5. Стилизуйте `.todo-highlight` через CSS: жёлтый фон, жирный текст
6. Подключите extension вместе со `StarterKit`, начальный контент должен содержать несколько вхождений "TODO" в разных местах

## Чеклист

- [ ] Компонент называется `Task12_2` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.12.2')` используется в заголовке
- [ ] Все вхождения "TODO" в тексте подсвечиваются автоматически
- [ ] Подсветка обновляется в реальном времени при редактировании (добавление нового "TODO" сразу подсвечивается)
- [ ] `editor.getHTML()` НЕ содержит класс `todo-highlight` (декорации не часть документа!)
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Откройте задание — все "TODO" в начальном тексте должны быть подсвечены
2. Напечатайте новое "TODO" в любом месте текста — оно должно подсветиться сразу же
3. Удалите одно из вхождений "TODO" — подсветка должна исчезнуть вместе с текстом
4. Выведите `editor.getHTML()` под редактором — убедитесь, что класс `todo-highlight` там отсутствует (декорации не сохраняются в документе)
