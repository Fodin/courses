# Задание 3.1: Квиз — Состояние, мутабельность, идемпотентность

## Цель
Проверить понимание иммутабельности, скрытого состояния и идемпотентности операций.

## Требования
1. Прочитайте теорию уровня 3 (README)
2. Пройдите квиз по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист
- [ ] Прочитана теория по иммутабельности и её преимуществам
- [ ] Прочитана теория по скрытому состоянию и его проблемам

- [ ] Прочитана теория по управлению состоянием (FSM, single source of truth)
- [ ] Пройден квиз с результатом не менее 80%

## Как проверить себя
1. Откройте квиз и ответьте на все вопросы
2. Проверьте объяснения для неправильных ответов
3. Если результат ниже 80% — перечитайте соответствующие разделы теории
