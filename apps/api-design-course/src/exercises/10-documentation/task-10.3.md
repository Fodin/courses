# Задание 10.3: Оценка реальных API

## Цель

Применить критерии из задания 10.1 к реальным публичным API и сформировать объективную оценку качества их документации.

## Требования

1. Оценить три публичных API: Stripe, GitHub, Twitter/X
2. Каждый API оценивается по 10 критериям с баллом от 1 до 10
3. Показать итоговый балл (среднее) с цветовой индикацией (зелёный 9-10, жёлтый 7-8, красный 5-6)
4. Каждый критерий — кликабельная карточка, при клике раскрывается комментарий-обоснование оценки
5. Мини-прогресс-бар внутри каждой карточки визуализирует балл
6. Кнопка "Показать сравнение всех трёх API" — раскрывает сводную таблицу
7. В таблице: строки — критерии, колонки — API, последняя строка — итоговый балл

## Критерии оценки

- Getting Started
- Аутентификация
- Reference
- Примеры кода
- Коды ошибок
- Интерактивность
- SDK / библиотеки
- Sandbox / тестовая среда
- Changelog
- Поиск по документации

## Эталонные оценки

**Stripe** — золотой стандарт (средняя оценка ~9.8/10): лучшие примеры на 8 языках, отличный sandbox с тестовыми картами  
**GitHub** — хорошая документация (средняя ~7.6/10): полный reference, но без Try it out и sandbox  
**Twitter/X** — достаточная (средняя ~6.2/10): есть всё необходимое, но качество ниже конкурентов

## Чеклист

- [ ] Три кнопки-таба для выбора API
- [ ] Итоговая карточка с цветным баллом и tagline
- [ ] 10 карточек критериев с баллами и прогресс-барами
- [ ] Клик на карточку — раскрывает обоснование
- [ ] Цветовая индикация баллов (зелёный / жёлтый / красный)
- [ ] Кнопка "Показать сравнение" — сводная таблица
- [ ] Итоговая строка в таблице с баллами всех трёх API

## Как проверить себя

1. Переключитесь между Stripe, GitHub и Twitter/X — данные должны меняться
2. Кликните на несколько карточек критериев — должны раскрываться комментарии
3. Нажмите "Показать сравнение" — должна появиться таблица со всеми тремя API
4. Убедитесь, что итоговые баллы в таблице совпадают с баллами в карточках
5. Проверьте цветовую индикацию: Stripe должен быть зелёным, Twitter/X — красным
