# Задание 3.1 — Ручное каррирование

## Цель

Реализовать универсальную функцию `curry`, которая принимает функцию произвольной арности
и возвращает каррированную версию. Показать интерактивную демонстрацию разных способов вызова.

## Требования

1. Реализуйте функцию `curry(fn)`:
   - Определяет арность через `fn.length`
   - Если передано достаточно аргументов — вызывает `fn`
   - Если аргументов не хватает — возвращает функцию, ждущую оставшиеся
   - Поддерживает смешанный вызов: `f(a, b)(c)`, `f(a)(b, c)`, `f(a)(b)(c)`, `f(a, b, c)`

2. Создайте каррированную функцию `add3 = curry((a, b, c) => a + b + c)`

3. Добавьте три поля ввода для аргументов a, b, c (числа)

4. Добавьте четыре кнопки, каждая демонстрирует один способ вызова:
   - `add3(a)(b)(c)` — строго по одному
   - `add3(a, b)(c)` — два, потом один
   - `add3(a)(b, c)` — один, потом два
   - `add3(a, b, c)` — сразу все

5. Каждая кнопка добавляет в лог шаги с промежуточными результатами:
   - промежуточный вызов показывает `function (ждёт аргументов)`
   - финальный вызов показывает числовой результат

## Чеклист

- [ ] `curry` реализована через рекурсию с накоплением аргументов
- [ ] `curry` не ломает функции с полным числом аргументов
- [ ] Лог очищается по кнопке "Очистить"
- [ ] При изменении a, b, c кнопки вызова обновляют свои метки

## Как проверить себя

Откройте компонент и нажмите все четыре кнопки с разными значениями a, b, c.
Убедитесь что во всех случаях финальный результат равен `a + b + c`.
Проверьте что промежуточные вызовы не вызывают ошибок.

**Подсказка:** Ключ реализации — сравнение `args.length >= arity`. Когда накоплено
достаточно аргументов — вызываем оригинальную функцию. Иначе — возвращаем
новую функцию через `(...more) => curried(...args, ...more)`.
