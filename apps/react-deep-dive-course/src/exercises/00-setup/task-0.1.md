# Задание 0.1: Диаграмма Trigger / Render / Commit

## Цель

Построить интерактивную диаграмму трёх фаз React. Каждая фаза кликабельна — при клике она подсвечивается и внизу появляется её описание. Это поможет закрепить понимание того, что делает React на каждом шаге.

## Требования

1. Создать массив данных с тремя фазами: `Trigger`, `Render`, `Commit`. У каждой фазы — название, короткое описание и цвет.
2. Хранить активную фазу в `useState` (по умолчанию — первая фаза или `null`).
3. При клике на фазу — устанавливать её как активную.
4. Активная фаза должна быть визуально выделена (другой фон, рамка или увеличенный размер).
5. Под диаграммой отображать описание активной фазы.
6. Между фазами нарисовать стрелки (например, символом `→`).
7. Использовать только `useState` и `inline CSS` — без внешних библиотек.

## Чеклист

- [ ] Три блока фаз расположены горизонтально
- [ ] Между блоками есть стрелки `→`
- [ ] Клик на фазу меняет состояние через `useState`
- [ ] Активная фаза визуально отличается от неактивных
- [ ] Под диаграммой отображается описание выбранной фазы
- [ ] Компонент не крашится при первом рендере (есть состояние по умолчанию)

## Как проверить себя

1. Открой компонент в браузере — должны быть видны три блока с подписями Trigger, Render, Commit.
2. Кликни на "Render" — блок должен подсветиться, внизу появится описание про вызов функций компонентов.
3. Кликни на "Commit" — предыдущая фаза перестаёт быть активной, появляется описание про изменение DOM.
4. Открой React DevTools Profiler и запиши клик — убедись, что рендер происходит только при смене активной фазы.
