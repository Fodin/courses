# Задание 11.1: Архитектурное сравнение брокеров

## Цель

Реализовать интерактивную сравнительную таблицу пяти брокеров сообщений (Kafka, RabbitMQ, NATS, Redis Streams, Pulsar) с детальными описаниями по каждому критерию. Студент должен самостоятельно собрать данные о каждом брокере и построить компонент с hover-эффектами и разворачиваемыми деталями.

## Требования

1. Определить интерфейс `BrokerRow` с полями: `broker: string`, `model: string`, `ordering: string`, `throughput: string`, `latency: string`, `persistence: string`, `protocol: string`, `clustering: string`, `color: string`, а также вложенным объектом `details` с теми же ключами от `model` до `clustering` — для развёрнутых объяснений.
2. Заполнить массив `BROKERS` из 5 элементов (Kafka, RabbitMQ, NATS, Redis Streams, Pulsar) с кратким значением каждого критерия (например, `throughput: '★★★★★'`) и подробным текстом в `details`.
3. Объявить константу `CRITERIA` — кортеж из 7 строк (`'model' | 'ordering' | 'throughput' | 'latency' | 'persistence' | 'protocol' | 'clustering'`) и словарь `CRITERION_LABELS` для русских названий.
4. Реализовать состояния: `detailBroker: string | null` (какой брокер раскрыт), `detailCriterion: Criterion | null` (какой критерий выбран), `highlightBroker: string | null` (hover).
5. Отрисовать таблицу: строки — брокеры, столбцы — критерии. При наведении строка подсвечивается.
6. Клик по имени брокера — раскрывает/скрывает детальный блок (стрелка ▼/▲).
7. Клик по ячейке критерия — открывает детальный блок для этого брокера с фокусом на выбранный критерий.
8. Детальный блок: при выбранном критерии показывает только его описание; без критерия — сетку всех 7 критериев с превью текста (первые 80 символов). Клик по плашке критерия — фокусируется на нём.
9. Кнопка "Закрыть" сбрасывает `detailBroker` и `detailCriterion`.
10. Внизу — легенда с цветными именами брокеров и счётчиком "5 брокеров · 7 критериев".

## Чеклист

- [ ] Интерфейс `BrokerRow` определён со всеми полями включая `details`
- [ ] Массив `BROKERS` содержит все 5 брокеров с краткими значениями и описаниями
- [ ] `CRITERIA` — кортеж из 7 значений, `CRITERION_LABELS` — русские переводы
- [ ] Hover по строке подсвечивает её фоном
- [ ] Клик по имени брокера раскрывает/скрывает детальный блок
- [ ] Стрелка ▼/▲ отображается рядом с именем брокера
- [ ] Клик по ячейке открывает детальный блок с фокусом на критерий
- [ ] Детальный блок показывает полное описание выбранного критерия
- [ ] Без выбранного критерия — сетка превью всех 7 критериев
- [ ] Цвет рамки детального блока соответствует цвету брокера
- [ ] Кнопка "Закрыть" сбрасывает оба состояния
- [ ] Легенда снизу с именами всех брокеров и счётчиком

## Как проверить себя

1. Откройте задание и убедитесь, что таблица отображает 5 строк (брокеры) и 7 столбцов (критерии).
2. Наведите мышь на строку "Apache Kafka" — фон строки должен измениться.
3. Нажмите на "Apache Kafka" — появится детальный блок с рамкой красного цвета (#e74c3c). Рядом с именем стрелка ▲.
4. Нажмите на ячейку "Throughput" в строке Kafka — блок должен показать подробное описание throughput Kafka.
5. Нажмите "Закрыть" — блок исчезает, стрелка снова ▼.
6. Нажмите на ячейку "Latency" для RabbitMQ напрямую — блок должен открыться для RabbitMQ с описанием latency.
7. Проверьте, что при открытом блоке без выбранного критерия видны 7 плашек с превью текста (~80 символов).
