# Задание 6.1: Каталог типов раннеров и executors

## Цель

Создать интерактивный каталог executor-ов GitLab Runner с карточками, сравнительной таблицей и фильтрацией по критериям.

## Требования

1. Определи интерфейс `Executor` со свойствами:
   - `id: string` — уникальный идентификатор (docker, shell, kubernetes, docker-machine)
   - `name: string` — отображаемое имя
   - `description: string` — краткое описание принципа работы
   - `pros: string[]` — список преимуществ
   - `cons: string[]` — список недостатков
   - `useCases: string[]` — когда использовать
   - `isolation: 'full' | 'partial' | 'none'` — уровень изоляции
   - `speed: 'fast' | 'medium' | 'slow'` — скорость старта
   - `complexity: 'low' | 'medium' | 'high'` — сложность настройки

2. Создай данные для 4 executor-ов: Docker, Shell, Kubernetes, Docker Machine

3. Реализуй отображение карточек (по 2 в ряд) с:
   - Названием и описанием
   - Бейджами isolation / speed / complexity
   - Списками плюсов (✅) и минусов (❌)
   - Разворачиваемым разделом "Use cases"

4. Добавь фильтрацию по уровню изоляции (All / Full / Partial / None)

5. Добавь сравнительную таблицу внизу страницы с колонками: Executor, Изоляция, Скорость, Сложность, Нужен Docker

6. При клике на карточку — выделяй её (selected state) и показывай пример config.toml для этого executor-а

## Ожидаемый результат

- Карточки с визуальными индикаторами характеристик
- Рабочая фильтрация по изоляции
- Сравнительная таблица
- При выборе executor-а — пример конфигурации

## Чеклист

- [ ] Интерфейс `Executor` с типизированными полями isolation/speed/complexity
- [ ] Данные для всех 4 executor-ов
- [ ] Карточки отображают pros, cons, бейджи
- [ ] Фильтр по isolation работает корректно
- [ ] Таблица показывает сравнение всех 4 executor-ов
- [ ] Клик по карточке показывает пример config.toml
- [ ] Весь код типизирован, нет any

## Как проверить себя

Нажми на карточку "Docker" — внизу должен появиться пример config.toml с `executor = "docker"`. Выбери фильтр "None" — должна остаться только карточка Shell executor. Таблица должна показывать 4 строки вне зависимости от фильтра.
