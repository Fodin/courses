# Задание 2.2 — Подбери метод для сценария

## Цель

Закрепить умение выбирать правильный HTTP-метод для реальных практических ситуаций. Научиться обосновывать выбор, опираясь на семантику методов, а не на интуицию.

## Требования

1. Компонент отображает 8–10 практических сценариев с описанием контекста.
2. Для каждого сценария пользователь выбирает метод из списка (GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS).
3. После выбора можно нажать «Проверить» для одного сценария или «Проверить все» для всех сразу.
4. При верном ответе — зелёное поле с объяснением. При неверном — красное, с правильным ответом и объяснением.
5. Кнопка «Сбросить» возвращает в начало.
6. В конце — итоговый счёт (правильных / всего).

## Чеклист

- [ ] Не менее 8 сценариев, охватывающих все 7 методов
- [ ] Выбор метода кнопками (все 7 вариантов)
- [ ] Проверка отдельного сценария и всех сразу
- [ ] Объяснение при правильном и неправильном ответе
- [ ] Итоговый счёт
- [ ] Сброс к начальному состоянию

## Как проверить себя

Пройдите все сценарии без подсказок. Обратите внимание на сценарии, где ошиблись: прочитайте объяснение и попробуйте сформулировать правило своими словами.
