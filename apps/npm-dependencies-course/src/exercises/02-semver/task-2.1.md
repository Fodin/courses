# Задание 2.1: Квиз — Семантическое версионирование

## Цель

Освоить операторы semver (^, ~, диапазоны), понять особое поведение ^0.x.x и научиться предсказывать, какую версию выберет npm для заданного диапазона.

## Требования

1. Прочитайте теорию уровня (Кратко и Подробно)
2. Пройдите квиз
3. Для каждого вопроса разберите объяснения всех вариантов
