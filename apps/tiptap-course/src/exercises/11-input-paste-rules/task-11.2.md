# Задание 11.2: Paste rules: автоссылки

## Цель

Реализовать автоматическое превращение вставленного URL в ссылку через `markPasteRule`, отдельно от input rule (которая реагирует на набор текста).

## Требования

1. Создайте кастомный `Mark.create({ name: 'autoLink', ... })` с `addAttributes()` для `href`
2. Реализуйте `addPasteRules()`, использующий `markPasteRule({ find: /https?:\/\/[^\s]+/g, type: this.type, getAttributes: (match) => ({ href: match[0] }) })`
3. `parseHTML()`/`renderHTML()` — сериализация как обычная ссылка `<a href="...">`
4. Подключите mark вместе со `StarterKit`
5. Предоставьте текстовое поле (обычный `<input>`, отдельно от редактора) с готовым текстом, содержащим URL, и кнопку "Скопировать", чтобы пользователь мог вставить его в редактор через `Ctrl+V`

## Чеклист

- [ ] Компонент называется `Task11_2` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.11.2')` используется в заголовке
- [ ] Вставка текста с URL через Ctrl+V автоматически создаёт ссылку
- [ ] Обычный набор того же URL с клавиатуры (без вставки) НЕ создаёт ссылку — это демонстрирует разницу paste rule vs input rule
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Скопируйте в буфер обмена текст вида `Смотрите https://tiptap.dev для примеров`
2. Вставьте его в редактор через `Ctrl+V` — URL должен автоматически стать ссылкой
3. Наберите тот же URL вручную посимвольно — ссылка автоматически не должна появиться (нет соответствующего input rule)
4. Проверьте `editor.getHTML()` — вставленный URL должен быть обёрнут в `<a href="https://...">`
