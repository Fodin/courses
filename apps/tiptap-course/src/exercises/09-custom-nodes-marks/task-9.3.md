# Задание 9.3: Настраиваемые атрибуты

## Цель

Расширить `callout` из задания 9.2 атрибутом `type` (`info` | `warning` | `error`), меняющим визуальное оформление, с UI для переключения типа.

## Требования

1. Добавьте в `Callout` из 9.2 (можно скопировать и расширить) `addAttributes()` с полем `type`: `default: 'info'`, `parseHTML` читает `data-callout-type`, `renderHTML` записывает `data-callout-type`
2. Реализуйте команду `setCalloutType: (type: 'info' | 'warning' | 'error') => ({ commands }) => commands.updateAttributes(this.name, { type })`
3. В React-компоненте добавьте три кнопки: "Info", "Warning", "Error" — каждая меняет тип текущей врезки через `setCalloutType`
4. Через CSS (по атрибуту `data-callout-type`) задайте разные цвета фона/рамки для каждого типа: info — синий, warning — жёлтый, error — красный

## Чеклист

- [ ] Компонент называется `Task9_3` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.9.3')` используется в заголовке
- [ ] Атрибут `type` корректно сохраняется и восстанавливается из HTML
- [ ] Переключение типа меняет визуальное оформление врезки без потери содержимого
- [ ] Три типа визуально различимы
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Вставьте врезку (кнопка "Вставить врезку" из 9.2 или аналогичная здесь), проверьте — по умолчанию она должна быть типа `info` (синяя)
2. Переключите на "Warning" — цвет должен смениться на жёлтый, текст внутри — сохраниться
3. Проверьте HTML-вывод — `data-callout-type="warning"` должен присутствовать
