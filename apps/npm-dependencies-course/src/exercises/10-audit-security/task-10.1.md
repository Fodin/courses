# Задание 10.1: Квиз — Безопасность и npm audit

## Цель

Научиться читать отчёты npm audit, понимать уровни severity, выбирать правильную стратегию исправления уязвимостей и грамотно настраивать audit в CI-пайплайне.

## Требования

1. Прочитайте теорию уровня (Кратко и Подробно)
2. Пройдите квиз
3. Для каждого вопроса разберите объяснения всех вариантов
