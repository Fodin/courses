# Задание 9.1 — Барель своего слайса замыкает цикл (простое)

## Цель

Увидеть, что цикл может возникнуть даже внутри ОДНОГО слайса — если сегмент вместо прямого импорта соседа проходит через собственный `index.ts`.

## Что дано

- `entities/user/model/name.ts` — `formatName` (🔒 только чтение).
- `entities/user/model/greet.ts` — импортирует `formatName` не напрямую из `./name`, а через `../index` (собственный public API слайса).
- `entities/user/index.ts` — реэкспортирует и `formatName`, и `greet` (🔒 только чтение).

## Требования

1. В `model/greet.ts` замените импорт `from '../index'` на прямой импорт соседа: `from './name'`.
2. Импорт `formatName` внутри слайса не должен идти через `index.ts` этого же слайса.
3. Нажмите «Проверить» — обе проверки должны стать зелёными.

## Чеклист

- [ ] `greet.ts` импортирует `formatName` из `./name`, а не из `../index`
- [ ] Проверка `noRuntimeCycles` — зелёная
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

Задайте вопрос: «Зачем сегменту одного слайса ходить через свой же public API?» — незачем, это и создаёт цикл `greet.ts → index.ts → greet.ts`. Внутри слайса сегменты вольны импортировать друг друга напрямую.
