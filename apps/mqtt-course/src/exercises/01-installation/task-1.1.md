# Задание 1.1: Установка Mosquitto через opkg

## Цель

Освоить пошаговый процесс установки Mosquitto на OpenWRT. Реализовать интерактивную пошаговую инструкцию с возможностью отмечать выполненные шаги, просматривать вывод команд и отслеживать прогресс.

---

## Требования

1. Определи интерфейс `InstallStep` с полями: `id`, `command`, `description`, `output` (ожидаемый вывод), `category` (`'prepare' | 'install' | 'verify'`)

2. Создай массив `installSteps` с минимум 6 шагами, охватывающими: `opkg update`, установку брокера, установку клиентских утилит, включение автозапуска, запуск и проверку

3. Реализуй прогресс-бар в верхней части компонента, показывающий количество выполненных шагов и процент. При 100% показывай поздравление.

4. Каждый шаг отображается как карточка с:
   - Чекбоксом (клик помечает шаг как выполненный)
   - Номером и командой в моноширинном шрифте
   - Бейджем категории (цветной)
   - Кнопкой копирования команды в буфер обмена
   - Стрелкой для раскрытия/скрытия деталей

5. При раскрытии шага показывать: описание и ожидаемый вывод (в стиле терминала, если есть) или пояснение "Нет вывода"

6. Категории должны иметь разные цвета: prepare (синий), install (фиолетовый), verify (зелёный)

---

## Чеклист

- [ ] Определён интерфейс `InstallStep` с полем `category`
- [ ] Массив из 6+ шагов с реалистичными командами OpenWRT/Mosquitto
- [ ] Прогресс-бар с анимированным заполнением
- [ ] Счётчик выполненных шагов (X/N, процент)
- [ ] Каждый шаг — раскрываемая карточка
- [ ] Чекбокс отмечает шаг как выполненный (смена цвета карточки)
- [ ] Кнопка копирования команды (с визуальным подтверждением ✓)
- [ ] Ожидаемый вывод в стиле терминала (тёмный фон)
- [ ] Цветные бейджи категорий
- [ ] Поздравление при 100% выполнении
- [ ] Корректная типизация TypeScript

---

## Как проверить себя

1. Видишь прогресс-бар с "0/N (0%)"?
2. Нажми чекбокс на первом шаге — прогресс изменился, карточка позеленела?
3. Нажми стрелку на шаге `opkg install mosquitto-nossl` — видишь вывод установки?
4. Нажми иконку копирования — кнопка изменилась на "✓"?
5. Отметь все шаги — появляется поздравление?
