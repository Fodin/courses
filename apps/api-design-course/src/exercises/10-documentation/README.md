# Уровень 10: Документация API

## Документация как часть DX

**Developer Experience (DX)** — это то, насколько легко и приятно разработчику работать с вашим API. Хорошая документация — главный компонент DX.

Плохая документация = разработчик уходит к конкуренту. Хорошая = разработчик становится евангелистом вашего продукта.

## Что должна содержать хорошая документация

| Элемент | Зачем |
|---------|-------|
| Getting Started | Первый рабочий запрос за 5 минут |
| Аутентификация | Как получить и использовать credentials |
| Reference | Полный справочник всех endpoints |
| Примеры кода | Копируемые примеры на нескольких языках |
| Коды ошибок | Что значит каждая ошибка и как её исправить |
| Rate limits | Ограничения и заголовки ответа |
| Sandbox | Безопасная среда для тестирования |
| SDK | Официальные библиотеки |
| Changelog | История изменений и breaking changes |

## Основные инструменты

**Swagger UI** — интерактивная документация из OpenAPI-спецификации. Try it out прямо в браузере. Идеален для внутренних команд и API-экспериментов.

**Redoc** — красивый трёхколоночный layout из OpenAPI. Лучший выбор для публичного developer portal, когда важны дизайн и читаемость.

**Stoplight** — полная платформа: дизайн API + документация + mock-сервер + линтинг. Для enterprise и крупных команд.

## Эталоны

- **Stripe** — золотой стандарт: примеры на 8 языках, интерактивный explorer, тестовые данные
- **Twilio** — отличный quickstart, понятная структура
- **GitHub** — полный reference, хорошая поддержка GraphQL
