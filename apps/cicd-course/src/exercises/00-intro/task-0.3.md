# Задание 0.3: Ландшафт CI/CD инструментов

## Цель

Изучить основные CI/CD инструменты и их характеристики. Реализовать интерактивные карточки с возможностью фильтрации и сравнения инструментов по ключевым параметрам.

---

## Что нужно сделать

Создай компонент `Task0_3`, который отображает карточки CI/CD инструментов с фильтрацией и сравнением.

### Требования

1. Определи TypeScript-интерфейс `CITool` с полями:
   - `id` — уникальный идентификатор
   - `name` — название инструмента
   - `type` — тип: `'saas' | 'self-hosted' | 'both'`
   - `free` — наличие бесплатного плана (boolean)
   - `configFile` — название конфигурационного файла (строка)
   - `ecosystem` — уровень экосистемы: `'small' | 'medium' | 'large'`
   - `setupComplexity` — сложность настройки: `'low' | 'medium' | 'high'`
   - `bestFor` — массив строк (сценарии использования)
   - `pros` — массив строк (преимущества)
   - `cons` — массив строк (недостатки)
   - `color` — цвет карточки (hex)

2. Создай массив `tools` с данными для 5 инструментов:
   - GitHub Actions
   - GitLab CI
   - Jenkins
   - CircleCI
   - Travis CI

3. Реализуй состояние для фильтрации по типу (`'all' | 'saas' | 'self-hosted'`)

4. Реализуй состояние `selectedTool` — хранит id выбранного инструмента для детального просмотра или `null`

5. Отобрази кнопки фильтров: "Все", "SaaS", "Self-hosted"

6. Отобрази карточки инструментов в виде сетки (flex wrap). Каждая карточка содержит:
   - Название и тип (бейдж SaaS/Self-hosted)
   - Иконку бесплатного плана (если есть)
   - Сложность настройки (цветные точки или шкала)
   - Кнопку "Подробнее"

7. При клике "Подробнее" показывай детальную панель с:
   - Конфигурационным файлом
   - Списком плюсов и минусов
   - Сценариями использования (bestFor)

---

## Ожидаемый результат

- Кнопки фильтрации по типу (All / SaaS / Self-hosted)
- Сетка карточек с базовой информацией
- Детальная панель при клике на карточку
- Визуальные индикаторы сложности настройки

## Как проверить себя

1. Открой компонент — видишь карточки всех 5 инструментов?
2. Нажми фильтр "SaaS" — остались только GitHub Actions, GitLab CI (saas), CircleCI?
3. Нажми фильтр "Self-hosted" — остались Jenkins и GitLab CI (both)?
4. Кликни "Подробнее" у Jenkins — видишь высокую сложность настройки и список плюсов/минусов?
5. Кликни "Подробнее" у GitHub Actions — конфигурационный файл `.github/workflows/*.yml`?
