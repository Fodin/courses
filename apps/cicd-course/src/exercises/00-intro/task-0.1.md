# Задание 0.1: CI vs CD vs CD — разбираемся в терминах

## Цель

Понять и закрепить разницу между тремя ключевыми концепциями: Continuous Integration, Continuous Delivery и Continuous Deployment. Реализовать интерактивную сравнительную таблицу, которая наглядно показывает чем они отличаются.

---

## Что нужно сделать

Создай компонент `Task0_1`, который отображает интерактивную таблицу сравнения трёх концепций CI/CD.

### Требования

1. Определи TypeScript-интерфейс `PhaseInfo` с полями:
   - `id` — уникальный идентификатор (`'ci' | 'delivery' | 'deployment'`)
   - `title` — название концепции (например, `'Continuous Integration'`)
   - `shortName` — короткое название (`'CI'`, `'C.Delivery'`, `'C.Deployment'`)
   - `goal` — основная цель фазы (строка)
   - `automatedSteps` — список автоматизированных шагов (массив строк)
   - `manualStep` — ручной шаг, если есть (строка или `null`)
   - `frequency` — как часто происходит (строка)
   - `color` — цвет для визуального выделения (строка с hex-кодом)

2. Создай массив `phases` с данными для всех трёх концепций

3. Реализуй состояние `selectedPhase` — хранит id выбранной фазы или `null`

4. Отобрази три карточки (по одной на концепцию) в ряд через flex. При клике на карточку она должна раскрываться и показывать детальную информацию

5. В раскрытой карточке покажи:
   - Список автоматических шагов с зелёными иконками (✅)
   - Ручной шаг (если есть) с жёлтой иконкой (⚠️) или надпись "Полностью автоматизировано" с зелёной иконкой (✅)
   - Частоту деплоев

6. Добавь секцию "Активности" — список из 6-8 действий (например: "запустить тесты", "задеплоить на prod", "собрать Docker-образ"), которые студент должен отнести к нужной фазе с помощью drag-and-drop или кнопок

---

## Ожидаемый результат

- Три карточки с цветовым выделением: синяя (CI), жёлтая (Delivery), зелёная (Deployment)
- Клик по карточке показывает детали этой фазы
- Визуальное различие между ручным шагом и автоматическим
- Список активностей с возможностью отнести каждую к нужной фазе

3. Кликни на "Continuous Deployment" — видишь "Полностью автоматизировано" (нет ручного шага)?
