# Задание 7.1: Квиз — Диагностика дерева зависимостей

## Цель

Освоить инструменты диагностики npm: уметь читать вывод npm ls, интерпретировать маркеры проблем, находить источник зависимости через npm explain и проверять окружение через npm doctor.

## Требования

1. Прочитайте теорию уровня (Кратко и Подробно)
2. Пройдите квиз
3. Для каждого вопроса разберите объяснения всех вариантов
