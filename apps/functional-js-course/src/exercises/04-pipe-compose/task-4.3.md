# Задание 4.3 — Builder через pipe

## Цель

Реализовать функциональный паттерн Builder: каждый шаг-функция принимает конфиг и возвращает расширенный конфиг. Pipe собирает шаги в цепочку.

## Требования

1. Реализуйте 5 функций-шагов, каждая возвращает `ConfigStep = (cfg: AppConfig) => AppConfig`:
   - `withDatabase(type)` — добавляет `{db: {type, host, port}}`
   - `withPort(port)` — добавляет `{server: {port}}`
   - `withLogging(level)` — добавляет `{logging: {level, format}}`
   - `withCors(origins)` — добавляет `{cors: {origins, methods}}`
   - `withAuth(strategy)` — добавляет `{auth: {strategy, secret}}`

2. Интерфейс:
   - Чекбокс для включения/выключения каждого шага
   - Параметр шага (select или input) — доступен только при включённом шаге
   - Шаги выполняются в фиксированном порядке через pipe

3. Визуализация:
   - JSON-просмотрщик итогового конфига обновляется при каждом изменении
   - При наведении на шаг — показывается промежуточный конфиг после этого шага
   - Список накопления: какие секции добавляет каждый шаг (цветные бейджи)

4. Генерация кода:
   - Блок с кодом `pipe(withDatabase(...), ...)({})`  — обновляется в реальном времени
   - Отключённые шаги не попадают в код

## Чеклист

- [ ] Каждая функция-шаг — чистая функция (не мутирует входной конфиг)
- [ ] Итоговый конфиг содержит только секции включённых шагов
- [ ] При отключении всех шагов конфиг равен `{}`
- [ ] Наведение на шаг показывает состояние конфига именно после этого шага
- [ ] Изменение параметра немедленно обновляет конфиг

## Как проверить себя

1. Включите только `withDatabase(postgres)` — конфиг должен содержать только `db`
2. Добавьте `withPort(3000)` — конфиг расширится секцией `server`
3. Отключите `withDatabase` — секция `db` должна исчезнуть, `server` остаться
4. Наведите на шаг `withLogging` — в preview должен быть конфиг без `cors` и `auth`

**Подсказка:** Используйте spread `{...cfg, newSection: {...}}` внутри каждого шага,
чтобы гарантировать иммутабельность. Промежуточные конфиги вычисляйте отдельным
`reduce` по включённым шагам, сохраняя результат после каждого.
