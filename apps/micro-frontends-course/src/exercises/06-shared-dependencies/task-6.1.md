# Задание 6.1 — Визуализатор графа зависимостей

## Цель

Создать интерактивный инструмент, который наглядно показывает, как включение/выключение shared-зависимостей влияет на итоговый bundle size микрофронтендов, и помогает обнаружить дублирование и конфликты версий.

## Требования

1. Предзаданные 4 MFE: Shell, Catalog, Cart, Profile — каждый с набором зависимостей (react, react-dom, react-router, zustand, lodash, axios, date-fns)
2. Для каждой из 7 библиотек — кнопка-переключатель `shared / local`
3. Динамический пересчёт итогового размера бандла при каждом переключении:
   - Shared библиотека загружается один раз (не в бандле каждого MFE)
   - Локальная библиотека умножается на количество использующих её MFE
4. Подсветка дублей: если библиотека не shared и используется в 2+ MFE — красный бейдж
5. Предупреждение о конфликте версий: Cart использует react 18.2.0, остальные — 18.3.0; предупреждение показывается только когда react включён в shared
6. Блок статистики с 4 карточками: итоговый размер, экономия (KB и %), дубликатов, конфликтов версий
7. Три пресета: «Ничего не шарить», «Только React», «Всё shared»
8. Список MFE с цветными бейджами для каждой зависимости (цвет зависит от статуса: shared / локальный / дубликат)

## Чеклист

- [ ] Переключатель shared/local работает для каждой библиотеки
- [ ] Итоговый размер бандла пересчитывается корректно при изменении shared
- [ ] Дублирующиеся библиотеки подсвечены красным
- [ ] Предупреждение о конфликте версий react появляется только при shared: true
- [ ] Статистика «Экономия» показывает правильный процент
- [ ] Все три пресета применяются корректно
- [ ] Бейджи в списке MFE отражают текущий статус зависимостей

## Как проверить себя

Откройте визуализатор и выполните последовательность:

1. Нажмите «Ничего не шарить» → убедитесь, что все бейджи синие (локальные), экономия = 0
2. Нажмите «Только React» → react и react-dom стали зелёными, предупреждение о конфликте версий появилось, размер уменьшился
3. Нажмите «Всё shared» → нет красных бейджей, «Дубликатов: 0», экономия максимальная
4. Вручную выключите react из shared → предупреждение о конфликте исчезло, Cart и Shell, Catalog, Profile показывают react как красный дубликат

## Подсказки

- Для подсчёта: если библиотека shared — прибавляется один раз; если нет — умножается на `usageCount`
- `libUsageCount` — Map из имени библиотеки в число MFE, которые её используют
- `totalWithoutSharing` (базовая линия) не зависит от переключателей — это сумма всех зависимостей всех MFE без шаринга
- Конфликт версий для react симулируется статически: Cart = 18.2.0, остальные = 18.3.0
