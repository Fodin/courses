# Задание 7.3: Debounce и Throttle async

## Цель

Реализовать функции `debounce` и `throttle` и применить их к поисковому инпуту. Визуализировать разницу: сколько нажатий клавиш вызвали реальные запросы.

## Требования

1. **Функция `debounce(fn, delay)`**:
   - Каждое новое событие сбрасывает таймер
   - `fn` вызывается через `delay`ms после **последнего** события
   - Реализовать через `useRef` для хранения таймера

2. **Функция `throttle(fn, delay)`**:
   - `fn` вызывается не чаще одного раза в `delay`ms
   - Реализовать через `useRef` для хранения времени последнего вызова

3. **Две вкладки**: Debounce (300ms) и Throttle (500ms) — при переключении состояние сбрасывается

4. **Поисковый инпут** — при каждом вводе фиксируется нажатие и (если прошло) вызов запроса

5. **Счётчики**: "нажатий" vs "запросов", процент экономии

6. **Timeline** — точки на горизонтальной оси: серые = нажатия, зелёные = реальные запросы

## Чеклист

- [ ] Компонент называется `Task7_3` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован и `t('task.7.3')` используется в заголовке
- [ ] Debounce: при быстром вводе только последнее нажатие вызывает запрос (после паузы)
- [ ] Throttle: запросы идут равномерно, не чаще одного в 500ms
- [ ] При переключении вкладок состояние сбрасывается
- [ ] Счётчик экономии показывает корректный процент
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Режим Debounce: введите 10 символов быстро, затем остановитесь — должен пройти **один** запрос (после паузы 300ms)
2. Режим Debounce: вводите медленно (пауза >300ms между символами) — каждый символ вызывает запрос
3. Режим Throttle: вводите быстро 2 секунды — запросы должны идти примерно каждые 500ms
4. Сравните счётчик нажатий и запросов — при быстром вводе разница значительная
