# Task 3.1 — Анатомия брокера сообщений

## Цель

Создать интерактивный компонент, который визуализирует внутреннюю архитектуру AMQP-брокера сообщений (RabbitMQ). Пользователь должен иметь возможность изучить каждый компонент брокера и увидеть путь сообщения от producer до consumer в пошаговой симуляции.

## Требования

1. Отобразить компоненты брокера, сгруппированные по трём уровням: Connection Layer (Connection, Channel), Routing Layer (Exchange, Binding), Storage Layer (Queue).
2. При клике на компонент — показывать панель с подробным описанием: иконка, название, описание, список ключевых деталей (4 пункта).
3. Повторный клик на выбранный компонент — скрывает панель деталей.
4. Реализовать пошаговую симуляцию пути сообщения через 5 шагов: Producer→Exchange, Exchange→Binding, Binding→Queue, Queue→Consumer, Consumer→ACK.
5. Во время симуляции кнопка "Запустить" должна быть заблокирована с текстом "Симуляция...".
6. Шаги симуляции отображаются как прогресс-бар с кружками (1–5), которые закрашиваются по мере выполнения.
7. Завершённые шаги показывают лог в терминальном стиле (тёмный фон, моноширинный шрифт) с полями: номер шага, название шага, детали.
8. Каждый компонент имеет уникальную цветовую схему (bgColor, borderColor, color).

## Чеклист

- [ ] Три уровня архитектуры отображаются с заголовками (Connection / Routing / Storage)
- [ ] Клик на компонент раскрывает панель с деталями
- [ ] Повторный клик скрывает панель
- [ ] Кнопка "Запустить симуляцию" запускает пошаговый flow
- [ ] Прогресс-бар из 5 шагов обновляется по ходу симуляции
- [ ] Кнопка заблокирована во время анимации
- [ ] Терминальный лог появляется и заполняется по шагам
- [ ] После завершения симуляции кнопка снова активна

## Как проверить себя

1. Кликните на каждый из 5 компонентов — должна появляться панель с деталями и исчезать при повторном клике.
2. Нажмите "Запустить симуляцию" — прогресс-бар должен заполняться шаг за шагом с задержкой ~700 мс.
3. Во время симуляции попробуйте нажать кнопку снова — она должна быть неактивна.
4. По завершении в терминале должны появиться все 5 записей лога.
5. Откройте консоль браузера — ошибок быть не должно.
