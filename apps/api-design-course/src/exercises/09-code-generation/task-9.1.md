# Задание 9.1: OpenAPI → TypeScript

## Цель

Создать интерактивный визуализатор, который показывает, как конструкции OpenAPI-спецификации превращаются в TypeScript-типы при генерации кода. Шесть примеров: простая модель, enum, массивы, вложенные объекты, oneOf, allOf.

## Требования

1. Реализовать интерфейс `MappingExample` с полями: `id`, `label`, `openapi`, `typescript`, `description`
2. Подготовить 6 примеров маппинга: `simple`, `enum`, `array`, `nested`, `oneof`, `allof`
3. Отображать табы для переключения между примерами — активный таб выделяется цветом `#6366f1`
4. Показывать описание текущего примера в жёлтом блоке-подсказке
5. Рядом (две колонки): слева — YAML OpenAPI на тёмном фоне, справа — TypeScript-типы синим цветом
6. Внизу — справочная таблица маппинга типов в виде карточек

## Что реализовать

- [ ] Интерфейс `MappingExample` и массив `MAPPING_EXAMPLES` (6 элементов)
- [ ] Состояние `activeId: string`, по умолчанию `'simple'`
- [ ] Блок табов: кнопки для каждого примера, активная с фиолетовым фоном
- [ ] Блок описания: жёлтый фон (`#fefce8`), граница `#fde68a`
- [ ] Левая панель (YAML): заголовок с зелёным бейджом `YAML`, тёмный фон `#1e293b`
- [ ] Правая панель (TS): заголовок с синим бейджом `TS`, тёмный фон, цвет текста `#93c5fd`
- [ ] Таблица маппинга: 12 пар (OpenAPI тип → TypeScript тип), сетка 3 колонки

## Примеры для маппинга

| Пример | Что показывает |
|---|---|
| `simple` | string, integer → number, boolean, required → обязательные |
| `enum` | enum: [a,b,c] → union type `'a' \| 'b' \| 'c'` |
| `array` | type: array + items → `T[]` |
| `nested` | $ref на другую схему → ссылка на interface |
| `oneof` | oneOf: [A, B, C] → `A \| B \| C` |
| `allof` | allOf: [$ref, {объект}] → intersection `A & B` или `extends` |

## Как проверить себя

- При клике на таб `enum` слева виден YAML с `type: string` и `enum: [...]`, справа — `type OrderStatus = 'pending' | ...`
- При клике на `allof` справа виден комментарий про intersection type и альтернативный вариант с `extends`
- Таблица маппинга содержит строку `oneOf: [A, B]` → `A | B`
- При переключении табов контент обновляется без перезагрузки страницы
