# Задание 3.3: Variable Expansion — разворачивание переменных

## Цель

Создать интерактивный демонстратор variable expansion: пользователь пишет YAML-скрипт с переменными, нажимает "Resolve" и видит развёрнутый результат — как это выглядело бы в реальном CI-логе.

## Требования

1. Textarea для ввода скрипта (многострочный, с переменными вида `$VAR` и `${VAR}`)
2. Секция предустановленных переменных-контекста (CI_COMMIT_SHA, CI_COMMIT_SHORT_SHA, CI_COMMIT_REF_NAME, CI_PROJECT_NAME, CI_REGISTRY_IMAGE)
3. Возможность добавить свою переменную (имя + значение) и удалить её
4. Кнопка "Resolve" — заменяет все `$VAR` и `${VAR}` в тексте реальными значениями
5. Вывод двух панелей: "Raw" (исходный скрипт) и "Resolved" (с подставленными значениями)
6. Поддержка синтаксиса `${VAR:-default}` — если переменная не задана, подставлять default

## Чеклист

- [ ] Textarea с placeholder-примером скрипта (3-5 строк с переменными)
- [ ] Блок предустановленных переменных с реалистичными значениями
- [ ] Форма добавления своей переменной (два input'а: имя и значение, кнопка "+")
- [ ] Кнопка удаления у каждой кастомной переменной
- [ ] Кнопка "Resolve" выполняет подстановку
- [ ] Панель "Raw" показывает исходный текст
- [ ] Панель "Resolved" показывает результат, незаменённые переменные выделены красным/курсивом
- [ ] Поддержка `${VAR:-default}`

## Как проверить себя

1. Введи `docker build -t $CI_REGISTRY_IMAGE:$CI_COMMIT_SHORT_SHA .` → должно развернуться в реальные значения
2. Введи `${UNKNOWN_VAR:-fallback}` → должно подставить "fallback"
3. Добавь кастомную переменную `APP_NAME=myservice`, используй её в скрипте → должна подставиться
4. Введи `echo $CI_COMMIT_REF_NAME` → должно вернуть имя ветки
5. Удали кастомную переменную, нажми "Resolve" снова → переменная больше не подставляется

## Подсказки

- Храни переменные как объект `Record<string, string>` — легко читать по имени
- Для подстановки используй `String.replace()` с регулярным выражением:
  - `\$\{(\w+):-([^}]*)\}` — для `${VAR:-default}`
  - `\$\{(\w+)\}` — для `${VAR}`
  - `\$(\w+)` — для `$VAR`
- Порядок важен: сначала обрабатывай `${VAR:-default}`, потом `${VAR}`, потом `$VAR`
- Для выделения незаменённых переменных в resolved-панели можно снова пробежать по тексту и обернуть `$...` в `<span style={{ color: 'red' }}>`
- Для рендера HTML из строки используй `dangerouslySetInnerHTML` в React
