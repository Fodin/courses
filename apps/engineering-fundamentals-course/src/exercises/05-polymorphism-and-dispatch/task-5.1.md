# Задание 5.1: Квиз — Полиморфизм и диспетчеризация

## Цель
Проверить понимание видов полиморфизма (параметрический, подтиповой, ad-hoc) и механизмов диспетчеризации.

## Требования
1. Прочитайте теорию уровня 5 (README)
2. Пройдите квиз по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист
- [ ] Прочитана теория по параметрическому полиморфизму (дженерики)
- [ ] Прочитана теория по подтиповому полиморфизму и принципу Лисков
- [ ] Прочитана теория по ad-hoc полиморфизму (перегрузка)
- [ ] Прочитана теория по статической vs динамической диспетчеризации
- [ ] Пройден квиз с результатом не менее 80%

## Как проверить себя
1. Откройте квиз и ответьте на все вопросы
2. Проверьте объяснения для неправильных ответов
3. Если результат ниже 80% — перечитайте соответствующие разделы теории
