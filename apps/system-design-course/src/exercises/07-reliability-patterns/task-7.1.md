# Задание 7.1: Квиз — Паттерны надёжности

## Цель

Проверить понимание паттернов надёжности: Circuit Breaker, retry с backoff, bulkhead, SLO/SLA/SLI, canary releases и стратегий деплоя.

## Требования

1. Прочитайте теорию уровня 7 (README)
2. Пройдите квиз из 5 вопросов по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ (один или несколько)
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист

- [ ] Понятны 3 состояния Circuit Breaker (Closed → Open → Half-Open)
- [ ] Понятна формула exponential backoff и зачем нужен jitter
- [ ] Понятен паттерн Bulkhead и аналогия с подводной лодкой
- [ ] Понятна разница между SLI, SLO и SLA
- [ ] Понятен error budget и burn rate
- [ ] Понятна разница между blue-green и canary deployments
- [ ] Понятна роль feature flags в релизном процессе
- [ ] Пройден квиз с результатом не менее 80%

## Как проверить себя

1. Откройте квиз и ответьте на все вопросы
2. Проверьте объяснения для неправильных ответов
3. Если результат ниже 80% — перечитайте соответствующие разделы теории
