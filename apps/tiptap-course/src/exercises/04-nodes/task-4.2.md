# Задание 4.2: Списки

## Цель

Реализовать переключение маркированного и нумерованного списка, продемонстрировать вложенность через отступы.

## Требования

1. Создайте `editor` с `StarterKit`
2. Кнопка "Маркированный список" — `toggleBulletList()`
3. Кнопка "Нумерованный список" — `toggleOrderedList()`
4. Подсветите активную кнопку через `isActive('bulletList')` / `isActive('orderedList')`
5. Начальный контент должен включать список минимум с одним вложенным пунктом (список внутри пункта списка), чтобы продемонстрировать вложенность
6. Добавьте текстовую подсказку под редактором: "Tab — увеличить отступ, Shift+Tab — уменьшить"

## Чеклист

- [ ] Компонент называется `Task4_2` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.4.2')` используется в заголовке
- [ ] Обе кнопки переключают соответствующий тип списка
- [ ] Начальный контент показывает вложенный список
- [ ] `Tab`/`Shift+Tab` внутри пункта списка меняют уровень вложенности
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Создайте маркированный список из 2-3 пунктов
2. Поставьте курсор во второй пункт, нажмите `Tab` — пункт должен стать вложенным (сдвинуться и получить свой под-список)
3. Нажмите `Shift+Tab` — пункт должен вернуться на исходный уровень
4. Переключите список на нумерованный кнопкой — маркеры должны замениться на числа
