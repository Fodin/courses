# Задание 3.2: then/catch/finally — визуализатор цепочки

## Цель

Создать визуальный "конвейер" из 5 блоков: `.then()`, `.then()`, `.catch()`, `.then()`, `.finally()`. Значение "проходит" через блоки с пошаговой анимацией. Для каждого блока можно включить режим "throw" — чтобы увидеть, как ошибка распространяется и перехватывается.

## Требования

1. **Конвейерная визуализация**: 5 блоков сверху вниз, соединённых стрелками:
   - Блок 0: `.then(v => v * 2)` — умножает на 2
   - Блок 1: `.then(v => v + 10)` — прибавляет 10
   - Блок 2: `.catch(err => 0)` — возвращает 0 при ошибке
   - Блок 3: `.then(v => \`result: ${v}\`)` — оборачивает в строку
   - Блок 4: `.finally(() => cleanup())` — только побочный эффект

2. **Цветовое обозначение** типов блоков:
   - `.then` — синий
   - `.catch` — красный
   - `.finally` — жёлтый

3. **Статусы блоков** с визуальным различием:
   - `idle` — серый, не выполнялся
   - `active` — яркая рамка нужного цвета + свечение
   - `pass` — зелёный (значение прошло через блок)
   - `handled` — фиолетовый (блок обработал ошибку — `.catch`)
   - `skipped` — полупрозрачный серый (блок пропущен — `.then` при ошибке или `.catch` без ошибки)

4. **Переключатели throw ON/OFF** для каждого блока (кроме `.finally`):
   - При `throw ON` блок бросает ошибку вместо нормального выполнения
   - Это показывает error propagation через цепочку

5. **Поле ввода начального значения** (число) — `Promise.resolve(значение)`

6. **Кнопки "Запустить" и "Сброс"** — запуск анимирует прохождение значения через конвейер с задержкой ~400мс между шагами

7. **Лог шагов** — каждый блок добавляет запись о том, что произошло

8. **Итоговый результат** — зелёный блок (fulfilled) или красный (rejected / unhandled)

9. **Легенда** статусов в интерфейсе

- [ ] Каждый блок имеет метку типа (then/catch/finally) и текст операции
- [ ] Блоки меняют визуальный стиль в зависимости от статуса
- [ ] Переключатель throw работает для блоков 0-3
- [ ] При запуске видна пошаговая анимация (блоки становятся active последовательно)

## Как проверить себя

1. Введите начальное значение `5`, нажмите "Запустить" без throw — результат: `"result: 20"` (5*2=10, 10+10=20)
2. Включите `throw ON` для блока 0, нажмите "Запустить" — блок 1 пропущен (skipped), блок 2 (catch) обработал ошибку (handled), блок 3 продолжил с `0`
3. Включите `throw ON` для блока 2, нажмите "Запустить" с throw в блоке 0 — итог: Unhandled rejection (ошибка из catch прошла мимо)
4. Убедитесь, что `.finally` всегда выполняется при любой конфигурации
