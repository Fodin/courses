# Задание 15.2: Drag handle

## Цель

Реализовать упрощённый drag handle — визуальную "ручку" рядом с каждым блочным абзацем, позволяющую перетащить блок на новую позицию в документе.

## Требования

1. Создайте `Extension.create({ name: 'dragHandle', addProseMirrorPlugins() {...} })`
2. Используйте `Decoration.widget(pos, () => {...}, { side: -1 })` для добавления DOM-элемента "ручки" (например, `⠿`) перед каждым top-level блочным узлом документа
3. На ручке настройте `draggable`, обработчик `dragstart` — сохраняет позицию блока в `event.dataTransfer`
4. На контейнере редактора обработайте `drop` через `props.handleDOMEvents.drop` — считывает `fromPos` из `dataTransfer`, вычисляет `toPos` через `view.posAtCoords`, перемещает содержимое блока (`deleteRange` + `insertContentAt`, либо аналогичная комбинация команд)
5. Стилизуйте ручку — маленький серый значок слева от блока, видимый только при наведении на блок

## Чеклист

- [ ] Компонент называется `Task15_2` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.15.2')` используется в заголовке
- [ ] Ручка появляется слева от каждого блока при наведении
- [ ] Перетаскивание блока меняет его позицию в документе
- [ ] После перетаскивания содержимое блока сохраняется без потери текста/форматирования
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Создайте документ из 3-4 параграфов
2. Наведите курсор на первый параграф — должна появиться ручка слева
3. Перетащите первый параграф вниз, за третий — порядок блоков должен измениться
4. Убедитесь, что текст и форматирование перемещённого блока не повредились
