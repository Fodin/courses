# Задание 8.3: addGlobalAttributes

## Цель

Реализовать extension `IdAttribute`, добавляющий атрибут `id` заголовкам и параграфам через `addGlobalAttributes`, и продемонстрировать, что он сериализуется в HTML.

## Требования

1. Создайте `Extension.create({ name: 'idAttribute', addGlobalAttributes() { ... } })` с `types: ['heading', 'paragraph']`
2. Атрибут `id`: `default: null`, `parseHTML` читает `element.getAttribute('id')`, `renderHTML` возвращает `{ id: attributes.id }` только если `id` не `null`
3. Подключите extension со `StarterKit`
4. Добавьте кнопку "Присвоить ID текущему блоку" — использует `editor.chain().focus().updateAttributes('paragraph', { id: 'block-' + Date.now() }).run()` (примените к текущему активному типу блока — параграфу или заголовку)
5. Под редактором выведите `editor.getHTML()`, чтобы показать, что `id` реально попал в разметку

## Чеклист

- [ ] Компонент называется `Task8_3` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.8.3')` используется в заголовке
- [ ] Атрибут `id` добавляется и параграфам, и заголовкам через один extension
- [ ] Кнопка присваивает уникальный `id` текущему блоку
- [ ] HTML-вывод показывает атрибут `id` у соответствующего тега
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Поставьте курсор в параграф, нажмите "Присвоить ID" — в HTML-выводе снизу должен появиться `id="block-..."` у соответствующего `<p>`
2. Поставьте курсор в заголовок, повторите — `id` должен появиться и у `<h2>` (тот же extension работает для обоих типов нод)
3. Убедитесь, что параграфы/заголовки без присвоенного `id` не получают пустой атрибут `id=""` в HTML (за это отвечает условие в `renderHTML`)
