# Задание 11.1: rAF vs setTimeout — сравнение плавности

## Цель

Реализовать визуальное сравнение двух подходов к анимации: `requestAnimationFrame` и `setTimeout(fn, 16)`. Пользователь должен увидеть разницу в плавности, особенно при включённой нагрузке.

## Требования

1. **Два шарика** — движутся горизонтально по треку:
   - Синий шарик анимируется через `requestAnimationFrame`
   - Оранжевый шарик — через `setTimeout(fn, 16)`

2. **FPS-счётчики** — для каждого шарика отдельно:
   - Вычисляются как среднее за последние 30 кадров
   - Обновляются каждые 500ms
   - Цвет: зелёный (≥55fps), жёлтый (≥30fps), красный (<30fps)

3. **Кнопки управления**:
   - "Старт" — запускает обе анимации одновременно
   - "Стоп" — останавливает обе
   - "Сброс" — возвращает в начальное состояние (доступна только когда остановлено)

4. **Переключатель нагрузки** — кнопка "Нагрузка: ВКЛ/ВЫКЛ":
   - В режиме нагрузки добавляется ~2ms синхронного кода в каждый "кадр" обоих шариков
   - При нагрузке setTimeout-шарик начинает дёргаться заметнее

5. **Пояснение** — блок текста объясняет почему существует разница

6. **Самодостаточность** — только inline CSS, нет импортов сторонних библиотек

## Чеклист

- [ ] Компонент называется `Task11_1` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован, `t('task.11.1')` используется в заголовке
- [ ] rAF-шарик использует настоящий `requestAnimationFrame`, не таймер
- [ ] setTimeout-шарик использует `setTimeout(fn, 16)`
- [ ] FPS вычисляется по массиву последних интервалов между кадрами
- [ ] `cancelAnimationFrame` вызывается при остановке и размонтировании
- [ ] `clearTimeout` вызывается при остановке и размонтировании
- [ ] Кнопка "Сброс" недоступна во время анимации
- [ ] Нагрузка влияет на оба шарика при включении
- [ ] Нет TypeScript-ошибок, нет `any`

## Как проверить себя

1. Нажмите "Старт" — оба шарика начинают двигаться
2. Наблюдайте FPS — оба должны показывать ~60
3. Включите "Нагрузка" — setTimeout-шарик начинает дёргаться
4. Нажмите "Стоп" — оба шарика останавливаются
5. Переключите нагрузку когда оба шарика остановлены — снова запустите, убедитесь что нагрузка применяется
6. Откройте DevTools → Performance и запишите 3-5 секунд: убедитесь, что rAF-анимация аккуратнее ложится в кадры
