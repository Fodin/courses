# Task 4.1 — JSON Response Transformer

## Goal

Learn to recognize typical problems in API JSON response structures and apply naming conventions, data formatting, and object structuring practices.

## Requirements

1. The component displays at least 5 examples of "bad" JSON responses from real situations.
2. Each example is accompanied by a list of specific problems.
3. A "Show fix" button reveals the correct version with an explanation of each change.
4. Examples are divided by categories: naming, structure, data formats, errors.
5. Filtering by categories is present.

## Checklist

- [ ] At least 5 examples of bad responses
- [ ] For each — a list of problems
- [ ] Toggle button for the fixed version
- [ ] Explanation of each fix
- [ ] Categories: naming, structure, data formats, errors
- [ ] Category filter

## How to Check Yourself

Close the theory. Open the component and try to explain all the problems of each example before clicking "Show fix". If you found all the problems and explained why each one is bad — the task is completed.
