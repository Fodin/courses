# Задание 5.1 — Визуализатор Shadow DOM изоляции

## Цель

Создать интерактивный визуализатор, который наглядно показывает принципы работы Shadow DOM: изоляцию стилей, проникновение CSS Custom Properties, механизм слотов и коммуникацию через CustomEvent.

## Требования

1. **Вкладка "Стили"** — два блока рядом: "Light DOM" и "Shadow DOM"
   - Панель управления: кнопки выбора цвета текста (минимум 3 варианта), фона (минимум 3 варианта), размера шрифта (3 варианта)
   - При смене стиля: в блоке Light DOM стили применяются, в блоке Shadow DOM — нет
   - Визуализация DOM-дерева для каждого блока (тег → дочерние элементы → shadow-root)

2. **Вкладка "CSS Custom Properties"** — два контрола для задания `--mf-primary` и `--mf-accent`
   - Наглядно показать, что CSS-переменные проникают в Shadow DOM
   - Показать CSS-контракт: как компонент публикует своё API стилизации через `var(--name, default)`

3. **Вкладка "Слоты"** — текстовый input для ввода контента
   - Контент из input отображается в default slot Shadow DOM компонента
   - Показать схему: Light DOM контент → slot → отображается внутри Shadow DOM
   - Показать разницу между default slot и named slot (`slot="footer"`)

4. **Вкладка "События"** — кнопки для диспатча CustomEvent
   - Кнопка "Dispatch из Shadow DOM" с `composed: true` — событие выходит в window
   - Кнопка "Dispatch из Light DOM" с `composed: false` — событие не всплывает
   - Лог событий: показывать timestamp, источник, имя события, detail
   - Показать код: как создать CustomEvent и как подписаться на него

5. **Лог событий** автоматически скроллится вниз при новых записях

6. Все стили — inline (без CSS-файлов)

## Чеклист

- [ ] Видны оба блока (Light DOM и Shadow DOM) рядом
- [ ] При смене глобальных стилей Light DOM меняется, Shadow DOM остаётся прежним
- [ ] CSS Custom Properties меняются в обоих блоках
- [ ] Слот отображает текст из input
- [ ] Два вида событий (composed true/false) — разное поведение в логе
- [ ] Визуализация DOM-дерева (host → shadow-root → elements)
- [ ] Лог событий работает и скроллится

## Как проверить себя

1. Измените цвет текста на "Красный" — Light DOM меняется, Shadow DOM нет
2. Поменяйте `--mf-primary` — цвет меняется и в Shadow DOM (CSS vars проникают)
3. Введите текст в поле слота — он появляется внутри Shadow DOM компонента
4. Нажмите "Dispatch из Shadow DOM" — событие появляется в логе через `window`
5. В DOM-дереве видна структура `host → #shadow-root → slot`
