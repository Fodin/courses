# Задание 1.1: Квиз — Масштабирование

## Цель

Проверить понимание основ масштабирования: вертикальное vs горизонтальное, stateless vs stateful, scaling cube, закон Амдала.

## Требования

1. Прочитайте теорию уровня 1 (README)
2. Пройдите квиз из 5 вопросов по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ (один или несколько)
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист

- [ ] Прочитана теория по вертикальному и горизонтальному масштабированию
- [ ] Понятна разница между stateless и stateful сервисами
- [ ] Понятны три оси Scaling Cube (X, Y, Z)
- [ ] Знаком с законом Амдала и его влиянием на масштабирование
- [ ] Пройден квиз с результатом не менее 80%

## Как проверить себя

1. Откройте квиз и ответьте на все вопросы
2. Проверьте объяснения для неправильных ответов
3. Если результат ниже 80% — перечитайте соответствующие разделы теории
