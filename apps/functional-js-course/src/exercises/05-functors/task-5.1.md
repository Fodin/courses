# Задание 5.1: Box — простейший функтор

## Цель

Реализовать класс `Box<T>` — простейший функтор-контейнер — и построить интерактивный визуализатор цепочки трансформаций.

## Требования

1. Реализуйте класс `Box<T>` со следующими методами:
   - `static of<T>(value: T): Box<T>` — создаёт Box из значения
   - `map<U>(fn: (value: T) => U): Box<U>` — применяет функцию к содержимому, возвращает новый Box
   - `fold<U>(fn: (value: T) => U): U` — извлекает значение, применяя функцию (выход из Box)
   - `inspect(): string` — возвращает строку вида `Box(value)`

2. Реализуйте компонент с интерактивным playground:
   - Поле ввода начального значения (строки)
   - Набор кнопок-трансформаций (минимум 5): `toUpperCase`, `trim`, `split(' ')`, `length`, `x * 2`, `reverse`, `add "!"`
   - Кнопка добавляет шаг `.map(fn)` в цепочку

3. Визуализация цепочки:
   - Каждый Box отображён как прямоугольник со значением внутри
   - Между Box-ами показана применяемая функция `.map(fn)`
   - Кнопка `x` у каждого шага удаляет его из цепочки
   - Кнопка `.fold(x => x)` появляется после последнего Box и извлекает значение

4. Блок "Эквивалентный код":
   - Отображает текущую цепочку в виде кода
   - После fold показывает результат в комментарии `// => ...`

## Чеклист

- [ ] `Box.of(value)` создаёт контейнер
- [ ] `map(fn)` возвращает новый `Box` с трансформированным значением, не меняя оригинал
- [ ] `fold(fn)` возвращает значение, не Box
- [ ] `inspect()` возвращает `Box(value)`
- [ ] Добавление шагов работает через кнопки
- [ ] Удаление шага работает
- [ ] Цепочка визуально обновляется при каждом изменении
- [ ] Блок кода синхронизирован с цепочкой

## Как проверить

1. Введите `"  hello  "` как начальное значение
2. Добавьте `.map(trim)` → должен появиться `Box("hello")`
3. Добавьте `.map(toUpperCase)` → должен появиться `Box("HELLO")`
4. Нажмите `.fold(x => x)` → должно появиться финальное значение `"HELLO"`
5. Удалите шаг `.map(trim)` → цепочка должна пересчитаться
