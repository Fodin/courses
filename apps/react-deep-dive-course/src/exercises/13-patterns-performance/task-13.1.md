# Задание 13.1: Context Splitting

## Задание

У вас есть приложение с одним большим `AppContext`, в котором хранятся: данные пользователя,
тема и поисковый запрос. При каждом нажатии клавиши в поиске весь UI ре-рендерится —
`UserCard`, `ThemeToggle` и `SearchResults` мигают одновременно, хотя user и theme не менялись.

Разделите один большой контекст на три независимых, чтобы каждый компонент ре-рендерился
только при изменении тех данных, которые он реально использует.

---

## Цель

Понять, как Context Splitting устраняет лишние ре-рендеры без React.memo.

---

## Требования

1. Создайте три отдельных контекста: `UserContext`, `ThemeContext`, `SearchContext`
2. `UserContext` хранит объект пользователя `{ name, avatar }` (меняется кнопкой "Сменить пользователя")
3. `ThemeContext` хранит строку `'light' | 'dark'` (меняется кнопкой "Переключить тему")
4. `SearchContext` хранит `{ query: string, setQuery: (q: string) => void }` (меняется полем ввода)
5. `UserCard` использует только `UserContext` — счётчик рендеров растёт только при смене пользователя
6. `ThemeToggle` использует только `ThemeContext` — счётчик рендеров растёт только при смене темы
7. `SearchResults` использует только `SearchContext` — счётчик рендеров растёт при каждом вводе
8. Каждый из трёх компонентов показывает счётчик рендеров
9. `SearchContext` значение (`{ query, setQuery }`) мемоизировать через `useMemo`

---

## Чеклист

- [ ] Три отдельных контекста с отдельными `createContext` и `Provider`
- [ ] `UserCard` — только `useContext(UserContext)`, счётчик растёт при смене user
- [ ] `ThemeToggle` — только `useContext(ThemeContext)`, счётчик растёт при смене theme
- [ ] `SearchResults` — только `useContext(SearchContext)`, счётчик растёт при каждом вводе
- [ ] Значение `SearchContext` мемоизировано (не создаётся новый объект при ре-рендере провайдера)
- [ ] UserCard и ThemeToggle НЕ ре-рендерятся при вводе в поиск (счётчики не меняются)

---

## Как проверить себя

1. Введите текст в поисковое поле — счётчик должен расти только у `SearchResults`
2. Нажмите "Сменить пользователя" — счётчик должен расти только у `UserCard`
3. Нажмите "Переключить тему" — счётчик должен расти только у `ThemeToggle`
4. Введите 5 символов в поиск — у `UserCard` и `ThemeToggle` счётчик должен остаться прежним

---

## Подсказки

- `setQuery` из `useState` стабильна по ссылке — не нужен `useCallback`
- Но объект `{ query, setQuery }` создаётся заново при каждом рендере провайдера →
  `useMemo(() => ({ query, setQuery }), [query])` предотвращает это
- Счётчик рендеров удобно реализовать через `useRef`: `const renders = useRef(0); renders.current++`
- Три `Provider` можно вложить: `<UserContext.Provider><ThemeContext.Provider>...`
