# Задание 9.1: Async пагинация

## Цель

Реализовать интерактивный демонстратор ленивой пагинации через async-генератор. Показать, что HTTP-запросы происходят ровно тогда, когда потребитель запрашивает следующую страницу — не раньше.

## Требования

1. **Симулятор API** — функция `fetchPage(page)`: возвращает `Promise<PageResponse>` с задержкой 600мс, генерирует 5 элементов на страницу, всего 6 страниц

2. **Async-генератор `fetchAllPages()`** — использует `async function*`:
   - Внутри цикл `while (true)` с `await fetchPage(page)` и `yield response`
   - Условие выхода: `page >= totalPages`
   - Каждый `yield` блокирует генератор до следующего `.next()`

3. **Хранение ссылки на генератор** — через `useRef` (не через state), чтобы инстанс не пересоздавался при ре-рендере

4. **Кнопка "Загрузить следующую порцию"** — при нажатии вызывает `genRef.current.next()` и добавляет элементы в список

5. **Счётчик HTTP-запросов** — показывает сколько раз был вызван `fetchPage`. Должен расти только при нажатии кнопки, не автоматически

6. **Прогресс-бар** — отображает текущую страницу из общего количества, заполняется от 0% до 100%

7. **Состояние "завершено"** — когда `done: true` из генератора, кнопка блокируется, показывается финальное сообщение

## Чеклист

- [ ] Компонент называется `Task9_1` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован, `t('task.9.1')` используется в заголовке
- [ ] Async-генератор объявлен как `async function* fetchAllPages()`
- [ ] Ссылка на генератор хранится в `useRef`, не в `useState`
- [ ] Кнопка "Загрузить следующую порцию" вызывает `await genRef.current.next()`
- [ ] Счётчик HTTP-запросов увеличивается только при нажатии кнопки
- [ ] Прогресс-бар обновляется после каждой загруженной страницы
- [ ] При `done: true` кнопка заблокирована
- [ ] Кнопка "Перезапустить" создаёт новый инстанс генератора и очищает список
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Нажмите "Создать генератор" — счётчик запросов = 0, список пуст
2. Нажмите "Загрузить следующую порцию" — через ~600мс появятся 5 карточек, счётчик = 1
3. Нажмите ещё 5 раз — после 6-й загрузки кнопка заблокирована, счётчик = 6
4. Между нажатиями кнопки счётчик НЕ меняется (нет фоновой загрузки)
5. Нажмите "Перезапустить" — всё сбрасывается, можно начать заново
