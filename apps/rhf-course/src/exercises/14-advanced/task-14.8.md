# Задание 14.8: Remote Form Submit

## Цель

Научиться управлять формой (отправка и сброс) из кнопок, расположенных вне тега `<form>`.

## Требования

1. Создайте форму создания задачи с полями: заголовок, описание, приоритет (low/medium/high)
2. Все поля обязательны, описание минимум 10 символов
3. Кнопки "Сохранить" и "Сброс" расположите в тулбаре НАД формой, вне тега `<form>`
4. Реализуйте два способа внешнего submit:
   - Кнопка с атрибутом `form="form-id"` и `type="submit"`
   - Кнопка с `onClick`, вызывающая `handleSubmit()` напрямую
5. Реализуйте сброс формы извне через вызов `reset()`
6. Кнопка сброса должна быть disabled, если форма не изменена

## Интерфейс данных

```typescript
interface TaskForm {
  title: string
  description: string
  priority: 'low' | 'medium' | 'high'
}
```

## Чеклист

- [ ] Кнопки submit находятся вне тега `<form>`
- [ ] Способ 1: кнопка с атрибутом `form="id"` отправляет форму
- [ ] Способ 2: кнопка вызывает `handleSubmit()` через onClick
- [ ] Кнопка сброса вызывает `reset()` извне формы
- [ ] Кнопка сброса disabled, когда форма не изменена
- [ ] Валидация работает при обоих способах отправки

## Как проверить себя

1. Нажмите "Сохранить (form=id)" без заполнения — должны появиться ошибки валидации
2. Нажмите "Отправить (onClick)" без заполнения — тоже ошибки
3. Заполните форму и используйте любую из кнопок — данные должны отправиться
4. Измените форму, затем нажмите "Сброс" — форма должна очиститься
5. Убедитесь, что кнопка "Сброс" неактивна, когда форма пустая
