# Задание 13.1: Saga Choreography

## Цель

Реализовать визуализатор **Choreography Saga** для e-commerce заказа. Система состоит из четырёх сервисов (OrderService, PaymentService, InventoryService, ShippingService), каждый из которых реагирует на события предыдущего и публикует своё. При ошибке на любом шаге запускаются компенсирующие события в строго обратном порядке.

## Требования

1. Объявить тип `StepStatus`: `'idle' | 'running' | 'success' | 'failed' | 'compensating' | 'compensated'`.
2. Объявить интерфейс `ChoreographyStep` с полями: `id: string`, `service: string`, `event: string`, `compensationEvent: string`, `color: string`, `status: StepStatus`.
3. Объявить константу `INITIAL_STEPS` — массив из 4 шагов (OrderService, PaymentService, InventoryService, ShippingService) с событиями `order.created`, `payment.processed`, `inventory.reserved`, `shipping.scheduled` и соответствующими компенсирующими событиями.
4. Объявить словари `STATUS_LABELS: Record<StepStatus, string>` и `STATUS_COLORS: Record<StepStatus, string>` для отображения статусов.
5. Реализовать состояния компонента: `steps`, `failAt` (номер шага, на котором произойдёт ошибка, по умолчанию 2), `running`, `log` (массив строк), `phase` (`'idle' | 'forward' | 'compensating' | 'done'`), `abortRef` через `useRef`.
6. Реализовать функцию `runSaga`:
   - Последовательно обходит шаги (с задержкой `sleep(700)` между ними).
   - При успешном шаге статус → `'success'`, добавляет строку `[OK] ...` в лог.
   - При шаге с ошибкой (`i === failAt`) статус → `'failed'`, добавляет `[ERROR] ...` в лог, запускает компенсацию.
   - Компенсация: обходит уже выполненные шаги в обратном порядке, статус → `'compensating'` → `'compensated'`, добавляет `[COMPENSATE] ...` в лог.
   - Если `failAt === -1` — Saga завершается успехом.
7. Реализовать функцию `reset`, которая сбрасывает все состояния через `abortRef.current = true`.
8. Отрисовать горизонтальную цепочку сервисных карточек со стрелками между ними. Цвет стрелки: зелёный при успехе (forward path), красный при компенсации.
9. Добавить `<select>` для выбора шага ошибки (опция "Без ошибок" при `value={-1}` и по одной опции на каждый сервис).
10. Добавить кнопку "Запустить Saga" / "Сбросить" (меняет текст в зависимости от `running`).
11. Отрисовать лог событий в тёмном блоке (`background: '#1a1a2e'`). Строки `[ERROR]` — красным, `[COMPENSATE]` — оранжевым, `[SAGA]` — зелёным.
12. Добавить CSS-анимацию `pulse` для кружков в статусах `'running'` и `'compensating'`.

## Чеклист

- [ ] Тип `StepStatus` с 6 значениями объявлен
- [ ] Интерфейс `ChoreographyStep` со всеми полями объявлен
- [ ] `INITIAL_STEPS` содержит 4 шага с событиями и компенсирующими событиями
- [ ] `STATUS_LABELS` и `STATUS_COLORS` объявлены как `Record<StepStatus, ...>`
- [ ] Состояние `phase` меняется: `idle → forward → compensating → done`
- [ ] `runSaga` последовательно меняет статус шагов с задержкой
- [ ] При ошибке компенсация выполняется в строго обратном порядке
- [ ] `abortRef.current = true` в `reset` прерывает асинхронный цикл
- [ ] Выбор `failAt === -1` приводит к успешному завершению всех шагов
- [ ] Карточки сервисов отображают текущий статус и событие (компенсирующее при откате)
- [ ] Стрелка между шагами меняет цвет: зелёный (success) / красный (compensating)
- [ ] Лог событий прокручивается и окрашивает строки по типу
- [ ] `<select>` заблокирован (`disabled`) во время выполнения
- [ ] CSS-анимация `pulse` работает для бегущих шагов

## Как проверить себя

1. Откройте задание — должна отобразиться горизонтальная цепочка из 4 карточек (все в статусе "Ожидание").
2. Выберите ошибку на "InventoryService" (шаг 2) и нажмите "Запустить Saga".
3. Первые два шага (OrderService, PaymentService) должны последовательно перейти в "Успешно" с зелёными стрелками.
4. InventoryService переходит в "Ошибка" с красной рамкой.
5. Запускается компенсация: PaymentService → "Откат...", затем "Откатано"; OrderService — то же самое. Лог содержит строки `[COMPENSATE]`.
6. В конце появляется `[SAGA] Компенсация завершена...`.
7. Выберите "Без ошибок" — все 4 шага последовательно переходят в "Успешно", лог заканчивается `[SAGA] Заказ успешно обработан всеми сервисами!`.
8. Нажмите "Сбросить" в процессе выполнения — анимация должна остановиться, все шаги вернуться в "Ожидание".
