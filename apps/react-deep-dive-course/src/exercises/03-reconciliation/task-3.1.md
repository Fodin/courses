# Задание 3.1: Diff Visualizer

## Цель

Реализовать упрощённый diff-алгоритм и визуализировать его результат. Пользователь вводит два массива элементов (before/after), компонент показывает список операций: CREATE, UPDATE, DELETE с цветной индикацией. Это поможет прочувствовать, как React решает, что делать с каждым элементом.

## Требования

1. Отобразить два редактируемых списка: "До" и "После" — каждый элемент имеет `key` (строка) и `value` (строка).
2. Добавить кнопки "Добавить элемент" в каждый список и возможность удалить любой элемент.
3. Реализовать функцию `diffArrays(before, after)`, которая сравнивает элементы по `key` и возвращает массив операций:
   - `CREATE` — key есть только в "После"
   - `DELETE` — key есть только в "До"
   - `UPDATE` — key есть в обоих, но `value` изменился
   - `NOOP` — key есть в обоих, `value` одинаков (без изменений)
4. Отображать результат diff в виде таблицы: операция (цветная иконка), key, старое value, новое value.
5. Показывать счётчик операций каждого типа в шапке результатов.
6. Использовать только `useState` и `inline CSS`.

## Чеклист

- [ ] Два редактируемых списка Before/After с key и value для каждого элемента
- [ ] Можно добавить и удалить элементы из обоих списков
- [ ] Функция diffArrays корректно находит CREATE, DELETE, UPDATE, NOOP
- [ ] Результаты отображаются в таблице с цветными индикаторами операций
- [ ] CREATE — зелёный, DELETE — красный, UPDATE — жёлтый, NOOP — серый
- [ ] Счётчики операций показываются над таблицей
- [ ] Таблица обновляется в реальном времени при редактировании списков

## Как проверить себя

1. Создай Before: `[{key: "a", value: "Alice"}, {key: "b", value: "Bob"}]`
2. After: `[{key: "b", value: "Bobby"}, {key: "c", value: "Charlie"}]`
3. Ожидаемый diff:
   - `DELETE` key="a" (было "Alice", нет в After)
   - `UPDATE` key="b" ("Bob" → "Bobby")
   - `CREATE` key="c" (нет в Before, есть "Charlie")
4. Измени value у "b" в After обратно на "Bob" — операция должна стать `NOOP`
5. Убедись, что счётчики обновляются моментально
