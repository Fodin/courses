# Задание 0.2: Калькулятор латентности

## Цель

Построить интерактивный калькулятор, который визуализирует из каких этапов складывается латентность HTTP-запроса и показывает waterfall-диаграмму.

## Требования

1. Создайте компонент с цепочкой этапов запроса: DNS Lookup, TCP Handshake, TLS Handshake, HTTP Request, Server Processing, Response Transfer
2. Для каждого этапа добавьте ползунок или поле ввода для настройки задержки (в мс)
3. Рассчитайте и отобразите суммарную латентность
4. Визуализируйте waterfall-диаграмму: горизонтальные бары для каждого этапа, расположенные последовательно
5. Добавьте пресеты сценариев: «Локальная сеть», «Один континент», «Межконтинентальный запрос»
6. Покажите, как keep-alive и кэширование DNS влияют на повторный запрос

## Чеклист

- [ ] Отображается список всех этапов запроса с настраиваемыми задержками
- [ ] Суммарная латентность рассчитывается автоматически при изменении любого параметра
- [ ] Waterfall-диаграмма визуально показывает длительность каждого этапа
- [ ] Есть минимум 3 пресета с реалистичными значениями задержек
- [ ] Видно разницу между первым и повторным запросом (DNS-кэш, keep-alive)
- [ ] Компонент использует `useState` для управления состоянием

## Как проверить себя

1. Откройте задание в браузере
2. Переключитесь между пресетами — значения задержек должны обновляться
3. Измените значение одного этапа — суммарная латентность и waterfall должны обновиться
4. Сравните первый и повторный запрос — повторный должен быть быстрее
5. Проверьте, что суммарная латентность = сумма всех этапов
