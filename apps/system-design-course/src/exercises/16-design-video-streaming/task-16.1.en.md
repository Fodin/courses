# Task 16.1: Quiz — Video Streaming (YouTube-like)

## Goal

Verify understanding of key decisions when designing a video platform: adaptive bitrate streaming (HLS/DASH), transcoding pipeline, CDN architecture for video, view counting at scale.

## Requirements

1. Read the level 16 theory (README)
2. Complete the 5-question quiz on key concepts
3. For each question, select the correct answer (some questions have multiple correct answers)
4. Try to answer without peeking at the theory

## Checklist

- [ ] Read the video platform design theory
- [ ] Understand the difference between HLS and DASH, why both are needed
- [ ] Understand the principle of adaptive bitrate (segments, quality switching)
- [ ] Understand the transcoding pipeline architecture (async, DAG, message queue)
- [ ] Understand the role of CDN (3-tier, push vs pull, cache hit rate)
- [ ] Understand the approach to view counting at scale (Kafka → aggregation → batch write)
- [ ] Passed the quiz with at least 80%

## How to check yourself

1. Open the quiz and answer all questions
2. Check explanations for incorrect answers
3. If the result is below 80% — reread the relevant theory sections
