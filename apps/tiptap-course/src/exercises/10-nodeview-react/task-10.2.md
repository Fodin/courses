# Задание 10.2: NodeViewContent: редактируемая зона

## Цель

Реализовать ноду-карточку (`card`) с нередактируемым заголовком (эмодзи + статичный текст) и редактируемой зоной содержимого через `NodeViewContent`.

## Требования

1. Создайте `Node.create({ name: 'card', group: 'block', content: 'inline*', ... })`
2. `addNodeView()` — `ReactNodeViewRenderer(CardComponent)`
3. `CardComponent` рендерит: `NodeViewWrapper` → статичный заголовок ("📇 Карточка", не редактируемый) → `NodeViewContent` (редактируемая зона для текста)
4. В основном компоненте задания — кнопка "Вставить карточку", вставляющая ноду с начальным текстом внутри (например, через `insertContent({ type: 'card', content: [{ type: 'text', text: 'Текст карточки' }] })`)
5. Стилизуйте карточку через CSS: рамка, отступы, визуально отделённый заголовок

## Чеклист

- [ ] Компонент называется `Task10_2` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.10.2')` используется в заголовке
- [ ] Заголовок карточки статичен и не редактируется пользователем
- [ ] Текст внутри `NodeViewContent` можно свободно редактировать (печатать, применять marks типа bold)
- [ ] Карточка визуально оформлена и отличима от обычного текста
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Нажмите "Вставить карточку" — должна появиться карточка со статичным заголовком и редактируемым текстом
2. Кликните в область текста карточки и отредактируйте его — изменения должны применяться
3. Попробуйте кликнуть на заголовок — курсор не должен туда попадать (заголовок статичен)
4. Выделите текст внутри карточки, примените bold — форматирование должно сработать (content: 'inline\*' разрешает marks по умолчанию)
