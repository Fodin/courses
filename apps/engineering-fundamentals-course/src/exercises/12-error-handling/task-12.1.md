# Задание 12.1: Квиз — Обработка ошибок

## Цель
Проверить понимание стратегий обработки ошибок: Result-тип, разделение ожидаемых и неожиданных ошибок, граница обработки.

## Требования
1. Прочитайте теорию уровня 12 (README)
2. Пройдите квиз по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист
- [ ] Прочитана теория по типам ошибок (ожидаемые vs неожиданные)
- [ ] Изучен паттерн Result/Either и Railway-ориентированное программирование
- [ ] Разобраны принципы Fail Fast и Defence in Depth
- [ ] Понята концепция границы обработки ошибок
- [ ] Пройден квиз с результатом не менее 80%

## Как проверить себя
1. Откройте квиз и ответьте на все вопросы
2. Проверьте объяснения для неправильных ответов
3. Если результат ниже 80% — перечитайте соответствующие разделы теории
