# Задание 16.1: Квиз — Видеостриминг (YouTube-like)

## Цель

Проверить понимание ключевых решений при проектировании видеоплатформы: adaptive bitrate streaming (HLS/DASH), transcoding pipeline, CDN-архитектура для видео, подсчёт просмотров at scale.

## Требования

1. Прочитайте теорию уровня 16 (README)
2. Пройдите квиз из 5 вопросов по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ (некоторые вопросы имеют несколько правильных ответов)
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист

- [ ] Прочитана теория по проектированию видеоплатформы
- [ ] Понятна разница между HLS и DASH, зачем нужны оба
- [ ] Понятен принцип adaptive bitrate (сегменты, переключение качества)
- [ ] Понятна архитектура transcoding pipeline (async, DAG, message queue)
- [ ] Понятна роль CDN (3-tier, push vs pull, cache hit rate)
- [ ] Понятен подход к подсчёту просмотров at scale (Kafka → aggregation → batch write)
- [ ] Пройден квиз с результатом не менее 80%

## Как проверить себя

1. Откройте квиз и ответьте на все вопросы
2. Проверьте объяснения для неправильных ответов
3. Если результат ниже 80% — перечитайте соответствующие разделы теории
