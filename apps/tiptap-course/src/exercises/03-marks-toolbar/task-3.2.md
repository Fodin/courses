# Задание 3.2: Inline code

## Цель

Добавить кнопку переключения инлайн-кода (`code` mark) и продемонстрировать, что этот mark визуально не сочетается с bold/italic в реальных приложениях (хотя технически можно применить одновременно).

## Требования

1. Создайте `editor` через `useEditor` с `StarterKit`
2. Добавьте кнопку "Code" (иконка `</>` или моноширинный текст `<>`), переключающую `toggleCode()`
3. Подсветите кнопку при `editor.isActive('code')`
4. Добавьте горячую клавишу-подсказку в title кнопки: `Ctrl+E` (это встроенный шорткат для code mark в StarterKit)
5. Стилизуйте инлайн-код через CSS так, чтобы он был виден — моноширинный шрифт, светлый фон

## Чеклист

- [ ] Компонент называется `Task3_2` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.3.2')` используется в заголовке
- [ ] Кнопка Code переключает моноширинное оформление
- [ ] Подсветка кнопки работает корректно
- [ ] Инлайн-код визуально отличим от обычного текста
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Выделите слово, нажмите кнопку Code — текст должен получить моноширинный шрифт и фон
2. Проверьте горячую клавишу `Ctrl+E` (или `Cmd+E`) — она должна тоже переключать code mark
3. Убедитесь, что HTML-вывод (можно временно вывести через `editor.getHTML()`) содержит тег `<code>`
