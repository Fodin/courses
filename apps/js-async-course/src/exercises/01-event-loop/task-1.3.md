# Задание 1.3: Предскажи порядок выполнения

## Цель

Реализовать интерактивный тренажёр-пазл, где студент видит фрагмент кода и должен расставить строки вывода в правильном порядке, нажимая кнопки с вариантами ответа.

## Требования

1. **Три пазла** разной сложности (переключаются вкладками):
   - Базовый: sync + setTimeout + Promise
   - Средний: вложенные .then + setTimeout
   - Сложный: queueMicrotask + Promise + setTimeout + sync

2. **Механика ответа** — кнопки с доступными вариантами вывода; студент нажимает в том порядке, в каком они должны выводиться

3. **Проверка** — кнопка "Проверить" активируется когда все варианты расставлены; зелёный цвет — правильно, красный — нет

4. **Объяснение** — после проверки показывается подробное пояснение для каждой строки: почему именно в этот момент

5. **Undo** — кнопка отмены последнего выбора

6. **Сброс** — кнопка сброса к начальному состоянию без смены пазла

## Чеклист

- [ ] Компонент называется `Task1_3` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован, `t('task.1.3')` используется в заголовке
- [ ] Три пазла переключаются вкладками, состояние сбрасывается при переключении
- [ ] Кнопки с вариантами показывают только ещё не выбранные значения
- [ ] Кнопка "Проверить" заблокирована пока не расставлены все варианты
- [ ] После проверки каждая позиция подсвечена зелёным или красным
- [ ] Пояснение отображает причину для каждой строки вывода
- [ ] Кнопка Undo убирает последний выбор (до проверки)
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Откройте пазл "Базовый"
2. Правильный порядок: A → D → C → B
3. Попробуйте нажать сначала B — потом проверьте — должно быть отмечено как ошибка
4. Сбросьте и нажмите правильный порядок A → D → C → B — должно быть всё зелёным
5. Прочитайте пояснения — они должны объяснять почему C (Promise) раньше B (setTimeout)
6. Переключитесь на пазл "Сложный" и попробуйте его
