# Задание 7.5: Circuit Breaker

## Цель

Реализовать паттерн Circuit Breaker с тремя состояниями (CLOSED → OPEN → HALF-OPEN). Защищать клиентский код от лавины ошибок при падении зависимого сервиса.

## Требования

1. **Три состояния автомата**:
   - `CLOSED` — запросы проходят, ведётся счёт ошибок
   - `OPEN` — запросы немедленно отклоняются с ошибкой (без ожидания)
   - `HALF_OPEN` — пробный запрос для проверки восстановления сервиса

2. **Переходы**:
   - CLOSED → OPEN: при N ошибок подряд (`failureThreshold`)
   - OPEN → HALF_OPEN: через `resetTimeout` миллисекунд
   - HALF_OPEN → CLOSED: если пробный запрос успешен (сброс счётчика ошибок)
   - HALF_OPEN → OPEN: если пробный запрос провалился

3. **Симулятор API** с тремя режимами: стабильный (0%), нестабильный (70% ошибок), упал (100%)

4. **Настройки**: `failureThreshold` (1-10), `resetTimeout` (1-10 секунд)

5. **Лог событий** с цветовой кодировкой: успех (зелёный), ошибка (красный), переход OPEN (красный), HALF-OPEN (жёлтый), CLOSED (зелёный), отклонён (серый)

6. **Визуализация автомата**: три блока состояний, активное выделено цветом

## Чеклист

- [ ] Компонент называется `Task7_5` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован и `t('task.7.5')` используется в заголовке
- [ ] Все три перехода состояний работают корректно
- [ ] В режиме OPEN запросы отклоняются мгновенно (без задержки сети)
- [ ] После `resetTimeout` автомат переходит в HALF-OPEN и делает пробный запрос
- [ ] Кнопка "10 запросов (авто)" удобно демонстрирует полный цикл
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Установите `failureThreshold = 3`, режим API = "Упал (100%)"
2. Нажмите "Один запрос" 3 раза — после третьей ошибки автомат должен перейти в OPEN
3. Нажмите ещё раз — запрос должен быть немедленно отклонён (без ожидания)
4. Подождите `resetTimeout` секунд, нажмите запрос — должен перейти в HALF-OPEN
5. Переключите API в "Стабильный", нажмите запрос — HALF-OPEN → CLOSED
6. Проверьте автоматический тест: установите "нестабильный" режим и запустите 10 запросов
