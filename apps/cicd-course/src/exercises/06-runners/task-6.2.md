# Задание 6.2: Tags и маршрутизация джобов

## Цель

Создать интерактивный симулятор маршрутизации: настраивай раннеры с тегами, создавай джобы с тегами и визуализируй, какой раннер возьмёт каждый джоб.

## Требования

1. Определи интерфейсы:
   - `Runner` с полями: `id, name, tags: string[], runUntagged: boolean, status: 'online' | 'offline'`
   - `CiJob` с полями: `id, name, tags: string[], assignedRunnerId: string | null, status: 'pending' | 'running' | 'matched' | 'no-runner'`

2. Создай начальные данные: 3 раннера (docker-runner с тегами [docker, linux], shell-runner с тегами [shell, windows, legacy], prod-runner с тегами [production, docker]) и 4 джоба (build без тегов, test с [docker], deploy-staging с [docker, linux], deploy-prod с [production, docker])

3. Реализуй логику сопоставления: раннер берёт джоб если:
   - Все теги джоба присутствуют у раннера
   - Если джоб без тегов — только если у раннера `runUntagged = true`

4. Отобрази два столбца:
   - Слева: список раннеров с их тегами (бейджи) и статусом
   - Справа: список джобов с их тегами и статусом назначения

5. Добавь кнопку "Запустить маршрутизацию" — анимирует процесс назначения джобов раннерам (по одному с задержкой)

6. Показывай результат: стрелки или подсветку, какой раннер взял какой джоб

7. Добавь возможность добавить кастомный тег к любому раннеру и пересчитать маршрутизацию

8. Особые случаи: если джоб не нашёл раннера — показать объяснение почему (какие теги не совпали)

## Ожидаемый результат

- Визуальное отображение раннеров и джобов
- После "Запустить маршрутизацию" — джобы получают раннеров
- Неназначенные джобы подсвечены красным с объяснением
- Добавление тега к раннеру и повторная маршрутизация работают

## Чеклист

- [ ] Интерфейсы Runner и CiJob типизированы
- [ ] Логика matchRunner корректно реализует правило "все теги джоба есть у раннера"
- [ ] Untagged jobs учитывают runUntagged у раннера
- [ ] Визуализация двух колонок с тегами-бейджами
- [ ] Кнопка запуска маршрутизации работает
- [ ] Неназначенные джобы показывают причину (какие теги отсутствовали)
- [ ] Интерактивное добавление тега к раннеру

## Как проверить себя

Нажми "Запустить маршрутизацию". Джоб "build" (без тегов) должен остаться без раннера (ни один не имеет runUntagged = true). Добавь тег к docker-runner, чтобы он покрыл все теги deploy-prod — он должен его подхватить.
