# Задание 6.1: Корзина с useReducer + раздельные Context

## Цель

Реализовать полноценную корзину интернет-магазина с `useReducer` для управления состоянием и двумя отдельными контекстами — для state и dispatch.

## Требования

1. Определите типы `CartItem`, `CartState`, `CartAction` (discriminated union с `ADD`, `REMOVE`, `INCREMENT`, `DECREMENT`, `CLEAR`)
2. Реализуйте `cartReducer(state, action): CartState` — чистая функция без мутаций
3. Создайте два контекста: `CartStateContext` и `CartDispatchContext` — они должны быть строго разделены
4. Реализуйте `CartProvider` — оборачивает оба контекста, внутри использует `useReducer`
5. Создайте хуки `useCartState()` и `useCartDispatch()` с проверкой на null и понятным сообщением об ошибке
6. Компонент `CartBadge` — показывает иконку корзины и общее количество товаров; подписан только на `CartStateContext`
7. Компонент `AddToCartButton` — кнопка добавления товара; меняет вид если товар уже в корзине
8. Компонент `CartDrawer` — боковая шторка со списком товаров: изменение количества (+/−), удаление, итоговая сумма, кнопка "Оформить заказ" (вызывает `CLEAR`)
9. Компонент `Task6_1` — каталог из минимум 3 товаров и кнопка открытия шторки с `CartBadge`

## Подсказки

- `useReducer` возвращает `[state, dispatch]`. `dispatch` стабилен — React гарантирует неизменность референса
- В case `ADD`: если товар уже есть — увеличиваем `quantity`, иначе добавляем с `quantity: 1`
- В case `DECREMENT`: после изменения количества отфильтруйте элементы с `quantity <= 0`
- Для шторки используйте `position: fixed` с `right: 0, top: 0, bottom: 0`
- Итоговую сумму считайте через `items.reduce((sum, i) => sum + i.price * i.quantity, 0)`

## Чеклист

- [ ] `cartReducer` — чистая функция, обрабатывает все 5 action-типов
- [ ] `CartProvider` использует `useReducer` и оборачивает два отдельных контекста
- [ ] `useCartState` и `useCartDispatch` бросают ошибку вне Provider
- [ ] `CartBadge` отображает корректное количество товаров
- [ ] `AddToCartButton` меняет вид (цвет/текст) если товар уже в корзине
- [ ] `CartDrawer` позволяет менять количество и удалять товары
- [ ] Нет общего объекта `{ state, dispatch }` в одном провайдере

## Как проверить себя

Добавьте несколько товаров — счётчик на кнопке должен обновиться. Откройте шторку — убедитесь, что можно менять количество (при 0 — товар удаляется). Нажмите "Оформить заказ" — корзина очищается. Убедитесь, что `AddToCartButton` не моргает при изменении количества уже добавленного товара (это значит, что dispatch-компоненты стабильны).
