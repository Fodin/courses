# Задание 7.4 — Разрыв цикла динамическим import() (простое)

## Цель

Разорвать двусторонний цикл `app.ts ↔ feature.ts`, заменив статический импорт на динамический `import()` внутри функции.

## Что дано

- `app.ts` — экспортирует `init`, `triggerFeature`; импортирует `runFeature` из `feature.ts` (🔒 только чтение);
- `feature.ts` — импортирует `init` из `app.ts` статически, хотя нужен он только внутри `runFeature`.

## Требования

1. В `feature.ts` уберите статический `import { init } from './app'`.
2. Сделайте `runFeature` асинхронной функцией.
3. Внутри неё получите `init` через `const { init } = await import('./app')`.
4. Нажмите «Проверить» — все проверки должны стать зелёными.

## Чеклист

- [ ] `feature.ts` не содержит статического импорта из `app.ts`
- [ ] `runFeature` использует `await import('./app')` внутри тела функции
- [ ] Цикл в графе импортов отсутствует
- [ ] Пройти квиз уровня ≥ 80%
