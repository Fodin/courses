# Задание 16.1: Квиз — Рефакторинг и код-ревью

## Цель
Проверить понимание принципов рефакторинга, распознавания Code Smells и проведения эффективного код-ревью.

## Требования
1. Прочитайте теорию уровня 16 (README)
2. Пройдите квиз по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист
- [ ] Прочитана теория по рефакторингу без изменения поведения
- [ ] Изучены основные Code Smells (Long Method, God Class, Feature Envy и др.)
- [ ] Разобраны техники рефакторинга (Extract Function, Introduce Parameter Object и др.)
- [ ] Понята методология проведения конструктивного код-ревью
- [ ] Пройден квиз с результатом не менее 80%

## Как проверить себя
1. Откройте квиз и ответьте на все вопросы
2. Проверьте объяснения для неправильных ответов
3. Если результат ниже 80% — перечитайте соответствующие разделы теории
