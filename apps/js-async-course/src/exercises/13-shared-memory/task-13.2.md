# Задание 13.2: Atomics API стенд

## Цель

Создать интерактивный стенд для изучения всех операций Atomics API. Пользователь выбирает операцию, ячейку и значение — видит `oldValue` и `newValue`. Фоновый Worker независимо обновляет одну ячейку, демонстрируя параллельный доступ к разделяемой памяти.

## Требования

1. **SharedArrayBuffer с 8 ячейками** — `new SharedArrayBuffer(8 * 4)`, `Int32Array[8]`.

2. **Визуализация ячеек** — 8 блоков с номером индекса и числовым значением. Клик по блоку выбирает ячейку для операции.

3. **Все операции Atomics**:
   - `store`, `load`, `add`, `sub`, `and`, `or`, `xor` — выбрать ячейку + значение → кнопка "Выполнить"
   - `compareExchange` — дополнительное поле `expected`; показать успех/неудача

4. **Результат операции** — панель с полями: `op`, `index`, `oldValue`, `newValue`. Для `compareExchange` — статус обмена.

5. **Подсветка изменённых ячеек** — при выполнении операции ячейка подсвечивается на 500мс.

6. **Фоновый Worker** — обновляет ячейку `[7]` через `Atomics.add(arr, 7, 1)` каждые ~200мс. Ячейка `[7]` помечена как "BG". Worker запускается при монтировании и останавливается при размонтировании.

7. **Лог фонового Worker'а** — показывает последние 10 обновлений ячейки `[7]`.

- [ ] `compareExchange` корректно показывает успех и неудачу
- [ ] Фоновый Worker обновляет ячейку `[7]` в реальном времени
- [ ] Подсветка ячейки при изменении (transition)

## Как проверить себя

1. Выберите операцию `store`, ячейку `[0]`, значение `100` → нажмите "Выполнить": ячейка покажет 100, `oldValue = 0`
2. Выберите `add`, ячейку `[0]`, значение `5` → ячейка покажет 105, `oldValue = 100`
3. Выберите `compareExchange`, ячейку `[0]`, expected `105`, replacement `0` → успех, ячейка → 0
4. Снова `compareExchange`, expected `999` → неудача (текущее значение != 999)
5. Понаблюдайте за ячейкой `[7]` — она автоматически инкрементируется каждые ~200мс
6. Выполните `load` на ячейку `[7]` — `oldValue === newValue` (операция только читает)
