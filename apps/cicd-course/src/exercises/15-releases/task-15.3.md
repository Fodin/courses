# Задание 15.3: Полный release pipeline

## Цель

Создать визуализатор полного release pipeline: от появления git-тега до публикации npm-пакета, Docker-образа и GitLab Release. Показать параллельное выполнение джобов, их зависимости и состояние.

## Требования

1. Отобразить все стадии pipeline в виде колонок: `test` → `build` → `release`
2. Показать джобы в каждой стадии:
   - test: `unit-tests`
   - build: `build-npm` и `build-docker` (параллельно)
   - release: `publish-npm`, `create-changelog`, `create-gitlab-release` (последний зависит от первых двух)
3. Реализовать кнопку "Запустить пайплайн" — она последовательно запускает джобы с имитацией выполнения (задержки через setTimeout)
4. Каждый джоб имеет три состояния: `pending` (серый), `running` (синий с анимацией), `success` (зелёный)
5. Показывать снизу лог текущего выполнения: что происходит на каждом шаге
6. После завершения pipeline отобразить итоговую сводку: версия опубликована в npm, Docker-образ с двумя тегами, GitLab Release создан

## Чеклист

- [ ] Три колонки стадий с правильным порядком
- [ ] Все шесть джобов отображаются в правильных стадиях
- [ ] build-npm и build-docker запускаются параллельно (одновременно переходят в running)
- [ ] create-gitlab-release ждёт завершения publish-npm и create-changelog
- [ ] Визуальные состояния: pending / running / success с разными цветами
- [ ] Лог обновляется по ходу выполнения пайплайна
- [ ] Кнопка "Запустить" блокируется во время выполнения и меняет текст на "Сбросить" после завершения
- [ ] Итоговая сводка после завершения (npm registry, Docker Hub, GitLab Release)

## Как проверить себя

1. Нажми "Запустить пайплайн" — unit-tests должен перейти в running
2. После завершения test-стадии — build-npm и build-docker должны запуститься одновременно
3. После завершения build — publish-npm и create-changelog запускаются параллельно
4. create-gitlab-release должен запуститься только после завершения обоих предыдущих
5. После полного завершения — появляется итоговая сводка с деталями публикации
6. Нажми "Сбросить" — все джобы возвращаются в pending

## Подсказки

- Состояние каждого джоба: `Record<string, 'pending' | 'running' | 'success'>`
- Используй `async/await` с `setTimeout` для имитации задержек: `await delay(1500)`
- Для параллельного запуска: `Promise.all([runJob('build-npm'), runJob('build-docker')])`
- Функция `delay(ms)`: `new Promise(resolve => setTimeout(resolve, ms))`
- Лог: `string[]` в useState, добавляй строки через `setLog(prev => [...prev, message])`
- Для анимации running-состояния: CSS `animation: pulse` или просто `opacity: 0.7` через дополнительный state
