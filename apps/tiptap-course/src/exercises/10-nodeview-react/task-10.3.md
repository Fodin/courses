# Задание 10.3: Интерактивная нода

## Цель

Реализовать todo-элемент (`todoItem`) с чекбоксом, локальным анимационным состоянием (например, эффект при отметке выполнения) и полем текста — комбинация локального React-состояния и атрибутов документа.

## Требования

1. Создайте `Node.create({ name: 'todoItem', group: 'block', content: 'inline*', ... })`
2. `addAttributes()` — `checked: { default: false }`
3. `addNodeView()` — `ReactNodeViewRenderer(TodoItemComponent)`
4. `TodoItemComponent`:
   - Чекбокс, синхронизированный с `node.attrs.checked`, изменение вызывает `updateAttributes({ checked: !checked })`
   - Локальное состояние `useState` для кратковременной CSS-анимации/подсветки при переключении (например, `justToggled`, сбрасываемое через `setTimeout`)
   - `NodeViewContent` для текста задачи, с зачёркиванием текста через CSS, если `checked === true`
5. Кнопка в основном компоненте — "Добавить задачу", вставляющая новый `todoItem`

## Чеклист

- [ ] Компонент называется `Task10_3` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.10.3')` используется в заголовке
- [ ] Чекбокс переключает `checked` через `updateAttributes`
- [ ] Текст зачёркивается визуально при `checked === true`
- [ ] Присутствует локальное React-состояние (не связанное с документом), дающее кратковременный визуальный эффект при переключении
- [ ] Можно добавить несколько задач, каждая работает независимо
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Нажмите "Добавить задачу" пару раз — должны появиться независимые todo-элементы
2. Отредактируйте текст одной из задач
3. Отметьте чекбокс — текст должен зачеркнуться, должен на короткое время появиться визуальный эффект (например, смена фона)
4. Снимите отметку — зачёркивание должно исчезнуть, эффект должен снова кратковременно сработать
5. Обновите значения у двух разных задач — убедитесь, что состояние не "перепутывается" между экземплярами
