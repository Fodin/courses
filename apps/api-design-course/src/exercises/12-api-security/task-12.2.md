# Задание 12.2: Матрица доступа (RBAC / scopes)

## Цель

Реализовать интерактивную матрицу авторизации. Студент выбирает «личность» (роль + scopes токена) и видит, какие эндпоинты вернут `200`, какие `403`, а при отсутствии токена — `401`. Цель — прочувствовать разницу между аутентификацией и авторизацией и между кодами 401/403.

## Требования

1. Список из 5–6 эндпоинтов с требуемыми правами, например:
   - `GET /orders` — требует scope `orders:read`
   - `POST /orders` — требует scope `orders:write`
   - `DELETE /orders/{id}` — требует роль `admin`
   - `GET /profile` — требует scope `profile:read`
   - `GET /admin/stats` — требует роль `admin`
2. Переключатель «личности»: `Аноним (без токена)`, `viewer`, `editor`, `admin` — у каждой свой набор роли и scopes
3. Для выбранной личности рассчитать и показать для каждого эндпоинта итог: `200 OK` (зелёный), `403 Forbidden` (оранжевый) или `401 Unauthorized` (красный, только для анонима)
4. Рядом с каждым результатом — краткое «почему» (какого scope/роли не хватило)
5. Панель токена: показать декодированный «токен» текущей личности (роль + список scopes) или пометку «токена нет» для анонима
6. Легенда: 401 = «не знаю, кто ты»; 403 = «знаю, но нельзя»; 200 = «можно»

## Чеклист

- [ ] Таблица эндпоинтов с указанием требуемого права
- [ ] Переключение между анонимом/viewer/editor/admin
- [ ] Для анонима все защищённые эндпоинты → 401
- [ ] Для аутентифицированных — 200 или 403 в зависимости от scope/роли
- [ ] Пояснение «почему» для каждого 403
- [ ] Панель текущего токена (роль + scopes)
- [ ] Легенда 401/403/200

## Логика прав (эталон)

| Личность | role | scopes |
|---|---|---|
| Аноним | — | — (нет токена → везде 401) |
| viewer | viewer | `orders:read`, `profile:read` |
| editor | editor | `orders:read`, `orders:write`, `profile:read` |
| admin | admin | `orders:read`, `orders:write`, `profile:read` (+ роль admin даёт админ-эндпоинты) |

Правило проверки для эндпоинта: сперва «есть ли токен?» (нет → 401), затем «есть ли нужный scope/роль?» (нет → 403, да → 200).

## Как проверить себя

1. Выбери «Аноним» — все защищённые эндпоинты красные (401).
2. Выбери `viewer` — `GET /orders` зелёный, `POST /orders` оранжевый (403, нет `orders:write`).
3. Выбери `editor` — `POST /orders` уже зелёный, но `DELETE /orders/{id}` и `/admin/stats` — 403 (нужна роль admin).
4. Выбери `admin` — всё зелёное.

## Подсказки

- Опиши эндпоинты как массив объектов `{ method, path, requiredScope?, requiredRole? }`.
- Функция решения: `if (!token) return 401; if (requiredRole && token.role !== requiredRole) return 403; if (requiredScope && !token.scopes.includes(requiredScope)) return 403; return 200`.
- Цвета: 200 `#22c55e`, 403 `#f59e0b`, 401 `#ef4444`.
