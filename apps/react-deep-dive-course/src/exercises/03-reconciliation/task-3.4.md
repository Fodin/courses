# Задание 3.4: Reconciliation Step-by-Step

## Цель

Реализовать упрощённый `reconcileChildren` — функцию, которая берёт старый список fiber nodes и новый список элементов и генерирует список операций. Пошаговый визуализатор покажет, как работает фаза 1 (линейный поиск) и фаза 2 (Map-based поиск) алгоритма reconciliation.

## Требования

1. Определить типы:
   - `FiberNode: { key: string; value: string; index: number }`
   - `Operation: { type: 'PLACEMENT' | 'UPDATE' | 'DELETION' | 'NOOP'; key: string; oldIndex?: number; newIndex?: number; note?: string }`
2. Реализовать функцию `reconcileChildren(oldFibers, newElements)`:
   - Фаза 1: линейный проход пока key совпадают (или отсутствует key — сравниваем по позиции)
   - Фаза 2: Map-based поиск для оставшихся элементов
   - Возвращать массив `Operation[]` и массив шагов (для визуализации)
3. Отобразить:
   - Два редактируемых массива: "Старые fibers" и "Новые элементы" (можно менять key, value, порядок)
   - Кнопку "Запустить reconciliation" — запускает пошаговый режим
   - Пошаговый визуализатор: "Шаг 1/N — [что происходит]" с кнопками "Назад" / "Вперёд"
   - На каждом шаге подсвечивать текущий элемент в обоих списках
   - Итоговый список операций с цветами
4. Preset-сценарии (кнопки):
   - "Добавить в начало" — старые [B, C], новые [A, B, C]
   - "Удалить из середины" — старые [A, B, C], новые [A, C]
   - "Переупорядочить" — старые [A, B, C, D], новые [B, C, D, A]

## Чеклист

- [ ] Типы FiberNode и Operation определены
- [ ] Функция reconcileChildren реализована (фаза 1 + фаза 2)
- [ ] Пошаговая визуализация с кнопками "Назад" / "Вперёд"
- [ ] Текущий обрабатываемый элемент подсвечивается
- [ ] Итоговые операции показаны с цветными индикаторами
- [ ] Preset-сценарии переключают тестовые данные
- [ ] Можно вручную редактировать old/new массивы

## Как проверить себя

1. Нажми preset "Переупорядочить" [A, B, C, D] → [B, C, D, A]
2. Запусти reconciliation. Ожидаемые шаги:
   - Фаза 1: newIdx=0, newKey=B, oldKey=A — несовпадение → прерываем
   - Фаза 2: строим Map {A:0, B:1, C:2, D:3}
   - B найден в Map, oldIndex=1, lastPlaced=0 → NOOP (остаётся)
   - C найден в Map, oldIndex=2, lastPlaced=1 → NOOP
   - D найден в Map, oldIndex=3, lastPlaced=2 → NOOP
   - A найден в Map, oldIndex=0 < lastPlaced=3 → PLACEMENT
3. Итого: только A получает PLACEMENT, остальные — NOOP.
4. Нажми "Добавить в начало" [B,C] → [A,B,C]:
   - Фаза 1: A vs B — несовпадение (с keys) → фаза 2
   - Или без keys: A обновляет fiber B, B обновляет fiber C, C — PLACEMENT (новый)
