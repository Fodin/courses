# Задание 0.2: Richardson Maturity Model

## Цель

Разобраться в четырёх уровнях зрелости REST API по модели Ричардсона и научиться определять уровень по примеру API.

## Требования

1. Создайте компонент `Task0_2` с интерактивной визуализацией всех **4 уровней RMM** (Level 0–3)
2. Для каждого уровня отображайте:
   - Название и описание уровня
   - Пример HTTP-запроса и ответа для одного сценария (например, "получить заказ")
   - Список характеристик уровня
3. Реализуйте переключение между уровнями (кнопки или табы) — по умолчанию активен Level 2
4. Добавьте **мини-квиз**: минимум 3 примера HTTP-запросов, для каждого пользователь выбирает уровень RMM
5. Квиз показывает правильный/неправильный ответ и объяснение
6. Считайте и отображайте количество правильных ответов

## Чеклист

- [ ] Все 4 уровня (Level 0, 1, 2, 3) реализованы
- [ ] Для каждого уровня есть пример запроса/ответа
- [ ] Переключение между уровнями работает
- [ ] Мини-квиз с минимум 3 вопросами
- [ ] Квиз показывает правильный ответ после выбора
- [ ] Счётчик правильных ответов работает
- [ ] После ответа на вопрос нельзя изменить ответ
- [ ] Компонент обёрнут в `<div className="exercise-container">`

## Как проверить себя

1. Откройте задание — должен быть активен Level 2
2. Переключите на Level 0 — убедитесь, что пример показывает "action tunneling" (всё через POST на один endpoint)
3. Переключите на Level 3 — в примере ответа должны быть `_links` с доступными действиями
4. Ответьте на первый вопрос квиза — должен сразу появиться правильный ответ и объяснение
5. Попробуйте ответить ещё раз на тот же вопрос — должно быть заблокировано
6. Ответьте на все вопросы и проверьте, что счётчик обновляется
