# Задание 7.2: Services — базы данных в CI

## Цель

Создать интерактивный конструктор конфигурации services для GitLab CI. Пользователь выбирает нужные сервисы (PostgreSQL, Redis, MongoDB) и видит готовый YAML со всеми необходимыми переменными окружения и корректными хостами для подключения.

## Требования

1. Показать список доступных сервисов: PostgreSQL, Redis, MongoDB, MySQL — каждый с иконкой и кратким описанием
2. При выборе сервиса добавить его в конфигурацию и показать блок с нужными переменными окружения (POSTGRES_DB, POSTGRES_USER, POSTGRES_PASSWORD и т.д.)
3. Для каждого сервиса показать правильный URL подключения (DATABASE_URL, REDIS_URL, MONGODB_URI) с корректным хостом (имя образа без тега)
4. Реализовать поле для ввода alias — пользователь вводит альтернативное имя хоста, и URL подключения обновляется
5. Показать визуализацию сети: контейнер джоба и сервисные контейнеры со стрелками подключения
6. Генерировать итоговый YAML-конфиг, обновляющийся в реальном времени

## Чеклист

- [ ] Карточки для выбора сервисов (PostgreSQL, Redis, MongoDB, MySQL)
- [ ] При выборе сервиса — блок с переменными окружения для инициализации
- [ ] Правильный хост в URL подключения (postgres, redis, mongo, mysql)
- [ ] Поле для ввода alias с live-обновлением URL
- [ ] Визуализация Docker-сети с контейнером джоба и сервисами
- [ ] YAML с секцией services и variables
- [ ] Подсказка: "Добавить ожидание готовности (pg_isready)" при выборе PostgreSQL

## Как проверить себя

1. Выбери PostgreSQL — в YAML должны появиться services: [postgres:15-alpine] и переменные POSTGRES_*
2. Укажи alias "database" для PostgreSQL — DATABASE_URL должен измениться на postgresql://...@database:5432/...
3. Добавь Redis к PostgreSQL — в YAML должны быть оба сервиса
4. Проверь визуализацию — она должна показывать два сервисных контейнера рядом с основным
5. Убери все сервисы — YAML не должен содержать секцию services

## Подсказки

- Данные о сервисах: объект с полями `image`, `alias`, `host`, `port`, `envVars`, `connectionUrl`
- Хост по умолчанию = имя образа без тега и версии: `postgres:15-alpine` → `postgres`
- Используй `useState` для `selectedServices` (Map или объект, где ключ = id сервиса)
- Визуализацию сети можно сделать через flex-контейнер с блоками и стрелками `→`
- URL меняется при вводе alias: если alias пустой — используй дефолтный хост
