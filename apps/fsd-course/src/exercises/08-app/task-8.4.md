# Задание 8.4 — Ничто не импортирует app (простое)

## Цель

Убрать импорт из `app` в `pages/home/ui/HomePage.tsx` — app вершина графа, ниже
неё ничего не может на неё ссылаться.

## Что дано

- `app/config/routes.ts` — константа `HOME_ROUTE` (🔒 только чтение);
- `pages/home/index.ts` — публичный API страницы (🔒 только чтение);
- `pages/home/ui/HomePage.tsx` — импортирует `HOME_ROUTE` прямо из `app/config/routes`.

## Требования

1. Уберите импорт `HOME_ROUTE` из `'@/app/config/routes'`.
2. Объявите `HOME_ROUTE` локальной константой прямо в `HomePage.tsx` (значение `'/'`).
3. Компонент должен по-прежнему выводить `HOME_ROUTE`.
4. Нажмите «Проверить» — все проверки должны стать зелёными.

## Чеклист

- [ ] В `HomePage.tsx` нет импорта из `@/app/...`
- [ ] `HOME_ROUTE` объявлена локально в файле
