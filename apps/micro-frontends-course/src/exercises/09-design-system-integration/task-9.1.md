# Задание 9.1 — Визуализатор CSS-конфликтов

## Цель

Создать интерактивный инструмент, который наглядно демонстрирует проблему CSS-конфликтов в MFE-архитектуре и показывает, как разные стратегии изоляции решают её.

## Требования

1. Отобразить два MFE-блока: «MFE A — Каталог (команда Alpha)» и «MFE B — Оформление (команда Beta)»
2. В каждом блоке показать кнопку и селектор CSS-класса (`selector: .btn` / `selector: .btn_hash` и т.д.)
3. Реализовать переключатель из четырёх стратегий: «Без изоляции», «CSS Modules», «Shadow DOM», «CSS Layers»
4. Для стратегии «Без изоляции» визуально симулировать конфликт: кнопка MFE A должна выглядеть как кнопка MFE B (красная, круглая), отображать предупреждение о конфликте
5. Для остальных стратегий: кнопки сохраняют свои правильные стили, отображать сообщение об успешной изоляции
6. Для «Shadow DOM» использовать реальный `attachShadow` с изолированными стилями
7. Показывать блок кода, иллюстрирующий текущую стратегию (разный CSS для каждой стратегии)
8. Отображать таблицу сравнения всех четырёх стратегий (изоляция, DX, runtime cost, поддержка браузеров)
9. Активная стратегия должна быть выделена в таблице и переключателе

## Чеклист

- [ ] Переключатель из 4 стратегий работает корректно
- [ ] При «Без изоляции» кнопка MFE A стилизована как MFE B (красная, скруглённая)
- [ ] При «Без изоляции» отображается предупреждение о конфликте
- [ ] При CSS Modules / Shadow DOM / CSS Layers отображается сообщение об успешной изоляции
- [ ] Shadow DOM реализован через `attachShadow`, а не через inline стили
- [ ] Блок кода меняется при смене стратегии
- [ ] Таблица сравнения отображается полностью со всеми 4 строками
- [ ] В переключателе и таблице активная стратегия выделена

## Как проверить себя

1. Переключите на «Без изоляции» — кнопка «Добавить» в MFE A должна быть оранжево-красной и с большим скруглением. Должен появиться красный блок с описанием конфликта.
2. Переключите на «CSS Modules» — обе кнопки должны иметь правильный вид, внизу MFE-блоков должны быть хеш-классы (.btn_a3x9k / .btn_b7m2p). Появляется зелёный блок об успехе.
3. Переключите на «Shadow DOM» — кнопки рендерятся через реальные Shadow DOM (проверьте в DevTools — элементы должны иметь `#shadow-root`).
4. В таблице строка активной стратегии должна быть выделена синим фоном.
