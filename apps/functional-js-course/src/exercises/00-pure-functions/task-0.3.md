# Задание 0.3: Рефакторинг к чистоте

## Цель

Превратить нечистую функцию `processOrder` в чистую, вынеся все побочные эффекты за её пределы через инъекцию зависимостей.

## Требования

1. Изучите нечистую функцию `processOrderImpure(order)`, которая:
   - Мутирует входной объект: добавляет поле `total` и `processedAt` прямо в аргумент
   - Использует `Date.now()` внутри (недетерминированность)
   - Вызывает `console.log` (побочный эффект I/O)
2. Реализуйте чистую версию `processOrderPure(order, now, logger)`:
   - Принимает `order: Order` (не мутирует его)
   - Принимает `now: number` вместо вызова `Date.now()` внутри
   - Принимает `logger: (msg: string) => void` вместо прямого `console.log`
   - Возвращает новый объект `ProcessedOrder` через spread: `{ ...order, total, processedAt: now, status: 'processed' }`
3. Создайте интерфейс с двумя панелями — код нечистой и чистой версии.
4. Добавьте кнопку "Запустить" — запускает обе функции с одинаковыми входными данными.
5. Покажите панель сравнения:
   - "Оригинал не мутирован?" — красный для нечистой (мутирован), зелёный для чистой (не тронут)
   - "Результат детерминирован?" — красный для нечистой (зависит от реального времени), зелёный для чистой
   - "Нет побочных эффектов?" — красный для нечистой, зелёный для чистой
6. Выведите лог побочных эффектов нечистой функции (перехваченные console.log сообщения).
7. Покажите JSON обоих результатов для сравнения.

## Чеклист

- [ ] `processOrderPure` не вызывает `Date.now()` внутри
- [ ] `processOrderPure` не вызывает `console.log` внутри
- [ ] `processOrderPure` возвращает новый объект, не изменяя `order`
- [ ] Вызов `processOrderPure(order, now, () => {})` с одинаковыми `now` всегда даёт одинаковый результат
- [ ] Нечистая версия реально мутирует аргумент (это показывает проблему, не ошибка в задании)
- [ ] Лог побочных эффектов нечистой функции виден в UI
- [ ] JSON-сравнение показывает, что оригинал для чистой версии остался неизменным

## Как проверить себя

1. Нажмите "Запустить" — в панели нечистой функции индикатор "Оригинал не мутирован?" должен быть красным.
2. В панели чистой функции все три индикатора должны быть зелёными.
3. Лог нечистой версии должен содержать строку вида `[processOrderImpure] processed order ORD-001`.
4. В JSON чистой версии `processedAt` должен быть фиксированным числом (не реальным timestamp), а у нечистой — реальным `Date.now()`.
5. Убедитесь, что в JSON нечистой версии объект-аргумент содержит добавленные поля (мутация произошла).
