# Задание 5.3: Topic Exchange

## Цель

Реализовать интерактивный симулятор Topic Exchange с поддержкой wildcard-паттернов `*` и `#`, визуальной подсветкой совпадений и возможностью добавления новых привязок.

## Требования

1. Определи интерфейс `TopicBinding` со свойствами: `id` (string), `pattern` (string), `queue` (string), `color` (string), `bgColor` (string).
2. Реализуй функцию `matchTopicPattern(pattern: string, key: string): boolean`:
   - `*` заменяет ровно одно слово (сегмент между точками)
   - `#` заменяет ноль или более слов
   - Для `#` в середине паттерна используй рекурсивный перебор оставшихся сегментов
3. Реализуй вспомогательную функцию `highlightPattern(pattern: string, key: string): React.ReactNode[]`, которая возвращает массив span-элементов:
   - wildcard-сегменты (`*`, `#`) — оранжевый цвет и жирный шрифт
   - совпадающие сегменты — зелёный цвет
   - несовпадающие сегменты — красный цвет
4. Инициализируй 5 привязок по умолчанию:
   - `order.#` → `all-orders`
   - `order.created.*` → `new-orders`
   - `*.paid.*` → `payments`
   - `user.#` → `user-events`
   - `#.error` → `error-handler`
5. Реализуй состояния: `bindings`, `routingKey`, `newPattern`, `newQueue`, `log`.
6. Вычисляй `matchedBindings` как производное от `bindings` и `routingKey` (без отдельного состояния).
7. Реализуй функцию `publish()`: добавляет в лог запись с ключом, временем и списком совпавших очередей.
8. Реализуй функцию `addBinding()`: добавляет новую привязку с цветом по циклу, очищает поля ввода.
9. Реализуй функцию `removeBinding(id)`: удаляет привязку по id.
10. Отобрази поле ввода routing key с крупным шрифтом и 8 кнопками-примерами под ним.
11. Отобрази список привязок: каждая карточка подсвечивается при совпадении, показывает паттерн с цветной разметкой, имя очереди и иконку ✅/❌.
12. Отобрази счётчик совпадений в заголовке списка привязок.
13. Добавь форму добавления нового binding с полями "паттерн" и "имя очереди".
14. Отобрази блок-справочник по wildcard-символам: `*` и `#` с примерами.

## Чеклист

- [ ] `matchTopicPattern` корректно обрабатывает `*` (ровно одно слово)
- [ ] `matchTopicPattern` корректно обрабатывает `#` (ноль или более слов)
- [ ] `matchTopicPattern` корректно обрабатывает `#` в середине паттерна (рекурсия)
- [ ] `highlightPattern` возвращает span-элементы с цветами для wildcard/match/no-match
- [ ] `matchedBindings` вычисляется реактивно без дополнительного состояния
- [ ] Счётчик совпадений обновляется при изменении routing key
- [ ] Кнопки-примеры устанавливают routing key одним кликом
- [ ] `addBinding` добавляет привязку и очищает поля
- [ ] `removeBinding` удаляет нужную привязку
- [ ] Лог содержит временную метку и список очередей-получателей
- [ ] Блок-справочник `*` и `#` присутствует с примерами

## Как проверить себя

1. Введите `order.created.eu` — должны совпасть `order.#`, `order.created.*` (3 сегмента, второй — `created`, третий — `eu`).
2. Введите `order.error` — `order.#` и `#.error` совпадают.
3. Введите `system.error` — только `#.error` совпадает.
4. Введите `order.paid.us` — `order.#`, `*.paid.*` совпадают.
5. Добавьте новый binding `order.*.eu` → `eu-orders` и введите `order.created.eu` — он должен совпасть.
6. Нажмите "Опубликовать" — лог пополняется записью с текущим ключом и очередями.
