# Задание 12.2: Конструктор мониторинг-конфигурации

## Цель

Создать интерактивную таблицу для настройки параметров мониторинга каждого MFE (SLO, алерты, Circuit Breaker) с генерацией готового JSON-манифеста и встроенной валидацией.

## Требования

1. Таблица с тремя строками MFE (Catalog MFE, Cart MFE, Profile MFE) и редактируемыми колонками:
   - MFE Name (только для чтения)
   - Team Owner (текстовое поле)
   - SLO % (числовое поле, шаг 0.01, допустимый диапазон 99–99.999)
   - Error Budget (вычисляется автоматически: 100 − SLO, показывает % и минуты/месяц)
   - Alert Channel (select: Slack / PagerDuty / Email)
   - Health-Check URL (текстовое поле)
   - CB Threshold (числовое поле, ошибок до Open)
   - CB Open (числовое поле, секунды в Open до Half-Open)
   - CB Reset (числовое поле, секунды в Half-Open до сброса)
2. Валидация (подсвечивает поля красной рамкой):
   - Team Owner не пустой
   - SLO >= 99%
   - Health-Check URL начинается с `http`
   - CB Threshold > 0
3. Кнопка «Сгенерировать манифест» — активна только при прохождении всей валидации
4. Сгенерированный JSON показывается в блоке с заголовком `monitoring-manifest.json` и кнопкой «Копировать»
5. JSON включает: version, generatedAt, массив MFE с ownership, slo (availability + errorBudgetPercent + errorBudgetMinPerMonth), alerting, healthCheck, circuitBreaker
6. Тёмный стиль (#0f172a фон), все стили inline

## Чеклист

- [ ] Таблица с 9 колонками отображает 3 MFE
- [ ] Error Budget пересчитывается автоматически при изменении SLO
- [ ] Показывается как процент и как минуты в месяц
- [ ] Alert Channel — выпадающий список с тремя вариантами
- [ ] Валидация подсвечивает невалидные поля красной рамкой
- [ ] Текст ошибки валидации выводится под таблицей
- [ ] Кнопка «Сгенерировать манифест» заблокирована при наличии ошибок
- [ ] Сгенерированный JSON содержит все обязательные поля
- [ ] Кнопка «Копировать» меняет текст на «Скопировано!» на 2 секунды
- [ ] Тоггл «Скрыть/Показать манифест» работает корректно

## Как проверить себя

1. Очистите поле «Team Owner» у любого MFE — поле подсвечивается красным, кнопка генерации блокируется
2. Введите SLO = 98 — поле подсвечивается красным с сообщением «SLO должен быть >= 99%»
3. Исправьте все ошибки — кнопка «Сгенерировать манифест» становится активной
4. Измените SLO Cart MFE с 99.95 на 99.5 — Error Budget должен обновиться с 0.05% до 0.5% (21.9 мин → 219 мин в месяц)
5. Сгенерируйте манифест — убедитесь, что `errorBudgetMinPerMonth` рассчитан как `(100 - SLO) / 100 * 43800`
6. Нажмите «Копировать» — текст кнопки меняется на «Скопировано!»
