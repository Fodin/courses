# Задание 2.2: Generic DataList с renderItem и renderEmpty

## Цель

Реализовать универсальный компонент `DataList<T>`, который принимает массив данных и функции рендера для элементов и пустого состояния. Продемонстрировать его на трёх разных типах данных.

---

## Требования

1. Компонент `DataList<T>` параметризован дженериком — TypeScript должен выводить тип `item` в `renderItem` автоматически из типа массива `data`
2. Пропсы:
   - `data: T[]` — массив данных
   - `renderItem: (item: T, index: number) => ReactNode` — рендер одного элемента
   - `renderEmpty?: () => ReactNode` — рендер при пустом списке (опционально)
3. Если `data` пустой и передан `renderEmpty` — вызвать `renderEmpty()`
4. Если `data` пустой и `renderEmpty` не передан — показать дефолтное сообщение «Список пуст»
5. Реализовать три независимых использования `DataList`:
   - **Список пользователей** `{ id, name, role }` — карточка с именем и ролью
   - **Список товаров** `{ id, title, price }` — строка с названием и ценой
   - **Список уведомлений** `{ id, message, read }` — уведомление с отметкой прочитано/нет
6. Для каждого из трёх списков добавить кнопку «Очистить» — при нажатии `data` становится пустым, чтобы продемонстрировать `renderEmpty`

---

## Подсказки

- Объявление дженерика: `function DataList<T>({ data, renderItem, renderEmpty }: DataListProps<T>)`
- TypeScript в TSX-файлах требует `<T,>` или `<T extends object>` чтобы отличить от JSX-тега
- Для `key` в списке — если `T` не имеет `id`, используйте `index` как запасной вариант
- Интерфейс пропсов можно вынести отдельно: `interface DataListProps<T> { ... }`

---

## Чеклист

- [ ] `DataList<T>` объявлен как generic-функция
- [ ] TypeScript корректно выводит тип `item` в `renderItem` без явного указания
- [ ] Пустое состояние работает: при `data=[]` показывается `renderEmpty()` или дефолт
- [ ] Список пользователей рендерится с именем и ролью
- [ ] Список товаров рендерится с названием и ценой
- [ ] Список уведомлений показывает статус прочитанности
- [ ] Кнопка «Очистить» переключает список в пустое состояние

---

## Как проверить себя

Нажмите кнопку «Очистить» для каждого из трёх списков — должно появиться сообщение об отсутствии данных. При этом другие два списка не должны быть затронуты (независимое состояние).
