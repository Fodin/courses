# Задание 15.2: Симулятор кластера распределённого кэша

## Цель

Реализовать интерактивный симулятор Redis-подобного кластера, демонстрирующий consistent hashing с hash slots, маршрутизацию ключей, добавление/удаление нод с rebalancing и failover при отказе ноды.

## Требования

1. **Инициализация кластера** (N нод, по умолчанию 3):
   - Каждая нода имеет имя, статус (active/failed) и диапазон hash slots
   - 16384 слота равномерно распределены между нодами
   - Визуальное отображение: таблица нод с их слотами

2. **Добавление ноды** (кнопка «Add Node»):
   - Новая нода получает часть слотов от существующих (rebalancing)
   - Показать: какие слоты переместились и откуда
   - Визуализация до/после rebalancing

3. **Удаление ноды** (кнопка «Remove Node»):
   - Слоты удалённой ноды распределяются между оставшимися
   - Показать: перераспределение слотов

4. **PUT / GET ключа**:
   - Ввод ключа и значения
   - Показать: вычисление hash slot (CRC16 mod 16384)
   - Показать: на какую ноду попал ключ
   - GET: найти ноду по ключу и вернуть значение

5. **Failover** (кнопка «Kill Node»):
   - Нода переходит в статус «failed»
   - Данные ноды недоступны (GET возвращает ошибку)
   - Показать: какие ключи потеряны
   - Кнопка «Recover» — восстановить ноду (данные потеряны, слоты возвращены)

6. **Визуализация slot distribution**:
   - Прогресс-бар для каждой ноды (ширина пропорциональна количеству слотов)
   - Цветовая индикация: active = зелёный, failed = красный
   - Лог событий: все операции с timestamps

## Чеклист

- [ ] Кластер из N нод с равномерным распределением 16384 слотов
- [ ] Добавление ноды с rebalancing (визуализация перемещения слотов)
- [ ] Удаление ноды с перераспределением слотов
- [ ] PUT: ввод key/value → вычисление slot → routing на ноду
- [ ] GET: поиск ноды по ключу → возврат значения (или ошибка для failed ноды)
- [ ] Kill Node: нода в статус failed, данные недоступны
- [ ] Recover Node: восстановление ноды без данных
- [ ] Визуализация: прогресс-бары слотов, цветовой статус нод
- [ ] Лог событий с описанием каждой операции

## Как проверить себя

1. Создайте кластер из 3 нод — каждая должна иметь ~5461 слот
2. Добавьте 4-ю ноду — каждая должна иметь ~4096 слотов
3. Поместите 5 ключей — убедитесь, что они распределяются по разным нодам
4. Убейте ноду с ключом — GET этого ключа должен вернуть ошибку
5. Удалите ноду — её слоты должны распределиться между оставшимися
6. Сравните свой симулятор с эталонным решением (Solution)
