# Задание 8.2: addStorage

## Цель

Реализовать extension `EditStats`, который через `addStorage` хранит изменяемую статистику редактирования: количество произведённых изменений (`updatesCount`) и общее число введённых символов с начала сессии.

## Требования

1. Создайте `Extension.create({ name: 'editStats', addStorage() { return { updatesCount: 0, totalChars: 0 } } })`
2. В хуке `onUpdate()` extension должен увеличивать `this.storage.updatesCount` на 1 и обновлять `this.storage.totalChars = this.editor.getText().length`
3. Подключите extension вместе со `StarterKit`
4. В React-компоненте подпишитесь на изменения через собственный `onUpdate` в `useEditor` (отдельно от extension) и синхронизируйте `editor.storage.editStats` в `useState`, чтобы отображать актуальные значения
5. Выведите оба значения: "Изменений: N", "Символов сейчас: M"

## Чеклист

- [ ] Компонент называется `Task8_2` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.8.2')` используется в заголовке
- [ ] `editStats.updatesCount` корректно увеличивается на каждое изменение
- [ ] `editStats.totalChars` отражает актуальную длину текста
- [ ] React-компонент синхронизирует storage с UI через `onUpdate` + `useState` (а не читает `editor.storage` напрямую в JSX)
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Введите несколько символов — "Изменений" должно увеличиваться на каждое нажатие клавиши, "Символов сейчас" — отражать актуальную длину
2. Удалите весь текст — "Символов сейчас" должно стать 0, а "Изменений" продолжить расти
3. Откройте `editor.storage.editStats` через консоль браузера (временно добавив `console.log`) — значения должны совпадать с UI
