# Задание 11.3: Шаблоны компании — reusable CI templates

## Цель

Создать симулятор корпоративной библиотеки CI-шаблонов. Пользователь выбирает тип проекта (Node.js, Python, Go), стек технологий и видит сгенерированный `.gitlab-ci.yml` с подключением шаблонов из корпоративного репозитория.

## Требования

1. Показать "структуру" репозитория `company/ci-templates` в виде дерева файлов (интерактивный список)
2. Предоставить форму конфигурации проекта:
   - Тип проекта: Node.js / Python / Go
   - Дополнительные модули: Docker Build, Security Scan, Deploy to K8s (чекбоксы)
   - Версия шаблонов: выпадающий список (v1.0.0, v2.0.0, v2.1.0 — latest)
3. При выборе `v2.0.0` вместо последней — показывать информационное сообщение "Доступна v2.1.0"
4. Генерировать итоговый `.gitlab-ci.yml` с правильными include и extends
5. Показывать, какие джобы будут в пайплайне (список с иконками) исходя из выбранных модулей
6. Добавить кнопку "Скопировать YAML" (копирует в clipboard через `navigator.clipboard.writeText`)

## Чеклист

- [ ] Дерево файлов репозитория ci-templates (минимум 4 шаблонных файла)
- [ ] Выбор типа проекта (3 варианта)
- [ ] Чекбоксы для дополнительных модулей (минимум 3)
- [ ] Выбор версии (3 варианта с пометкой latest)
- [ ] Уведомление о доступной новой версии при выборе не-latest
- [ ] Сгенерированный YAML обновляется при изменении любого параметра
- [ ] Список джобов пайплайна обновляется вместе с YAML
- [ ] Кнопка "Скопировать YAML" с фидбеком ("Скопировано!")

## Как проверить себя

1. Выбери Node.js + Docker Build + Security Scan — YAML должен содержать три `include` блока
2. Выбери версию v1.0.0 — должно появиться уведомление о доступной v2.1.0
3. Добавь "Deploy to K8s" — список джобов пайплайна должен увеличиться
4. Нажми "Скопировать YAML" — текст кнопки должен измениться на "Скопировано!" на 2 секунды
5. Переключись на Go — YAML должен изменить шаблон с `nodejs.yml` на `golang.yml`

## Подсказки

- Структура состояния: `{ projectType, selectedModules: [], templateVersion }`
- Для кнопки копирования: `navigator.clipboard.writeText(yaml).then(() => setCopied(true))`; через `setTimeout` сбросить обратно
- Список версий: `[{ value: 'v1.0.0', label: 'v1.0.0' }, { value: 'v2.0.0', label: 'v2.0.0' }, { value: 'v2.1.0', label: 'v2.1.0 (latest)' }]`
- Шаблоны по типу проекта: `nodejs.yml`, `python.yml`, `golang.yml`
- Модули: `docker.yml` (Docker Build), `security.yml` (Security Scan), `deploy-k8s.yml` (Deploy to K8s)
- Для дерева файлов используй вложенные `div` с отступами и иконками (📁 / 📄)
