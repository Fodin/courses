# Задание 0.1: Чистая vs нечистая функция

## Цель

Наглядно показать разницу между чистой и нечистой функцией, запустив обе с одинаковыми входными данными несколько раз подряд и сравнив результаты.

## Требования

1. Реализуйте чистую функцию `calculateTotal(items)`, которая принимает массив `{ price: number, qty: number }[]` и возвращает сумму `price * qty` для всех элементов.
2. Реализуйте нечистую версию `calculateTotalImpure(items)`, которая помимо вычисления суммы увеличивает внешнюю переменную `globalDiscount` и вычитает её из результата.
3. Создайте интерфейс с двумя панелями — левая для чистой функции, правая для нечистой. Каждая панель показывает код функции.
4. Добавьте кнопку "Запустить 5 раз" — по клику обе функции вызываются 5 раз с одинаковым массивом `DEMO_ITEMS`.
5. Результаты каждого запуска отображаются в соответствующей панели с порядковым номером.
6. Напротив каждого результата чистой функции показывайте зелёную галочку, нечистой — красный крестик.
7. Под списком результатов выводите итоговое сообщение: для чистой — "Все результаты одинаковые — предсказуемо", для нечистой — "Результаты разные — непредсказуемо".

## Чеклист

- [ ] Функция `calculateTotal` не читает и не изменяет ничего вне своих аргументов
- [ ] Функция `calculateTotalImpure` мутирует внешнюю переменную (это намеренно — чтобы показать проблему)
- [ ] Перед каждым нажатием кнопки `globalDiscount` сбрасывается в `0`, чтобы демонстрация была воспроизводимой
- [ ] Пять вызовов чистой функции дают одинаковые числа
- [ ] Пять вызовов нечистой функции дают разные числа (каждый раз на 5 меньше предыдущего)
- [ ] Визуально панели различаются цветом заголовка (зелёный / красный)

## Как проверить себя

1. Нажмите кнопку — в левой колонке все 5 чисел должны быть одинаковыми (350).
2. В правой колонке числа должны убывать: 345, 340, 335, 330, 325.
3. Нажмите кнопку ещё раз — чистая снова даст 350 пять раз, нечистая снова начнёт убывать от 345 (потому что discount сбрасывается).
4. Если вы видите одинаковые числа в обеих колонках — нечистая функция не реализована правильно.
