# Задание 2.1: Состояния джоба

## Цель

Реализовать интерактивную визуализацию state machine джоба CI/CD, которая наглядно показывает переходы между состояниями при различных событиях.

## Требования

1. Отобразить текущее состояние джоба с иконкой и цветовой индикацией (pending, running, success, failed, canceled, skipped, manual)
2. Реализовать кнопки-события: **Start**, **Success**, **Fail**, **Cancel**, **Timeout** — каждая переводит джоб в соответствующее состояние
3. Кнопки должны быть активны только тогда, когда переход допустим (например, нельзя нажать "Success" если джоб не в состоянии `running`)
4. Вести лог переходов: каждый переход записывается в список с временной меткой и описанием события
5. Кнопка **Reset** — возвращает джоб в исходное состояние `created` и очищает лог

## Реализация

- Определи тип `JobState` — union type всех возможных состояний
- Определи константу `transitions` — объект, описывающий допустимые переходы из каждого состояния
- Каждое состояние отображается своим цветом: pending — серый, running — синий, success — зелёный, failed — красный, canceled — оранжевый, skipped — серый, manual — фиолетовый

## Ожидаемый результат

```
Текущее состояние: [running ▶️]

[Start] [✓ Success] [✗ Fail] [Cancel] [Timeout]    [Reset]

Лог переходов:
14:23:01  created → pending     Джоб поставлен в очередь
14:23:05  pending → running     Раннер взял джоб
```

## Подсказки

- Используй `useState` для хранения текущего состояния и массива лог-записей
- Функция `canTransition(from, event)` проверяет, допустим ли переход
- Для временной метки используй `new Date().toLocaleTimeString('ru-RU')`
- Кнопки делай `disabled` через `!canTransition(currentState, 'start')` и т.д.

## Проверь себя

- [ ] Все 7 состояний отображаются корректно с правильными цветами
- [ ] Недопустимые переходы заблокированы (кнопки `disabled`)
- [ ] Лог показывает историю всех переходов с временными метками
- [ ] Reset возвращает к начальному состоянию и очищает лог
- [ ] Интерфейс интуитивно понятен: сразу ясно какое состояние активно
