# Задание 2.1: MouseTracker с render prop

## Цель

Реализовать компонент `MouseTracker`, который отслеживает позицию курсора в пределах своей области и передаёт координаты через render prop. На базе `MouseTracker` создать tooltip-follower и отображение координат.

---

## Требования

1. Компонент `MouseTracker` принимает пропс `render: (pos: { x: number; y: number }) => ReactNode`
2. Компонент отслеживает движение мыши через `onMouseMove` в пределах своего блока-контейнера
3. Контейнер имеет явно заданные размеры (например, `height: 300px`) и стиль `position: 'relative'`
4. Координаты `x` и `y` — это позиция мыши относительно окна (`clientX`, `clientY`), либо относительно контейнера (на ваш выбор, но документируйте)
5. Реализовать два использования `MouseTracker`:
   - **Отображение координат**: показывает текст `x: ..., y: ...` внутри области
   - **Tooltip-follower**: кружок/элемент, который следует за курсором (через `position: absolute`)

---

## Подсказки

- `onMouseMove` принимает `React.MouseEvent<HTMLDivElement>` — из него берём `clientX`, `clientY`
- Для следования за курсором используйте `position: 'absolute'`, `left: x`, `top: y` с `transform: 'translate(-50%, -50%)'` чтобы центрировать элемент
- Тип для render prop: `render: (pos: { x: number; y: number }) => ReactNode`
- Не забудьте добавить `cursor: 'none'` на контейнер, если tooltip заменяет системный курсор

---

## Чеклист

- [ ] Компонент `MouseTracker` объявлен с типизированным render prop
- [ ] `onMouseMove` правильно обновляет состояние через `useState`
- [ ] Первый пример: координаты отображаются как текст внутри области
- [ ] Второй пример: элемент следует за курсором через `position: absolute`
- [ ] Область трекинга визуально выделена (рамка, фон)

---

## Как проверить себя

Откройте компонент в браузере. Двигайте мышью над областью трекинга:
- Цифры координат должны обновляться в реальном времени
- Tooltip-элемент должен плавно следовать за курсором без задержки
- Если убрать мышь за пределы области — позиция не должна обновляться (события не приходят)
