# Задание 6.1: HTML vs JSON

## Цель

Наглядно продемонстрировать разницу между HTML- и JSON-представлением одного и того же документа, переключаясь между режимами просмотра.

## Требования

1. Создайте `editor` через `useEditor` с `StarterKit`
2. Начальный контент должен включать заголовок, форматированный текст и список (богатая структура)
3. Заведите переключатель режима просмотра: "HTML" / "JSON" (радио-кнопки или табы)
4. В режиме HTML выводите `editor.getHTML()` в `<pre>`
5. В режиме JSON выводите `JSON.stringify(editor.getJSON(), null, 2)` в `<pre>`
6. Оба значения должны обновляться в реальном времени через `onUpdate`
7. Добавьте текстовое пояснение под переключателем: "HTML удобен для хранения и SEO, JSON — для точного восстановления документа"

## Чеклист

- [ ] Компонент называется `Task6_1` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.6.1')` используется в заголовке
- [ ] Переключение между HTML и JSON работает корректно
- [ ] Оба представления обновляются при редактировании текста
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Отредактируйте текст, примените форматирование (bold, заголовок)
2. Переключитесь на HTML — убедитесь, что видны соответствующие теги (`<strong>`, `<h2>` и т.д.)
3. Переключитесь на JSON — убедитесь, что видна структура с `type`, `attrs`, `marks`
4. Сравните: JSON явно показывает `marks: [{ type: 'bold' }]`, тогда как HTML просто оборачивает текст в `<strong>`
