# Задание 2.2: Отключение extensions

## Цель

Научиться выключать ненужные extensions через `StarterKit.configure()` и показать разницу между "полным" и "урезанным" редактором.

## Требования

1. Создайте два переключаемых режима через `useState<'full' | 'minimal'>`
2. В режиме `full` — обычный `StarterKit` без конфигурации
3. В режиме `minimal` — `StarterKit.configure({ heading: false, bulletList: false, orderedList: false, blockquote: false, codeBlock: false, horizontalRule: false })` — оставьте только параграфы, bold/italic и историю
4. При переключении режима редактор должен пересоздаваться с новым набором extensions (используйте `key` на компоненте-обёртке редактора, чтобы React полностью размонтировал/смонтировал `useEditor`, либо примите, что задание — это два раздельных под-компонента, переключаемых условным рендером)
5. В `minimal`-режиме кнопки/попытки создать заголовок не должны работать (соответствующей команды просто не существует)

## Чеклист

- [ ] Компонент называется `Task2_2` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.2.2')` используется в заголовке
- [ ] Переключатель между `full` и `minimal` режимами работает
- [ ] В `minimal` режиме заголовки, списки, цитаты, код и разделитель недоступны
- [ ] В `full` режиме всё работает как обычно
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. В режиме `full` попробуйте применить любое форматирование — всё должно работать
2. Переключитесь на `minimal` — редактор должен пересоздаться с чистым содержимым
3. Убедитесь, что в `minimal`-режиме доступны только bold/italic (можно добавить пару тестовых кнопок форматирования для проверки)
