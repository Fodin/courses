# Задание 14.3: CollaborationCaret: курсоры соавторов

## Цель

Добавить к синхронизированным редакторам из задания 14.2 визуализацию курсоров соавторов через `CollaborationCaret` — каждый участник должен видеть, где находится курсор другого, подписанный именем и выделенный цветом.

## Требования

1. Возьмите за основу пару редакторов с `WebrtcProvider` (как в 14.2)
2. Для каждого редактора подключите `CollaborationCaret.configure({ provider: providerX, user: { name: 'Имя', color: '#hex' } })`, где у двух редакторов разные имена и разные цвета
3. Стилизуйте курсор соавтора через CSS (селекторы `.collaboration-carets__caret`, `.collaboration-carets__label` — стандартные классы, генерируемые расширением)
4. Выведите список активных пользователей через `editor.storage.collaborationCaret.users` под каждым редактором

## Чеклист

- [ ] Компонент называется `Task14_3` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.14.3')` используется в заголовке
- [ ] Курсор одного редактора виден в другом при перемещении/клике
- [ ] У курсора отображается подпись с именем участника
- [ ] Список активных пользователей корректно отображается
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Кликните в разных местах первого редактора — во втором редакторе должен быть виден цветной курсор с подписью имени "участника А"
2. Выделите текст в одном редакторе — во втором должно быть видно выделение соответствующим цветом
3. Проверьте список пользователей под каждым редактором — должны отображаться оба участника
