# Задание 9.4: Review Apps — динамические окружения для Merge Request

## Цель

Создать симулятор системы Review Apps: открытие MR автоматически создаёт окружение, закрытие или merge — удаляет его. Показать полный жизненный цикл Review App и сгенерировать GitLab CI конфиг.

## Требования

1. Отобразить список веток (минимум 4 заранее заданных): `feature/user-auth`, `fix/login-bug`, `feature/dark-mode`, `refactor/api-client`
2. Для каждой ветки кнопки: "Открыть MR" / "Мёрж" / "Закрыть без мёржа"
3. При открытии MR — автоматически создать Review App с URL на основе slug ветки (показать URL)
4. При Мёрже или Закрытии без мёржа — удалить Review App, показать запись в логе "stop-review запущен"
5. Показать счётчик активных Review Apps (и ресурсов: каждый Review App "стоит" 1 pod)
6. Показать GitLab CI YAML конфигурацию для Review Apps (deploy-review + stop-review джобы)
7. Параметр `auto_stop_in` — выпадающий список или кнопки: `1 day`, `1 week`, `30 days`; YAML обновляется

## Чеклист

- [ ] Список веток с кнопками действий (состояние кнопок зависит от статуса ветки)
- [ ] При открытии MR — появляется карточка Review App с URL и статусом "deploying" → "active"
- [ ] URL формируется из slug ветки: `feature/user-auth` → `feature-user-auth.review.myapp.com`
- [ ] При Мёрже/Закрытии — карточка удаляется, в лог добавляется "stop-review: namespace удалён"
- [ ] Счётчик активных окружений и "потребляемых ресурсов"
- [ ] Кнопка "Открыть MR" недоступна, если MR уже открыт
- [ ] YAML с deploy-review и stop-review джобами
- [ ] Выбор auto_stop_in обновляет YAML в реальном времени

## Как проверить себя

1. Открой MR для двух веток — должны появиться две карточки Review App с разными URL
2. Сделай Мёрж одной — её карточка удаляется, лог показывает остановку окружения
3. Открой все 4 MR — счётчик ресурсов должен показывать 4 пода
4. Смени auto_stop_in на "1 day" — YAML должен обновиться немедленно
5. Закрой без мёржа — окружение удаляется так же, как при мёрже

## Подсказки

- Храни `branches` — массив объектов `{name, mrOpen, reviewAppActive, slug}`
- Slug: `name.toLowerCase().replace(/[^a-z0-9]/g, '-').replace(/-+/g, '-')`
- URL: `` `https://${slug}.review.myapp.com` ``
- Для анимации "deploying": можно использовать простой boolean `isDeploying` и менять его при клике
- YAML формируй как template literal, подставляя `autoStopIn` из стейта
