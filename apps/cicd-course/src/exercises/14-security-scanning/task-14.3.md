# Задание 14.3: DAST и Secret Detection

## Цель

Реализовать интерактивный компонент, демонстрирующий работу DAST (сканирование работающего приложения) и Secret Detection (обнаружение утечек секретов в коде). Показать последствия найденных секретов и сформировать полный security pipeline.

## Требования

1. Реализовать **симулятор Secret Detection**: текстовое поле для ввода кода — при изменении в реальном времени подсвечивать найденные секреты (проверять наличие паттернов: `sk_live_`, `AKIA`, `-----BEGIN RSA PRIVATE KEY-----`, `password=`)
2. Показать **панель DAST-настроек**: поле для TARGET_URL, переключатель режима (baseline / full-scan) с предупреждением для full-scan, поле DAST_PATHS
3. Отобразить **визуализацию DAST-запросов**: кнопка "Запустить сканирование" — анимировать 3-4 последовательных запроса к разным endpoint-ам с результатом (OK / WARNING / CRITICAL)
4. Реализовать **конструктор полного security pipeline**: 5 переключателей (SAST / Dependency Scanning / Container Scanning / Secret Detection / DAST) — YAML обновляется, показывая include-шаблоны для включённых инструментов
5. Показать **итоговую матрицу**: какой инструмент что находит — 5 строк инструментов × 4 столбца типов угроз

## Чеклист

- [ ] Текстовое поле для кода с подсветкой секретов в реальном времени
- [ ] Минимум 4 паттерна для определения секретов
- [ ] Поле TARGET_URL для DAST
- [ ] Переключатель baseline / full-scan с предупреждением
- [ ] Кнопка "Запустить сканирование" с последовательной анимацией запросов
- [ ] 5 переключателей инструментов для конструктора pipeline
- [ ] YAML обновляется при включении/выключении инструментов
- [ ] Матрица 5×4 с галочками покрытия

## Как проверить себя

1. Введи в поле текст `AWS_KEY=AKIAIOSFODNN7EXAMPLE` — должна появиться подсветка или предупреждение
2. Введи `password=mysecret123` — тоже должно сработать
3. Выбери режим full-scan — должно появиться предупреждение об активных атаках
4. Нажми "Запустить сканирование" — должны появиться запросы с результатами
5. Включи все 5 инструментов в конструкторе — YAML должен содержать 5 include-шаблонов

## Подсказки

- Паттерны секретов проверяй через `string.includes()` или простые регулярные выражения
- Для "анимации" запросов используй `setTimeout` + `useState` для массива результатов
- YAML конструктора: каждый включённый инструмент добавляет строку в `include:` секцию
- Матрицу рисуй через таблицу: `['Code injection', 'Dependency CVE', 'Container CVE', 'Leaked secrets']` × инструменты
- Для подсветки секрета в textarea используй `<span>` с `background: #ffeb3b` поверх текста (или просто показывай предупреждение под полем)
