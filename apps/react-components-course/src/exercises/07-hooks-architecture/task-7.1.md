# Задание 7.1: useAsync → useApi → UserSearch

## Цель

Реализовать цепочку хуков для загрузки данных: базовый `useAsync<T>` → специализированный `useApi<T>` с отменой запросов → компонент `UserSearch`, который использует хук и занимается только рендерингом.

## Требования

1. Реализуйте тип `AsyncState<T>` с полями `loading: boolean`, `data: T | null`, `error: string | null`
2. Реализуйте хук `useAsync<T>(fn: () => Promise<T>, deps: DependencyList)`:
   - При изменении `deps` запускает `fn()` и обновляет состояние
   - Обновляет `loading`, `data`, `error` атомарно (все три поля за раз)
   - Использует флаг `cancelled` для защиты от race condition при быстрых переключениях
   - Возвращает `AsyncState<T>`
3. Реализуйте хук `useApi<T>(url: string)`:
   - Строится поверх `useAsync` или реализует собственную логику с `AbortController`
   - При изменении `url` отменяет предыдущий запрос через `controller.abort()`
   - Игнорирует `AbortError` (это не ошибка, а нормальная отмена)
   - Возвращает `AsyncState<T>` + функцию `refetch`
4. Реализуйте компонент `UserSearch`:
   - Поле ввода для поискового запроса
   - Использует `useApi` для загрузки списка пользователей
   - Показывает состояние загрузки (индикатор или текст)
   - Показывает сообщение об ошибке при неудаче
   - Рендерит список пользователей с именем и email

## Подсказки

- Для демо используйте `https://jsonplaceholder.typicode.com/users` — возвращает 10 пользователей
- `AbortController` создаётся через `new AbortController()`, сигнал передаётся в `fetch(url, { signal: controller.signal })`
- `err.name === 'AbortError'` позволяет отличить отмену от настоящей ошибки
- В `useEffect` возвращайте функцию очистки: `return () => { controller.abort() }`
- Если `url` пустая строка — не делайте запрос (проверяйте перед вызовом `fetch`)
- Флаг `cancelled` внутри useEffect: `let cancelled = false` → в `.then()` проверяем `if (!cancelled)` → в cleanup: `cancelled = true`

## Чеклист

- [ ] `AsyncState<T>` типизирован с тремя полями
- [ ] `useAsync` запускает `fn` при монтировании и при изменении `deps`
- [ ] `useAsync` защищён от race condition через флаг `cancelled`
- [ ] `useApi` отменяет предыдущий запрос при новом вызове
- [ ] `AbortError` не отображается как ошибка пользователю
- [ ] `UserSearch` использует хук и не содержит fetch-логики
- [ ] Показывается состояние загрузки и ошибки
- [ ] Список пользователей рендерится после успешной загрузки

## Как проверить себя

Откройте демо — должен загрузиться список из 10 пользователей. Введите текст в поле поиска и быстро удалите — ни loading, ни error не должны "мигать" (AbortController отменяет незавершённые запросы). Отключите сеть в DevTools и нажмите кнопку обновления — должно появиться сообщение об ошибке.
