# Задание 14.2: Dependency Scanning и Container Scanning

## Цель

Реализовать визуализацию многоуровневого сканирования: показать, что Dependency Scanning и Container Scanning покрывают разные "слои" приложения, и построить интерактивный pipeline с обоими инструментами.

## Требования

1. Отобразить **слоистую диаграмму** Docker-образа: код приложения (5%) → зависимости (30%) → OS пакеты (65%) — каждый слой кликабельный, при клике показывает, какой инструмент его сканирует
2. Реализовать **симулятор нахождения уязвимостей**: кнопка "Найти уязвимости" — появляется список с двумя группами (найдено в зависимостях / найдено в OS)
3. Показать **настройку порога severity**: кнопки LOW / MEDIUM / HIGH / CRITICAL — при выборе показывает, сколько из найденных уязвимостей заблокирует пайплайн
4. Добавить **переключатель --ignore-unfixed**: при включении часть уязвимостей из списка "серая" (нет патча) и не считается
5. Отобразить итоговый YAML с настройками для обоих инструментов
6. Показать сравнительную таблицу: Dependency Scanning vs Container Scanning

## Чеклист

- [ ] Слоистая диаграмма с тремя слоями и процентами
- [ ] Клик на слой показывает описание инструмента для этого слоя
- [ ] Кнопка "Сканировать" — появляется 4-6 фиктивных уязвимостей в двух группах
- [ ] Кнопки выбора severity (4 варианта) — счётчик "заблокирует X из Y"
- [ ] Переключатель --ignore-unfixed с эффектом на список
- [ ] YAML-блок с конфигом dependency-scanning и container-scanning
- [ ] Сравнительная таблица из 2 строк

## Как проверить себя

1. Кликни на средний слой (зависимости) — должно появиться описание Dependency Scanning
2. Нажми "Сканировать" — должны появиться уязвимости разных severity
3. Выбери порог HIGH — уязвимости LOW и MEDIUM должны не блокировать
4. Включи --ignore-unfixed — часть уязвимостей должна стать серыми/неактивными
5. Проверь YAML — должны быть оба джоба с правильными artifact reports

## Подсказки

- Фиктивные уязвимости можно захардкодить как массив объектов: `{ name, severity, source: 'deps'|'os', fixed: boolean }`
- Слои рисуй через `div` с разной высотой и `background-color`
- Для счётчика: фильтруй уязвимости по `severity >= выбранный порог`
- При `ignoreUnfixed: true` дополнительно фильтруй по `fixed: true`
- Порядок severity для сравнения: LOW=1, MEDIUM=2, HIGH=3, CRITICAL=4
