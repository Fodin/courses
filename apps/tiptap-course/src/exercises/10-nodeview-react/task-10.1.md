# Задание 10.1: ReactNodeViewRenderer: базовый NodeView

## Цель

Реализовать ноду-счётчик (`counter`) с полноценным React-компонентом внутри документа: кнопки `-`/`+`, отображение текущего значения, кнопка удаления.

## Требования

1. Создайте `Node.create({ name: 'counter', group: 'block', atom: true, ... })`
2. `addAttributes()` — `count: { default: 0 }`
3. `parseHTML()`/`renderHTML()` — базовая сериализация через `div[data-counter]`
4. `addNodeView()` — возвращает `ReactNodeViewRenderer(CounterComponent)`
5. `CounterComponent` принимает `NodeViewProps`, использует `node.attrs.count`, `updateAttributes`, `deleteNode`
6. Обёрните компонент в `NodeViewWrapper`
7. В основном React-компоненте задания добавьте кнопку "Вставить счётчик", вызывающую `editor.chain().focus().insertContent({ type: 'counter' }).run()`

## Чеклист

- [ ] Компонент называется `Task10_1` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.10.1')` используется в заголовке
- [ ] Счётчик вставляется как интерактивный блок в документ
- [ ] Кнопки `-`/`+` изменяют значение через `updateAttributes`
- [ ] Кнопка удаления убирает узел из документа через `deleteNode`
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Нажмите "Вставить счётчик" — должен появиться интерактивный блок с кнопками и значением 0
2. Нажмите `+` несколько раз — значение должно увеличиваться
3. Нажмите `-` — значение должно уменьшаться
4. Нажмите кнопку удаления — счётчик должен полностью исчезнуть из документа
5. Вставьте два счётчика подряд — они должны работать независимо друг от друга
