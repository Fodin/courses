# Задание 6.2: Обработка ошибок в async/await

## Цель

Реализовать интерактивную демонстрацию трёх стратегий обработки ошибок в `async/await`: классический `try/catch`, `.catch()` на вызове и Go-style обёртка `[err, data]`. Один сценарий (API-запрос), переключатель "симулировать ошибку", вывод результата для каждой стратегии.

## Требования

1. **Три стратегии (вкладки):**
   - `try/catch` — классический подход
   - `.catch()` на вызове — `await fetchData().catch(handleError)`
   - Go-style — `const [err, data] = await to(fetchData())`

2. **Для каждой стратегии:**
   - Блок кода с отображением реализации
   - Список плюсов (минимум 2) и минусов (минимум 1)
   - Вывод выполнения (лог строк с цветами: зелёный для успеха, красный для ошибок)

3. **Управление:**
   - Кнопка "Запустить" — выполняет демо-запрос (задержка 600ms)
   - Чекбокс "Симулировать ошибку" — переключает между успехом и отказом
   - Статус-бейдж: "Успех" или "Ошибка перехвачена" после выполнения

4. **Таблица сравнения** трёх подходов: Читаемость, Гранулярность, Доп. зависимость

5. **Go-style вспомогательная функция:** `to<T>(promise)` — возвращает `[Error | null, T | null]`

## Чеклист

- [ ] Компонент называется `Task6_2` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован и `t('task.6.2')` используется в заголовке
- [ ] Три вкладки переключают стратегию и сбрасывают лог
- [ ] Кнопка "Запустить" показывает загрузку и блокируется во время выполнения
- [ ] При успехе в логе — зелёный вывод, при ошибке — красный
- [ ] Чекбокс "Симулировать ошибку" работает корректно
- [ ] Таблица сравнения отрисована и содержит 3 строки

## Как проверить себя

1. Откройте компонент на вкладке "try/catch", нажмите "Запустить" — через ~600ms появляется зелёный результат
2. Включите чекбокс, снова "Запустить" — в логе красная строка catch, статус "Ошибка перехвачена"
3. Переключитесь на ".catch() на вызове" — лог сбрасывается, та же симуляция работает
4. Go-style: при ошибке должно появиться `[err, null]`, при успехе `[null, result]`
5. Таблица сравнения видна под логом на всех вкладках
