# Задание 14.7: Формы в модальных окнах

## Цель

Научиться создавать формы внутри модальных окон с изолированным состоянием.

## Требования

1. Создайте список контактов с кнопкой "Добавить"
2. По нажатию "Добавить" открывается модальное окно с формой (имя, email, телефон)
3. Форма валидируется внутри модала — все поля обязательны, email должен быть валидным, телефон минимум 5 символов
4. При успешной отправке контакт добавляется в список, модал закрывается
5. Используйте `useForm` внутри модального компонента — при закрытии/открытии форма сбрасывается автоматически
6. Модальное окно реализуйте через div-overlay (без внешних библиотек)
7. Клик по overlay (фону) должен закрывать модал и сбрасывать форму

## Интерфейс данных

```typescript
interface Contact {
  name: string
  email: string
  phone: string
}
```

## Чеклист

- [ ] Список контактов отображается в таблице
- [ ] Кнопка "Добавить" открывает модальное окно
- [ ] Форма в модале валидируется (имя, email, телефон)
- [ ] При успешной отправке контакт появляется в списке
- [ ] Модал закрывается при успешной отправке и по клику на overlay
- [ ] Состояние формы сбрасывается при каждом открытии модала
- [ ] `useForm` находится внутри модального компонента

## Как проверить себя

1. Откройте модал и введите невалидные данные — должны появиться ошибки
2. Закройте модал и откройте снова — форма должна быть пустой (состояние сброшено)
3. Заполните форму валидными данными и отправьте — контакт должен появиться в списке
4. Добавьте несколько контактов — все должны отображаться в таблице
