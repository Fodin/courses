# Задание 0.2: Мини-тулбар

## Цель

Добавить к редактору из задания 0.1 простейшую панель инструментов с двумя кнопками — Bold и Italic — и научиться вызывать команды редактора из React-обработчиков.

## Требования

1. Создайте редактор так же, как в задании 0.1 (`useEditor` + `StarterKit`)
2. Над `EditorContent` разместите панель с двумя кнопками: **Bold** и _Italic_
3. По клику на кнопку Bold вызывайте `editor.chain().focus().toggleBold().run()`
4. По клику на кнопку Italic вызывайте `editor.chain().focus().toggleItalic().run()`
5. После клика фокус должен возвращаться в редактор (для этого в цепочке используется `.focus()`)
6. Кнопки должны быть отключены (`disabled`), пока `editor === null`

## Чеклист

- [ ] Компонент называется `Task0_2` и экспортируется
- [ ] `useLanguage` импортирован и `t('task.0.2')` используется в заголовке
- [ ] Кнопка Bold переключает жирность выделенного текста
- [ ] Кнопка Italic переключает курсив выделенного текста
- [ ] После клика на кнопку курсор остаётся в редакторе (можно сразу продолжать печатать)
- [ ] Кнопки не вызывают ошибку, если `editor` ещё `null`
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Введите текст в редактор, выделите слово
2. Нажмите кнопку Bold — слово должно стать жирным
3. Нажмите Bold ещё раз — жирность должна исчезнуть (toggle)
4. Выделите другое слово, нажмите Italic — слово должно стать курсивным
5. После клика на кнопку сразу начните печатать — новый текст должен появляться в редакторе без дополнительного клика мышкой
