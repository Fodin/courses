# Задание 8.4 — Cross-import слайсов одного слоя рождает цикл (простое)

## Цель

Устранить cross-import между двумя соседними слайсами одного слоя, который одновременно нарушает изоляцию слайсов и создаёт рантайм-цикл.

## Что дано

- `src/entities/user/model/user.ts` (редактируется) — импортирует `getLastOrderId` из соседнего слайса `entities/order`.
- `src/entities/order/model/order.ts` (редактируется) — импортирует тип `User` из соседнего слайса `entities/user`.

`user` и `order` — слайсы **одного** слоя `entities`, они не должны знать друг о друге. Вместе два импорта образуют двухузловой цикл `user ↔ order`.

## Требования

1. Уберите импорт `getLastOrderId` из `entities/user/model/user.ts`.
2. Уберите импорт `User` из `entities/order/model/order.ts`.
3. Замените зависимость от «чужого» объекта на примитив — передавайте `id` (строку) параметром вместо импорта типа/функции соседнего слайса.
4. Публичные функции (`describeUser`, `getLastOrderId`, `attachOwner`) должны продолжать работать, но уже без прямых импортов между `user` и `order`.
5. После правки в проекте не должно быть рантайм-цикла, а слайсы одного слоя не должны импортировать друг друга.

## Чеклист

- [ ] `entities/user/model/user.ts` не импортирует ничего из `entities/order`
- [ ] `entities/order/model/order.ts` не импортирует ничего из `entities/user`
- [ ] Нужные значения передаются параметрами, а не через импорт
- [ ] Проверка «нет рантайм-цикла» — зелёная
- [ ] Проверка «импорты уважают слои и изоляцию слайсов» — зелёная
- [ ] Пройти квиз уровня ≥ 80%

## Как проверить себя

1. Нажмите «Проверить» — обе проверки должны стать зелёными.
2. Убедитесь, что ни один файл слайса `entities/user` не упоминает путь `../order`, и наоборот.
3. Сравните с эталоном через «Показать эталон», если застряли.
