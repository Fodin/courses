# Задание 14.1: Визуализатор monorepo vs polyrepo

## Цель

Построить интерактивный визуализатор, который наглядно показывает разницу между monorepo и polyrepo подходами в MFE-архитектуре: структуру файлов/репозиториев, CI pipeline, граф зависимостей и ключевые метрики. Позволяет «добавить MFE» и увидеть, как каждый подход масштабируется.

## Требования

1. Реализовать переключатель «Monorepo» / «Polyrepo» (две кнопки), визуализация меняется при клике
2. Для каждого режима показать дерево файлов/репозиториев: monorepo — единая папочная структура с apps/ и packages/, polyrepo — список отдельных репозиториев с иконкой git
3. Показать CI pipeline в виде последовательности шагов: monorepo — affected-only с пометкой пропущенных шагов, polyrepo — полный прогон всех MFE параллельно
4. Отобразить граф зависимостей между MFE и shared-пакетами в виде связанных блоков
5. Показать 4 метрики с числовыми значениями: время CI (сек), cross-MFE refactoring (easy/hard), onboarding (clone N repo), dependency consistency (auto/manual)
6. Кнопка «+ Добавить MFE» — добавляет новый MFE в список, пересчитывает время CI: для monorepo время не растёт (affected-only), для polyrepo прибавляется ~30 сек на каждый MFE
7. Показать сравнительную таблицу итогов под визуализацией с 5 критериями

## Чеклист

- [ ] Переключатель Monorepo/Polyrepo работает, меняет всю визуализацию
- [ ] Дерево файлов корректно отображает структуру для каждого режима
- [ ] CI pipeline показывает affected-only в monorepo (часть шагов серые — пропущены) и полный прогон в polyrepo
- [ ] Граф зависимостей показывает MFE и shared-пакеты с линиями связей
- [ ] 4 метрики отображаются с правильными значениями для каждого режима
- [ ] Кнопка «+ Добавить MFE» добавляет MFE в структуру и пересчитывает CI-время
- [ ] В polyrepo время CI растёт линейно, в monorepo остаётся постоянным (affected-only)
- [ ] Сравнительная таблица показывает все 5 критериев с корректными значениями
- [ ] Темная тема, все стили inline

## Как проверить себя

1. Откройте задание — должен быть показан один из режимов (monorepo по умолчанию)
2. Переключитесь на Polyrepo — структура, pipeline и метрики должны измениться
3. Нажмите «+ Добавить MFE» 3 раза в режиме Polyrepo — время CI должно вырасти (~90 сек за 3 MFE)
4. Переключитесь на Monorepo и нажмите «+ Добавить MFE» 3 раза — время CI должно остаться постоянным
5. Таблица сравнения должна отражать актуальное количество MFE в строке онбординга
