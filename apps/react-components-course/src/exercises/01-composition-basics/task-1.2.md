# Задание 1.2 — PageLayout с четырьмя слотами

## Цель

Создать компонент `PageLayout`, который принимает четыре слота (`header`, `sidebar`, `children`, `footer`) и демонстрирует сборку полноценного dashboard-интерфейса через композицию.

## Требования

1. Реализовать компонент `PageLayout` с пропсами:
   - `header: React.ReactNode` — верхняя навигационная панель (обязательный)
   - `sidebar?: React.ReactNode` — левая боковая панель (необязательный)
   - `children: React.ReactNode` — основной контент страницы (обязательный)
   - `footer?: React.ReactNode` — нижний колонтитул (необязательный)
2. Если `sidebar` не передан — основной контент занимает всю ширину
3. Если `footer` не передан — нижний блок не рендерится
4. Реализовать компонент `DashboardPage` который использует `PageLayout` и наполняет слоты:
   - `header`: навигационная панель с названием приложения и иконкой пользователя
   - `sidebar`: навигационное меню с 4-5 пунктами (Главная, Аналитика, Пользователи, Настройки)
   - `children`: сетка из минимум трёх карточек со статистикой (используйте Card из задания 1.1 или упрощённую версию)
   - `footer`: строка с копирайтом
5. Все блоки визуально разграничены (фоновые цвета, отступы, бордеры)
6. Использовать flexbox через inline styles

## Подсказки

- Для горизонтального разделения sidebar + content используйте `display: flex`
- Sidebar имеет фиксированную ширину, content занимает `flex: 1`
- Header и Footer — полная ширина, `position: static` (не sticky)
- Для сетки карточек подойдёт `display: grid, gridTemplateColumns: 'repeat(3, 1fr)'`
- Минимальная высота layout: `minHeight: '100vh'` с `flexDirection: 'column'`

## Чеклист

- [ ] `PageLayout` принимает `header`, `sidebar?`, `children`, `footer?`
- [ ] При отсутствии `sidebar` — контент занимает всю ширину
- [ ] При отсутствии `footer` — нижний блок не рендерится
- [ ] `DashboardPage` наполняет все четыре слота
- [ ] Header отрендерен на всю ширину
- [ ] Sidebar и Content расположены горизонтально рядом
- [ ] Footer отрендерен на всю ширину внизу
- [ ] Статистические карточки в контентной зоне визуально оформлены

## Как проверить себя

Уберите `sidebar` из `DashboardPage` — контент должен автоматически расшириться на всю ширину. Уберите `footer` — нижняя полоса должна исчезнуть. Замените содержимое `header` на другой JSX — `PageLayout` должен это принять без изменений кода самого компонента.
