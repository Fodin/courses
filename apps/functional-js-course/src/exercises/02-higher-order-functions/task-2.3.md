# Задание 2.3 — Замыкания и приватное состояние

## Цель

Реализовать два классических примера замыканий: `createCounter` с приватным счётчиком
и `createRateLimiter` с ограничением частоты вызовов. Показать изоляцию состояния
между экземплярами.

## Требования

### Часть 1 — createCounter

1. Реализуйте функцию `createCounter(initial: number)` возвращающую объект:
   ```ts
   interface Counter {
     increment: () => void
     decrement: () => void
     reset: () => void
     getCount: () => number
   }
   ```
2. Переменная `count` должна быть **приватной** (недоступной снаружи объекта).
3. Отобразите **два независимых экземпляра** рядом: `createCounter(0)` и `createCounter(10)`.
4. Для каждого — кнопки `+`, `-`, `Reset` и отображение текущего значения.
5. Продемонстрируйте изоляцию: изменение одного счётчика не влияет на другой.

### Часть 2 — createRateLimiter

1. Реализуйте `createRateLimiter(maxCalls: number, windowMs: number)` — HOF возвращающий
   обёртку для функции.
2. Внутри хранится приватный массив меток времени вызовов.
3. При вызове `wrapped.call()`:
   - Удаляются метки старше `windowMs` миллисекунд.
   - Если вызовов в окне меньше `maxCalls` — вызов проходит (allowed: true).
   - Иначе — блокируется (allowed: false).
4. Кнопка "API Call" — показывает PASS/BLOCK в лог-записи с таймстампом.
5. Ползунки для настройки `maxCalls` (1-10) и `windowMs` (1000-5000 мс).
6. При изменении настроек — лимитер сбрасывается и создаётся новый.

## Чеклист

- [ ] `createCounter` реализован с приватной переменной `count` через замыкание
- [ ] Два экземпляра с разными `initial` отображаются рядом
- [ ] Кнопки +, -, Reset работают независимо для каждого экземпляра
- [ ] `createRateLimiter` возвращает HOF который оборачивает функцию
- [ ] Лог вызовов показывает PASS/BLOCK с таймстампами
- [ ] Ползунки maxCalls и windowMs меняют поведение лимитера
- [ ] Показан код с объяснением замыкания

## Как проверить себя

1. В части 1: нажмите `+` у counterA несколько раз — counterB не должен меняться.
2. Нажмите Reset у counterB — значение должно вернуться к initial, counterA не изменится.
3. В части 2: установите maxCalls=2, windowMs=3000, нажмите кнопку 5 раз подряд —
   первые 2 записи должны быть PASS, остальные BLOCK.
4. Подождите 3 секунды и снова нажмите — должно снова пройти.

## Подсказки

- Закрытая переменная создаётся объявлением `let count = initial` внутри `createCounter`
  до `return`.
- Для хранения экземпляров counter в React используйте `useState(() => createCounter(0))`.
- После каждого вызова `counter.increment()` нужно обновить React-стейт через
  `setCount(counter.getCount())`.
- В `createRateLimiter`: при изменении ползунков создавайте новый экземпляр лимитера
  и очищайте лог.
