# Задание 6.1: async/await vs Promise

## Цель

Реализовать интерактивную визуализацию, которая показывает параллельно: слева — код на `async/await`, справа — эквивалентная Promise-цепочка. Пошаговое выполнение с подсветкой активной строки в обоих видах и лог выполнения внизу.

## Требования

1. **Три примера для переключения:**
   - "Простой запрос" — базовый `fetch` + `json()`
   - "С обработкой ошибки" — `try/catch` vs `.catch()`
   - "Вложенные await" — три последовательных запроса, демонстрирующих "пирамиду смерти" в Promise-варианте

2. **Параллельная панель кода:**
   - Слева: async/await вариант с подсветкой текущей строки (зелёный акцент)
   - Справа: Promise-цепочка с подсветкой соответствующей строки (жёлтый акцент)
   - Нумерация строк слева от кода

3. **Лог выполнения:**
   - Показывает объяснение текущего шага
   - Последняя запись выделяется цветом, предыдущие — тусклые
   - Минимум 4 шага для каждого примера

4. **Управление:**
   - Кнопка "Шаг вперёд" — переход к следующему шагу
   - Кнопка "Сброс" — возврат к началу
   - Счётчик шагов (текущий / всего)
   - При переключении примера — автоматический сброс

5. **Информационный блок:** фиксированный текст "await приостанавливает функцию, но не поток"

## Чеклист

- [ ] Компонент называется `Task6_1` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован и `t('task.6.1')` используется в заголовке
- [ ] Три вкладки для переключения примеров работают и сбрасывают состояние
- [ ] Подсветка строк меняется синхронно в обоих панелях при каждом шаге
- [ ] Лог выполнения показывает объяснение текущего шага
- [ ] Кнопка "Шаг вперёд" заблокирована на последнем шаге
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Откройте компонент — должны быть видны три вкладки и два блока кода рядом
2. Нажмите "Шаг вперёд" — подсветка должна переместиться в обоих блоках одновременно
3. Переключите на "С обработкой ошибки" — стейт сбрасывается, подсветка на строке 0
4. На последнем шаге кнопка "Шаг вперёд" неактивна
5. Кнопка "Сброс" возвращает к шагу 1, лог очищается
