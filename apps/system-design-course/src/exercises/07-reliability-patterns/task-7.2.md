# Задание 7.2: Circuit Breaker симулятор

## Цель

Построить интерактивный симулятор Circuit Breaker: визуализировать переходы между состояниями Closed → Open → Half-Open при разных уровнях ошибок сервиса.

## Требования

1. **Сервис с настраиваемым error rate:**
   - Слайдер или кнопки для выбора вероятности ошибки (0%, 25%, 50%, 75%, 100%)
   - Каждый «запрос» — случайный успех/ошибка на основе заданного error rate
2. **Визуализация состояния Circuit Breaker:**
   - Текущее состояние: Closed (зелёный), Open (красный), Half-Open (жёлтый)
   - Счётчик последовательных ошибок / успехов
   - Визуальный индикатор перехода между состояниями
3. **Настраиваемые параметры:**
   - **Failure threshold** — после скольких ошибок подряд переход в Open (например, 3 или 5)
   - **Recovery timeout** — через сколько секунд из Open → Half-Open (например, 5s или 10s)
4. **Кнопка «Отправить запрос»** — один запрос через circuit breaker
5. **Лог событий** — хронология запросов и переходов состояний
6. **Счётчики:** всего запросов, успешных, неуспешных, заблокированных (circuit open)
7. **Reset** — сброс в начальное состояние

## Чеклист

- [ ] Слайдер/кнопки error rate (0%, 25%, 50%, 75%, 100%)
- [ ] Визуализация состояния (Closed=зелёный, Open=красный, Half-Open=жёлтый)
- [ ] Настройка failure threshold (3, 5, 10)
- [ ] Настройка recovery timeout (5s, 10s, 30s)
- [ ] Кнопка «Send Request» — один запрос
- [ ] Корректные переходы: Closed→Open при threshold, Open→Half-Open при timeout
- [ ] Half-Open→Closed при успехе, Half-Open→Open при ошибке
- [ ] Лог событий с отметками переходов состояний
- [ ] Счётчики: total, success, failure, blocked
- [ ] Reset

## Как проверить себя

1. Error rate 0%: все запросы проходят, состояние всегда Closed
2. Error rate 100%, threshold 3: после 3 запросов → Open, следующие запросы заблокированы
3. Error rate 100% → Open → подождать timeout → Half-Open → отправить запрос → Open (ошибка)
4. Error rate 100% → Open → переключить error rate на 0% → подождать timeout → Half-Open → запрос → Closed
5. Reset сбрасывает всё в начальное состояние
