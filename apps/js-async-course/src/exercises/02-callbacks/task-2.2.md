# Задание 2.2: Из колбэков в промисы

## Цель

Построить интерактивный компаратор: слева — тот же pipeline из 5 операций на вложенных колбэках, справа — эквивалентная Promise-цепочка (`.then().then()...`). Оба варианта запускаются одновременно и приходят к одному результату. Визуально продемонстрировать разницу: пирамида против плоской цепочки.

## Требования

1. **Две колонки кода** — синхронно отображают выполнение:
   - Левая: callback-версия с вложенностью (5 уровней отступа)
   - Правая: promise-версия — плоская цепочка `.then()`

2. **Подсветка соответствия**: при наведении на строку в любой колонке подсвечивается соответствующий шаг в обеих колонках одновременно

3. **Прогресс-бары**: под каждой колонкой — 5 сегментов, закрашивающихся по мере выполнения шагов

4. **Параллельный запуск**: кнопка "Запустить оба" стартует оба варианта одновременно, они выполняются независимо

5. **Таблица метрик** — сравнение двух подходов:
   - Глубина вложенности
   - Количество строк кода
   - Обработка ошибок
   - Читаемость

6. **Итоговое сообщение**: когда оба варианта завершены, показывается сообщение о том, что результат одинаковый

7. **Кнопки**: "Запустить оба" и "Сброс"

## Чеклист

- [ ] Компонент называется `Task2_2` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован, `t('task.2.2')` используется в заголовке
- [ ] Левая сторона использует вложенные колбэки (не промисы!)
- [ ] Правая сторона использует `.then().then().then()...` цепочку
- [ ] Hover-подсветка работает в обеих колонках одновременно при наведении на соответствующую строку
- [ ] Прогресс-бары обновляются независимо для каждой стороны
- [ ] Таблица метрик наглядно показывает разницу между подходами
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. Нажмите "Запустить оба" — оба pipeline должны начать выполнение одновременно
2. Наблюдайте, как прогресс-бары заполняются по мере завершения шагов
3. Наведите на первую строку левой колонки — первая строка правой должна тоже подсветиться
4. Дождитесь завершения — должно появиться сообщение об одинаковом результате
5. Сравните таблицу метрик: убедитесь, что промисы показывают лучшие показатели читаемости
6. Нажмите "Сброс" — всё должно вернуться в начальное состояние
