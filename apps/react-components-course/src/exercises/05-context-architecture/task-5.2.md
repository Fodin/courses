# Задание 5.2: Разделить монолитный AppContext на 4 контекста

## Цель

Взять готовый монолитный `AppContext` (user + theme + locale + notifications в одном) и разбить его на 4 независимых контекста. Доказать оптимизацию с помощью счётчиков рендеров.

## Требования

1. Возьмите монолитный `AppContext` из шаблона и разделите его на 4 независимых провайдера:
   - `UserProvider` — `{ user, setUser }`
   - `ThemeProvider` — `{ mode, setMode }`
   - `LocaleProvider` — `{ locale, setLocale }`
   - `NotificationsProvider` — `{ notifications, addNotification, dismissNotification }`

2. Каждый провайдер создайте через `createStrictContext<T>` из задания 5.1 (или реализуйте аналог прямо в файле).

3. Каждый провайдер мемоизирует значение через `useMemo`.

4. Реализуйте 4 демо-компонента, каждый читает только "свой" контекст:
   - `UserWidget` — показывает имя пользователя
   - `ThemeWidget` — показывает и переключает тему
   - `LocaleWidget` — показывает и переключает локаль
   - `NotificationsWidget` — показывает список и кнопку "Добавить уведомление"

5. В каждый виджет добавьте счётчик рендеров через `useRef`:
   - `const renderCount = useRef(0); renderCount.current += 1`
   - Отображайте счётчик в углу компонента: `Рендеров: {renderCount.current}`

6. Продемонстрируйте изоляцию: при нажатии "Добавить уведомление" счётчик должен расти только у `NotificationsWidget`, но не у `UserWidget`, `ThemeWidget` и `LocaleWidget`.

## Подсказки

- `useRef` для счётчика — именно `useRef`, не `useState`. `useState` провоцировал бы лишний рендер
- Счётчик в `useRef` увеличивается при каждом вызове функции компонента, это и есть рендер
- При изменении темы — только `ThemeWidget` должен увеличить счётчик рендеров

## Чеклист

- [ ] 4 отдельных контекста: User, Theme, Locale, Notifications
- [ ] Каждый провайдер использует `useMemo` для мемоизации значения
- [ ] Каждый виджет подписан только на "свой" контекст
- [ ] Счётчик рендеров через `useRef` в каждом виджете
- [ ] При добавлении уведомления — только `NotificationsWidget` ре-рендерится
- [ ] При смене темы — только `ThemeWidget` ре-рендерится
- [ ] Нет `any` в типах

## Как проверить себя

Откройте задание в браузере. Вы увидите 4 виджета со счётчиками рендеров.

1. Нажмите "Добавить уведомление" несколько раз — счётчик должен расти только у `NotificationsWidget`
2. Нажмите "Сменить тему" — счётчик должен вырасти только у `ThemeWidget`
3. Нажмите "Сменить локаль" — счётчик должен вырасти только у `LocaleWidget`

Если при добавлении уведомлений растут все счётчики — значит контексты не разделены (или монолитный AppContext ещё используется).
