# Задание 5.3: Promise.race — гонка промисов

## Цель

Реализовать двухрежимную визуализацию `Promise.race`. Первый режим — гонка трёх «бегунов» с настраиваемой задержкой и результатом. Второй режим — практический паттерн таймаута через `race([fetch, timeout])`.

## Требования

### Режим «Гонка бегунов»

1. **3 бегуна** с настраиваемыми параметрами:
   - Слайдер задержки от 300мс до 3000мс для каждого
   - Переключатель outcome: OK / FAIL (определяет, fulfilled или rejected будет промис)
   - Имена: Бегун А, Бегун B, Бегун C с разными цветами

2. **Трек гонки** — горизонтальные прогресс-бары:
   - Анимируются параллельно с разной скоростью
   - Первый финишировавший получает метку «ПОБЕДИТЕЛЬ» или «ПЕРВЫЙ REJECTED»
   - Остальные продолжают анимацию (но их результат игнорируется)

3. **Результат**: цветной блок с объяснением — кто победил, тип результата (fulfilled/rejected), его задержка

4. **Важный нюанс**: объяснение что `race` реагирует на первый результат любого типа (в отличие от `any`)

### Режим «Паттерн: Timeout»

5. **Два слайдера**: задержка fetch (500–5000мс) и таймаут (500–5000мс)
6. **Два прогресс-бара**: синий (fetch) и красный (timeout) — анимируются одновременно
7. **Подсказка под слайдерами**: «fetch быстрее таймаута на Xмс — ответ придёт» или «таймаут наступит раньше»
8. **Сниппет** с функцией `withTimeout(promise, ms)` — реальный паттерн

## Чеклист

- [ ] Компонент называется `Task5_3` и экспортируется по умолчанию
- [ ] `useLanguage` импортирован, заголовок из `t('task.5.3')`
- [ ] Два режима переключаются через вкладки без перезагрузки
- [ ] Слайдеры задержки обновляют значения в реальном времени
- [ ] Переключатель OK/FAIL меняет исход промиса
- [ ] Трек показывает реальную анимацию — бегуны финишируют в порядке задержек
- [ ] При FAIL outcome первый упавший становится результатом (demonstrated)
- [ ] Таймаут-режим показывает два прогресс-бара и корректно определяет победителя
- [ ] Нет TypeScript-ошибок типа `any`

## Как проверить себя

1. В режиме гонки: выставьте Бегуну A 2000мс, B — 800мс, C — 1500мс. Запустите — B должен победить
2. Выставьте Бегуну B исход FAIL — теперь B завершается ошибкой первым, результат race = rejected
3. Переключитесь на режим таймаута. Fetch=3000мс, Timeout=2000мс — победит таймаут
4. Поменяйте Fetch=1000мс, Timeout=2000мс — победит fetch
5. Убедитесь что подсказка под слайдерами правильно описывает ситуацию ещё до запуска
