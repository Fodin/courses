# Задание 4.1: Promise Pipeline — визуализатор цепочки трансформаций

## Цель

Построить интерактивный "конвейер", который показывает, как данные проходят через пять шагов `.then()`. Пользователь запускает конвейер кнопкой и видит анимацию: каждая станция загорается по очереди, показывая вход и выход данных. Второй элемент управления — переключатель "return Promise vs return value" на одном из шагов: студент видит, что результат одинаков в обоих случаях.

## Требования

1. Отрисовать 5 вертикальных карточек-станций:
   - `fetchUser` → `getPosts` → `filterRecent` → `sortByLikes` → `formatOutput`
   - Каждая карточка содержит имя функции, описание, значения входа и выхода
2. Кнопка "Запустить конвейер" — анимирует последовательную активацию карточек (задержка ~700 мс между шагами)
3. Активная карточка визуально выделяется (подсветка фоном, рамкой цветом станции)
4. Выполненные карточки остаются "зажжёнными" (менее яркими, с отметкой ✓)
5. Переключатель "return Promise / return value" меняет код на одном из шагов и показывает пояснение, что результат цепочки не меняется
6. Кнопка "Сброс" возвращает в начальное состояние

## Как проверить себя

1. Откройте компонент в браузере — должны быть видны 5 карточек в "тёмном" состоянии
2. Нажмите "Запустить конвейер" — карточки должны загораться одна за другой с паузой
3. После завершения все 5 карточек должны быть помечены ✓
4. Переключите режим "return value" — code-сниппет должен измениться, показав `recent.sort(...)`
5. Нажмите "Сброс" — карточки должны вернуться в начальное состояние, кнопка "Запустить" снова активна
