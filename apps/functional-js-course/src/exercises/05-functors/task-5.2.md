# Задание 5.2: Законы функторов

## Цель

Реализовать интерактивный "Law Checker" — инструмент, который проверяет выполнение двух законов функтора для разных контейнеров, включая намеренно сломанный `BadFunctor`.

## Требования

1. Реализуйте три контейнера:
   - `Box` — корректный функтор (из задания 5.1)
   - `Array` — использовать встроенный JavaScript массив (`[value].map(fn)`)
   - `BadFunctor` — сломанный функтор: метод `map(fn)` добавляет `"!"` к результату каждого вызова

2. Реализуйте проверку **Закона 1 — Идентичность**:
   ```
   F.map(x => x)  ===  F
   ```
   - Вычислить левую часть
   - Вычислить правую часть (исходное значение)
   - Сравнить через `JSON.stringify`
   - Показать "Закон выполняется" (зелёный) или "Закон нарушен" (красный)

3. Реализуйте проверку **Закона 2 — Композиция**:
   ```
   F.map(f).map(g)  ===  F.map(x => g(f(x)))
   ```
   - Вычислить обе части
   - Сравнить и показать результат

4. Добавьте элементы управления:
   - Выбор функтора (Box / Array / BadFunctor)
   - Выбор начального числового значения
   - Выбор функций `f` и `g` из предустановленных: `x + 1`, `x * 2`, `String(x)`, `x.toUpperCase()`

5. Для `BadFunctor` — объяснить что именно сломано

## Чеклист

- [ ] `Box` проходит оба закона
- [ ] `Array` проходит оба закона
- [ ] `BadFunctor` нарушает хотя бы один закон
- [ ] При нарушении показывается красный текст с объяснением
- [ ] Переключение функтора немедленно пересчитывает результаты
- [ ] Смена `f` или `g` немедленно пересчитывает закон 2
- [ ] Итоговый вывод: "X является/не является корректным функтором"

## Как проверить

1. Выберите `Box` с любыми f и g — оба закона должны быть зелёными
2. Выберите `Array` — оба закона должны быть зелёными
3. Выберите `BadFunctor`:
   - Закон 1 (identity) должен нарушаться — `map(x => x)` добавляет "!" и меняет значение
   - Закон 2 (composition) тоже нарушается — два map дают двойное "!!"
4. Убедитесь, что итоговый вывод отражает нарушение
