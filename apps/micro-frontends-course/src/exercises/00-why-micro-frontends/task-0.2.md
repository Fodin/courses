# Задание 0.2 — Аудит готовности к MFE

## Цель

Реализовать форму-опросник из 8 вопросов, которая вычисляет индекс готовности проекта к переходу на микрофронтенды и даёт обоснованные рекомендации с разбивкой по категориям.

## Требования

1. Отрендерить **8 вопросов** в виде карточек:
   - Категория (маленьким текстом: Организация, Деплой, Разработка, Производительность, Архитектура)
   - Номер и текст вопроса
   - Подсказка (hint) курсивом — почему этот вопрос важен
   - 4 варианта ответа (radio-кнопки) с весами 0, 1, 2, 3

2. **Прогресс-бар**: отвеченные / всего вопросов.

3. Кнопка **"Получить результат"** — активна только когда все 8 вопросов отвечены. Иначе показывать сколько осталось.

4. **Результат** (показывается после нажатия кнопки):
   - Индекс готовности: `Math.round(totalScore / maxScore * 100)`%
   - Цветовая шкала:
     - < 30% → зелёный → "Монолит подходит"
     - 30-60% → оранжевый → "Рассмотрите Partial Decomposition"
     - > 60% → синий → "Пора переходить на MFE"
   - Текстовое объяснение рекомендации
   - **Разбивка по категориям**: для каждой категории — процент готовности + прогресс-бар
   - После показа результата — для каждого выбранного ответа показывать `explanation`
   - Кнопка "Пройти снова" — сбрасывает state

5. Вопросы и их варианты:

| Вопрос | Варианты (вес) |
|---|---|
| Кол-во команд | 1 (0), 2 (1), 3-5 (2), 6+ (3) |
| Частота деплоев | Раз в месяц (0), Раз в неделю (1), Несколько раз/неделю (2), Несколько раз/день (3) |
| Merge-конфликты | Почти никогда (0), Иногда (1), Регулярно (2), Постоянно (3) |
| Размер бандла | < 200 КБ (0), 200-500 КБ (1), 500 КБ-1 МБ (2), > 1 МБ (3) |
| Время CI | < 5 мин (0), 5-15 мин (1), 15-30 мин (2), > 30 мин (3) |
| Shared state | Всё в одном сторе (0), Есть локальный (1), Минимальный (2), Изолированы (3) |
| Разные стеки | Нет (0), Для новых фич (1), Есть legacy (2), Команды требуют (3) |
| Автономия команд | Один архитектор (0), RFC-процесс (1), Автономны в области (2), Полная автономия (3) |

## Чеклист

- [ ] 8 вопросов отображаются в виде карточек с категорией, подсказкой и вариантами
- [ ] Radio-кнопки: выбранный вариант визуально выделен
- [ ] Прогресс-бар обновляется по мере ответов
- [ ] Кнопка результата деактивирована до ответа на все вопросы
- [ ] Индекс рассчитывается по формуле: `round(sum / (8*3) * 100)`
- [ ] Три уровня рекомендаций с разными цветами и текстами
- [ ] Разбивка по категориям с прогресс-барами
- [ ] После результата объяснения показываются у выбранных ответов
- [ ] Кнопка "Пройти снова" сбрасывает все ответы

## Как проверить себя

1. Ответьте на все вопросы, выбирая минимальные оценки (0) → результат должен быть < 30% → зелёная рекомендация "Монолит подходит".
2. Ответьте на все вопросы, выбирая максимальные оценки (3) → результат должен быть > 60% → синяя рекомендация "Пора переходить на MFE".
3. Смешанные ответы → оранжевая рекомендация в диапазоне 30-60%.
4. Убедитесь, что объяснения к вариантам появляются только после нажатия "Получить результат".
