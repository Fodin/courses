# Задание 11.1: Квиз — Именование и стиль кода

## Цель
Проверить понимание принципов именования, конвенций оформления кода и практик самодокументирующегося кода.

## Требования
1. Прочитайте теорию уровня 11 (README)
2. Пройдите квиз по ключевым концепциям
3. Для каждого вопроса выберите правильный ответ
4. Постарайтесь ответить без подглядывания в теорию

## Чеклист
- [ ] Прочитана теория по принципам именования
- [ ] Изучены конвенции camelCase, PascalCase, SCREAMING_SNAKE_CASE, kebab-case
- [ ] Разобраны принципы длины функций и глубины вложенности
- [ ] Понята роль комментариев в самодокументирующемся коде
- [ ] Пройден квиз с результатом не менее 80%

## Как проверить себя
1. Откройте квиз и ответьте на все вопросы
2. Проверьте объяснения для неправильных ответов
3. Если результат ниже 80% — перечитайте соответствующие разделы теории
